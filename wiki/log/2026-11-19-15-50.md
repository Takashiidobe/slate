# slate-78pa.1.7 SVE sizeless types and sv* builtins: core::arch::aarch64 stdarch lowering, fixed<->sizeless svld1/svst1, Z-register extern shim

_2026-11-19 15:50:54_

- kind: feature

- area: crates/slate/src/frontend/lowerer/sve_table.rs
- area: crates/slate/tools/gen_sve_table.py

- flavor: gcc
- target: aarch64

Outcome: gcc aarch64 SVE code using sizeless sv*_t types and non-overloaded sv* ACLE builtins translates to core::arch::aarch64 (nightly stdarch_aarch64_sve) and matches gcc under qemu; fixed-length SVE vectors cross to and from sizeless values and into extern C functions in Z registers.

Gap and why it mattered: the parser modelled sizeless types and sv* builtin rows,
but every `sizeless<..>` type and sv* call was a barrier, so no SVE intrinsic
code translated.

Before:
  scaled_sum  return  return type sizeless<svint32_t>
  main        function svwhilelt_b32_s32: builtin without a lowering

After (`static svint32_t f(svbool_t pg, svint32_t a) { return svext_s32(a, a, 1); }`):
  unsafe fn f(pg: core::arch::aarch64::svbool_t, a: core::arch::aarch64::svint32_t)
      -> core::arch::aarch64::svint32_t {
      return unsafe { core::arch::aarch64::svext_s32::<{ ((1 as i32) as u64) as i32 }>(a, a) };
  }

Implementation:
- `crates/slate/tools/gen_sve_table.py` writes `frontend/lowerer/sve_table.rs`
  from stdarch sve/sve2 `generated.rs`: 5543 functions (each one's arity plus
  const generics equals gcc's C arity from the plugin dump) and 41 types.
- `sve::builtin_sve` matches c_builtin declarations by name; `lower_sve_call`
  emits the stdarch call with trailing immediates as const-generic blocks
  (`svpattern`/`svprfop` via `transmute::<i32, _>`), and `_` for type generics.
- `Type::Sizeless` lowers to `core::arch::aarch64::<name>`. Uninitialized
  locals start from `svdup_n_<t>(0)`/`svpfalse_b()`/`svcreateN`, because
  `mem::zeroed::<svint32_t>` needs `+sve` crate-wide (rustc rejects it).
- `vector_bit_cast` between fixed and sizeless is `svld1`/`svst1` with ptrue
  (`sve::sve_convert`).
- An extern with `AbiPass::Scalable` operands is declared with sizeless types;
  the vector-ABI shim (`vector_abi_feature` returns "sve") converts.
- Parser fix: `svint32_t (*fp)(svint32_t)`, `typedef __builtin_va_list (*f)(int)`
  and `__int128_t` in the same spot failed with "a type specifier is required";
  `(svint32_t)` read as a K&R identifier list. `ParseContext::is_type_name`
  now counts target builtin and builtin integer typedef names.

Fixture: crates/slate/tests/fixtures/gcc/aarch64/sve_sizeless_intrinsics.c,
sve_fixed_sizeless_convert.c, sve_fixed_extern_zreg.c (extern defined in
file-scope SVE asm), fixtures.dylink/abi_sve_scalable (dlsym'd native SVE lib,
translated callback), slate-parser gcc/linux/aarch64/sizeless_declarators.c.

Limits: overloaded sv* names (slate-78pa.1.5); f16/bf16/mfloat8 SVE types have
no stdarch type; exported definitions with fixed SVE, fixed svbool_t
conversions and fixed SVE in function pointer types are slate-78pa.1.8. The
dylink native side is clang, not gcc; gcc's Z-register convention is checked by
the asm fixture.
