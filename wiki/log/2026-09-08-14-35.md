# one-way oracle declaration compatibility probe

_2026-09-08 14:35:35_

Reworked the manual declaration emitter to parse only oracle headers. Each generated source includes the shim header, redeclares the oracle function under a slate_oracle_<symbol> name, statically compares the two function types with __builtin_types_compatible_p, and forces a link relocation for the shim symbol. This proves the shim exposes a compatible declaration for every selected oracle function without parsing shim headers. The next implementation step is an oracle-only canonical type/declarator renderer for source spellings that use oracle-private typedefs such as __sighandler_t.
