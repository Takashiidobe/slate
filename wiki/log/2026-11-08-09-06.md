# Ignore cl /d2 backend options

_2026-11-08 09:06:25_

slate-3amj.52: ReactOS's toolchain-msvc.cmake passes /d2FH4- on every TU and slate-parser rejected it as unknown (the only one of ReactOS's 68 distinct cl flags rejected). /d2... options go to cl's backend (c2.dll), so none can change macros or the IR: added CodegenOnlyFlag::value("/d2", MSVC_ONLY) (compiler_args.rs), which accepts any /d2 suffix. Fixture msvc/windows/x86_64/codegen_only_options.c gains /d2FH4- /d2guard4 (failed with 'invalid compiler argument /d2FH4-' before). Documented in wiki/concepts/compiler-flags.md. parser 9034/9034. ReactOS calc.exe (8 TUs) now translates and builds for x86_64-pc-windows-msvc with its database flags unmodified.
