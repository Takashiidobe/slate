# Close transparent_union extern-boundary bead

_2026-11-07 09:12:41_

slate-p58o.4.8: closed without code change. transparent_union requires members of the first member's size and non-float/vector, so Slate's repr(C) union classifies like the first member on x86_64, i686, aarch64 and armv7; glibc __SOCKADDR_ARG (pointer members) passes identically. The only difference is that char/short first members are not sign/zero-extended by the caller, which only an optimized clang callee across an extern boundary would observe. Documented in wiki/concepts/ir/calls-abi.md#transparent-unions. Epic slate-p58o.4 closed.
