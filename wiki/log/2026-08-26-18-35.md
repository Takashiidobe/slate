# Lower cir.exp10 (slate-3i0x.7)

_2026-08-26 18:35:20_

cir.exp10 is only emitted via **builtin_elementwise_exp10 (plain **builtin_exp10 lowers to a cir.call, not the typed op). Rust has no exp10 std method, so lower_exp10 in builtins.rs routes scalar and per-lane vector operands through a synthetic extern shim link_name=exp10/exp10f, mirroring the frexp shim shape. Wired Op::Exp10 in dispatch.rs. Added an exp10 probe to tests/fixtures/math_builtin_ops.c (falls back to pow(10,x) when the builtin is unavailable). SLATE_DIFF_FIXTURE=math_builtin_ops passes; confirmed via translate-lowered that the extern-shim path is actually exercised. Full lowering profile, fmt, clippy clean.
