# Parse and check block literals under -fblocks

_2026-11-02 10:24:00_

slate-3amj.42.2: ^ret(params){body}, ^(params){body}, ^{body} parse as ExprKind::Block(BlockLiteral{signature: TypeName, deduced_return, body}); const_expr::Parser::parse_block_literal synthesizes a function type name from the header tokens. __block is Keyword::Block -> DeclarationSpecifiers.is_block. Names pass binds params in a scope and records NameResolution.block_ranges (binding-id range) for capture analysis. Checker::block_literal checks the body in its own StatementContext (Returns::Deduce infers the return type from the first return), records TypeResolver.block_signatures; typer types the literal as a block pointer. Assigning a captured non-__block local is rejected. Lowering (sema/block.rs) produces ValueKind::Block(BlockLiteral{function, captures}) with captures = referenced locals declared before the block, by_reference for __block. Calls through block pointers reuse Callee::Indirect with a BlockPointer-typed value. Conversions: identical/compatible block types, null constant, void* both ways, casts to pointers and ints, ==/!= and truth tests. IR walkers (effects, macro_strip, counted_loops, sequencing) handle ValueKind::Block. Fixtures: clang/block_literals.c, error/clang/linux/x86_64/block_captured_assignment.c.
