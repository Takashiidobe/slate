# Lower unprototyped extern declarations and fn(unprototyped) pointers

_2026-10-19 08:17:55_

An unprototyped extern declaration (extern int f();) now lowers as a Rust extern fn with no fixed parameters and a C variadic tail, so calls pass default-promoted arguments as in C. A pointer to an unprototyped function type lowers to a zero-parameter fn pointer, the same type definitions already get. An indirect call through one transmutes the pointer to a fn type built from the call's argument types before unwrapping it; the transmute is skipped when the types already match.

New fixture tests/fixtures/unprototyped_extern.c (dg-options -std=gnu17) covers a declaration-only libc callee, a pointer to one, and a pointer to a two-parameter definition called with arguments.

Promotions: c-testsuite 87, 88, 89, 95, 210; chibicc function; gcc-dg gcc-only attr-ms_struct-packed1.
