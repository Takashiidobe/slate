# Parallelize FileCheck regeneration

_2026-09-01 07:49:47_

Reworked the Justfile FileCheck recipes around Just mapped dependencies. Standalone fixtures, multi-TU projects, and library projects each run as an independent worker. The public recipes forward --jobs to the parallel scheduler, defaulting to 8 when no job count is supplied. Explicit fixture paths remain supported. Validated fixture discovery counts, updater mode routing, bounded concurrency, cargo fmt, and cargo clippy.
