# slate-8ge7.24.10.1 ir LabeledBlock: block %N with break %N as multi-level forward exit, Module::fresh_binding for transforms

_2026-11-21 19:56:10_

- bead: slate-8ge7.24.10.1
- kind: feature
- area: crates/slate-parser/src/ir
- area: crates/slate/src/frontend/lowerer

Outcome: the IR has a labeled block, `Statement::LabeledBlock { id, body }` printed `block %N { ... }`, that `break %N` leaves; transforms mint its id with `Module::fresh_binding`.

Gap: goto structuring (slate-8ge7.24.10) needs a multi-level forward exit. `Break(id)` could only name a loop or switch, and transforms had no way to allocate a BindingId.

Before: no IR form for "skip to the end of this region"; forward gotos stayed `goto %N` / `label %N`.

After (printed by `emit-slate-ir --passes=structure-goto`):

    block %78 {
        if lt<i32>(...)
            break %78;
        ...
    }

Implementation:
- `crates/slate-parser/src/ir/module.rs`: `Statement::LabeledBlock`; `Module::next_binding` (one past the largest id sema allocated, set at the end of `effects_statements::normalize` from `Hoister::next_id`) and `Module::fresh_binding`.
- Printer `module_print.rs`, visitor `visit.rs`, `effects_statements.rs` handle it. Sema never emits it, so parser fixtures are unchanged.
- slate-analysis walkers (def_use, pointer, counted_loops, inline_temporaries::children) treat it like `Block`.
- Lowering: structured `statements.rs` emits `Stmt::LabeledBlock { label: break_label(id) }`; `lower_dispatch`'s `Graph::statement` registers `breaks[id] = next`, so a labeled block inside a still-dispatched function works. names/nested/switch/macro_keep walkers updated.
- Spec: wiki/concepts/ir/control-flow.md, ir-grammar.md.

Fixture: crates/slate/tests/fixtures.transforms/structure-goto/forward.c (the first producer is slate-8ge7.24.10.2).
