# Lower MS \_Interlocked* and \_bittest* intrinsics

_2026-10-11 16:40:23_

slate-parser-v74.1.8. The registry prototypes use clang's msint32_t, which builtin_type did not map, so every \_Interlocked*/\_bittest* call had no signature and failed as 'unsupported Clang builtin'. msint32_t now maps like msuint32_t (long where long is 32 bits, else int, signed). New Expansion::Ms { intrinsic, ordering } parsed from the record name (\_acq/\_rel/\_nf -> acquire/release/relaxed, plain -> seq_cst, non-interlocked bit tests nonatomic); Lowerer::ms_intrinsic in sema/atomic.rs builds atomic update (fetch ops return old; Increment/Decrement return new), exchange, and form=old compare-exchange (comparand is expected; release fails relaxed). Bit tests address byte base + (offset >> 3), bit offset & 7, as clang does, with the offset bound once. \_setjmp under --flavor=msvc failed because the user's jmp_buf typedef was registered as a builtin typedef only for clang; now for msvc too. Migrated clang-test CodeGen/X86 and AArch64 mskernel-interlocked.c and bittest-intrin.c (clang+msvc), regenerated ms-setjmp.c to cover the undeclared config. Split v74.1.20: \_InterlockedCompareExchange128 and aarch64-only \_Interlocked\*\_acq/\_rel/\_nf (missing from the registry). Parser 8198/8198.
