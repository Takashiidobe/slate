# Lower array subscripts to Index

_2026-10-16 20:40:15_

slate-5vj0.5.3. The lowerer now emits place[idx as usize] for deref(ptr_offset(array_decay(place), idx)) when the decayed place is a fixed-length (>0) array reached from a binding through fields or other subscripts (Tables::array_subscript / indexable_array in lowerer/places.rs). It is a type fact from the IR, not a bounds proof: out-of-range C subscripts are UB and now panic instead. Pointer subscripts, p->arr[i], string literals, VLAs, register globals, flexible and zero-length arrays keep the offset form. place_is_unsafe/place_is_static recurse into the array, so local subscripts lose their unsafe blocks.

Exposed rewrites:

- constant_index_casts accepts U128 literals, so (2 as i32) as usize folds to 2.
- array_iter reuses for_range::int_value, accepts the \_\_SlateAlign wrapper (a.0), and now rejects writes through a[i], &a[i], and arrays mutated or mutably borrowed (invariant_within) while iterating. These bugs were latent because the rule never fired.
- printf_format hoists any argument containing a mutable borrow or as_mut_ptr, not only top-level calls, to avoid println! borrow conflicts with a[i] arguments.
- codegen prints Index without parenthesizing the index.
