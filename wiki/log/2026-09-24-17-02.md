# Resolve compiler headers from slate-sysroots

_2026-09-24 17:02:41_

Added a shared version-aware compiler header path resolver. The CLI automatically selects matching Clang, Apple Clang, GCC, or MSVC bundles from ../slate-sysroots/compiler-headers, with SLATE_COMPILER_HEADERS as an override. Removed host /usr/lib/clang/22/include fixture annotations and updated FileCheck expectations. cargo clippy --allow-dirty --fix, cargo fmt, and cargo nextest run --release pass.
