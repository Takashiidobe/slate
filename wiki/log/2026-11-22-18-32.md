# slate-8ge7.24.19.11 heap buffers elided_release: free of an owned Vec is elided before a return or at the end of its declaring scope, drop kept for mid-scope frees

_2026-11-22 18:32:25_

- bead: slate-8ge7.24.19.11
- kind: rewrite
- area: crates/slate-analysis/src/pointer.rs
- area: crates/slate-analysis/src/facts.rs
- area: crates/slate/src/frontend/lowerer

Outcome: `free(p)` of an owned heap buffer (`Owner::Vec`) is elided when only other frees follow it and then a `return`, or the end of the block that declares `p`; any other free stays `drop(p)` as a deliberate early release.

Before (C: `char *buf = malloc(n); ...; int result = total(buf, n); free(buf); return result;`):

```rust
let result: i32 = total(&buf, n);
drop(buf);
result
```

After:

```rust
let result: i32 = total(&buf, n);
result
```

and `free(buf); for (...) result += i; return result;` keeps `drop(buf);` before the loop; `if (n > 2) free(buf); return result + n;` keeps the conditional `drop(buf)`.

Rule (`slate-analysis/src/pointer.rs`):
- `Walker::statements` scans each statement list backwards and gives every free in a trailing run of frees (comments and null statements are skipped) an `Ending`: `Returns` when a `return` that does not mention the freed binding ends the run, `ClosesScope` when the list ends, `Continues` otherwise.
- Every statement list gets a scope id; `Allocation { depth, scope }` records the `let`'s. A release is elided when it is `Returns`, or `ClosesScope` in the `let`'s own scope (the end of an inner `if` block is not the end of `p`'s scope, so that free keeps `drop`).
- `Ownership::elided` feeds `Owned::elided` per candidate; `analyze` keeps only those of nodes that end up owned and publishes them as `PointerFacts::elided_releases`, exposed as `ValueFacts::elided_release` keyed by `(UnitId, NodeId)` (the value map was keyed by `NodeId` alone and empty before).
- Lowering: `statements.rs` lowers an `Expression` statement that is an elided free of an owned binding (`heap_buffers::elided_release`) to an empty statement.

Fixture: tests/fixtures/heap_byte_buffers.c adds `released_early` (drop kept before a loop) and `released_in_branch` (conditional drop kept); every other free in it is now elided. Regenerated: gnu_library_builtins (`drop(buffer)` before `0` gone). mem_safe_slice_idioms keeps `drop(src_g)` (a loop follows).

Limits: "only frees and a return" is strict: `free(buf); printf(..); return 0;` keeps `drop`.

See: slate-8ge7.24.19.4 (owned heap buffers), wiki/concepts/slate-analysis.md#heap-buffers.
