# __builtin_constant_p folding

_2026-09-19 09:36:49_

slate-parser-eb8. __builtin_constant_p(x) now folds to const<i32>(0|1) with c_builtin metadata, in IR bodies (1 when the lowered operand folds, so shadowing is respected) and in the resolver's constant_value (static_assert, array bounds). ice_shape accepts it and __builtin_types_compatible_p, which it previously rejected, so static asserts on either were silently skipped. names.rs skips resolving the builtin callee. The IR lowerer's TypeResolver never learned enumerator constants, so int a[K]; failed with 'nonconstant or unknown identifier'; enum resolution now declares each enumerator as Ordinary::Constant. The resolver still holds no objects (slate-parser-lh7.2.27), which is harmless here since objects are never constant. Answer is clang -O0's: GCC or optimized builds may return 1 after inlining. The builtin signature table left in the bead is epic slate-parser-6lz's job. Fixture: sema/ir_constant_p.c (clang and gcc accept it).
