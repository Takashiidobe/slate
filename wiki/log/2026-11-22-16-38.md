# slate-8ge7.24.19.3 c_string_arrays: char buf[N] with terminating writes is a &CStr view; strlen/strcmp lift, strcpy/strcat become slate_support helpers

_2026-11-22 16:38:36_

- bead: slate-8ge7.24.19.3
- kind: rewrite
- area: crates/slate-analysis/src/c_string_arrays.rs
- area: crates/slate/src/frontend/lowerer/string_views.rs
- area: crates/slate/vendor/slate-support

Outcome: a local `char buf[N]` whose every write keeps a terminator is a `&CStr` view (`slate_support::__slate_c_str(&buf)`), so strlen/strcmp/strncmp on it lift to CStr methods and discarded strcpy/strcat into it become `slate_support::__slate_strcpy`/`__slate_strcat`.

Before (C: `char buf[32]; strcpy(buf, "hello"); strcat(buf, ", world"); printf("%s\n", buf); return strlen(buf);`):

```rust
unsafe { strcpy(buf.0.as_mut_ptr() as *mut core::ffi::c_char, c"hello".as_ptr() as *const core::ffi::c_char) as *mut i8 };
unsafe { strcat(buf.0.as_mut_ptr() as *mut core::ffi::c_char, c", world".as_ptr() as *const core::ffi::c_char) as *mut i8 };
...
unsafe { (strlen((buf.0.as_mut_ptr() as *const i8) as *const core::ffi::c_char) as u64) as i32 }
```

After:

```rust
slate_support::__slate_strcpy(&mut buf.0, "hello");
slate_support::__slate_strcat(&mut buf.0, ", world");
...
(slate_support::__slate_c_str(&buf.0).count_bytes() as u64) as i32
```

and `strcmp(greeting, "hi ") == 0` -> `slate_support::__slate_c_str(&greeting.0) == c"hi "`, `strcmp(greeting, name) > 0` -> `__slate_c_str(&greeting.0) > name`.

Rule:
- `slate-analysis/src/c_string_arrays.rs`: plain local byte array, unique name in the function, initializer none / literal with a NUL inside N / zero-filled aggregate. Every `PlaceKind::Binding` naming it at macro depth 0 must be modeled: strcpy/strcat dst+src, fgets/snprintf dst, string_arguments positions, printf/fprintf/snprintf/puts/fputs args, element reads (`deref(ptr_offset(decay))`), `Statement::Write`/`Store` of constant 0. Order-insensitive: each modeled write leaves a NUL in bounds.
- Blocks: memcpy into the array, non-zero element store, `&buf`, any other callee, macro use, element type not the target's `c_char`, `strcpy(buf, buf)`, a strcpy/strcat whose result is used, a source without a view (raw pointer).
- Lowering: `string_views.rs` `c_string_array`/`lower_c_string_copy`; arrays count as `Argument::Viewed` partners in constant_strings.
- `slate_support/src/strings.rs` (core): `__slate_c_str(&[c_char]) -> &CStr`, `__slate_strcpy`/`__slate_strcat(&mut [c_char], impl AsRef<[u8]>)` (slice index panics where C overflows).

Fixture: tests/fixtures/char_array_c_strings.c (build, initialized, zero store, memcpy stays raw). Regenerated: atoi_atol_prelude_dynamic, c23_library (snprintf output), gnu_builtins_memory, stdio_gets_loop_unsupported (fgets line), string_copy_fixup, string_libc_fixup; runtime all OK.

Limits: storage stays `[c_char; N]` (no `[u8; N]` retype); each use re-derives `__slate_c_str(&buf)`; ASCII/UTF-8 levels for arrays, strncpy/strncat, sprintf, and non-zero constant element stores are not modeled; a pointer cursor into the array (`char *p = buf`) still makes it raw.
