# slate-e36k.17 lower_elementwise_abs: signed _BitInt operands hit a lowering barrier

_2026-11-24 11:49:14_

- bead: slate-e36k.17
- kind: bug
- area: crates/slate/tests/fixtures.unsupported

Outcome: The unsupported ratchet covers Clang elementwise absolute value on _BitInt.

Clang accepts signed _BitInt(17) and _BitInt(65), which Slate lowers
with different Rust representations. Lean models wrapping absolute
value and verifies the chosen inputs, including the 17-bit minimum
and a negative 65-bit value whose magnitude exceeds signed i64.
Clang emits llvm.abs with the poison-at-minimum flag disabled.

Clang runs the fixture successfully on all four Linux targets.
Slate preserves the widths in call signatures, but its elementwise
absolute-value lowering rejects both calls.

Fixture: crates/slate/tests/fixtures.unsupported/bitint_elementwise_abs.c
Limits: _BitInt abs support remains open in slate-e36k.17.
See: slate-jut0 covered native scalar and vector abs.
