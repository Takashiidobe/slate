# slate-8ge7.24.9 copy coalescing: preserve source locals and parameter names

Outcome: Rust preserves source parameter names and local copies that the old copy-coalescing rules removed.

Before: int copy_param(int source) { int copy = source; return copy + 1; } emitted fn copy_param(copy: i32) with no local. A raw-pointer copy in copy_pointer similarly vanished, with the dereference retargeted to source.

After: copy_param takes source and emits let copy = source. copy_pointer also retains its pointer copy and dereferences it. Source copies remain visible through cleanup guards, callbacks and address-taking.

Rule: remove param_spills::fold and the arena parameter-rename API. Restrict raw_ptr_alias::elide to LocalOrigin::Synthetic and retain its existing source-stability and use checks. No new IR transform for user-written copies.

Trace: 850 of 877 direct fixture translations succeeded across the default and GCC host lanes, including the new fixture. Temporary instrumentation recorded param_spills firing 19 times on source bindings and 36 on synthetic bindings. raw_ptr_alias fired 18 times on source bindings and 55 on synthetic bindings. Those categories are based on origin flags, independent of generated names. The checked-in output contains no instrumentation.

Fixture: crates/slate/tests/fixtures/copy_bindings_preserved.c. Regenerated changed FileCheck blocks for Slate, release builds and merge, including all three Windows targets in selectany_globals.c.

Limits: Some synthetic parameter copies are visible after the removal. The bit-int switch and x86 headers provide examples. slate-8ge7.24.16 tracks avoiding generated copies at their origins without losing sequencing or required storage.

Validation: release Slate (44) and merge (1) passed with regenerated checks. Clippy and formatting passed.
