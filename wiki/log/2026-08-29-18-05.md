# const usage-bound buffer lift (slate-y0qs.4.8.5)

_2026-08-29 18:05:17_

Adds const usage-bound recovery to interproc/length_lattice.rs: buffer ptr
params with NO companion length param now lift to &[T]/&mut [T] when a constant
bound N is provable from the body and every call site proves its source holds

> = N elements. Fail-closed otherwise.

Mechanism (new apply_const_length phase, runs after the (ptr,len) phase and is
NOT gated on pairings being non-empty):

- const_candidates: per static/private fn, ptr param resolving to Slice/SliceMut
  (borrowed only). Recovers N from collect_loop_bounds where the guard rhs
  resolves to an integer literal (resolve_full does not recurse into Binary, so
  `i < _v3` keeps its vars and \_v3 resolves to a literal via value defs). Every
  offset access on the ptr must use a bounded loop-index var; any unbounded or
  literal-index offset rejects the candidate. bound = max over accesses.
- const_accepted: every call site must prove source_len_at_least(N) via a fixed
  array root (>= N) or malloc(K\*sizeof) / literal-byte malloc (>= N). Reuses
  array_root_name / resolved_integer / is_malloc. Accept only if >=1 site and
  ALL sites prove. Forwarding a bare param fails the proof -> stays raw.
- Apply: body substitutes ptr -> ptr.as_ptr()/as_mut_ptr() as \*mut T using the
  ORIGINAL param mutability for the cast target (raw_mutable), retypes param to
  &[T]/&mut [T]; call sites bridge with from_raw_parts/\_mut(ptr, N).

Reuses the existing keep-raw-internally trick, so the body is untouched beyond
the param decl. No signature-dropping (there is no len param).

Fixtures (annotation-directive style, scaffolded via tools/update_filecheck.py):
buffer_const_bound (shared/array), \_mut (SliceMut/array), \_malloc (shared/heap),
\_unbounded (negative, p[5] literal -> stays raw). ptr_len_const_bound's rewrites
block regenerated: it now lifts (was asserting the old non-lifting behavior).

Docs: documented the @rewrite-begin/@lowering-begin region directives +
update_filecheck.py in wiki/concepts/differential-fixtures.md and the fixup
checklist. Full rewrites profile 110/110.
