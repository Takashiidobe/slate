# lowering module split and typed errors

_2026-08-11 00:00:00_

Two related structural changes: breaking up the monolithic `lower.rs` and starting a typed-error migration.

- **`0c840a7a`**: split the single 11,951-line `src/lower.rs` into `src/lower/lowerer.rs` (3,367 lines, the core dispatch) plus 14 focused submodules under `src/lower/lowerer/` — `arithmetic.rs`, `asm.rs`, `atomic.rs`, `builtins.rs`, `calls.rs`, `cir_ops.rs`, `constants.rs`, `control_flow.rs`, `expressions.rs`, `intrinsics.rs`, `memory.rs`, `op_utils.rs`, `runtime_support.rs`, `storage.rs`, `types.rs`, `values.rs`. This is the direct ancestor of today's `src/frontend/lowerer/*.rs` split documented in `wiki/concepts/lowerer-internals.md` — later renamed under `frontend/` in `3b578ff7`.
- **`3b578ff7`**: grouped the C-side pipeline stages (parsing, macro handling, directive translation, the new `lower/` tree) under a single `src/frontend/` module, updating `CLAUDE.md`/`docs/passes.md` to match.
- **`0dfe3f4d`**: moved macro semantics specifically into `frontend/c_ast.rs`/`frontend/lowerer/storage.rs`.
- **`c32f9649`**: moved the Rust-side rewrite/fixup pipeline into a `backend` module, updating `docs/facts.md`/`docs/fixups.md` to reflect the new module boundary.
- **`560ba19a`**: deleted the effects interpreter (an alternate/experimental execution-semantics engine that had gone unused) along with its Cargo dependencies.
- Typed-error migration, in order: **`b9e1a51d`** planned the migration; **`6d835669`** typed frontend-loading errors (`api.rs`, `frontend/c_ast.rs`); **`2b8dd2f0`** typed `compile_commands.rs` parsing errors; **`c69d9c8a`** typed directive-translation errors (`frontend/directive_translate.rs`, +237 lines); **`4c3f8756`** made `Diagnostics` (`ctx.rs`) implement `Display` and aggregate multiple translation errors into one report instead of stopping at the first; **`911721b7`** centralized CLI error rendering in `main.rs` (91-line rework) so every command formats errors the same way; **`1ef3e1ae`** documented typed-error ownership conventions in `docs/README.md`.
- **`7340f893`**: made the program-summary trace output (`backend/trace.rs`) copy instead of borrow, a small cleanup surfaced by the module reshuffle.

This is the reorg that the current CLAUDE.md's "`src/frontend/lowerer.rs` and its submodules hold the `cir.*` handlers" line describes — worth linking from `wiki/concepts/lowerer-internals.md` if that page doesn't already cite this split's origin.
