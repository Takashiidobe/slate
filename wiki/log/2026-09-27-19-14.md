# MSVC __asm effects table

_2026-09-27 19:14:37_

slate-parser-25m.6.4: MSVC `__asm` now infers memory access and register clobbers.

- New `src/sema/ms_asm_effects.rs`: hand-curated per-mnemonic table.
  Operand 0 is readwrite unless read-only (cmp/test/bt/push/j*/call/out,
  1-operand mul/imul/div/idiv, comis*, ptest, ...) or write-only (mov, lea,
  pop, set*, in, mov* SSE/MMX, cvt*, x87 stores); later operands are reads
  except xchg/xadd.
- Memory operands join access over every reference to the object.
- Written registers are clobbered, widened to 32-bit names; esp and flags
  are never listed (nostack and preserves_flags are off).
- Implicit defs: mul/div family, cdq family, cpuid, rdtsc(p), rdmsr,
  xgetbv, cmpxchg(8b), lahf, xlat, loop, enter/leave, popad, string ops
  plus ecx under rep, emms (mm0-7). Any f* clobbers st..st(7). call
  clobbers eax/ecx/edx (clang does not).
- Verified against clang on a 90-instruction probe and the example file:
  equal or supersets; clang misses rep/loop ecx, xlat, enter, xchg's
  memory write, x87 stack and call.
- Fixture: sema/i686-pc-windows-msvc/ms_asm_effects.c; existing ms_asm
  fixtures regenerated. Docs: msvc-asm.md effects section, ir-spec.md.
