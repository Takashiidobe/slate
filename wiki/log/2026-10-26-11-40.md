# Lower omp parallel to a closure called through GOMP_parallel

_2026-10-26 11:40:52_

slate-3amj.24.3: OmpParallel lowers for gnu targets (msvc stays a barrier until .24.12).
Support module frontend/support/libgomp.rs (__slate_libgomp, emitted on use, #[link(name = "gomp")]): parallel<F: Fn()>(num_threads, body) passes &body to GOMP_parallel through an extern "C" trampoline (panics abort; unwinding through the runtime is UB).
lowerer/openmp.rs: threads = num_threads or 0, if(c) -> if c { n } else { 1 }. Shared variables get raw pointers taken once outside the non-move closure (addr_of_mut!, or the element pointer for a VLA); FunctionLowerer.omp_shared redirects lower_binding/vla_address to *ptr inside the body, so no &mut is created per thread. Nested regions derive from the enclosing pointer. Private copies use the normal Let lowering (zeroed); firstprivate copies are then std::ptr::read from a pointer to the original. Bodies with labels/goto get their own goto dispatch inside the closure. collect_statement_names names the copies.
IR: OmpParallel.shared is now Vec<OmpShared { binding, ty }> and excludes static/thread storage locals (they lower to statics and need no capture).
Harness: run_with_emulator sets OMP_NUM_THREADS=4 for oracle and translation.
Fixture: crates/slate/tests/fixtures/gcc/openmp_parallel_gcc.c (team sizes, if, private, firstprivate scalar+struct, shared scalar/param/VLA, static local, goto in region, nested), passing on x86_64, i686, aarch64.
Wiki: new concepts/openmp-lowering.md; ir/control-flow shared entry.
Follow-ups: .24.16 omp.h missing from the sysroot gcc headers (fixture declares omp_* itself), .24.17 link libgomp under -fopenmp without regions.
