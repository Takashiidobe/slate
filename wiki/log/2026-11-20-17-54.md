# slate-8ge7.1 pointer_lattice give-up oracles: copy chain and reassigned local stay raw; benchmark lifted/raw counts

_2026-11-20 17:54:50_

- bead: slate-8ge7.1
- kind: feature
- area: crates/slate/tests/fixtures
- area: tools/benchmark

Outcome: slate-8ge7 has give-up oracles: two differential fixtures and two benchmark shapes where pointer_lattice lifts nothing today, plus a lifted/raw count column in the scaling benchmark.

Gap and why it mattered: .1 showed interproc is linear on every shape, but only because the analysis bails out early. With no super-linear shape to beat, the IR port needs a precision oracle: inputs where a correct lift is easy and today's pass gives up.

Before (current output, recorded in the fixtures' FileCheck blocks):

```c
static int sum(const int *p, int n) { const int *t1 = p; const int *t2 = t1; ... t2[i] ... }
static int pick(const int *a, const int *b, int n, int which) { const int *q = a; if (which) q = b; ... q[i] ... }
```

```rust
fn sum(t2: *const i32, n: i32) -> i32
fn pick(mut q: *const i32, b: *const i32, n: i32, which: i32) -> i32
```

After (target for the IR port): `p: &[i32]`; `a`, `b`, `q` all `&[i32]`, and C names kept.

Implementation:
- crates/slate/tests/fixtures/pointer_lift_local_copy_chain.c and pointer_lift_reassigned_local.c (both pass differentially).
- tools/benchmark/interproc_scaling.py: shapes `copy_chain` (N chained const copies of a param) and `reassign` (N branches reassigning a local between two params). New `output #lifted` / `#raw` rows count pointer-typed bindings (`name: &`, `*const`, `*mut`) in the emitted Rust; `#raw` includes main's argv/envp (constant 2).

Measured (N=50..400): copy_chain and reassign lift 0 at every N, wall slope 0.04 and 0.28; buf_chain lifts N+1 as a positive control.

Fixture: the two fixtures above; regenerate their FileCheck blocks when the port lands and check the signatures.

Limits: the names in the Before output come from param_spills::fold renaming the parameter to the copied local (slate-gbgp.11), a separate bug.
