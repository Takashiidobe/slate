# slate-5exy.14 float classification: builtin expansions duplicate and drop argument evaluations

_2026-11-24 11:57:28_

- bead: slate-5exy.14
- kind: bug
- area: crates/slate/tests/fixtures.unsupported

Outcome: The unsupported ratchet checks operand evaluation in three floating classification builtins.

Clang calls each operand once. In Slate's typed IR, islessgreater
clones both operands into two comparisons. isinf_sign clones its
operand into the infinity and sign tests. fpclassify clones the
operand into each classification test and calls only the selected
result-code argument. In the fixture the normal-value path calls
the float operand three times and evaluates one of five codes.

Lean models the resulting counter and bitmask observations. The
Clang oracle exits 0 and the generated Rust exits 7 on x86_64,
i686, aarch64 and armv7. Each set bit identifies one builtin.
