# slate-8ge7.24.20 pointer analysis: nullable borrows lower as Option<&T>, null checks fold without null sources, pointer returns lift

_2026-11-22 19:10:11_

- bead: slate-8ge7.24.20
- kind: feature
- area: crates/slate-analysis/src/pointer.rs
- area: crates/slate/src/frontend/lowerer

Outcome: nullable pointer classes lower as Option<&T>/Option<&mut T>/Option<&[T]>, null checks with no null source fold to constants, and single-parameter pointer returns lift to &T/Option<&T>.

Gap and why it mattered: any class compared with NULL was NULLABLE and therefore raw, so a defensive `if (!p)` kept a whole call chain on raw pointers, and every pointer return (find/lookup helpers) was raw.

Before:
    static const int *find(const int *xs, int n, int key) {
      for (int i = 0; i < n; i++) if (xs[i] == key) return &xs[i];
      return NULL;
    }
    fn find(xs: *const i32, n: i32, key: i32) -> *const i32 { ... core::ptr::null::<i32>() }
    let hit: *const i32 = find(xs.as_mut_ptr() as *const i32, 3i32, key);

After:
    fn find(xs: &[i32], key: i32) -> Option<&i32> { ... return Some(&xs[i as usize]); ... None }
    let hit: Option<&i32> = find(xs, key);
    if hit.is_none() { return -1; }
    *hit.unwrap()

Implementation:
- slate-analysis pointer.rs: NULLABLE only from null sources (null assignment/return, CallSite.nulls for null arguments). Borrow gains `nullable`; capability().borrow() no longer refuses nullable classes. Returns flow source->ret directly. `lifetimes` picks the single tracked parameter P whose class holds every return source (`element_of` accepts &P[i], P+i); `liftable` additionally needs P and ret unwritten and, at every call site, the argument object neither stored (`Summary.stored`) nor passed to a writing callee. PointerFacts.returns / BindingFacts.returns carry the return Borrow. Liftable returns do not pin arguments (the `returned` reach skips them). `projected` nodes (`&p->f`) of a nullable class are raw.
- lowerer optional.rs: lower_optional (None/Some/map), nullable reads as map_or(null, ..), null_check (is_none/is_some or a folded bool), lifted calls (lower_lifted_call, raw conversion via map_or), lower_element_borrow for &xs[i] / split_at.
- borrows.rs: deref of a lifted call is *call / call.unwrap(); string-literal statics passed to a shared byte borrow become promoted `&[97i8, 0i8]` instead of borrowing a static mut; the raw->borrow fallback derefs with Pointee::Raw so it lands in unsafe.
- return_cleanup.rs: Option<&T> counts as Copy for the tail/slot folds.

Fixture: crates/slate/tests/fixtures/nullable_option_borrows.c (find/lookup/either lift, second -> &i32, defensive folds to &i32, optional(None), store(Option<&mut i32>), find_written stays raw because its caller writes the array while the result lives). Twelve FileCheck blocks regenerated (no_delete_null_pointer_checks, nonnull_contract_positions, c23_nullptr, ...).

Limits: checks lower as is_none()/unwrap(), not `if let Some(p) = p` / `let Some(p) = p else` (slate-8ge7.24.22, needs IfLet/LetElse Stmt kinds). Folded checks leave `if true`/`if false` in the output. Locals assigned several addresses (`p = flag ? &a : &b` via statements) stay raw. The deleted old-pass fixtures option_box_local_* and memchr_nullable_pointer need Option<Box<T>> (slate-8ge7.21).

See: slate-8ge7.24.22, slate-8ge7.21, wiki/concepts/slate-analysis.md (Pointer capabilities).
