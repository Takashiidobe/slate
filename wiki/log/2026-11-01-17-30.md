# Keep integer casts and spelled conversions in sema

_2026-11-01 17:30:01_

slate-f2zu.9.5.12.11, .13: a written integer cast on a macro argument is now one int_cast node, kept even when the types match, so (ush)x lifts as one $x as u16 template for every integer argument. An integer conversion between C types with the same IR type but different spellings is kept as reinterpret<T>, so each target prints the same cast and merge splices the text. Rust lowering drops that reinterpret when the two Rust spellings match, so plain translate output is unchanged. Sema: kept_integer_conversion in sema/operand.rs, used by the arithmetic conversion path and emit_cast. Fold, asm and f80 accept the new forms. Removed two record_operand_c_type calls in the kept path: they re-recorded a type the operand already had, and the parser profile passes without them. The FileCheck changes were not caused by those calls. The fixtures changed because the IR gained reinterpret nodes and the operand now keeps its own [c=...] tag instead of having it overwritten by the converted type. Adjacent [c=...] [c=...] tags occur on 268 changed lines both before and after, so they are pre-existing. Fixtures: new fixtures.merge/spelled_conversions.c, 406 parser fixtures and 11 merge fixtures regenerated. Variants drop in macro_arg_casts, macro_arguments, macro_nesting and macro_templates. Cost: libc_spellings gains a variant because glibc ctype macros print c as i32 at inline sites, and macro_calls gains a hoisted alias; tracked in a follow-up bead. Validation: parser profile 8959/8959, slate profile 32/33 before regenerating merge fixtures, project_merge 5/5 after.
