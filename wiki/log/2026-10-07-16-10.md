# Order definitions by definition position

_2026-10-07 16:10:29_

slate-1zxm. attach_declaration_comments records one order entry per node at its defining declaration (dedupe keeps the last), computes comment positions from the final list, and orders functions before their local statics so a definition's leading comment is owned by the function. Definitions containing static locals were previously not recognised as redefinitions, so exported sqlite3Window* functions kept their header ranks and window.c's comment block landed ~3600 lines late; it now sits before the first function defined in the file. Fixture comments_definition_order.c. Parser, slate, library and release suites green; slate-sqlite regenerated.
