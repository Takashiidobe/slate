# slate-dghn.56.5 macro keep gate: kept macro whose argument gains hoisted effect statements after inner macro strip referenced dropped temp (E0425 __v3489)

_2026-11-14 09:04:30_

- bead: slate-dghn.56.5
- kind: bug
- area: crates/slate-parser/src/sema/module.rs
- area: crates/slate/src/frontend/macro_keep.rs

Outcome: under --merge, a kept macro whose argument gains hoisted side-effect statements only after an inner macro is stripped is now rejected, so cpython ceval.rs no longer references the dropped temporaries __v3489/__v3505.

Symptom: cargo check of translated cpython, src/ceval.rs: E0425 for __v3489 / __v3505 in _ITER_NEXT_TUPLE / _ITER_NEXT_LIST:
`PyStackRef_FromPyObjectNew__3!(... .offset(__v3489 as isize), it)`, with `_Py_CAST__6!` containing `let __v = $it; (*__v).it_index += 1; $expr`. Not a rewrite: it comes from the macro-keep gate.

Reproducer (translate-project, merge):

    #define TO_LONG(op) ((long)(op))
    #define WRAP(obj) scale(TO_LONG(obj))
    #define ITEM(op, i) ((op)->items[i])
    long first = WRAP(ITEM(seq, it->index++));

Cause: Lowerer::normalize_kept_expansions (slate-parser sema/module.rs) ran the keep gate (macro_keep::kept_expansions) once, on the IR normalized with every expansion present. There the post-increment statements sit in ITEM's evaluation, so only ITEM was rejected (argument_reads_macro_local). After ITEM is stripped, the second effects_statements::normalize hoists those statements into TO_LONG's evaluation, outside its hole, while the hole still reads the temporary. The template then holds the increment, pass_caller_locals turns `it` into a hidden `$it` parameter, and the call-site argument names a temp bound only inside the macro (Rust hygiene).

Fix: normalize_kept_expansions now loops: restore the saved bodies, strip to `kept`, normalize, and run the gate again on the result. If any kept expansion is rejected, it drops out of `kept` and the loop repeats. Rejection reasons from every round are merged into macro_rejections. When nothing changes, the only extra cost is one more gate pass.

Regression test: crates/slate/tests/fixtures.merge/macro_argument_effects.c (the ITEM sites stay inline with __vN bound before the call; an effect-free WRAP still lifts to WRAP!/TO_LONG!).

See: slate-dghn.56.6 (same cpython check run).
