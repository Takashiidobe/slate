# cxx-exceptions-lowering concept doc

_2026-08-25 12:27:16_

Added wiki/concepts/cxx-exceptions-lowering.md: CIR's C++ exception support is more complete than cxx-translation-pain-points.md claimed (empirically verified cir.throw/cir.try/cir.alloc.exception on the current -emit-cir build, no -Xclang -fclangir needed). Documents the CIR shapes (throw carries obj ptr + RTTI + dtor; try carries ordered RTTI-tagged catch clauses + resume-on-no-match unwind clause) and the raw-lowering target: throw -> panic_any, try/catch -> catch_unwind + downcast_ref chain, unwind -> resume_unwind, mirroring the existing setjmp/longjmp -> catch_unwind precedent. Records the planned follow-up (rewrite panics to typed Result propagation) as explicitly gated on the raw panic-based lowering compiling and passing its own fixtures first, same sequencing setjmp/longjmp used (raw FFI lowering before SetjmpRecovery). Corrected the stale 'CIR doesn't support C++ yet' framing in cxx-translation-pain-points.md's header and cross-linked both docs. No code changed.
