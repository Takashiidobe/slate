# null_compare: rewrite null-pointer comparisons to is_null()

_2026-10-18 18:25:58_

slate-o3gw.5: new engine rule rules/null_compare.rs (NullCompare, priority 45, ALL_EXPRS).
- x == std::ptr::null[_mut]::<T>() or RustValue::NullPtr on either side -> x.is_null(); != -> !x.is_null().
- PartialEq on raw pointers needs both sides to have the same pointer type, so the non-null operand is always a raw pointer. is_null takes self by value, so a static mut receiver is a copy, not a reference.
- !(x != null) folds to x.is_null(): the double Not is collapsed bottom-up.
- NULL is (void*)0, so comparisons come out as (head as *mut ()) == null_mut::<()>(). The ptr cast is peeled when its operand is a raw-pointer-typed local. Other operands keep the cast (follow-up slate-o3gw.11).
- Function-pointer nulls (!= None) are untouched.
