# slate-8ge7.24.17.4 unsafe cleanup: lowerer/rules stop wrapping unsafe, NodeKind::Unsafe, nested_unsafe, unsafe_marks deleted

_2026-11-22 13:29:04_

- bead: slate-8ge7.24.17.4
- kind: rewrite
- area: crates/slate/src/backend/engine
- area: crates/slate/src/frontend/lowerer

Outcome: the lowerer and engine rules no longer build unsafe blocks; rules never see NodeKind::Unsafe (deleted), and unsafe_placement is the only producer of Expr::Unsafe/Stmt::Unsafe.

Before (volatile bit-field write, rules blocked by the lowerer's grouping):
    {
        let mut __t3 = unsafe { core::ptr::read_volatile(addr_of_mut!(gs.__slate_bits_0)) };
        __t3.__set_c(__t2);
        unsafe { core::ptr::write_volatile(addr_of_mut!(gs.__slate_bits_0), __t3) };
    }
After:
    let mut __t3 = unsafe { core::ptr::read_volatile(addr_of_mut!(gs.__slate_bits_0)) };
    __t3.__set_c(__t2);
    unsafe { core::ptr::write_volatile(addr_of_mut!(gs.__slate_bits_0), __t3) };

Implementation:
- values.rs unsafe_op only marks; unsafe_wrap deleted. Multi-statement wrap sites became the bare statement, Stmt::Scope/Block (when they declare locals) or a let-free Stmt::Block that placement splices like an old Stmt::Unsafe. C compound statements lower to Stmt::Scope, so a non-empty Stmt::Block is never a C scope.
- control_flow's function-wide dispatch wrap and functions.rs's dispatch return wrap are gone.
- macro_sites: unsafe_places and make_place_parameter's read_is_unsafe deleted; the macro call site is covered by placement (place-context args).
- Rules: slot_promote zeroed, prelude CStr::from_ptr, printf_format fflush, libc_call discarded-result wrap build bare calls. printf_format matched `Stmt::Expr(Expr::Unsafe(printf))` and now matches the bare call (without this ~530 fixtures lost println!).
- arena: NodeKind::Unsafe/NodeKindTag::Unsafe deleted with their arms in inline_temps, pure_stmts, return_cleanup, label_elide, raw_ptr_alias, branch_init, walk, literal_casts; a stray Stmt::Unsafe builds as NodeKind::Block.
- Deleted rules/nested_unsafe.rs, engine/unsafe_marks.rs (and SLATE_UNSAFE_MARK_CHECK); needs_unsafe moved into unsafe_placement.rs. peel_unsafe deleted.

Fixture: 48 FileCheck blocks regenerated (scope flattening, tail returns, dropped mut now that rules see through former wrappers). slate and merge profiles pass, no E0133, no unused_unsafe.

Limits: plain-tree helpers (walk.rs, inline_temps, libc_call peel_wrapper, printf_format, macro_templates) still have Expr::Unsafe/Stmt::Unsafe alternatives; harmless but dead before placement.
