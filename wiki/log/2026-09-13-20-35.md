# Tag definitions live in TranslationUnit.tags with TagId identity

_2026-09-13 20:35:24_

Closes slate-parser-lh7.3.4 and slate-parser-lh7.1.17.

- CType::Tagged { kind, name, body } is replaced by CType::Tag(TagSpecifier)
  with Reference { kind, name } | Definition(TagId). Decl::Record, Decl::Enum,
  RecordDecl and EnumDecl are gone; struct S { ... }; is a Declaration with no
  declarators whose specifier is Definition(id).
- TranslationUnit.tags: Vec<Span<TagDefinition>> { id, kind, name, attributes,
  body: Record(fields) | Enum(enumerators), provenance }. Every definition gets
  an id: file scope, nested, block scope, sizeof/cast type names. The dump
  prints tag[id] entries before decl[n].
- Parser owns Rc<RefCell<Vec<..>>>: parse_stmts_from_tokens clones Parser for
  typedef scoping, and the table must be shared across those clones.
- Enumerator gains provenance; fields and enumerators parsed from tokens get
  Parser::token_provenance (line from the preprocessor line_starts, header
  kind/outer header from the file's PP nodes) instead of Provenance::default.
- DeclaratorParser defines tags only with a Parser; without one (#if,
  attributes) a tag body is 'tag definition is not allowed here'. The stmt.rs
  function-signature parsers now pass the Parser.
- reachability marks tags through Definition ids and maps tag/enumerator names
  of file-scope definitions to their declaration; unreachable tags are pruned
  without renumbering, and speculative parses that are abandoned leave unused
  ids, so ids have gaps. TranslationUnit::tag looks ids up.
- sema checks a definition's attributes and fields where its declaration is;
  register-variable checks read the definition's kind.
- New fixture tests/fixtures/tag-definitions.c; 713 fixtures regenerated, no
  diagnostic lines changed; a scan found no Definition id without a tag entry.
