# slate-f2zu.14.40.9 hoist_global_asm: hoisted .set alias asm landed in another CGU than its target, assembler dropped the weak alias (efi_mem_desc_lookup modpost error)

_2026-11-16 13:54:46_

- bead: slate-f2zu.14.40.9
- kind: bug
- area: crates/slate/src/project/link_order.rs
- corpus: linux

Outcome: alias-defining file-scope asm (`.weak X` / `.set X, {sym}`) is no
longer hoisted to the crate root, so the alias stays in the CGU that defines its
target and the assembler keeps it.

Symptom: kernel relink after slate-f2zu.14.40.6:
`ERROR: modpost: vmlinux: .export_symbol section references '__efi_mem_desc_lookup', but it does not seem to be an export symbol`.
vmlinux.o had `efi_mem_desc_lookup` as UND.

C (drivers/firmware/efi/efi.c):

```c
int __efi_mem_desc_lookup(u64 phys_addr, efi_memory_desc_t *out_md) { ... }
extern int efi_mem_desc_lookup(u64, efi_memory_desc_t *) __weak __alias(__efi_mem_desc_lookup);
EXPORT_SYMBOL_GPL(efi_mem_desc_lookup);
```

Cause: `hoist_global_asm` (crates/slate/src/project/link_order.rs,
slate-f2zu.14.40.4) moved the alias block
`.weak efi_mem_desc_lookup\n.set efi_mem_desc_lookup, {0}` into the crate root.
In the shard staticlib the root asm landed in CGU 8xz7..., while
`__efi_mem_desc_lookup` was codegenned in CGU 11ujv.... An ELF alias cannot
point at a symbol undefined in the same object, so the assembler dropped
`efi_mem_desc_lookup` and resolved the export entry's
`.quad efi_mem_desc_lookup` to `__efi_mem_desc_lookup`.

Fix: `hoistable` rejects any global_asm whose template has a `.set` line.
Aliases emit no section data, so link order never needed them hoisted.

Verified on the kernel: re-translated drivers**packed_r9 only;
`efi_mem_desc_lookup` is now WEAK FUNC in the same CGU as
`**efi_mem_desc_lookup`, and the export relocation names `efi_mem_desc_lookup`.

Limits: no fixture. Small fixture crates (two units, and link_order_asm's 8
units) put the alias and its target in one CGU, so the bug does not reproduce
there; it needs a crate big enough for rustc to split them. Slate profile not
rerun (only the hoist predicate changed). See: slate-f2zu.14.40.4,
slate-f2zu.14.40.8
