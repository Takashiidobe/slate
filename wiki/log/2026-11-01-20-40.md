# GCC x86 target builtin table for the gcc flavor

_2026-11-01 20:40:03_

slate-3amj.50 (part of slate-parser-cxg.43): the gcc flavor never consulted an x86 target builtin table, so gcc's intrinsics headers (x86gprintrin.h -> lwpintrin.h, immintrin.h, nmmintrin.h) failed with 'unresolved ordinary name __builtin_ia32_*'. Only 1339 of the 3463 __builtin_ia32_* names gcc 16's headers use exist in clang's table, so falling back to it was not an option. New tools/generate_gcc_x86_builtins.py reads gcc's config/i386 (BDESC rows in i386-builtin.def, i386-builtin-types.def, MULTI_ARG aliases, def_builtin calls in i386-builtins.cc) and writes src/sema/gcc_x86_builtins.rs (GCC_X86_BUILTINS, GCC_X86_64_BUILTINS for OPTION_MASK_ISA_64BIT). builtins.rs: gcc_target_builtin is consulted after the generic gcc and clang tables for x86 and x86_64 only. generate_clang_builtins.py now accepts a qualifier after a _Vector<> base. Promoted gcc-dg gcc-only pr98219-1/-2 (torture and guality) and ubsan__pr82498. The earlier note that these were -muintr failures was wrong. aarch64 and arm32 still return no gcc target builtins (slate-parser-cxg.43 stays open).
