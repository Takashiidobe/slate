# slate-f2zu.14.24 address_images: integer poison in a function-pointer static field (BPF_PTR_POISON) failed const validity; emit MaybeUninit image

_2026-11-14 17:57:31_

- bead: slate-f2zu.14.24
- kind: bug
- area: crates/slate/src/frontend/lowerer/globals.rs
- area: crates/slate/src/frontend/lowerer.rs
- flavor: clang

Outcome: a static whose constant initializer stores a non-null integer address in a function-pointer slot (BPF_PTR_POISON in bpf_tail_call_proto.func) is emitted as `MaybeUninit<Image>` storage, so rustc's const validity check no longer rejects it.

## Symptom

kernel/bpf/core.c:3216 `const struct bpf_func_proto bpf_tail_call_proto = { .func = BPF_PTR_POISON }` failed with E0080 "constructing invalid value ... encountered 0xdead00000000eb9f[noalloc], but expected a function pointer". The field lowers as `Option<unsafe extern fn(...)>`, and rustc validates a static's final value against its type.

## Reproducer

    #define PTR_POISON ((void *)(0xeB9FUL + 0xdead000000000000UL))
    struct proto { unsigned long (*func)(unsigned long, unsigned long); int gpl_only; };
    const struct proto tail_proto = { .func = PTR_POISON, .gpl_only = 1 };
    unsigned long (*hook)(unsigned long, unsigned long) = PTR_POISON;

## Cause

CTFE checks validity only on the final value of a static. `MaybeUninit<T>` is not validated, and the `address_images` path (frontend/lowerer/globals.rs, `address_image`) already emits exactly that: a `__SlateImage_<name>` alias for the storage type (align wrapper included), a `MaybeUninit` static filled through `as_mut_ptr`, and every use as `*(addr_of_mut!(g) as *mut __SlateImage_<name>)` (`lower_binding`). But only integer-typed address fields routed there.

## Fix

- `Tables::holds_integer_function_pointer` matches an aggregate member or scalar of type pointer-to-function whose `fold_pointer_address` is a non-zero constant.
- The `address_images` set in lowerer.rs now includes these globals.
- In `address_image`, a scalar initializer that is not an address integer gets a plain `*image = value` assignment.

The record's field type is unchanged for every other user. Exported layout is identical because MaybeUninit is repr(transparent).

## Regression test

crates/slate/tests/fixtures/static_function_pointer_poison.c (struct with poison func, struct with a real func, a pointer table referencing both, a scalar poisoned fn pointer reassigned at runtime). kernel/bpf/core.c cargo checks clean when translated alone.
