# Packed records with over-aligned members and empty unions; close slate-oreg.4

_2026-10-18 13:19:10_

slate-oreg.4: promoted gcc-torture 20040709-2, 20040709-3, pr23324; new fixture x86_64/packed_long_double.c.

- E0588: a packed record field whose type carries repr(align) (LongDouble, align(16), or a record with raised alignment, transitively) is now stored as std::mem::MaybeUninit<[u8; size]>. MaybeUninit because LongDouble has 6 uninitialized padding bytes, which const eval rejected in a plain [u8; 16].
- Dependencies::erased_fields records (record id, field index). places::erased_field_address yields addr_of!(base.f) as \*T. Reads use read_unaligned, writes and aggregate members use write_unaligned, AddressOf and ArrayDecay cast it. Any other place use of an erased field (nested field or index) stays a barrier through lower_place.
- contains_raised_align now treats F80 as raised.
- Empty unions (GNU, size 0) lower as zero-field repr(C) structs: Rust rejects zero-field unions.

slate profile green.
