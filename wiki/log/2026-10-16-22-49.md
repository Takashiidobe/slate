# Lower unprototyped function definitions

_2026-10-16 22:49:32_

An unprototyped () definition (pre-C23) is now lowered as a zero-parameter, non-variadic Rust fn. Sema already turns K&R identifier-list definitions into a Prototype with promoted types, so Parameters::Unprototyped on a definition always means zero parameters. Defined unprototyped functions are no longer flagged is_variadic, and function_has_vector/passes_long_double now check the return type of unprototyped functions too (they returned false early).

New fixture tests/fixtures/unprototyped_definition.c (dg-options -std=gnu17, since the differential harness defaults to C23 where () is already a prototype).

Promotions: c-testsuite 187, chibicc 40, gcc-dg 2 (229). Of the 67 gcc fixtures whose only lowering barrier was this one, the rest now fail later: runtime kills (slate-z3tq), packed E0793 (slate-bxg0), \__builtin_ libc aliases (slate-3f8g.3.12), complex (slate-u1le), misc rustc errors (new P1 coverage bead). Unprototyped extern declarations and fn(unprototyped) pointer types split into a P2 coverage bead.
