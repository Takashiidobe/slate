# Fix cross-target FileCheck commonization breaking CHECK-NEXT adjacency

_2026-09-05 14:52:31_

tools/update_filecheck.py's commonize_checks() (added in 099b93be) did a
bag/multiset diff of two targets' check lists, emitting one COMMON block
followed by each target's residual block appended afterward. CHECK-NEXT
needs physical adjacency, so any divergence not at the file's tail (e.g. a
struct field whose pointee type differs by char signedness) broke the
FileCheck run. 2df45dab regenerated ~400 fixtures with this scheme, and
tests/differential.rs's Default flavor never selected an arch-specific
prefix at all (its check call site used check_generated_rust, ignoring
check_prefixes() entirely) — so only the incomplete COMMON block ran.
Together: 358/498 lowering differential fixtures failing.

Fix: replaced commonize_checks with interleave_checks, using
difflib.SequenceMatcher to positionally diff the two targets' check lists.
Equal runs collapse onto the bare LOWERING/REWRITES tag (always selected);
divergent runs keep their own target prefix in place at the point of
divergence, preserving CHECK-NEXT adjacency for whichever target a run
selects. Wired the missing prefix selection into
FixtureFlavor::check_prefixes and fixed the Default check call site to use
it. Regenerated all 403 default + 6 bionic arch-split fixtures.

Result: differential failures 358 -> 10. Each of the 10 is a distinct,
independently pre-existing bug (verified present before this change): stale
snapshots (long_double, saturating_arith, target_feature_bmi,
vec_masked_load_ops), a label-block FileCheck absorption bug
(over_aligned_local, pointer_compare_address, volatile), an LLVM intrinsic
gap (target_stack_builtin_ops), a real align(16) codegen regression
(long_double_x86_64_gnu), and a forward-declared-enum lowering bug
(gnu_init_designator_survey) — also the cause of the remaining
gcc_torture_suite/c_testsuite_suite/cross_tu failures, tracked separately.
