# ClangIR drops const qualifier on function-pointer pointee types

_2026-08-20 12:37:32_

Filed upstream: https://github.com/llvm/llvm-project/issues/217687. CIR loses the const qualifier on a function pointer's parameter types -- e.g. `int (*p)(const char *, const char *) = strcmp;` lowers p's cir.func type with plain !cir.ptr<!s8i> params, dropping the const seen correctly in the Clang AST. First hit via chibicc's search_lsearch.c (lsearch/lfind take a const void* comparator), which was moved supported -> unsupported in 87afb4a7 (2026-08-20) pending an upstream fix; nothing to do on slate's side until CIR preserves the qualifier.
