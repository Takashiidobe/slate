# Fold bit builtins in case labels

_2026-10-05 11:55:57_

slate-parser-6x05.38.32: kernel htons(CONST) in a case label expands to __builtin_bswap16 and failed with 'internal error: nonconstant case expression' (37 kernel TUs, e.g. net/core/skbuff.c). The checker accepted it through types.constant_integer, but module.rs lowered the label as a runtime expression and re-folded the IR with fold::integer_constant, which has no rule for builtin calls, so every bit builtin (popcount, ctz, bswap...) failed in case labels while working in enums and array sizes. case_value now builds the value with types.constant_value (the same evaluator the checker used), applies the recorded conversion, and folds that. Fixture: clang/linux/x86_64/case_label_bit_builtins.c (bswap16/32/64, popcount, ctzll, values checked against clang).
