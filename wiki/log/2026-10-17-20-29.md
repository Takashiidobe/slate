# Lower ifunc via global_asm gnu_indirect_function

_2026-10-17 20:29:17_

slate-9ox1.4.1-4: slate never lowered ifunc (the old CIR frontend listed IFuncAttr as unsupported; slate-parser only recorded SymbolAttributes.ifunc). ModuleLowerer::lower*ifunc now emits a global_asm! block per ifunc function: .globl SYM [.hidden SYM] / .type SYM, @gnu_indirect_function / .set SYM, {sym resolver}. The resolver is referenced with a sym operand, so its Rust name needs no no_mangle. The extern declaration stays, so calls link normally. Static ifuncs use \_\_slate_ifunc*<name> (hidden) via link_name on the extern decl. ELF targets only (Linux/Android/FreeBSD); others report a barrier. attr-ifunc-1/3/4/5 promoted. torture\_\_pr53922 (slate-9ox1.4.5) is a weak undefined function, not ifunc; left open with a note.
