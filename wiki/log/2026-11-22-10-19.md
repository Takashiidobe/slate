Outcome: IR transforms declare a scope (`decls`, `function`); the runner runs each top-level function, then each block literal and nested function as its own function, and the function-scoped walker stops at inner functions with a `Visitor::capture` hook.

Gap and why it mattered:
- Every pass looped over `module.functions` itself, and `walk_body` descended into `^{}` and nested-function bodies as if they were the outer function's code. Each pass patched this its own way (inline_temporaries::InnerFunctions, truth_locals `nests()`, structure_goto `Uses` capture noting, def_use/pointer arms).
- Passes that recurse by statement lists (structure-goto) never reached block bodies at all.
- The IR printer showed a block literal as `statements=N`, so no fixture could check a transform inside one.

Before (structure-goto, block body untouched):
```
block_fn %12(%5 c: i32) -> i32 {
    if gt<i32>(read<i32>(%5), read<i32>(%3))
        goto %4;
    ...
    label %4 out:
        return read<i32>(%5);
```
After:
```
block_fn %12(%5 c: i32) -> i32 {
    block %13 {
        if gt<i32>(read<i32>(%5), read<i32>(%3))
            break %13;
        ...
    }
    return read<i32>(%5);
```

Implementation:
- slate-parser `ir/visit.rs`: `CaptureKind { Escape, Read }`, `Visitor::capture`, `walk_function_body`/`walk_function_value` (+ `_with_macros`), `for_each_inner_function` (direct inner functions). `BlockCapture::kind()`: `__block` is Escape, by-value is Read; nested captures are always Escape. Plain `walk_body` still descends (sema, macro_strip, macro_keep, lowerer switch rely on it).
- slate-parser printer: `block_literal<T, %F, captures=[..]>` inline, body as `block_fn %F(..) -> T { .. }` after the holding statement or global (separate commit).
- `transform/mod.rs`: `Pass { decls, function }`, `PassContext { module (functions taken out), captured, visible, retire }`. `visible` for an inner function adds the enclosing function's params and locals, for labeled-blocks' shadow check. Inner-function names are only collected when a function has an inner function.
- Passes: const-fold and truth-canonicalize split into `globals` + per function; others per function. Deleted `InnerFunctions`, `record_captures`, the nested-function arm of `nests()`, structure-goto capture noting.
- truth-locals taints every captured local (retyping to bool would leave `BlockCapture::ty` and the block body at i32).
- DefUse: nested capture -> Escape, by-value block capture -> `Access::Capture` (never a single read), no descent.
- pointer.rs: nested function marks only its captures (ESCAPE|WRITE, leaked, written), no whole-function opaque. By-value block captures stay ESCAPE|WRITE: the block holds a copy of the pointer.

Fixture: `crates/slate/tests/fixtures.transforms/structure-goto/block.c` (failed first), `truth-locals/block.c`, `decl-init/block.c` (regression guards; truth-locals and decl-init already fired inside blocks through the descending walker).

Limits: nested functions are untested (no lowering support); their captures are always Escape. Each pass does one extra walk per function to detect inner functions.
