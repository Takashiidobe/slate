# Scope flatten keeps scopes whose lets shadow names used afterwards

_2026-10-03 16:41:22_

slate-dghn.22: singleton_scopes::flatten spliced every nested Scope into its parent. Arena idents are plain interned strings, so a scope-local 'let x' that shadows an outer x then stayed in scope for the parent's later statements: scoped_local_bindings exited 49 instead of 10 (main's x read the inner 40; shadow_params' value/step read the inner shadows).

Fix: shadow_outlives_scope blocks flattening when a name declared directly in the scope is read or written (def_use_neighbors includes assignment targets) by a later sibling in the parent's child list, or by the parent node itself (a Block/Unsafe tail). Only later siblings matter: the parent list is a Rust block, so the spliced lets end there; a parent Scope rechecks its own (now larger) direct lets when it is considered.
