# Hybrid C++ migration with residual fallback

_2026-08-25 14:34:37_

Added wiki/concepts/cxx-hybrid-migration.md to record a possible incremental C++ migration architecture. Unsupported whole functions remain residual C++ behind generated adapters instead of aborting translation. Native Rust and C++ representations may coexist through lazy, single-authority shadows with explicit synchronization; eager mirroring is reserved for proven value-like bridges or validation. A whole-program fixed-point pass can delete C++ shadows after callers, callbacks, exports, globals, and type-graph consumers stop requesting them. Recorded proven/guarded/assumed/observed/residual evidence levels, exact through assisted rewrite policies, the limits of profile evidence, guarded fallback, shadow execution, Rust-only diagnostics, migration reports, and a staged implementation sequence. Cross-linked the C++ pain-point and stdlib-shim concepts and added the note to the wiki index. No code changed.
