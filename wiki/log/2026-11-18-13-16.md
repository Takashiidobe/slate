# slate-5q63.19 --merge: freestanding projects lost Program.runtime/no_builtins and merged into hosted std crates

_2026-11-18 13:16:37_

- bead: slate-5q63.19
- kind: bug
- area: crates/slate/src/project/merge.rs
- area: crates/slate/tests/project_merge.rs

Outcome: `translate-project --merge` of a project that is freestanding on every target writes a `#![no_std]`, `#![no_builtins]` crate with the panic handler, like the non-merge path.

Gap and why it mattered: `merge.rs` `program_of` built each merged unit's `Program` with `..Default`, so `runtime` was `Std` and `no_builtins` false. The runtime fact was added after `--merge`, so freestanding projects (the kernel) merged into hosted std crates.

Before (`-ffreestanding -fno-builtin` on x86_64 and i686 linux):
  lib.rs had no `#![no_std]`, no `#![no_builtins]`, no `__slate_panic`; Cargo.toml had no panic=abort or link-order rustflags.
After:
  lib.rs starts with `#![no_std]`, `#![no_builtins]`, has `mod __slate_panic { #[panic_handler] ... }`; the manifest uses panic = "abort", slate-support without default features, and the link-order rustflags.

Implementation:
- `merge()` sets each merged unit's `runtime` and `no_builtins` from the per-target `codegen_facts` (which now also records `no_builtins: !module.hosted`); `no_builtins` is true if any target sets it.
- A unit hosted on one target and freestanding on another is an error: `<stem>: hosted on <triple> but freestanding on <triple>; --merge needs every target hosted or every target freestanding`.
- `tests/project_merge.rs`: a crate without `src/main.rs` (freestanding `main` is an ordinary symbol, so the crate is a library) is built per feature subset instead of run; a failed merge with no printed report needs no `merge-report.txt`.

Fixtures:
- `crates/slate/tests/fixtures.merge/freestanding_runtime.c`
- `crates/slate/tests/fixtures.merge/freestanding_runtime_mixed.c` (the error)

Limits: mixed hosted/freestanding targets are rejected rather than gated with `cfg_attr(..., no_std)`.

See: slate-3amj.36.1 (added `codegen_facts`), slate-xw0x.13 (unrelated `flush_value_writers` merge failure).
