# predefines: cull leftover libc-shim __SLATE_* target macros from Linux targets

_2026-11-18 08:43:34_

- bead: slate-parser-6x05.38.8
- kind: bookkeeping
- area: crates/slate-parser/src/predefines
- area: crates/slate-parser/src/target_registry.rs
- area: tools/clangd_flags.py

Outcome: Linux targets no longer predefine the old libc-shim __SLATE_{ARCH,VENDOR,KERNEL,LIBC,GLIBC_MINOR__,OBJ,WORDSIZE,ENDIAN}_* macros, so clang/gcc i686 and x86_64 predefines match the native compiler exactly (gcc_macro_diff: 0 differences).

These came from the old in-tree libc, which slate-sysroots replaced, and nothing read them. Removed: the slate_{x86,aarch64,arm32}_linux_defaults.h headers (target_registry.rs defaults are now ""); the __SLATE_ lines in slate_target_defaults.h (it keeps __STDC_VERSION__ 202311L); the unreferenced fixtures.abi-probe/linux-libc-abi.c; both target_feature_macros.c fixtures, which only checked these macros under the never-defined _SLATE_LIBC; the __SLATE_LIBC_GLIBC term in the Windows predefines fixtures; and the -D__SLATE_* flags in tools/clangd_flags.py. No bead (follow-up to slate-parser-6x05.38.8).
