# x86 intrinsic lowering: stdarch override table

_2026-08-21 00:00:00_

Implemented mining stdarch's own #[link_name] attributes as the override table for intrinsics where LLVM's canonical mangled name has no working ISel pattern. Verified against the AVX512 mask.expand repro with no regression to the already-working non-overloaded path. See wiki/concepts/x86-intrinsic-lowering.md.
