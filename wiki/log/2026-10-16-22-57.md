# Lower __builtin_ library aliases as libc calls

_2026-10-16 22:57:45_

slate-parser's builtin declaration metadata now carries c_builtin_library="X" for __builtin_X when X is a registered Library builtin in CLANG_BUILTINS (clang's rule: codegen calls the library function when it does not open-code the builtin). Slate's FunctionName.library reads it; extern declarations get #[link_name = X] and calls are no longer barriers. This replaces slate's hard-coded 8-entry builtin_library_name table (abort, nan*, mem*).

__builtin_ffs/ffsl/ffsll are not library aliases in clang's registry; slate open-codes them as if x == 0 { 0 } else { x.trailing_zeros() as i32 + 1 } (values.rs lower_find_first_set) and skips their extern declaration.

New fixture tests/fixtures/gnu_library_builtins.c (malloc/strcpy/strncpy/sprintf/snprintf/strlen/memchr/printf/strcmp/ffs*/abs/labs/free). Parser FileChecks for the new metadata regenerated (ir_builtin_noreturn, freestanding_library_builtins, ir_implicit_builtins); builtin_alloca, builtin_alloca_with_align, gnu_libc_platform blocks gained the alloca link_name. Promoted 59 fixtures: gcc-torture 50, gcc-dg 4, tests/fixtures 5. slate and parser profiles green.
