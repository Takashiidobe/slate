# Arch-only fixture directories (arm/, aarch64/)

_2026-09-07 09:39:34_

Replaced the ad-hoc FileCheck-prefix-filtering trick and by-name skip-list
entries for arch-exclusive asm fixtures with a directory-based convention,
mirroring the existing tests/fixtures/{bionic,macos,msvc}/ pattern.

tests/fixtures/arm/ and tests/fixtures/aarch64/ now hold fixtures whose
extended-asm only makes sense on that one target. differential_arm.rs and
differential_aarch64.rs each collect the shared root plus their own arch
dir (new support::list_c_fixtures helper); every other runner only reads
the root, so a fixture in one of these dirs is structurally unreachable
from the wrong target -- no skip-list entry or prefix hack needed to keep
it out.

tools/update_filecheck.py's default_targets_for_path now recognizes the
arm/aarch64 path component and emits single-target ARMV7-GNU/AARCH64-GNU
checks automatically (same mechanism as bionic/macos/msvc), so
--target overrides are no longer needed when generating checks for these.

Moved asm_arm_general_low_reg.c -> tests/fixtures/arm/ and
asm_aarch64_reg_width_modifiers.c -> tests/fixtures/aarch64/ (dropping the
now-unneeded skip-list entries in each other's runner). Verified: x86
lowering/rewrites, arm-lowering/rewrites (qemu-arm-static), and
aarch64-lowering/rewrites (qemu-aarch64-static) all pass; moved-fixture
FileCheck output is byte-identical to before the move.
