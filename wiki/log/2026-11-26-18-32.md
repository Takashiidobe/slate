Outcome: Slate's website build publishes the root mdBook at /docs/ beside the playground.

Before: The playground's Documentation link opened crates/slate/docs/src on
GitHub. The user guide started with a checkout build and described project
translation as executable-only.

After: The Docs tab opens /docs/. The book links back to the playground and
covers CLI installation, single-file translation, executable and library
projects, target headers, and multi-target manifests.

Implementation: www/build.sh writes the book to its selected output
directory. The release workflow installs mdBook 0.5.4 before the build.
Use mdbook serve docs for documentation previews and deploy www/dist to
publish the playground and book together.

Validation: The default and custom site builds passed, the playground
smoke tests passed, and both outputs served the docs navigation and
internal URLs over HTTP. CLI checks covered host and cross-target file
translation, merged target manifests, a runnable executable, and a static
library. ShellCheck passed. Actionlint passed with its diagnostic for the
existing ubuntu-26.04 runner labels suppressed.
