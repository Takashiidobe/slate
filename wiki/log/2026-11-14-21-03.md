# slate-f2zu.14.32 string_statics: &"literal" address-of referenced \_\_slate_strN statics that were never emitted (8250_pci REPORT_CONFIG)

_2026-11-14 21:03:42_

- bead: slate-f2zu.14.32
- kind: bug
- area: crates/slate/src/frontend/lowerer.rs
- area: crates/slate/src/frontend/lowerer/places.rs

Outcome: a string literal whose address is taken as a whole array (`&"lit"`, not
decayed) is now emitted as a `static mut __slate_strN: [i8; N]`, so its
references in static images, plain statics and function bodies resolve.

Symptom (linux check stage, drivers_tty: 4 errors): E0425
`cannot find value __slate_str2970` in drivers/tty/serial/8250/8250_pci.rs. The
blacklist table's `.driver_data = REPORT_CONFIG(PARPORT_SERIAL)` expands to
`(kernel_ulong_t)&"PARPORT_SERIAL"`, and the image initializer wrote
`addr_of_mut!(__slate_str2970)` for a static that was never defined.

Reproducer: static unsigned long plain = (unsigned long)&"plain"; static const
char (\*whole)[6] = &"whole"; int main(void) { unsigned long local = (unsigned
long)&"local"; ... }

Cause: `ModuleLowerer::new` routes every `.strN` global through
`lower_string_global` into `Tables::strings`, which keeps it out of `statics`,
so `declare` never emits it. `ArrayDecay` of a string binding inlines the bytes
as `c"..."`, but any other place use (`AddressOf` of the binding) goes through
`lower_place` -> `lower_binding` and names a static that does not exist. This
affected every non-decayed use, not only the static-image path the bead guessed.

Fix:

- `Dependencies::string_statics`: `lower_place`'s `PlaceKind::Binding` arm
  records string bindings it reaches.
- `ModuleLowerer::define_string_statics`, called at the end of `lower_bodies`,
  lowers those globals through `lower_static` and pushes a private `static mut`
  under the binding's name. Decayed uses still inline `c"..."`.

Regression test: crates/slate/tests/fixtures/string_literal_address_of.c (table
image with the REPORT_CONFIG stringize pattern, plain static integer,
pointer-to-array static, local).

Kernel: re-translated only drivers_tty in ~/slate-translated/slate-linux; cargo
check is clean (was 4 errors).

See: slate-f2zu.14.31, slate-f2zu.14.30
