# Add whole-item multi-config merge with projection check

_2026-10-30 20:05:59_

slate-mbr2.1.6: translate-project --merge writes one crate from a matrix; --check-projection all|<count> compares with direct whole-project translation. New src/project_merge.rs; the shared pipeline moved there from main.rs (translate_units, imported_commons, collect_all_errors, rust_ident), and main.rs gained write_project_crate.

Departure from the bead: conditions do not come from per-item trace data and the planner's cover is not compiled. Each unit compiles every assignment of the features its trace calls relevant (UnitPlan.relevant), and each item's cfg is Quine-McCluskey-minimized from the table, with failed assignments as don't-cares. Type-only dependencies (struct field under a feature) need no name mapping because the table is complete. The trace's remaining claim, that other features do not matter, is what the projection check tests. Cost: 186 compiles per zlib target vs about 30 from --plan; nfq8.3 is what can use the cover.

shared_types: nothing to merge. Exports::Fixed returns no shared module, and slate-mbr2.1.7 specifies Fixed for multi-config builds.

Extern blocks split per decl so one differing decl does not gate the block. target_cfg now emits target_env=musl (glibc and musl collided, also affects --targets); merge errors if two targets share a cfg.

The check found a real bug: deflate.c takes zcalloc's address, so direct translation gives it a distinct link_section, which a unit compiled alone cannot see (1024 mismatches on zlib). Sections now use symbols taken in any compile of the target. That can over-protect, which is harmless, so the check allows added sections and rejects lost ones.

Results on zlib: linux-x86_64 186 compiles, 512/512 configurations 0 mismatches, 78s including the check. 10 targets 1860 compiles, 160 sampled, 0 mismatches, 94s. cargo check passes on 8 targets with default and lit-mem,no-gzip; aarch64 and thumbv7a windows not checked (rust-std not installed). Merged linux-x86_64 is 106k lines vs 27k for one configuration. Not covered: darwin, freebsd, android (planner errors, parser beads). Commons ownership comes from the default config, so a common whose owner changes with a feature is only caught by the check.

Fixtures: tests/fixtures.merge (build and run each feature subset against clang), zlib_projection_sample. slate and parser profiles pass.
