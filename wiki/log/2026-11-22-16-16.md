# slate-yar4.60 slate_support: std feature gates alloc/OS helpers, set from Runtime::Std in project emission

_2026-11-22 16:16:21_

- bead: slate-yar4.60
- kind: feature
- area: crates/slate/vendor/slate-support
- area: crates/slate/src/main.rs
- area: crates/slate-cargo-toml

Outcome: slate_support has a `std` feature (replacing `hosted`) that gates everything needing alloc or the OS, and project emission selects it explicitly from the runtime.

Gap: helpers were either ungated core code or libc re-exports behind `hosted`, with no named place for std-only helpers, so each new one risked inventing its own gate.

Before (emitted Cargo.toml, hosted and freestanding):

```toml
[dependencies.slate-support]
path = "slate-support"                 # hosted: default feature "hosted"
default-features = false               # freestanding
```

After:

```toml
[dependencies.slate-support]           # hosted (Runtime::Std)
path = "slate-support"
default-features = false
features = ["std"]

[dependencies.slate-support]           # every unit Runtime::Core
path = "slate-support"
default-features = false
```

Implementation:
- `vendor/slate-support/Cargo.toml.template`: `std = ["dep:libc"]`, still the default so standalone consumers (differential harness manifest, slate-libc-gen probes) keep it.
- `lib.rs`: `#[cfg(feature = "std")] extern crate std;`, `hosted.rs` (libc re-exports) and the new `process.rs` (`pub fn __slate_exit(status: c_int) -> !` over `std::process::exit`) behind it; `strings.rs` stays ungated.
- `main.rs`: `crate_manifest` adds `.without_default_features().with_features(["std"])`; `make_manifest_freestanding` clears the features; `write_slate_support` vendors `process.rs`.
- `slate-cargo-toml`: `Dependency::with_features`.
- Pattern documented in wiki/concepts/slate-architecture.md#slate_support-features.

Verified: translate-project on a hosted probe emits `features = ["std"]` and a call to `slate_support::__slate_exit` builds; a `-ffreestanding -nostdinc` probe emits no features and builds without std. `slate` profile 44/44.

Limits: nothing lowers to `__slate_exit` yet (`exit` still lowers to `std::process::exit`); it is the pattern's example. No alloc tier by design.

See: slate-8ge7.24.19.1 (core-only strings.rs), slate-3amj.56 (freestanding identities).
