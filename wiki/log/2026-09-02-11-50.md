# simplify: peephole cleanup of structure_dispatch output

_2026-09-02 11:50:23_

structure_dispatch emitted the maximal Stackifier form -- every unit wrapped in
a labeled block, every CFG edge an explicit break/continue. goto_multi_exit_loop
had 11 nested labels for one loop.

Added src/backend/engine/rules/structure_dispatch/simplify.rs, run at the end of
structure(). Core is a continuation analysis: the walk carries a Cont
(Continue(label) | Opaque(point-id)) for where falling off the current statement
list goes, and every labeled construct records the Cont of its own exit, so two
constructs whose exits are the same program point compare equal. From that:

- retarget: a jump's target Cont is re-emitted against the innermost frame with
  an equal Cont, turning break-out-of-block into an unlabeled break of the
  enclosing loop. Unlabeled needs no labeled block in between (E0695, hit by c89).
- delete: a jump whose target equals the current list's Cont is a no-op.
- sink_tail: `if c { X; jump-to-cont } S...` -> `if c { X } else { S... }`. This
  is what recovers real if/else from a goto DAG. The mirrored else-case must keep
  the whole then-branch; an early version dropped its last statement (surfaced as
  a slice underflow in c_testsuite, but it was a live miscompile). Same rule on
  Match when exactly one arm falls through.
- elide unused labels, then invert `if c {} else { X }`.

Split negation into rules/negate.rs; added rules/not_fold.rs (priority 50, after
inline_temps) so `!(a < b)` folds to `a >= b` once temps inline -- only when an
operand is provably integral, since NaN makes the flip unsound for floats.

goto_nested_if now emits the source's nested if/else exactly; 77 fixtures shrink
1114 lines to 791. Switch fallthrough keeps its labeled-block chain: that is the
duplication-free encoding, not a miss. rewrites 91/92, the failure being the
pre-existing 7-case gcc_torture set (identical against a stashed baseline).
