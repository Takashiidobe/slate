# Reject static initializers that read variables

_2026-11-06 21:19:57_

slate-parser-6x05.47: 'int x; static unsigned long v = x * 8UL;' lowered to a global initializer reading x at runtime; clang and gcc reject it. InvalidConstantArithmetic (sema/assertion.rs) now also rejects a bare non-const, non-array, non-function variable used as an operand of binary ops, + - ! ~, or casts, with 'reads a variable'. Const-qualified variables are exempt (both compilers fold them); ++/-- are skipped because clang accepts them inside VLA bounds (gcc-dg c99-const-expr-11). Fixture: error/clang/linux/x86_64/static_initializer_reads_variable.c. Not covered: reads under address-of/index/member (&arr[x], (long)&x * 1, which clang rejects).
