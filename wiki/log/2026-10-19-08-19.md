# dylink Windows hosts include windows.h

_2026-10-19 08:19:34_

fixtures.dylink/dylink.h now includes <windows.h> on _WIN32 instead of declaring LoadLibraryA, GetProcAddress and FreeLibrary by hand, followed by #undef small because windows.h defines small as char and data_structs uses struct small. GetProcAddress returns FARPROC, an unprototyped fn pointer, which now lowers after slate-8x0b. dylink_windows passes under wine with SLATE_DYLINK_REQUIRE_WINDOWS=1. Removed the CLAUDE.md note that Windows hosts declare LoadLibraryA themselves.
