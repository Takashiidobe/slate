# Make Slate target queries independent of Clang

_2026-10-01 19:02:42_

slate-p58o.6.4: moved active target, target cfg, scalar widths, char signedness, long-double format, and FMA queries into slate::target, backed by slate-parser TargetInfo/registry.
Removed the duplicated triplers layout table, macro-query subprocesses, getconf calls, and unused triplers dependency.
Slate parser argument parsing now shares active-target defaults and inherited compiler flags; explicit arguments win.
The rewrite engine receives the IR module target through backend::apply_with_target, including directive variants, so long and char helpers match lowering.
record_file and record_translation_unit use slate-parser predefines/preprocessing, ordered macro options, forced files, includes, and directive diagnostics; record-cfg resolves quoted headers beside its input.
Removed SLATE_CLANG throughout executable configuration and helper scripts at the user request. Differential C oracles now use clang on PATH; CIR ingestion temporarily retains a fixed compiler path until slate-p58o.6.5.
Added an e2e CLI regression using the existing dynamic atoi/atol fixture: translate, translate-lowered, translate-project, and record-cfg work with empty PATH and explicit target overriding an invalid default.
Native clang exposed a spurious differential result for asan__use-after-scope-2. Removed it and asan__pr105396, both dg-shouldfail sanitizer cases intentionally exercising UB; corpus admission now excludes dg-shouldfail instead of admitting accidental uninstrumented successes.
Updated target-query and differential documentation, crate toolchain instructions, and corpus READMEs.
Validation: cargo clippy -p slate --allow-dirty --fix (clean), cargo fmt, cargo nextest r --release --profile slate (11 passed, 4 skipped), shell syntax checks, git diff --check.
No CIR test runtime gates were run, per user direction; the Slate profile remains the required gate.
