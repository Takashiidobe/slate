# Support clang's __is_target_* feature checks in #if

_2026-10-12 07:53:35_

Closed slate-parser-v74.1.14. New pp/has_checks/target.rs implements __is_target_arch/vendor/os/environment from TargetInfo::triple with clang's PPMacroExpansion.cpp rules (arm matches thumb, armv7 matches thumbv7 not armv6, 'unknown' environment only when the triple has none, ios does not match a macOS triple, unrecognised names are 0). __is_target_variant_os/environment are always 0: slate has no Darwin target variant. Clang flavor only; the operand is not macro-expanded (linux is a predefined macro), defined() and __has_builtin report all six. Fixtures clang/{linux/x86_64,linux/armv7..gnueabihf,windows/x86_64,windows/thumbv7a,darwin/aarch64,android/aarch64}/is_target.c, each also run through native clang. Not migrated: Preprocessor/is_target_environment_version.c uses msvc18.0.0, a versioned environment slate's registry cannot express. Wiki: preprocessor. Parser profile: 8240/8240 pass.
