# Add SVE/SME builtins and enumerators to the gcc aarch64 tables

_2026-11-01 21:16:47_

slate-78pa.1.4: dump_gcc_builtins.py now compiles arm_sve.h and arm_sme.h (-march=armv9-a+sve2+sme2) so GCC_AARCH64_BUILTINS holds about 9300 concrete sv*/sme functions with sizeless prototypes (generated gcc_arm_builtins.rs grew to 10MB). The plugin flags attribute-less sv* decls as 'overload' (about 1100 placeholders such as svabd_m typed void()); the generator skips them, tracked in slate-78pa.1.5. The plugin also dumps enumerator values for the ACLE names SV_POW2, SV_VL*, SV_MUL3/4, SV_ALL and SV_PLD*/SV_PST* by looking them up in the compiled TU, and GCC_AARCH64_ENUMERATORS feeds enum svpattern / enum svprfop declarations in the gcc aarch64 predeclared_typedefs prelude (so, like the sv type names, they exist without arm_sve.h). Calls to concrete names (svadd_s32_x, svptrue_pat_b8(SV_VL4), svprfb, svzero_za) now resolve. Fixture: gcc/linux/aarch64/sve_builtins.c.
