# Accept null pointer constants as computed goto operands

_2026-11-07 17:50:20_

slate-parser-7cxn: 'goto *0;' (and any zero-valued integer constant like 'goto *(1 - 1)') was rejected as 'nonpointer computed goto'. gcc accepts it, and clang does too when the function takes a label address. The checker (sema/assertion.rs) now records a conversion of a null pointer constant operand to void* (new Typer::void_pointer, sema/typer.rs); lowering (sema/module.rs) applies it, giving 'goto *null<ptr<void>>'. Non-zero integers are still rejected. Fixture: gcc/linux/x86_64/computed-goto-null-constant.c.
