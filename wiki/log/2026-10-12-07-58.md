# SEH jump diagnostics: goto into protected scopes and -Wjump-seh-finally

_2026-10-12 07:58:31_

Closed slate-parser-v74.1.19. Checker::statement (sema/assertion.rs) now rejects goto into a __try body, __except block or __finally block with clang's 'cannot jump from this goto statement to its label'. New sema/seh_scopes.rs collects each label's SEH scope path per function (scope identity is the SehTry node id plus body/handler); the goto compares it with the current path. New warning Warning::JumpSehFinally (-Wjump-seh-finally, on by default) for return, break, continue, named break/continue, __leave and goto that leave the innermost __finally. StatementContext records loops/breakables/named targets/try depth when a __finally is entered, so a break inside a loop inside the finally stays quiet, as in clang's test/Sema/__try.c. Nested functions get a fresh context.
