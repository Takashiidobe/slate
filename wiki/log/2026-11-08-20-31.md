# Implicit function declarations and implicit int by flavor and standard (cxg.14)

_2026-11-08 20:31:12_

slate-parser-cxg.14. Calls to undeclared functions and implicit int now follow gcc and clang per standard and -W flags (300-combination matrix checked against both).

- names.rs: an undeclared callee is implicitly declared for every flavor and standard except clang C23 (stays 'unresolved ordinary name', clang's 'use of undeclared identifier'). Previously msvc only, or gcc with -fpermissive.
- diagnostics.rs: implicit-function-declaration and new implicit-int default to Ignored in C89 and msvc, Error from C99 (permerror: -Wno-error=, -Wno-, gcc -fpermissive downgrade). Warning::group: -Wimplicit covers both; gcc's -Wno-error=implicit downgrades neither (WarningSetting.no_error_from_group), clang's does. DiagnosticContext::severity_error_by_default for clang's unknown __builtin_* ('use of unknown builtin', error by default even in C89).
- module.rs: messages per flavor (gcc 'implicit declaration of function', clang C99+ 'call to undeclared function ...'). expression.rs: calls through an implicit declaration skip deprecated-non-prototype, as clang does.
- dialect.rs: StandardFeatures::implicit_int is derived from the implicit-int severity (Rejected when error, Extension when downgraded, never for clang C23); replaces the -fpermissive special case.
- declarator.rs: a qualifier-only type name ('(const) 0', 'sizeof(volatile *)') is implicit int when implicit int is accepted (was parsed as a parenthesized identifier 'const').
- gcc_dg_sweep.py fixture_text keeps -Wno-* flags in ARGS (the sweep oracle already used them).

Fixtures: {clang,gcc}/linux/x86_64/implicit_function_declarations.c, error/{clang,gcc}/linux/x86_64/implicit_function_modes.c; 37 gcc.dg migrations (19 gcc, 18 clang); 16 gcc-torture/va-opt fixtures regenerated for the new messages; error/clang/linux/aarch64/x86_target_builtin.c now uses --dump-ir (the error moved from name resolution to lowering).
Left over: slate-78pa.6 (gcc conflicting redeclaration after implicit decl), slate-78pa.7 (mode(vector_size) ignored), permerror-* noted on cxg.10. No -Wall group, so gcc/clang C89 -Wall -Werror is not modelled.
