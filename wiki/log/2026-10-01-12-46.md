# Drop cargo init from init_crate

_2026-10-01 12:46:29_

slate-p58o.7.14. init_crate spawned cargo init (through the rustup proxy) only to create the crate directory: write_crate_manifest overwrites Cargo.toml right after, and both callers write every main.rs/lib.rs they need. It now just creates <crate>/src. Removed the cargo() helper and the Command import, which only cargo init used (tests/support still reads SLATE_CARGO for building).

The chibicc translated crate is identical to HEAD apart from the directory-derived package name.
chibicc translate-project (hyperfine, 15 runs): 140ms -> 129ms.
slate profile 10/10 pass.

Remaining planned speedups: slate-p58o.7.15 (include-guard multiple-include optimization; ~33ms fixed per-TU header cost), slate-p58o.7.16 (fuse lower/emit/format/write phases).
