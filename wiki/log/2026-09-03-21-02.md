# chibicc epic slate-pcek: promote 8 fixtures, close out remaining triage

_2026-09-03 21:02:23_

Went through slate-pcek's 14 remaining unsupported/ chibicc fixtures (ticket descriptions were 7 weeks stale -- several named files were already gone). Findings and fixes:

- compat/const/typedef: implicit-int declarations (K&R laxness, e.g. `const x;`), a hard error on modern clang. Fixed by adding explicit `int` at each bare-qualifier site; compat/const promoted. typedef.c has one separate real issue left: `typedef int t; t t = 1;` (a typedef legally shadowed by a same-name variable) -- valid C, clang rejects it -- tracked as slate-pcek.23.
- generic/literal/sizeof: chibicc's nonstandard bare-f float suffix (100f, 1f, 8f) isn't valid C; rewrote to 100.0f/1.0f/8.0f. Promoted.
- predefined_macros: deleted the __STDC_IEC_559__ assertion (clang no longer predefines it). Promoted.
- pointer: added a new per-fixture clang-args.txt mechanism (tests/support/mod.rs, tests/chibicc_suite.rs) to downgrade -Wincompatible-pointer-types to non-fatal for just this fixture. Parses/lowers now, but still fails differentially on *(&x + 1) -- genuine stack-layout-dependent UB, not fixable -- tracked as slate-pcek.24.
- float: (double)(unsigned long)(long)-1 -> int is UB (no representable int value for ~1.8e19); deleted that one assertion. Promoted.
- control (565 lines): deleted two invalid-C comma-expression-as-lvalue ASSERTs, and six ASSERT blocks doing computed-goto into labels inside a statement-expression (clang statically rejects this GNU-extension combo regardless of slate). Promoted.
- atomic, initializer: both crash inside ClangIR itself (atomic inc/dec NYI; ConstantLValueEmitter NYI + segfault) before slate's frontend runs. Marked blocked (slate-pcek.25, .26), same shape as the existing asm/.21 naked-function blocker.

Net: 45 -> 52 supported fixtures. unsupported/ now holds only genuinely-blocked-on-upstream (asm, atomic, initializer) or already-tracked (pointer/.24, typedef/.23, variable) cases. Closed slate-pcek.12/.14/.17; epic itself left open per the gcc-torture-epic precedent (blocked children stay open under an open epic).
