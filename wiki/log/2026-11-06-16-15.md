# Give bound stdio functions one call identity

_2026-11-06 16:15:40_

slate-f2zu.9.5.8.9: stdio bindings (fprintf, printf, fputs, puts, fputc, putc, putchar, fopen...) now take FunctionIdentity::Known(support symbol) on every target (lowerer/stdio.rs bind_stdio), as ctype already did, so textually identical calls collapse out of cfg(unix)/cfg(windows) blocks in --merge output. Side effect: Windows printf became eligible for the println! rewrite, which breaks dylink_windows (C stdout is text mode there, so \n becomes \r\n under wine; println! writes \n). printf_format::rewrite now takes the TargetInfo and skips the println!/print! conversion on Windows (RewriteState.println_ok); the flush wrapping still applies. Windows printf with a literal format therefore keeps slate_support::printf instead of println!. 19 fixtures.merge baselines regenerated, diffs sampled. Validation: slate profile green (35/35 incl. dylink_windows, project_merge); msvc profile green before the Windows gate, the gate only removes rewrites there.
