# slate-8ge7.6 slate-analysis pointer: IR-side pointer capabilities for params and locals, compared with pointer_lattice under SLATE_SHADOW; reassigned/copied locals now decided

Outcome: slate-analysis computes pointer capabilities for parameters and locals from the IR, and `SLATE_SHADOW=pointer_lattice` compares them with the Rust-side solve; the give-up oracles now show the IR side deciding what the Rust side misses.

Gap and why it mattered: the Rust-side `pointer_lattice` tracks only parameters and follows a local copy only until the local is reassigned, so `q = a; if (w) q = b; q[i]` decided `a = Ref` (it is indexed) and never typed `q`. slate-8ge7 needs an IR analysis that decides every pointer binding once, near-linearly, before lowering can emit the types directly.

Before (crates/slate/tests/fixtures/pointer_lift_reassigned_local.c):

```
slate-shadow pass=pointer_lattice kind=rust_only unit=0 fn=pick binding=a rust=Ref ir=-
slate-shadow pass=pointer_lattice kind=rust_only unit=0 fn=pick binding=b rust=Slice ir=-
```

After:

```
slate-shadow pass=pointer_lattice kind=differ unit=0 fn=pick binding=a rust=Ref ir=Slice
slate-shadow pass=pointer_lattice kind=ir_only unit=0 fn=pick binding=q rust=- ir=Slice
slate-shadow pass=pointer_lattice summary agree=1 differ=1 rust_only=0 ir_only=1
```

pointer_lift_local_copy_chain.c: `sum::p` agrees (Slice), `t1` and `t2` are `ir_only Slice`.

Implementation (`crates/slate-analysis/src/pointer.rs`, design in wiki/concepts/slate-analysis.md#pointer-capabilities):
- Per-function summaries in parallel: nodes for pointer params, locals, temporaries, call results and the return value; intra-function copies unify classes; use flags per class; `raw` per binding, forward along copies.
- Join: argument -> parameter and return -> result flows; use flags propagate backward, nullable forward, one reachability pass per flag. Aliased arguments (same class or same `&local`) escape when written.
- Candidates: not exported (`lowerer::exports_symbol`, now a `Program::new` predicate), not `main`, not variadic, address not taken.
- Facts: `BindingFacts::pointer: Option<PointerFact { role, capability }>`, `UnitFacts::pointer_bindings(function)`. Lowering renders them into `Program.shadow` through `pointer_lattice::ir_shadow_decision` (`PointerFact::resolved`), only when shadow mode is on.
- Timing: `SLATE_INTERPROC_TIMING` prints pass `ir_pointer` phases `summarize`/`join` and `#nodes`, picked up by interproc_scaling.py.

Measured: interproc_scaling N=800, `ir_pointer` <= 1 ms on every shape (Rust-side extract 2-4 ms). sqlite: 10.9 ms, 17,957 nodes (Rust-side extract 144 ms + validate 245 ms). Sweep: fixtures agree 347 differ 71 rust_only 13; gcc-torture agree 585 differ 141 rust_only 38; sqlite agree 976 differ 782 rust_only 4; 0 failures. Triage of the differ groups is on slate-8ge7.6 (notes).

Fixture: none new; the oracles pointer_lift_local_copy_chain.c and pointer_lift_reassigned_local.c show the result under SLATE_SHADOW. Emitted Rust is unchanged.

Limits: shadow only; lowering does not read the facts yet (step 3). Intrinsic arguments escape, Steensgaard joins inside a function, no string-flag sources beyond libc calls, heap aliasing of struct pointers not modeled (same as the Rust side).
