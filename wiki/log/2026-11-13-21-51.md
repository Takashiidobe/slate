Outcome: clang `__builtin_neon_*` lane reads, across-vector reductions and element-wise ops (vgetq_lane, vaddvq, vaddlvq, vmaxvq/vminvq, vmaxnmvq/vminnmvq, vbslq, vabsq, vmaxq/vminq, vmaxnmq/vminnmq, vqaddq/vqsubq, vfmaq, vsqrtq, vcagtq) expand in sema; NumPy clang-aarch64 drops from 723 to 461 blocked functions.

Gap: slate-e36k.11 only typed the NEON table. With no expansion, every arm_neon.h call went to the extern path and hit "vector C ABI".

Before:
```
help: function __builtin_neon_vgetq_lane_f32: vector C ABI
```
After: `vgetq_lane_f32(v, 2)` is `v[2]`. `vmaxq_f32` declares `#[link_name = "llvm.aarch64.neon.fmax.v4f32"]`, `vaddvq_f32` declares `llvm.aarch64.neon.faddv.f32.v4f32`, both in an `extern "llvm-intrinsic"` block.

Implementation:
- `Expansion::Neon(NeonOp)`. `neon_op(record)` in sema/neon_builtins.rs matches records after the x86, compare and MS names (the NEON records are the full `__builtin_neon_` names).
- Polymorphic `_v` builtins: the last argument is the clang NeonTypeFlags code. `& 0xf` gives the element (0-3 int, 4-6 poly as unsigned, 9 f32, 10 f64), `0x10` unsigned, `0x20` 128-bit. Operands are `vector_convert`ed (VectorBitCast) from int8x16 to the decoded type, and the result goes back the same way. f16/bf16/poly128 codes return `Err(parts)`, so those keep the extern call.
- Intrinsics follow clang CGBuiltin, so NaN propagation, ±0 and saturation match the instruction: `neon.fmax` (not `llvm.maxnum`), `neon.faddv` (pairwise (a0+a1)+(a2+a3), not reduce.fadd), `neon.facgt` (the code is the integer result; operands are floats of that width). `vfmaq_v(a, b, c)` is `llvm.fma(b, c, a)`.
- `vaddlv` widens the lanes with `elementwise_conversion` and then `llvm.vector.reduce.add`. `vbsl` is `b ^ ((a ^ b) & m)` and falls back if an operand has effects.
- All of these intrinsics were already in the generated catalog (intrinsics_table.rs AArch64 section); no Rust-side change.

Fixture: crates/slate/tests/fixtures/aarch64/neon_lanes_reductions_elementwise.c (slate-aarch64 profile, qemu). Signed/unsigned extremes, NaN and -NaN lanes, ±0, denormals, saturating overflow. Output is printed as raw bits.

Limits: the remaining 461 NumPy aarch64 rows are loads/stores (58.7.2), shifts/tbl (58.7.7), widen/narrow/vmull (58.7.6) and rounding/vcvtn (58.7.5).
