# slate-f2zu.14.17 static initializer: pointer round trip through uintptr_t (__ADDRESSABLE) failed rustc const eval

_2026-11-14 17:19:35_

- bead: slate-f2zu.14.17
- kind: bug
- area: crates/slate/src/frontend/lowerer/values.rs
- area: crates/slate/src/frontend/lowerer/pointers.rs

Outcome: static initializers that round-trip a pointer through a pointer-width integer (`__ADDRESSABLE(sym)`, `(void *)(uintptr_t)&x`) now lower to a direct pointer cast that rustc const-evaluates.

## Symptom

Kernel shards failed rustc with `pointers cannot be cast to integers during const eval` / E0080 `unable to turn pointer into integer` (22424 errors, 60 of 69 shards):

    static mut __UNIQUE_ID_addressable_x: *mut () = ((addr_of_mut!(x)) as u64) as *mut ();

## Reproducer

    int x;
    static void *p = (void *)(uintptr_t)&x;
    static void *q = (void *)(long)(unsigned long)(char *)(uintptr_t)&x;

## Cause

`lower_value_node` lowered `int_to_ptr(ptr_to_int(p))` literally; Rust const eval cannot turn a pointer into an integer, even when the result goes straight back to a pointer.

## Fix

`Tables::pointer_int_round_trip_root` (frontend/lowerer/pointers.rs) walks down from an `IntToPtr` through `Convert`/`Copy` nodes while every intermediate type is a pointer or an integer of exactly `target.pointer_width` bits (any signedness), and returns the pointer-typed root. In a static initializer, `lower_value_node` (values.rs) replaces the chain with a synthesized `PointerCast` of that root, so function decays still go through the existing transmute path.

A narrower integer step (`(void *)(uint32_t)&x`) is left alone: clang and gcc reject it in static initializers too ("not a compile-time constant"), so it never comes from a TU that compiled natively. Runtime code is unchanged; `as` round trips truncate there exactly like C.

## Regression test

crates/slate/tests/fixtures/static_init_pointer_int_round_trip.c: direct, function, unsigned long, intptr_t, nested ptr/int/ptr/int, mixed signedness, array element, struct field, array of pointers, and the `__ADDRESSABLE` macro shape.

Limits: arithmetic in the middle (`(void *)((uintptr_t)&x + 4)`) is not a round trip and still fails; see slate-f2zu.14.19.
