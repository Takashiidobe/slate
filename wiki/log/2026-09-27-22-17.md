# Pin windows.h on i686-pc-windows-msvc

_2026-09-27 22:17:46_

Added tests/fixtures/sema/i686-pc-windows-msvc/windows_h_{clang,msvc}.c (slate-parser-g097). They include <windows.h> from the xwin sysroot, check that sizeof(HANDLE) and sizeof(LONG_PTR) are 4 and that LARGE_INTEGER has size and alignment 8, and call Int64ShllMod32 so winnt.h's MS __asm body lowers end to end. The values were diffed against clang --target=i686-pc-windows-msvc -emit-llvm and cl.exe x86 /FAs (4/4/8/8); the asm operands (two *m reads, ecx clobber) match clang's IR. No code change was needed: the MSVC __asm work in slate-parser-25m.6 already made windows.h parse. Writing the fixture with _Static_assert exposed an unrelated reachability bug: a header typedef used only by a main-file _Static_assert gets pruned (filed as slate-parser-4opf), so the fixture uses sized globals instead.
