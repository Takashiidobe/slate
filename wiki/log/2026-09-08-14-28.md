# manual libc declaration probe emitter

_2026-09-08 14:28:26_

Added the first oracle-derived libc declaration probe tool under tests/support. It invokes the target-configured Clang on a generated one-header source, extracts one named FunctionDecl from AST JSON, writes a shim source with an oracle-derived typedef plus __builtin_types_compatible_p assertion and forced symbol reference, then compiles and links through the selected target sysroot. The ignored libc_declaration_probe runner emits each generated C file for header-by-header inspection. Verified open/read/qsort across glibc and musl. Macros, variables, aliases, and full-header inventory remain follow-up work.
