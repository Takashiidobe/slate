# Initializer plan: one checker walk, lowering executes

_2026-09-30 13:15:57_

slate-parser-ygrj.4.

- The checker's current-object walk (record_initializer -> plan_braced / walk_fill / walk_place / walk_item) now emits an InitializerPlan per declarator or compound literal into TypeResolver::initializer_plans: ordered writes of a (AggregateTarget, QualType) path plus an Element / CodeUnits / Complex / Braced / Open value. Designated paths keep Range steps; the continuation after a designator uses last_position.
- Lowering's braced/fill/init_into/item_entry/designate/resume, Cursor, Builder::next/full/advance, convert_element's compatibility check, and element_targets are gone. Builder::place runs each write through partitions/write.
- Plans whose root has unbound extents (VM) are re-planned by lowering with the bound type, as operand_steps does. Failed plans are stored as errors and returned checked.
- Fix: {[1].b = 5, [0 ... 2] = 7} on a union array kept b = 5 in [1], because the old lowering treated the written union as full. Now all three are a = 7, matching clang -emit-llvm. Added reopened and elided_pairs to designated_range_overwrites.c.
- Representation change: an intermediate range under a nested designator is no longer split at its last element unless a later write needs it (gnu99-init-1, gnu89-init-1, c90-init-1 regenerated). The values are unchanged; checked by diffing the old and new binaries.
