# slate-8ge7.24.17.5 link bind_calls: Rust-path bound calls to safe definitions drop their unsafe block

_2026-11-22 13:40:01_

- bead: slate-8ge7.24.17.5
- kind: rewrite
- area: crates/slate/src/backend/link

Outcome: a cross-unit call that link binds by Rust path to a safe definition no longer gets an unsafe block; only arguments that need unsafe keep one.

Before (tests/fixtures.release/cross_unit_shared_types, main.c calling shapes.c):
    let registry: *mut registry = unsafe { registry_new() };
    unsafe { shape_move(shapes.0.as_mut_ptr().offset(i as isize), i, 1i32) };
    unsafe { registry_free(registry) };
After:
    let registry: *mut registry = registry_new();
    shape_move(unsafe { shapes.0.as_mut_ptr().offset(i as isize) }, i, 1i32);
    registry_free(registry);

Rule: link::bind_calls (interproc, before the per-unit engine and unsafe_placement) clears Expr::Call unsafe_ in clear_safe_calls when
- the call is CallBinding::Direct (not a fn-pointer call) with func Expr::Var naming a function this unit now imports by `use crate::__slate_unit_<stem>::f`,
- and the definition's FnDef.unsafe_ is false (applies to rust_bound and c_bound exports alike).
Placement then covers only the arguments through their own markers (raw deref, .offset, from_raw_parts, static mut reads).
macro_templates::visit_exprs_mut is now pub(in crate::backend) for the walk.

Fixture: cross_unit_shared_types, cross_unit_pointer_lift, cross_unit_slice_lift, cross_unit_address_taken_exports, flush_value_writer, weak_strong_override (fixtures.release) and fixtures.select/requested_small_target regenerated. slate and merge profiles pass.

Limits: the unused shared-type imports half of slate-o3gw.18 is not addressed; o3gw.18 stays open for it.
