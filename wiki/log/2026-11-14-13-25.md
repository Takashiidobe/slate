# slate-f2zu.14.7 lower_static: weak global definitions and aligned extern of incomplete type were 'attributes' barriers (bpf protos, init_uts_ns, runqueues)

_2026-11-14 13:25:15_

- bead: slate-f2zu.14.7
- kind: bug
- area: crates/slate/src/frontend/lowerer/globals.rs
- area: crates/slate/src/frontend/lowerer.rs
- flavor: clang

Outcome: weak global definitions lower to `#[linkage = "weak"]` exported
statics, and an extern declaration with an alignment on an incomplete type is no
longer a barrier.

Symptom: 55 kernel globals in 26 TUs hit `global <name>: attributes` in
`lower_static`. Three shapes:

- weak tentative definitions:
  `const struct bpf_func_proto bpf_map_lookup_elem_proto __weak;`
  (kernel/bpf/core.c), `__weak const struct bpf_map_ops arena_map_ops;`,
  `void __weak (*pm_power_off)(void);`
- weak declaration then strong definition (attribute merges, still weak):
  init/version.c `struct uts_namespace init_uts_ns __weak;` before
  version-timestamp.c defines it; same for `linux_banner`.
- `DECLARE_PER_CPU_SHARED_ALIGNED(struct rq, runqueues)` in sched.h:2446: an
  extern of incomplete `struct rq` with `__aligned__(64)` and a section.

Reproducer:

```c
struct rq;
extern __attribute__((section(".x"))) struct rq runqueues __attribute__((aligned(64)));
const struct proto lookup_proto __attribute__((weak));
```

Cause: `lower_static` kept `weak` in its symbol mask for definitions (so any
weak definition failed the `symbol != default` check), and rejected
`alignment.is_some() && storage_of(ty).is_none()` even for declarations, where
neither the alignment nor the section changes the Rust extern.

Fix: the mask clears `weak` (weak declarations already go through the
`extern_weak` path); the alignment check applies only to definitions. In
`declare`, a weak definition gets `Attr::WeakLinkage` and is forced exported
(`#[no_mangle]` or `export_name`) so a strong definition elsewhere wins at link
time. `#![feature(linkage)]` is now also requested when an `Item::Static`
carries `WeakLinkage`.

Regression test: crates/slate/tests/fixtures/weak_global_definitions.c. Promoted
fixtures.gcc-dg.gcc-only/torture\_\_pr43560.c (weak `int *g_85[2][1]`).

Limits: no cross-unit fixture proves a strong definition in another unit
overrides the weak one; that relies on the symbol being exported and weak.
