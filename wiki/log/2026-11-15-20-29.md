# slate-f2zu.14.34.31 static lowering: static const tables emitted as static mut so LLVM could not fold BUILD_BUG_ON loads (immutable static, \_\_SlateConst Sync wrapper)

_2026-11-15 20:29:09_

- bead: slate-f2zu.14.34.31
- kind: bug
- area: crates/slate/src/frontend/lowerer
- area: crates/slate/src/backend/rust_ast.rs
- area: crates/slate/src/backend/codegen.rs

Outcome: C `static const` / `const` global definitions lower to an immutable
Rust `static` (LLVM constant global) instead of `static mut`, so loads from
const tables fold and kernel BUILD_BUG_ONs over them no longer leave undefined
`__compiletime_assert_N`.

Symptom: relink 2026-11-15 left 3 undefined asserts: drm_edid.c
`BUILD_BUG_ON(cea_mode_for_vic(27)->vtotal != 312)` (assert_741) and mac80211
parse.c `BUILD_BUG_ON(sizeof(x) != empty_non_inheritance[1] + 2)` (assert_2232).
clang folds them because the tables are LLVM constants.

Reproducer (crates/slate/tests/fixtures.release/const_table_folds.c):

```c
static const struct display_mode modes[] = { ..., {{0, 0}, "1440x288", 312} };
static const struct display_mode *mode_for(int i) { return &modes[i]; }
const void *volatile escaped_mode;
int check_mode(void) { if (mode_for(2)->vtotal != 312) __compiletime_assert_1(); ... }
int main(void) { escaped_mode = mode_for(1); ... }
```

Before: `static mut modes: __SlateAlign16<[display_mode; 3]>`; rust-lld:
undefined symbol: \_\_compiletime_assert_1. The address must escape: an internal
never-stored `static mut` is already marked constant by GlobalOpt, which is why
small tests folded. After: `static modes: ...`, the call folds and the crate
links.

Cause: ModuleLowerer::declare hard-coded `mutable: true` on every Item::Static
definition, ignoring the IR's `[const]` (`Variable::is_const`).

Fix:

- `Tables::read_only`: definitions with `is_const`, static storage, not
  common/selectany/atomic/thread, not an address image (MaybeUninit image filled
  at runtime) or flexible-member storage. Those emit `mutable: false`.
- Sync: `Tables::is_sync` (ir::Type: scalars, enums, arrays and records of Sync;
  pointers, va_list, support-library records are not). A non-Sync read-only
  static without an align wrapper becomes `__SlateConst<T>`
  (`#[repr(transparent)]`, new `Repr::Transparent`), place `.0` via
  `sync_wrapped` in `lower_binding`. `__SlateAlignN` / `__SlateAlignLargeArray`
  now always get `unsafe impl<T> Sync` (new `TraitRef::Sync`, printed
  `unsafe impl`), so no nested wrappers. Integer tables stay bare.
- Addresses: `lower_address(place, mutable=true)` on a read-only place
  (`Tables::place_is_read_only`) emits `(&raw const X).cast_mut()`.
- Backend wrapper detection (`array_iter`, `dead_store`, `length_lattice`) goes
  through `rust_ast::is_storage_wrapper`, which accepts `__SlateConst`. Merge
  dedups the Sync impls by `impl:Sync:<ty>` key.

Regression tests: fixtures.release/const_table_folds.c (failed to link before),
fixtures/const_table_address_cast.c (const tables cast to non-const and read,
`__SlateConst` pointer global, bare u8 table). 224 FileCheck blocks regenerated:
static mut -> static, Sync impls, `.0` places where i686/aarch64 now wrap in
`__SlateConst`.

Verified single kernel TUs (x86*64-unknown-none, release): drm_edid.c and
net/mac80211/parse.c translate and build with 0 undefined
`\_\_compiletime_assert*\*`; both asserts are still guarded in the Rust. Limits:
not relinked.

See: slate-f2zu.14.34.30, wiki/concepts/ir-to-rust-lowering.md (Types and
storage).
