# Slate output formatted with prettyplease, written in parallel

_2026-10-01 12:33:03_

slate-p58o.7.12. Slate-frontend Rust is formatted in-process instead of spawning rustfmt.
- backend::pretty_rust = syn::parse_file + prettyplease::unparse; it falls back to format_rust (rustfmt) only if syn rejects the source. write_pretty_rust wraps it.
- Used by translate-project --frontend=slate, translate-lowered --frontend=slate, and api::translate_with_frontend_args(Slate). The CIR path keeps rustfmt (legacy, frozen).
- Vendored support sources (aligned, bitint, num-complex, slate-support, build.rs) are written verbatim with a new write_file helper, for both frontends.
- translate_slate_project: the serial pass collects cargo features/shims and splices child mods into the root; emit + pretty + write then run on the rayon pool.
- New deps: syn 3 (full, parsing), prettyplease 0.3.

Pre-check: all 4664 generated suite .rs files under crates/slate/target/*-suite parse with syn 3, and the prettyplease output re-parses.

chibicc translate-project (hyperfine, 10 runs): serial+rustfmt 754ms -> parallel parse/lower 491ms -> + prettyplease/parallel write 164ms.
The translated chibicc builds and passes make test and make test-stage2 (self-hosted).
slate profile 10/10 pass (31s -> 26s).
