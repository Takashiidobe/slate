# Accept and ignore codegen-only cl options

_2026-10-25 11:01:50_

slate-3amj.5.6: the msvc flavor accepts cl.exe options with no C-level effect as MSVC_ONLY rows in CODEGEN_ONLY_FLAGS (compiler_args.rs): /O*, /G* codegen, /Qspectre*, debug info, output files, /nologo /c /MP, /analyze*, /external:*, warning controls, /Y*, /TC /Tc, /MT, and the C++-only options cl accepts in C (/EH*, /GR, /permissive, C++ /Zc:). New row forms: exact, toggle (trailing -), number, and separate (bare spelling takes the next argument: /Fo: out.obj, /wd 4996, /external:I dir). /W0-4 /Wall /w set _MSVC_WARNING_LEVEL (MicrosoftFlags::warning_level, pp/mod.rs): last wins, /Wall sticky, other numbers are 1, non-numbers rejected. /TP /Tp /clr /ZW /await are rejected as C++. /favor:INTEL64 defines _NO_PREFETCHW and is left to slate-3amj.5.11. All checked against cl.exe 19.51.
