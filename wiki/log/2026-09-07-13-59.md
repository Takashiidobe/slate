# Fix gcc-dg/gcc-torture bare-asm-under-c23 dialect blocker, promote 54 fixtures

_2026-09-07 13:59:33_

Worked slate-os0h.3.1.66.1 (lower no-template inline asm with memory/
generic constraints). Root cause was NOT missing constraint-lowering
support -- m/rm/g/+g/imr already resolve correctly through the existing
storage-class lattice (verified by translating the 9 named fixtures under
-std=gnu23 directly). The real blocker: support::translate_with_args
forces -std=c23 for every suite built on it (gcc-dg, gcc-torture,
c-testsuite, differential.rs), and this clang build's C23 mode does not
recognize the bare GNU `asm` keyword -- only `__asm__` -- confirmed
against both the CIR-enabled frontend and the reference oracle clang
22.1.8 (asm("nop") : "=r"(x) rejected as "undeclared identifier" under
both). Every currently-supported asm fixture in-repo already used
`__asm__`; the failing gcc-dg/gcc-torture files are unmodified upstream
GNU C using plain `asm`.

Fix (scoped per user decision, not a global std change): added
support::gnu_dg_option_flags() in tests/support/mod.rs, defaulting to
-std=gnu23 with a fixture's own dg-options -std= still winning (appended
after). Switched tests/gcc_dg_suite.rs and tests/gcc_torture_suite.rs to
it; c_testsuite_suite.rs and differential.rs untouched (those corpora are
strict-ISO by design).

Result: far larger than the 9 named cases -- 54 gcc-dg fixtures total
newly pass end-to-end and were promoted (git mv) from
fixtures.gcc-dg.unsupported/ to fixtures.gcc-dg/, including
torture__pr58670 (the exact case behind sibling slate-os0h.3.1.66.2,
asm-goto + memory operand). gcc-torture had zero newly-passing cases.
Full `cargo nextest r --release --profile lowering` rerun: only
pre-existing failures remain (abi_unadjusted rustc-feature-removal,
4 fixtures, confirmed present on main before this change, already
tracked as slate-3f8g.4.16.19) -- no regressions.

Closed slate-os0h.3.1.66, .66.1, .66.2 (all resolved by this fix) and
slate-os0h.3.1.66.3 (MIPS -- separately closed as out-of-scope, Slate has
no MIPS TargetArch).

Note: tests/support/mod.rs got a formatter pass from a PostToolUse hook.
Also found CLAUDE.md and wiki/concepts/differential-fixtures.md modified
with new regen-filecheck/justfile documentation neither authored by this
session nor requested -- left as-is, flagged to the user rather than
committed or reverted.
