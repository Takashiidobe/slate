# slate-xw0x.18 dylink: ratchet unsupported shared-library fixtures

_2026-11-24 14:16:21_

- bead: slate-xw0x.18
- kind: feature
- area: crates/slate/tests/dylink.rs
- area: crates/slate/tests/fixtures.dylink.unsupported

Outcome: The dylink suite ratchets known translation, build, and runtime failures across a native shared-library boundary.

A failing fixture goes in fixtures.dylink.unsupported with the same host,
lib, and dylink.json layout. Each leg builds and runs the native oracle
before accepting a translated failure. When the translated result matches
the oracle, the suite prints the promotion command.

Both buckets reuse compile_c_cached, fresh_tree, and the release Cargo
target cache. A second run preserved the native binaries, unchanged crate
files, and translated executable. Each bucket has its own work directory.

The slate-yar4.73 fixture now passes each aliased callback from two
translated host units to a native shared library. Clang prints
strong=1 weak=1. Slate prints strong=0 weak=0. The fixture selects the
x86_64-unknown-linux-gnu leg and the FileCheck updater accepts that selector.

Fixture: crates/slate/tests/fixtures.dylink.unsupported/long_double_cross_unit_alias
Limits: The alias ABI bug remains open in slate-yar4.73.
