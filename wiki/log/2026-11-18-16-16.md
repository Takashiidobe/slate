# slate-5q63.22.7 slate-libc-gen: SYMBOLS / CLIB_RECORD_TYPES tables and probe items built with quote + prettyplease

Outcome: slate-libc-gen builds the CLIB_RECORD_TYPES and SYMBOLS tables and its Rust probe crates from quote! token streams instead of format! strings; tables print through prettyplease, probe items stay one per line; checked-in tables regenerated with identical content.

Gap and why it mattered:
decide::table and symbols::table spelled rows with format!/writeln! (`CLibRecord {{ rust_path: \"{rust_name}\" ..` wrote the path unescaped), and the layout and symbol probes spliced provider paths and catalog shape strings into `#[unsafe(no_mangle)] pub static ..` text.

Before:
    format!("const _: () = assert!({path} as i128 == {}i128); #[unsafe(no_mangle)] pub static S{index}: u8 = 0;", candidate.shape)
After:
    Probe::Constant { path: syn::Path, value: i128 } -> quote!(const _: () = assert!(#path as i128 == #value); #marker)

Implementation (crates/slate-libc-gen):
- emit.rs: `file(TokenStream)` = prettyplease::unparse(syn::parse2), `parse::<T>(&str)`.
- symbols.rs: `Probe` enum (Function/Global/Float/Integer/Constant) parsed from a Candidate (rust_path -> syn::Path, shape -> syn::Type / syn::TypePtr / i128); `&raw` access comes from the parsed pointer's mutability. A candidate whose path or shape does not parse is rejected with "Rust path or shape does not parse" (before, it failed to compile and was rejected as incompatible).
- rust_side.rs: layout `Probe.value` is a TokenStream (size_of/align_of/offset_of over syn::Type and syn::Ident).
- Probe sources are written with `TokenStream::to_string()`, one item per line, because compile_lines/collect map rustc errors back to probes by line number. Lines look like `# [unsafe (no_mangle)] pub static S10 : unsafe extern "C" fn (..) -> i32 = libc :: _NSGetExecutablePath ;`.
- decide::table / symbols::table return Result.

Verified: HEAD's and the new generator on x86_64 linux/darwin/msvc: identical reports, identical probe line counts, tables equal after rustfmt. Full 15-target run (69 s): tables equal to the checked-in ones after rustfmt; installed as prettyplease output (include!d, so cargo fmt does not touch them): clib_records_table.rs 1,580 -> 5,755 lines, libc_symbols_table.rs 4,581 -> 56,097 lines. slate-c2rust builds.
