# slate-5q63.22.2 build.rs: BuildScript/Step builder emits generated build.rs via rust_ast + codegen + rustfmt instead of format! strings

_2026-11-18 15:46:47_

- area: crates/slate/src/frontend/c_shim.rs
- area: crates/slate/src/main.rs

Outcome: the generated crate's build.rs is built as a `backend::build_script::BuildScript` of typed `Step`s, lowered to a rust_ast `fn main` and printed through codegen + rustfmt, instead of format!-built strings.

Gap and why it mattered:
main.rs wrote build.rs as `format!("fn main() {{\n{statements}}}\n")` around a hand-escaped println!/`CARGO_CFG_TARGET_OS` block, and c_shim::build_script_condition rendered `Cfg` gates into Rust source text with its own parenthesization and `{value:?}` quoting.

Before (main.rs):
    format!("    println!(\"cargo:rerun-if-changed=build.rs\");\n    if std::env::var(\"CARGO_CFG_TARGET_OS\").as_deref() == Ok(\"linux\") {{\n ...")

After:
    script.extend([
        Step::RerunIfChanged("build.rs".into()),
        Step::When { cfg: Cfg::Opt { key: "target_os", value: "linux" },
                     steps: vec![Step::LinkArg { target, arg: "-Wl,-z,nostart-stop-gc" }] },
    ]);
    write_file(&build_script, &script.render()?)?;

Implementation (crates/slate/src/backend/build_script.rs):
- `Step` {RerunIfChanged, LinkArg{target, arg}, CompileC{file, library}, When{cfg, steps}}.
- `cargo_directive` builds `println!("cargo:key=value")` as `Expr::Macro` (format braces escaped there only).
- `cfg_condition(&Cfg) -> Expr`: Flag -> `std::env::var_os("CARGO_CFG_X").is_some()`, feature -> `CARGO_FEATURE_X`, key/value -> `std::env::var("CARGO_CFG_K").is_ok_and(|v| v.split(",").any(|v| v == "value"))`, Not/Any/All as Unary/Binary exprs (codegen handles precedence; empty Any/All are `false`/`true`).
- `render` prints `Item::Fn(main)` with `item_to_string` and `format_rust`.
- c_shim::shim_build_statements -> shim_build_steps returns `Vec<Step>`; build_script_condition is gone.

Output change: the Linux link-arg check uses the shared Cfg path, `is_ok_and(|v| v.split(",").any(|v| v == "linux"))` instead of `.as_deref() == Ok("linux")` (same meaning; target_os has one value). Output is rustfmt-formatted.

Verified: translate-project of a long double program (ungated shim + link arg) builds and runs; a scratch x86_64+aarch64 --merge fixture produced the `CARGO_CFG_TARGET_ARCH`-gated cc::Build and its crate built and ran (no committed fixture covers gated shims). merge profile: only flush_value_writers fails, also at HEAD (slate-xw0x.13). dylink/project_plan/project_select/build_filecheck/differential(non-generated): 25 passed.

Limits: tests/support/mod.rs still writes its own harness build.rs as text (test crate cannot use the module).
