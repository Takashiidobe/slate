# Tier-2 (call-target) dispatch + LibcExit ported

_2026-08-27 22:41:26_

slate-y0qs.3: built tier-2 dispatch from rewrite-engine-v2.md's target
architecture item 3, and used it to port the first call-rewriting pass.

- NodeRule gained call_anchor() -> Option<Ident> (default None). RuleRegistry
  (engine/mod.rs) now builds by_anchor: HashMap<(NodeKindTag, Ident), Vec<u32>>
  alongside the existing by_kind buckets at build time; anchored rules are
  removed from the generic by_kind scan entirely and only surface via
  candidates(kind, call_anchor) when a popped node's own call target matches.
  Combining both index lookups sorts the merged index list to preserve global
  priority order (each source list is already increasing-index/priority).
- NodeKind::call_anchor() (arena.rs) extracts the callee Ident from a node's
  own-level expr (Expr/Return/Let-init), via expr_call_anchor unwrapping
  Unsafe/Block(if empty stmts)/Cast wrappers down to the terminal Expr::Call's
  func -- matches baseline lowering's actual shapes ('unsafe { exit(x) }',
  'let v = unsafe { printf(...) };'). Does not descend into arbitrary
  subexpressions (f() + g() has no single anchor) -- fine, since anchored
  rules need the call to BE the statement's whole rewritable content anyway.

Ported LibcExit (engine/rules/libc_exit.rs, priority 59 = passes.md's #59)
as the proof case: exit(code) -> std::process::exit(code), the simplest call
rewrite (no purity/aliasing reasoning, no facts dependency). Chose it
specifically because it's a genuine call-rewriting pass (validates tier-2),
not because it's representative of the harder ones (printf/sprintf/malloc
still need real precondition logic once ported).

Verified end-to-end, not just via the test suite: translated
tests/fixtures/noreturn_prototype.c, compiled the generated Rust standalone
against libc, ran it and diffed stdout+exit code against clang-compiled C
directly -- identical (both print "main\nbailing with 7\n", exit 7).
rewrites profile 110/110, fmt/clippy clean.

~62 passes remain unported; the bulk are call-rewriting (printf, sprintf,
strcpy, malloc, qsort, ...) and now have tier-2 to land on without paying a
per-call matches() scan across every call-rewriting rule in the registry.
