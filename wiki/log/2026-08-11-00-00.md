# gcc-torture vendoring and c-testsuite integration

_2026-08-11 00:00:00_

Vendored the gcc-torture and c-testsuite corpora as first-class test suites and removed the older alive2/fuzz-based regression harness in the same window.

- **`e0a32152`**: added `tests/fixtures.gcc-torture(.unsupported)` with real GCC-history regression fixtures (e.g. `20000223-1.c`, `20000227-1.c` — dated by the GCC bug they originally regression-tested); wired `translate-project`-style batch running through `src/main.rs`.
- **`e0d1821f`**: split `parallel_map`/`compare_batch` in `tests/support/mod.rs` into job-count-parametrized variants (`parallel_map_with_jobs`, `compare_batch_with_jobs`) so the gcc-torture runner can pick its own parallelism instead of always using the ambient `test_jobs()` count — meaningfully cut wall-clock runtime for the full-corpus run.
- **`dea339f3`**: started porting libc-test, vendoring `COPYRIGHT`/`FILTER.tsv`/`README.md` and adding a `.config/nextest.toml` profile for it — this is the seed of what later became the dedicated `libc` nextest profile.
- **`ada1621a`**: c-testsuite now compiles under GNU C17 (not the default C standard) to match the corpus's actual dialect assumptions; added a `lower.rs` accommodation for a GNU-C17-only construct.
- **`20052995`**: integrated c-testsuite into `cargo nextest r` proper so it runs (and blocks) on every regular test invocation instead of being a manually-triggered side suite.
- **`1fe29101`**: removed `tests/alive_regression.rs` and `tests/bnf_fuzz.rs` (and the `SLATE_ALIVE_TV` env var / alive-tv dependency from CLAUDE.md) — the alive2 translation-validation and BNF-grammar fuzzer weren't finding bugs proportionate to their maintenance cost, in favor of investing in the corpus-based suites instead.
- **`94c9ab02`**: closed the gcc-torture-vendoring epic.

Net effect: shifted regression-catching strategy from formal-verification/fuzzing tooling toward large real-world C corpora (gcc-torture, c-testsuite, and the libc-test port started here), which is the strategy still in place per `wiki/concepts/gcc-torture-triage.md`.
