# x86 ISA tables generated from tablegen; -march=<cpu> and the full -m<feature> set for clang

_2026-10-03 19:06:14_

- tools/generate_x86_isa.py reads X86.td (features, implications, CPU feature lists) and clang's Options.td (m_x86_Features_Group) via llvm-tblgen --dump-json, takes macro names from clang -dM deltas, and writes src/target/x86_isa_tables.rs: 105 features, 84 CPUs (incl. 32-bit-only ones), 64-bit-only features (uintr).
- Where clang's driver (X86TargetParser.cpp) differs from X86.td the script holds explicit overrides: EXTRA_IMPLIES (amx-avx512 -> avx10.2) and CPU_OVERRIDES (sgx on 22 Intel CPUs, kl/widekl tigerlake, invpcid knl/knm, mmx amdfam10, no cx16 on k8-sse3).
- tools/x86_isa_diff.py is the test oracle: every CPU and -m flag on x86_64 and i686 plus -mno-<f> on diamondrapids, 593 cases vs clang -dM: 0 mismatches; what slate rejects is listed (clang-only aliases, apxf/vzeroupper, pre-SSE2 32-bit CPUs).
- x86_isa.rs keeps folding and gcc's implication rules; X86Feature/X86Arch now index the tables. --flavor=gcc accepts only the x86-64 levels and the original 26 features; -march=<64-bit-less cpu> on x86_64 and -muintr on i686 are rejected like clang.
- Fixtures: x86_isa_march_haswell, x86_isa_march_cpu_overrides, x86_isa_tablegen_features, and four error fixtures. Parser profile 7622/7622 before the new fixtures; x86_isa fixtures 25/25.
