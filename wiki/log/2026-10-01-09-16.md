# Fold switch case constants with integer_number

_2026-10-01 09:16:06_

Follow-up to slate-p58o.4.9.

- slate-parser's case_value (sema/module.rs) wrapped every folded case constant as Number::SignedInteger regardless of type, so an unsigned _BitInt(128) case above i128::MAX arrived as a SignedInteger the slate lowerer could not parse as i128. It now uses fold::integer_number like every other folded constant: Integer for non-negative values, SignedInteger only for negative ones.
- The printer renders both variants identically, so no parser FileCheck output changed; switch_case_u128_values.c (slate differential) is the coverage.
- Removed the slate-side u128 fallback for SignedInteger case values.
- _BitInt wider than 128 bits never reaches switch lowering: the slate frontend has no Rust type for it yet and barriers on the type.
