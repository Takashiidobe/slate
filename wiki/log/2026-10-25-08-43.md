# Fix -ftrivial-auto-var-init pattern fills; typed scalar init; gcc fixture oracle

_2026-10-25 08:43:01_

Review fixes for ccf8fdbe1 (slate-3amj.4). Oracles: clang 23 and gcc 16, x86_64 and -m32.
IR: PatternFill is now Typed { integer, floating } (clang) or ValueBits(byte) (gcc), printed pattern(typed, ..) / pattern(value_bits=..). TypeResolver::auto_init(ty) (sema/types.rs) picks clang integer 0xFF when pointers are narrower than 64 bits (was always 0xAA, wrong on i686/armv7), and returns AutoInit::Zero for gcc locals of _Bool, _Complex long double, or a 12-byte x87 long double, which gcc zero-fills.
Lowering (lowerer/auto_init.rs): replaced the per-byte image with a write tree. Unions: clang fills the storage member (max align, max size, first), gcc ORs member value bits (was last member wins). x87 tail bytes zero for both flavors. gcc _BitInt and bit-fields keep value bits only. Arrays of records become a for loop, so the 512-run cap no longer blocks e.g. struct {int; float} a[600], and no image is allocated for large locals. Records always get a background memset, because a typed move drops Rust padding.
Scalars and fixed arrays of scalars now get a typed initializer (i32 literal, f32::from_bits, [..; N], usize as *mut T), and std::ptr::write in the goto dispatch path, so these locals are no longer address-taken for write_bytes.
Attribute: uninitialized outside an automatic local warns under -Wignored-attributes (sema/attributes.rs inapplicable), like clang and gcc.
Tests: tests/fixtures/gcc/ and gcc/<arch>/ are new gcc-flavor differential dirs. They translate with --flavor=gcc and run real gcc (gcc -m32 for i686, aarch64-linux-gnu-gcc) as the oracle. CrossTarget::gcc and update_filecheck.py support it. The gcc auto-var-init fixture moved there and its .expected was removed; gcc/i686 fixture added. The clang layout fixture gained union, x87 tail, complex long double, and 600-element record array cases and now passes on i686. Parser auto_var_init.c fixtures cover every attribute spelling and the misplaced-attribute warnings.
Follow-up: slate-v97o (unscoped unknown [[...]] attributes do not warn).
Docs: ir/initialization.md, ir-grammar.md, compiler-flags.md (row fixed), attributes.md, differential-fixtures.md, crates/slate/CLAUDE.md.
