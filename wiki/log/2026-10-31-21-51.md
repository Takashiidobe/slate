# Bind stdio to slate-support and vendor libc for all generated crates

_2026-10-31 21:51:40_

slate-f2zu.9.5.8.2: every generated crate, not only --merge, now depends on vendor/slate-support, which re-exports a vendored vendor/libc (0.2.191) and adds stdin/stdout/stderr accessors, putc, getc and __sputc per libc. lowerer/stdio.rs binds a table of stdio functions and the FILE records (_IO_FILE, __sFILE, _iobuf) to slate_support paths, and recognizes each libc's stream shape (stderr, __stderrp, &__sF[2], __acrt_iob_func(2)), so call sites match across targets and Tracev/Tracevv collapse to one macro. Any FILE layout use (by-value FILE, field access, address of a bound function) re-lowers the unit without bindings. unreachable_stdio_helpers re-lowers once more without header helpers and stream externs left unused (_vfprintf_l, __stdio_common_vfprintf, __swbuf, _OptionsStorage). Bugs found by the slate profile: printf_format missed writers read through a path in value position (gcc-torture printf-1, output reordered), fixed with a slate_support:: form of reads_var; function addresses skipped the fallback (c-testsuite case_00189). FreeBSD's putc macro exposes __sputc in value position, so printf_format's early return now applies to deflate under zlib-debug there, adding one FLUSH_BLOCK_ONLY variant. Non-merge output changed: 601 fixture baselines regenerated; the diff audited as renames, dropped declarations and line wraps. Fixture: fixtures.merge/stdio_bindings.c. zlib 45163 to 40702 lines. Before the last prune: cargo check 30/30, validate_merge 6/6 default and all. After it: projection 1024/0, signatures 694/0, slate, slate-targets and msvc profiles green; validate_merge and cargo check not rerun.
