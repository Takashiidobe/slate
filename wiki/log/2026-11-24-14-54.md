# slate-e36k.25 parser: reject unsupported Clang swiftcall

_2026-11-24 14:54:10_

- bead: slate-e36k.25
- kind: bug
- area: crates/slate-parser/src/parser/attributes.rs
- area: crates/slate/tests/fixtures.dylink.unsupported/swiftcall_boundary

Outcome: The parser diagnoses `swiftcall` before it can become a default C ABI callback.

## Symptom

Clang passes the callback context in r13 and the next ordinary argument
in rsi. Slate previously discarded swiftcall, so its callback took the
ordinary argument as its context and printed 19 instead of 42.

## Fix

Reject the convention when parsing a registered attribute. FileCheck covers
function definitions, function typedefs, pointer typedefs, and scoped Clang
attributes.

Fixture: `crates/slate/tests/fixtures.unsupported/x86_64/calling_convention_swiftcall.c`

Native oracle: `crates/slate/tests/fixtures.dylink.unsupported/swiftcall_boundary`

Limits: Native ABI support remains open in slate-e36k.25.
