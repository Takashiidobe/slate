Outcome: clang `__builtin_neon_*` loads/stores (vld1/vst1 [q], _lane, vld2/vst2), immediate and register shifts (vshl_n, vshr_n, vshl) and table lookups (vqtbl1..4) expand in sema instead of hitting the "vector C ABI" barrier.

Gap: these were the largest remaining NumPy clang-aarch64 barrier groups (vld1q_v 112, vst1q_v 95, vld1_v 39, vst1q_lane_v 37, vshrq_n_v 22, vshlq_v 16, vqtbl1q_v 7, ...).

Before:
```
help: function __builtin_neon_vld1q_v: vector C ABI
```
After: `vld1q_f32(p)` is `(p as *mut Simd<f32, 4>).read_unaligned()`; `vqtbl1q_u8` declares `#[link_name = "llvm.aarch64.neon.tbl1.v16i8"]`.

Implementation (sema/neon_builtins.rs, `Expansion::Neon`):
- Memory ops (`neon_memory`): the pointer is `PointerCast` to the decoded vector (or element) type, read/written through `PlaceKind::Deref` with `Access::align = element size` when that is below the vector size; the backend (places.rs) then emits read_unaligned/write_unaligned. `PlaceKind::Index` with a pointer base does not lower (`(p as *mut T)[1]`), so `p + 1` is `ValueKind::PointerOffset`.
- Stores are `Sequence(store, Void)` typed void (same as atomic `discarded`).
- Lane loads splat the element and two-operand shuffle it into lane `n % lanes`; lane stores store `lane(v, n % lanes)`.
- vld2/vst2: two vector reads/stores at `p`, `p + 1` plus even/odd (de)interleave shuffles instead of `llvm.aarch64.neon.ld2/st2` (struct-returning). `ret`, `p`, `a`, `b` are bound once via `bind_all` (now pub(super) in x86_vector_builtins.rs, with read_place/shuffle/zero). `expand_neon` now receives the builtin signature for that.
- vshr_n by the lane width (allowed by NEON): signed shifts by width-1, unsigned is zero, matching CGBuiltin's EmitNeonRShiftImm.
- vshl_v: `llvm.aarch64.neon.{s,u}shl`. vqtbl{n}: tables stay int8x16, index/result take the decoded type, `llvm.aarch64.neon.tbl{n}`.

Fixture: crates/slate/tests/fixtures/aarch64/neon_loads_stores_shifts_tables.c (slate-aarch64, qemu): element-aligned but not vector-aligned addresses, a side-effecting pointer argument to vld2q (called once), shift by 0/width/negative counts, out-of-range tbl indices.

Limits: NumPy corpus not rerun. Remaining NEON groups: 58.7.5 (rounding, vcvtn) and 58.7.6 (vmovl/vmovn/vmull).
