# Add libc oracle matrix runner

_2026-09-07 20:45:35_

Implemented tools/libc-abi-matrix.py and extended tools/libc-abi-probe.py with a separate Slate Clang compile phase and target linker phase.\n\nThe matrix enumerates x86-64, i686, ARM32, and AArch64 for musl and glibc, generates exact Slate libc/ISA defines, requires explicit glibc sysroots, uses the built musl sysroots, links with target wrappers, and runs cross-target probes through QEMU. It writes per-case oracle/shim JSON plus a manifest and never falls back to the host sysroot.\n\nValidated all four musl cases reach comparison, and validated configured AArch64 glibc reaches comparison. Existing shim ABI mismatches are reported for later fixes rather than hidden.
