# slate-f2zu.14.16 asm constant_asm_operands: dead \_\_builtin_constant_p arms and written-parameter entry values (nf_hook, test_bit_acquire, rip_rel_ptr) blocked asm 'i'

_2026-11-14 15:26:50_

- bead: slate-f2zu.14.16
- kind: parser
- area: crates/slate-parser/src/sema/asm_constants.rs
- corpus: linux

Outcome: the clang linux barriers sweep reports 0 blocked functions in 3005
kernel TUs. Asm "i" operands guarded by a folded \_\_builtin_constant_p or
IS_ENABLED, and "i"(p) on a parameter the same asm writes (rip_rel_ptr), no
longer block lowering.

Gap and why it mattered: the last 35 kernel barriers (17 arch_static_branch from
nf_hook, 16 constant_test_bit_acquire, 2 rip_rel_ptr in arch/x86/boot/startup)
were all `no usable constraint alternative: NotConstant`. The bead's guess
(constants flowing through plain static inline callers) was wrong:

- nf_hook and arch_test_bit_acquire guard the asm path with
  `__builtin_constant_p(param)`, which sema already folds to 0 in the shared
  body. The call to the generic always_inline asm function sat in a dead
  `if ne(0, 0)` arm, which kept the generic body unresolved and referenced.
  clang's codegen never emits a constant-false arm that has no labels.
- rip_rel_ptr is `asm("leaq %c1(%%rip), %0" : "=r"(p) : "i"(p))`. The asm output
  writes p, so `Uses::stable` refused to treat it as known, and specialize never
  cloned it.

Before (-O2, x86_64):

```c
static inline int hook(unsigned char pf, unsigned int nr) {
    if (__builtin_constant_p(pf) && __builtin_constant_p(nr) && !branch(&keys[pf][nr])) return 1;
    return 2; }
static inline __attribute__((always_inline)) void *rip_rel(void *p) {
    asm("leaq %c1(%%rip), %0" : "=r"(p) : "i"(p)); return p; }
void *g(void) { return rip_rel(table); }
```

`branch: ... NotConstant`, `rip_rel: ... NotConstant`.

After: the generic branch, constant_bit and rip_rel bodies are dropped. g calls
`rip_rel__const1`, whose asm has `in 1 "i" -> sym sym(table)`.

Implementation (crates/slate-parser/src/sema/asm_constants.rs):

- `unresolved_functions` computes the unresolved set and call-graph propagation.
  `prune_dead_arms` runs `DeadArms` on unresolved functions. When it prunes
  anything, the set is recomputed before candidates are chosen.
- `DeadArms` replaces an `If` whose condition folds through
  `integer_with_objects` with its taken arm, and a `Conditional` value with its
  taken value of the same type. `JumpTargets` keeps the dead arm when it has a
  label or a case or default for a switch outside it.
- `entry_prefix`: a known argument for an unstable parameter applies to the
  leading top-level statements, up to and including the first `Write` or `Asm`
  that touches it, and stops before any statement containing a label. specialize
  reselects and redirects that prefix with the entry values and the rest without
  them. Entry values are part of the clone key.
- Spec: wiki/concepts/ir/asm.md.

Behavior: clones of nf_hook-style callers were never made, so
`__builtin_constant_p(param)` is 0 in their bodies, as clang allows when it does
not inline. The dead asm arms are not reachable, so runtime results do not
change.
