# slate-8ge7.24.10.10 switch lowering: emit duplicated-tail fallthrough match directly; structure_dispatch::structure deleted

_2026-11-21 21:01:02_

- bead: slate-8ge7.24.10.10
- kind: rewrite
- area: crates/slate/src/frontend/lowerer/switch.rs
- area: crates/slate/src/backend/engine/rules

Outcome: the switch lowering emits the duplicated-tail `match` for fallthrough switches directly; the Rust rule `structure_dispatch::structure` (crates/slate/src/backend/engine/rules/structure_dispatch.rs) is deleted.

Before: `lower_fallthrough_switch` emitted `let __tN = match sel { ... }; 'sw: loop { match __tN { 0 => { a; __tN = 1; continue 'sw; } 1 => { b; break 'sw; } _ => break 'sw } }`, and structure_dispatch parsed that back into a `match` with each fallthrough tail copied into the arms before it. It fired 12 times in 11 files (switch_fallthrough.c, switch_default_*_fallthrough.c, switch_torture.c, gnu_case_ranges.c, goto_project_control_flow.c, gcc-torture 20011223-1, 20020529-1, 920506-1, ...).

After: same final Rust, built in crates/slate/src/frontend/lowerer/switch.rs:
- `lower_fallthrough_switch` lowers every arm body once, then `duplicated_switch` builds `match sel { p0 => { a; b } p1 => { b } _ => ... }`. A trailing `break 'sw` is dropped, empty fallthrough arms merge their patterns into the next arm, copied tails get fresh `__tN` temps (`freshen`), and the match is wrapped in `'sw: { }` only when a `break 'sw` is left inside (`breaks_to`).
- More than 24 duplicated non-temp statements (`MAX_DUPLICATED_STMTS`, the rule's limit) falls back to the case loop, now built by `case_loop` from the same lowered bodies, so arms are never lowered twice.
- Folded and wide-int (indexed) switches keep the case loop, as before; the rule never matched them.

Validation: slate profile passes with no FileCheck change, both with the rule still registered (0 fires) and after deleting it. SLATE_RULE_TRACE over tests/fixtures, gcc-torture, gcc-dg, c-testsuite, chibicc: structure_dispatch::structure 12 / 11 -> 0.

Wiki: rewrite-engine-v2.md and sqlite-runtime-performance.md no longer name structure_dispatch.rs.
