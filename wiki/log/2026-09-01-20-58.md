# Derive C shim includes from bridge identity

_2026-09-01 20:58:07_

C-shim renderers now start with _GNU_SOURCE and add only headers supplied by FunctionIdentity::Known.

Typed ABI bridges preserve identity from lowering, so calls such as strfroml emit stdlib.h without an unrelated fixed stdio/stdlib/math preamble. Internal long-double and fenv support still include the headers they require themselves.

The cross-TU C23 strfrom integration test asserts the generated shim includes stdlib.h and omits stdio.h; it passes under the release rewrites profile. Cargo fmt, Clippy, and diff checks pass.
