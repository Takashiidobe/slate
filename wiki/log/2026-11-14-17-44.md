# slate-f2zu.14.20 macro va_start and param_spills shadow restore: cannot find __va_args in macro_rules, __ret_1 after parameter renamed to shadow name

_2026-11-14 17:44:01_

- bead: slate-f2zu.14.20
- kind: bug
- area: crates/slate/src/frontend/macro_keep.rs
- area: crates/slate/src/backend/engine/shadow.rs

Outcome: `va_start` expansions stay inline instead of becoming `macro_rules!` that cannot see `__va_args`, and a parameter renamed by `param_spills::fold` to a uniquified shadow name gets the same restored name as its uses.

## Symptom

Kernel shards failed rustc with E0425 (94 errors, 32 shards):
- `cannot find value __va_args`: `macro_rules! va_start { ($v:expr) => { $v = transmute::<VaList, VaList<'static>>(__va_args.clone()) } }` (include/linux/stdarg.h `#define va_start(v, l) __builtin_va_start(v, l)`; arch/x86/boot/printf.c, drivers/acpi/osl.c, ...).
- `cannot find value __ret_1` (fs/dcache.c d_hash): `fn d_hash(__ret__slate_shadow_1: u64)` while the body used `__ret_1`.

## Reproducer

    #define va_start(v, l) __builtin_va_start(v, l)
    int f(int n, ...) { va_list ap; va_start(ap, n); ... }

    #define shr(val) ({ __typeof__(0u+(val)) __ret = (val); __asm__("shrl $12,%k0" : "+r"(__ret)); __ret; })
    static unsigned long *d_hash(unsigned long h) { return ptr(table) + shr(h); }   /* ptr() also declares __ret */

## Cause

1. `__va_args` is the function's implicit Rust variadic binding, not an IR binding, so `pass_caller_locals` cannot pass it as a hidden macro argument, and macro_rules hygiene hides it from the template body.
2. `uniquify` renamed the second `__ret` to `__ret__slate_shadow_1`; `param_spills::fold` (`let __ret.. = hashlen` at top level) renamed the parameter to it; `shadow::restore` renamed body uses back (to `__ret_1`, since the retired let left zero binders) but never touched parameters.

## Fix

1. `Survey::value_kind` (frontend/macro_keep.rs) rejects open expansions containing `ValueKind::VaStart` ("va_start_reads_variadic_arguments"); `va_copy`/`va_end` templates are unaffected.
2. `shadow::restore` (backend/engine/shadow.rs) takes `&mut [FnParam]`, counts a parameter carrying a fresh name as a binder whose scope mentions every relevant body name, and renames parameters with the same mapping as the body.

## Regression test

- crates/slate/tests/fixtures/macro_va_start_reads_variadic_arguments.c (va_start/va_copy/va_end macros, vsnprintf forwarding).
- crates/slate/tests/fixtures/x86_64/stmt_expr_local_renames_spilled_param.c (two statement expressions declaring `__ret`, the d_hash shape).
