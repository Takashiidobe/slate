# Flatten singleton scopes around recovered for loops

_2026-10-16 21:30:00_

slate-5vj0.5.14: after for_range turned '{ let mut i = 0; while i < 8 { ...; i += 1; } }' into a for, the braces stayed. singleton_scopes::flatten refuses when a name declared in the scope is read by a later sibling, and it counted the For pattern as a declaration, so any later loop reusing 'i' blocked it.

- rules/singleton_scopes.rs: shadow_outlives_scope ignores For nodes, whose pattern is scoped to the loop body and cannot leak into later siblings.
- Baselines regenerated: memcpy.c, memmove.c, mem_safe_slice_idioms.c (bare sibling for loops).
