# pthread_cancel-points: new deterministic SIGABRT regression, root cause unisolated

_2026-09-03 14:52:03_

Answering "are there any failing libc-test assertions?" -- cargo nextest r
--release --profile libc has exactly one failure:
libc_test_functional_supported_tests_match_c, pthread_cancel-points: C exits
0, Rust binary is killed (SIGABRT).

Reproduced directly against
target/test-cache/target-libc-test-functional-suite-supported-batch-cargo/debug/pthread_cancel_points:
deterministic SIGABRT, 3/3 runs. gdb backtrace shows the abort happening
entirely inside glibc (pthread_kill <- raise <- abort <- anonymous libc.so.6
frame <- pthread_testcancel <- sem_wait), before unwinding ever reaches the
Rust frames (execute_sem_wait / run_execute) that called it. This is glibc's
NPTL forced-stack-unwind cancellation path (_Unwind_ForcedUnwind via
libgcc_s) aborting on its very first step when execute_sem_wait's sem_wait()
call notices the thread has a pending pthread_cancel().

Ruled out the easy explanations before filing:
- libgcc_s.so.1 is linked (ldd confirms)
- PT_GNU_EH_FRAME program header present, .eh_frame/.eh_frame_hdr populated
- readelf --debug-dump=frames shows FDEs covering both execute_sem_wait's
  and run_execute's PC ranges -- not simply missing CFI for those frames

Root mechanism not isolated further (didn't bisect the 188 commits since
the fixture was promoted, or dig into whether some other frame between
execute_sem_wait and the thread's pthread_create entry point lacks CFI, or
whether there's a libgcc_s/std unwinder registration mismatch).

This is a regression: slate-os0h.19.3.6's notes record pthread_cancel-points.c
as fixed and promoted in commit 4acc2473 (2026-08-22, a cir_type_to_ctype
function-pointer field bug) -- unrelated to this crash, which is a runtime
unwind-ABI issue, not a codegen type bug.

Filed as slate-cu47 (new bead, P2 bug, no existing epic fit well). Did not
demote the fixture back to unsupported/ or attempt a fix -- flagging back to
the user to decide whether to chase the unwind-ABI root cause or demote for
now to get the libc profile green.
