# Gate C99 stdlib and time extensions

_2026-09-18 18:44:57_

Tightened stdlib.h extension declarations to require GNU source or the strict X/Open mode used by libc-test, preventing glibc GNU99 leaks while preserving supported API probes. Restricted musl time extensions to active source feature macros, removing the C99 extras. C99 and GNU99 stdlib/time audit rows are empty; libc nextest, cargo fmt, and cargo clippy pass.
