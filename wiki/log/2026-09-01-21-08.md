# Consolidate typed C shim rendering

_2026-09-01 21:08:22_

Moved typed C-shim construction into one shared builder accepting bridge declarations and any required record definitions.

Single-program rendering now collects its extern declarations and long-double records before calling the builder. Project translation shares the same declaration collector instead of maintaining a second copy. Headers, ABI helper blocks, record definitions, and typed bridge declarations therefore use one policy.

Focused release rewrites tests pass for generated project shims, direct-program long-double callback shims, and library FileCheck. Cargo fmt, Clippy, and diff checks pass.
