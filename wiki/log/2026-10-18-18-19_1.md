# Remove redundant nested unsafe

_2026-10-18 18:19:36_

slate-o3gw.4. New final engine pass (rules::unsafe_registry, run after printf_format
so its Stmt::Expr(Expr::Unsafe(printf)) matching is unaffected) in
crates/slate/src/backend/engine/rules/nested_unsafe.rs:

- nested_unsafe::stmt turns a NodeKind::Unsafe with an Unsafe ancestor into a
  Scope (or a Block if it has a tail); ScopeFlatten in the same pass merges it.
- nested_unsafe::expr unwraps Expr::Unsafe under an unsafe context, either an
  enclosing unsafe block or an outer unsafe expression. A block with statements
  becomes a plain block; unsafe { e } becomes e and codegen adds parentheses.
- Unsafe fn bodies do not count as unsafe context (2024 unsafe_op_in_unsafe_fn).
- unsafe { place } is a value: it copies. It is unwrapped only in a value
  position; borrow, &raw, method receiver, field/index/ArrayPtr base, macro
  argument and match scrutinee positions keep it. Without this,
  println!(.., unsafe { trace }) on a static mut became a static_mut_refs error
  (goto_basic_block_chain), and autoref/field writes would hit the original
  place instead of the copy.
