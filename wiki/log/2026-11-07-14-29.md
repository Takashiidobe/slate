# Link the i686 C oracle against Rust's compiler_builtins

_2026-11-07 14:29:22_

slate-xw0x.7: bitint_float and bitint_rotate failed on i686 at the C oracle link (undefined __floattidf/__floattisf/__fixdfti/__fixsfti/__umodti3). libgcc has no TI-mode helpers on i686, and compiler-rt's i386 builtins build those objects empty (no __int128 on 32-bit). Rust's i686 compiler_builtins rlib defines them. CrossTarget gained cc_link_args, appended after the source and -lm/-latomic (tests/support/mod.rs); i686 sets -lgcc, then the sysroot's libcompiler_builtins-*.rlib (rust_compiler_builtins), then -Wl,--defsym=rust_eh_personality=0 for the DW.ref some compiler_builtins objects carry. -lgcc first keeps libgcc resolving everything it already provided. The args are part of the C cache key. Removed bitint_float and bitint_rotate from fixtures.unsupported/i686-unknown-linux-gnu.txt; slate-i686 differential passes (2/2). gcc -m32 links with the same args.
