# Label every macro expansion in the preprocessor

_2026-11-01 10:35:56_

slate-f2zu.9.5.12.2: top-level calls used a location join (MacroInvocations::sites) and nested calls used token labels. Now there is one table, MacroInvocations.expansions (MacroExpansion: definition, parent, spelled, empty), and every recorded expansion stamps Span.macro_nesting on its body and argument tokens. Object-like expansions in source are labeled too, because they enclose nested regions (OBJECT -> LEAF). sites(), nest(), MacroInvocation, NestedExpansion and MacroRegionId are gone; a region is a MacroExpansionId. An expansion is recorded before its arguments are prescanned, so ids run outer first and a call inside an argument gets the outer call as parent. Runs of argument tokens with the same enclosing label share one Arc. --show-macros prints [macro=NAME#id body|argN] and macro_expansion lines (macro_invocations.c, macro_nesting.c regenerated; wiki preprocessor, ir-grammar, ir/pipeline updated).

Kept: macro_regions::touches still uses SpelledCall.site overlap, since F(1); with a two-statement body has a last statement with no label. Noted on .8; the subtree rule from .3 should replace it.

Also fixed from .1: the macros report section broke the FileCheck block of all 28 fixtures.merge fixtures, because they check the whole report and .1 was committed without running them. Regenerated in one call: 101 lines added, 0 removed, all of them report lines, so generated Rust did not change on any merge fixture.

Validation: zlib output byte-identical before and after this change. 80 reuse lines in both reports. Translate 3:35 to 3:44 in single runs, not a controlled measurement.
