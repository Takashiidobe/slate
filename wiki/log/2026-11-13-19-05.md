# slate-dghn.58.1 x86_vector_builtins: hand-expanded x86 SIMD builtins (cmp*, blend, vec_set/ext, byteshift, masked load, mask conversions) were vector C ABI barriers

_2026-11-13 19:05:56_

- bead: slate-dghn.58.1
- kind: feature
- area: crates/slate-parser/src/sema
- area: crates/slate/src/frontend/lowerer/vectors.rs
- target: x86_64

Outcome: x86 header builtins that clang's CGBuiltin expands by hand (compares, blends, lane insert/extract, byte shifts, permutes, subvector inserts, undef, AVX-512 mask conversions and masked loads, elementwise sqrt) now expand in sema and translate instead of stopping at "vector C ABI" barriers.

Gap: NumPy's SIMD sources (simd/sse, avx2, avx512 headers) call _mm_cmpord_ps, _mm_insert_epi32, _mm256_cmp_ps, _mm512_cmp_ps_mask, _mm512_maskz_loadu_epi32, _mm512_movepi8_mask... Their builtins have no LLVM intrinsic, so they stayed calls to a vector-ABI builtin declaration: 31 of 33 NumPy translate barriers.

Before:
```
unsupported slate-parser IR in __builtin_ia32_cmpordps
help: function __builtin_ia32_cmpordps: vector C ABI
```

After (IR for _mm_cmpord_ps):
```
vector_bit_cast<vector<f32, 4>>(and<vector<i32, 4>>(eq<..>(read(%a), read(%a)), eq<..>(read(%b), read(%b))))
```

Implementation:
- sema/builtins.rs: new Expansion variants (Zero, LaneInsert, LaneExtract, Blend, PermuteQuads, ByteShift, Compare, CompareMask, MaskToVector, VectorToMask, MaskedLoad, InsertSubvector) and the record mapping; named_compare parses cmp{eq,lt,le,unord,neq,nlt,nle,ord}{ps,pd,ss,sd}.
- sema/x86_vector_builtins.rs: expand_x86_vector builds shuffles, vector compares, bit casts and splats. Compare predicates use imm & 15 (signalling bit ignored) from eq/lt/le/gt/ge/ne plus ord/unord and not. Operands are bound once (bind_once/captured). A non-constant immediate keeps the call.
- New slate intrinsics, lowered in lowerer/vectors.rs: slate.vector_sign_bitmask -> simd_lt(v, Simd::default()).to_bitmask() as T; slate.masked_load -> Simd::load_select_ptr(p as *const Lane, Mask::from_bitmask(k), passthrough), which never reads disabled lanes.
- __builtin_nondeterministic_value and undef* give zero; ElementwiseSqrt is llvm.sqrt (scalars too, f128 included).

Fixture: crates/slate/tests/fixtures/x86_64/x86_header_expanded_builtins.c (SSE/AVX2/AVX-512 incl. NaN operands, all 32 cmp_ps predicates, tail masks). Promoted by the ratchet: freeze_builtin_ops.c, x86_64/vec_masked_load_ops.c. Parser FileCheck regenerated: builtin_pointer_to_vector_param, f128_intrinsics, freeze_builtin_ops (now expanded IR).

Limits: masked stores (storedqu*_mask) stay calls. NumPy translate now reaches further units and hits 15 more hand-expanded builtins (cmpb512_mask, ucmpb512_mask, shufps, palignr256, permti256, vperm2f128_*, roundps, gathers/scatters, reduce_fmax_pd512, vcvtph2ps512_mask, vfmaddsubpd512_mask, storedqudi512_mask); still open under slate-dghn.58.1.
