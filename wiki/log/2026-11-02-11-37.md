# Lower block literals to stack blocks with copy/dispose helpers

_2026-11-02 11:37:30_

slate-3amj.42.5: block literals were malloced with refcount 1 and never freed, and captured blocks were never retained, so a C stack block captured by a translated block dangled. A literal with captures now writes a _NSConcreteStackBlock into a MaybeUninit slot hoisted to the function top (__slate_blocks::stack); a captureless literal is a global block, as clang emits it. Each literal gets a static Descriptor (descriptor::<Caps>) whose slate-only tail lists (offset, BLOCK_FIELD_IS_BLOCK) for captured block pointers; shared copy_helper/dispose_helper read it through the block's own descriptor and call _Block_object_assign/_Block_object_dispose, so BLOCK_HAS_COPY_DISPOSE blocks are retained on Block_copy and released on dispose. Promoted fixtures.library/block_capture_retain (was SIGSEGV). New tests/fixtures/block_lifetime.c: copy identity (C returns a new object for a stack block, the same for heap and global), captured block outliving its release, no heap growth for 100k non-escaping literals (was 457 MB for 10M). __block cells are unchanged (leaked Box, no forwarding): next step is Block_byref. Ran the four block fixtures (x86_64, block_lifetime also i686/aarch64), library_differential, library_unsupported_tests_still_fail, release_build_differential; no other fixture uses -fblocks, full slate profile not run.
