# Implement Darwin sockets and network libc ABI

_2026-08-31 11:26:05_

slate-sfzn.6.9: added self-contained Darwin overlays for sys/socket.h,
netinet/in.h, sys/un.h, netdb.h, and ifaddrs.h, with arpa/inet.h using the
dispatched Darwin types.

Modeled length-prefixed sockaddr layouts, 128-byte sockaddr_storage,
IPv4/IPv6 and Unix addresses, message/control headers, linger, Darwin address
families, socket options, ancillary-data alignment, addrinfo ordering and
resolver constants, legacy host/service/protocol records, and interface
records. Linux-only accept4, mmsghdr, SOCK_CLOEXEC, and MSG_CMSG_CLOEXEC remain
absent.

Added the macos-net header manifest, standalone ABI/signature/negative
compilation checks, central SDK probe coverage, and the macOS network
cross-target fixture with generated lowering/rewrite FileCheck assertions.

Validation: focused lowering and rewrites fixtures pass; release libc profile
passes; cargo fmt and release all-target clippy pass. The macOS SDK oracle
explicitly skipped because SLATE_MACOS_SDK is unset.
