# slate-p58o.3.9: automatic locals and scoped bindings

_2026-09-30 21:45:18_

Closed slate-p58o.3.9 (Lower automatic locals and scoped bindings).

Binding identity, shadowing, and scopes already lowered correctly: BindingId
names are resolved up front, colliding names get an _<id> suffix or r#, and
IR blocks become Rust scopes. The gap was locals declared without an
initializer. They lowered to a bare 'let mut x: T;', which Rust's
definite-initialization check rejects when the address is taken
(fill(&x)) or when it cannot prove every path assigns (E0381).

Change (lowerer.rs, Statement::Let): every uninitialized local now starts
at a default value: false for bool, 0 as T for other primitives, and
unsafe zeroed() for everything else (pointers, fn pointers -> None,
records, va_list). C leaves the value indeterminate, so zero is a valid
choice. The array and VaList special cases are kept or subsumed.

Fixture: scoped_local_bindings.c (new; failed with E0381 on 'filled')
covers nested and sibling shadowing, parameters shadowed in inner blocks,
a local shadowing a static, Rust keyword names, declarator initializer
order, per-iteration loop locals, and uninitialized locals filled through
pointers or assigned in branches.

Promoted 40: c11_callbacks; c-testsuite case_00141, case_00144; gcc-dg
stdckdint-1; gcc-torture 20010711-1 through usad-run (36 files).

param_spill.c blocks on an _Atomic parameter (atomics are Phase 4).
