# Wide string literals as typed static arrays; close slate-oreg.6

_2026-10-18 13:30:52_

slate-oreg.6: promoted gcc-torture 20010325-1 and widechar-3, chibicc string, and fixtures.unsupported/c23_library.c (passes on x86_64, i686, aarch64). New fixture wide_string_literals.c (L, u, U, concatenation, indexing, wcslen, byte view).

- lower_string_global turned every .strN CodeUnits global into a byte string, and the inline byte path reinterpreted that as \*mut i32. Wide units >255 hit the 'wide string' barrier. Only 8-bit element arrays take the byte-string path now. Wider literals are ordinary statics with typed array initializers (CodeUnits already lowers to a typed ArrayLit).
- rust*binding_name maps IR synthetic names with a leading '.' to \_\_slate*<rest> (.str9 -> \_\_slate_str9); before, they were emitted verbatim, which is not a Rust identifier.

slate profile green apart from the two ratchets that flagged the promotions above; the cross-target checks were single-fixture runs.
