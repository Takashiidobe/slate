# slate-8ge7.24.10.9 lower_dispatch: structure the dispatch block graph in the lowerer; structure_goto::reducible rule deleted

_2026-11-21 21:20:02_

- bead: slate-8ge7.24.10.9
- kind: rewrite
- area: crates/slate/src/frontend/lowerer/structure.rs
- area: crates/slate/src/frontend/lowerer/control_flow.rs
- area: crates/slate/src/backend/engine/rules

Outcome: lower_dispatch structures its own basic-block graph into loops, labeled blocks and ifs; the Rust rule structure_goto::reducible (rules/structure_goto.rs + structure_goto/reducible.rs, ~1130 lines) that reparsed `'__slate_dispatch: loop { match __slate_state }` is deleted.

Before: lower_dispatch_region always emitted `let mut __slate_state = N; '__slate_dispatch: loop { match __slate_state { ... } }` and the reducible rule rebuilt a CFG from the arena (state assignments + `continue '__slate_dispatch`) and restructured it. It fired 49 times in 41 fixture files after .10.8, including all computed-goto/asm-goto functions the IR transform skips.

After: crates/slate/src/frontend/lowerer/structure.rs runs the same algorithm (reverse postorder, dominators, natural loops, join labels, `split_irreducible` SCC selectors) on the `(state, Vec<Stmt>)` arms lower_dispatch_region just built, and the lowerer emits `'__slate_dispatch: { ... }` directly. `__slate_state` is declared only when an irreducible SCC keeps a selector. The full state machine is emitted only when `structure` returns None (state read outside assignments, duplicate states, a prefix that escapes the dispatch, or still irreducible after splitting).
- Arena reads became `Stmt` traversals (`bodies`, `diverges`, `Dispatch::escapes`, `Dispatch::steers` replaces `collect_uses`).
- Orphans removed: arena::insert_stmts, arena::reify_bodies.

Measured (SLATE_RULE_TRACE=1 slate translate over tests/fixtures minus msvc/aarch64/i686, gcc-torture, gcc-dg, c-testsuite, chibicc): structure_goto::reducible 49 / 41 -> 0, then deleted. No goto rule remains in rules/ except the label_elide cleanups.

Fixtures: fixtures/gcc/openmp_parallel_gcc.c (dispatch inside the OpenMP closure, which the arena rule never visited, is now structured). Merge fixtures regenerated (merge profile had not been rerun since .10.1-.2): macro_control_flow, macro_fold, macro_dispatch_locals, macro_values lose zeroed slots / unsafe blocks; macro_arguments loses a do-while(0) loop; splice_ladder only renames copied temps.

Also fixed here (bug in .10.10, wiki/log/2026-11-21-21-01.md): `switch.rs` `is_temp` counted `__v` temporaries against MAX_DUPLICATED_STMTS, so splice_ladder's alpha+beta variant kept the fallthrough case loop. It now skips both `__v` and `__t` lets, as the deleted rule did.

Wiki: rewrite-engine-v2.md, sqlite-runtime-performance.md point at frontend/lowerer/structure.rs.

Limits: still-irreducible regions and computed/asm-goto entries keep the dispatch loop; slate-8ge7.24.10.11 holds the IR-side nested-goto shapes, slate-8ge7.24.10.5 the remaining label_elide cleanup.
