# slate-8ge7.2.6 ProvenanceCheck: SLATE_CHECK_MACRO_STRUCTURE fails when an IR transform drops a kept macro's node or region without macro_rejections; pass audit finds all compliant

_2026-11-27 16:16:04_

- bead: slate-8ge7.2.6
- kind: feature
- area: crates/slate/src/frontend
- area: crates/slate-analysis/src/transform
- area: wiki/concepts/macro-provenance-transforms.md

Outcome: `SLATE_CHECK_MACRO_STRUCTURE=1` (on in `project_merge`) now fails a unit when an IR transform drops a node or `Statement::MacroExpansion` region of a macro expansion that has no `Module::macro_rejections` reason, and `wiki/concepts/macro-provenance-transforms.md` states the rule and audits every slate-analysis pass.

Gap: slate-8ge7.2.6 asked that transforms stop at macro boundaries or record a rejection, and for a check that catches provenance lost silently. Nothing verified it.

Implementation:
- `Passes::run_observed(module, slot, after)` calls `after(pass_name, module)` after each pass; `Passes::run` uses it with a no-op.
- `frontend::macro_provenance::ProvenanceCheck`: before `Slot::BeforeMacroKeep` it records, per expansion, the `macro_values`-wrapped node ids present in function bodies and the statement regions. After each pass and after the macro-keep strip (step `macro-keep`) it records the first missing site. `report` fails with `Error::MacroProvenanceLost` for expansions with no rejection, naming the step.
- `lower_parsed` wires it in behind the existing env var.

Audit result: every pass already complies. Depth-tracking passes (const-fold, truth-canonicalize, dead-temporaries, decl-init, truth-locals) block inside expansions and holes; inline-temps rejects temps read in a region; do-while-zero, labeled-blocks and structure-goto use `inline_temporaries::children`, which never enters `Statement::MacroExpansion`. No pass needed a fix.

Validation: full `slate` profile with the env var set, and the `merge` profile: no unexcused loss. Debug run over the differential suite: 275 lost sites, all for expansions macro-keep had already rejected (`system_header`, `not_function_like`, `stringify_or_paste`, `variadic`, `hoist_split_region`); const-fold folding object-like constants is the only pass-attributed loss.

Limits: presence only. An in-place rewrite of a wrapped node under the same id, or a move into a region, is not caught; span `macro_nesting` is not checked. Expansions split by sema hoisting before the snapshot are not seen. Passes stay stricter than the rule inside holes.

See: slate-8ge7.2.5 (concept page), wiki/concepts/macro-provenance-transforms.md.
