# Public IR printer for single statements

_2026-10-01 07:28:43_

slate-p58o.12. slate-parser's statement printing lived in private DisplayModule methods that only needed the metadata table and compact flag. They now live on a private Printer { metadata, compact } that DisplayModule builds via printer(); Span<Statement>::display() is a new public DisplayStatement that prints one statement (with nested body, no metadata, trailing newline trimmed) through the same code. Module IR output is unchanged (parser profile 7500/7500). In Slate, lower_statement now takes the Span<Statement> and Construct::Statement carries the printed IR instead of a Rust Debug dump; lowering-barriers prints only the first line of a multi-line construct so it stays one row per barrier. Documented in wiki/concepts/ir/pipeline.md.
