# Carry owned comments through IR and the Rust AST

_2026-10-07 14:47:05_

slate-6cgg.2.

IR: Module.comments is now ir::Comments { owned, detached, order }. owned maps a NodeId (function, global, type, field, enumerator, parameter) to leading/trailing/inner comments; detached holds prologue and section comments with a position into order; order lists top-level IR nodes in source order with their file. Sema resolves ownership from the AST siblings (Comments::distribute: Leading goes to the next node, Trailing to the previous, a Skipped sibling breaks the chain), so the IR stays self-contained and carries no AST ids. Decls map to IR nodes via the tag type they define plus the functions/globals/definitions they added. Record and enum comments are distributed inside the type resolver where the AST items and the new IR spans meet; a record or enum's unowned comments become its inner comments. Parameter comments are owned by the Parameter span at the three lowering sites. Deleted the per-field/enumerator/parameter forwarding into Module.comments.

--show-comments prints owned comments on their own lines above the owner (params prefixed 'param <name>') and only detached ones at the top. ir_comment_attachment.c, ir_comments.c, parser_token_annotations.c regenerated.

Slate: rust::Comment carries attach/doc; FnDef, FnParam, Item::Static get comments; RecordDef/RecordField already had them. claim_comments replaces take_comments (no offset search). module_comments places detached comments, and owned comments whose node was not emitted (erased prototypes, aliases), at the next emitted item of the same file by node id, else after the previous one, else the top. Rendering is still raw // lines; normalization and doc promotion are slate-6cgg.4, statement comment migration is .3.
