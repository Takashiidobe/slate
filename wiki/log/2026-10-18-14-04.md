# Accept rustc-rejected C idioms; close slate-oreg.8

_2026-10-18 14:04:27_

slate-oreg.8: six gcc-torture cases failed because rustc rejected the generated Rust.

- pr98681, pr97888-1: deny-by-default arithmetic_overflow / unconditional_panic fired on UB in dead branches (x << -64, d / i with i == 0). Tables::may_trip_known_panics sets Dependencies.known_panics for an integer shift whose count folds out of range, or an integer div/rem whose divisor is not a nonzero constant and is built only from constants and safe local reads (what rustc's KnownPanicsLint can const-propagate). The crate then gets #![allow(arithmetic_overflow, unconditional_panic)]. Gating it this way keeps the attribute out of most fixtures; 13 FileCheck blocks gained the line. Non-root translate-project units still drop crate Allow attrs, as they already did for long_running_const_eval.
- 20011121-1: &((struct s *)0)->b lowered to addr_of_mut!((*null).b), rejected as a null deref. AddressOf/ArrayDecay of a field chain rooted at a null pointer now lowers to the folded layout offset cast to the pointer type (13usize as *mut [i8; 2]), reusing Tables::null_place_offset.
- 20011115-1: foo == foo compared two Option<fn item> values (E0369). When both operands are FunctionDecay, the left side is bound to a let typed as the fn pointer, so the right side coerces.
- pr68249: slate-parser bug. For GNU a ?: b the shared condition kept its IR bool type while its C type is int, so the IR read bool where it used i32. The shared value is now converted to its C type (from_bool) before it is captured. 4 parser FileCheck blocks were regenerated.
- 980506-2: a C function named self emitted fn self. function_rust_name applies path_keyword_free (self_, crate_, ...). Exported definitions with a renamed symbol get export_name and extern declarations get link_name, so the C symbol is kept.

New fixture tests/fixtures/rustc_rejected_idioms.c covers all six. Promoted all six cases into fixtures.gcc-torture/.
