# Lower variadic blocks

_2026-11-02 12:04:29_

slate-3amj.42.5: variadic blocks. Parser: va_start inside a block literal was checked against the enclosing function's FunctionNames, so a variadic block in a fixed-arg function was rejected and va_start in a fixed-arg block inside a variadic function was accepted. Types::block_function_names derives variadic/convention from the block signature; the checker (assertion.rs block_literal) and lowering (sema/block.rs) swap it in around the body. Slate: lower_block_call keeps variadic block types (adds ... to the transmuted fn pointer) and promotes variadic arguments through the new FunctionLowerer::lower_call_argument, shared with ordinary calls (calls.rs). lower_block_function emits mut __va_args: ... and marks variadic block functions unsafe. Also fixed: unreachable_stdio_helpers did not scan dependencies.block_items, so externs used only inside blocks (vprintf) were pruned. Fixtures: slate tests/fixtures/block_variadic.c, tests/fixtures.library/block_variadic (native C calls translated variadic blocks and vice versa), parser clang/block_variadic.c and error/clang/linux/x86_64/block_va_start_fixed.c. parser and slate profiles pass.
