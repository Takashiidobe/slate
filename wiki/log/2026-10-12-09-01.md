# slate-3f8g.4.17.14.3 MS asm local labels

_2026-10-12 09:01:44_

asm_template runs numeric_local_labels before unique_labels: a LocalLabel piece followed by text starting with ':' is the definition and gets a number (2.., skipping all-0/1 digit numbers, which Rust rejects); other occurrences print Nf or Nb by position. A reference with no definition in the same block (a jump to another block's label) is a barrier, left for .14.4. Duplicate definitions in a block are a barrier. Two asm blocks in one function may reuse a C label name since each asm! has its own numbers. Also: ir::Statement::Temporary without an initializer is now declared mut, because the parser shares one synthetic eax local across every asm block of a function and a second block assigned it twice (E0384). Fixture i686/ms_asm_labels.c: backward loop, forward skip, same label name in two blocks.
