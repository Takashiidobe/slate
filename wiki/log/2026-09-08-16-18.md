# probe public external header objects

_2026-09-08 16:18:41_

Added oracle AST collection and shim-only type/link probes for public external VarDecl objects. Private __ names are excluded, and macro-backed names such as errno never enter the VarDecl inventory. The generated source redeclares the oracle type under a slate_oracle name, checks typeof compatibility with the shim-visible object, and references the shim object so the selected target libc must resolve it. Added glibc unistd.h environ coverage: oracle type char ** compiles and links through libc-shim.
