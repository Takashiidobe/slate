# Lower switch case fallthrough in the slate frontend

_2026-10-01 08:53:16_

slate-p58o.3.41.

- A switch where any non-last arm falls through (body not ending in break/continue/return) now lowers to the old CIR lowerer's trampoline instead of hitting the 'switch: fallthrough' barrier:
  { let sel = discriminant; let mut case: i64 = <default index or -1>; if sel == v.. { case = i } else ...;
    '__slate_break_<id>: loop { match case { i => { body; case = i+1; continue '__slate_break_<id>; } ... _ => break } } }
- A falling-through last arm gets break; arms ending in a jump get nothing appended. break/continue inside arms are unchanged (break targets the loop's label, continue targets the enclosing loop's labeled block).
- Switches without fallthrough keep the existing if-else chain. The equality-condition and selector-let construction are shared helpers (switch_arm_condition, switch_selector).
- Still refused: case ranges, statements before the first case, nested case labels (Duff's device).
- Promoted: switch_fallthrough, switch_default_first_fallthrough, switch_default_middle_fallthrough, and gcc-torture 20011223-1, 920506-1, pr35800, vprintf-1.
