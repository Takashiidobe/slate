# slate-8ge7.24.10 structure_goto design: IR transform structures reducible gotos, lower_dispatch keeps irreducible residue

_2026-11-21 19:36:34_

Outcome: goto structuring is decided as an IR transform (slot 2) that structures every reducible goto; whatever is not reducible stays Goto/Label in the IR and lower_dispatch lowers only that region.

Decisions (slate-8ge7.24.10):

1. Owner: transform work under slate-8ge7.24. slate-8ge7's "Rust-only residue" text no longer lists goto structuring. End state deletes the Rust rules structure_goto (normalize, reducible), structure_dispatch and the goto-made labels in label_elide.
2. Multi-level exit: extend the slate-parser IR. A block gets a BindingId and Break(id) may target it; printed, verified, specced in ir-spec/ir-grammar, lowered to a Rust labeled block. Sema never emits it, so parser fixtures do not change. Rejected: do { } while (0) (captures continue) and a slate-only node (transform fixtures must print plain IR).
3. Algorithm: goto elimination on the statement tree (Erosa-Hendren style). Move a goto outward/inward until it is a sibling of its label, then forward goto -> labeled block + break, backward goto -> loop. Statements without gotos keep their shape and NodeIds (nodes are moved, never cloned). The transform emits plain loops and labeled blocks; it never picks for vs while. counted_loops and loop shaping see the result because facts run after transforms. Rejected: flatten to CFG and rebuild (what the Rust rules do), because it rebuilds unrelated code and fights the NodeId and macro-region invariants.
4. Irreducible residue: the transform structures everything reducible. Multi-entry loops, computed goto, label addresses, asm goto, and regions the transform bails out of (goto/label crossing a surviving MacroExpansion boundary) stay Goto/Label. The residual region is the lowest statement list holding every remaining goto and its labels; lower_dispatch runs on that list only and the rest lowers structured. This replaces split_irreducible's SCC-local dispatch on the Rust side.
5. No IR state machine. Computed goto (&&label values in data tables) and asm goto (label operands set a Rust flag) cannot become an IR switch-in-loop, so lower_dispatch stays regardless; an IR state machine would be a second path re-solving local hoisting, VLAs, cleanup arming and the __builtin_unreachable fixes (slate-f2zu.14.34.36/.37). Deferred, filed only if a fact consumer needs facts inside irreducible regions.
6. Rule deletion is by fire count: when SLATE_RULE_TRACE shows 0 fires over the fixtures, delete the rule. If normalize still fires on lower_dispatch output, have lower_dispatch emit coalesced/threaded blocks directly, then delete normalize.
7. No corpus measurement: the fixture suites (tests/fixtures, gcc-torture, gcc-dg, c-testsuite, chibicc) have enough goto functions.

Constraints every child keeps: cleanup-attribute variables run their cleanup on every structured exit leaving their scope (slate-f2zu.14.40.2); jumps into __builtin_unreachable blocks keep diverging (slate-f2zu.14.34.36/.37); asm goto keeps the __slate_asm_target flag lowering (slate-f2zu.14.34.27).

Stale text: the bead's inline_temps::late 89/23 count predates slate-8ge7.22 (late now fires 9).
