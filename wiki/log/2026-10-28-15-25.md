# Counted-loop fact on ir::Statement::For

_2026-10-28 15:25:45_

slate-gbgp.2.1: new pass sema/counted_loops.rs runs after effects_statements::normalize and sets Statement::For.counted = Some(CountedLoop { index, start, end, inclusive }) when the for provably runs index over start..end (..= when inclusive). Conditions: the last init statement declares the index (integer, automatic, not volatile/atomic, no register asm/cleanup); nothing in the function escapes it (address-of, decay, asm/OpenMP place); the condition has no hoisted statements and is lt(read i, end)/gt(end, read i) in the index's own type (le/ge only with a constant end below the type max); end is constants, conversions, arithmetic and reads of non-escaped plain parameters/automatic locals, never the index itself; the increment, after substituting its temporaries, is exactly write(i, add(read i, 1)); the body writes neither the index nor end's bindings and has no label, foreign case/default, asm, SEH or OpenMP. An exhaustive Uses walker over Statement/Value/Place classifies writes vs escapes. Printed as 'counted: %i in start..end' after increment. Slate lowerer ignores it until slate-gbgp.2.2 (patterns gained ..). Fixtures: clang/linux/x86_64/ir_counted_loops.c, ir_counted_loops_rejected.c (incl. i < i + 5, which the first draft wrongly counted); 182 existing IR fixtures regenerated, the only diff is the added counted line. Wiki: ir/control-flow.md Counted loops, ir-grammar.md. char/short indices compare after promotion and are not counted yet.
