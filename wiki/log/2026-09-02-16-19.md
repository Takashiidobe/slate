# Fold generated parameter spills in the worklist engine

_2026-09-02 16:19:02_

Added ParamSpillFold after ZeroInitFold. It recognizes a same-typed top-level local initialized from a parameter whose complete def-use set contains only that initializer, transfers the local name and mutability to the parameter, and removes the binding. Arena now owns function parameter metadata so rules can update signatures and reification writes those changes back. The rule is 79 lines. Added an atomic-parameter differential fixture and regenerated affected rewrite expectations. On giflib, direct parameter spills fall from 225 to 34 and generated Rust falls from 22,127 to 21,988 physical lines; retained cases have additional parameter uses or are synthesized main locals. Release rewrite tests pass 92/92, focused lowering passes, and clippy is clean.
