# slate-8ge7.24.10.11 lower_dispatch split_irreducible: nested multi-entry cycles get a selector instead of the flat state machine fallback

_2026-11-21 22:01:01_

- bead: slate-8ge7.24.10.11
- kind: rewrite
- area: crates/slate/src/frontend/lowerer/structure.rs

Outcome: lower_dispatch structures nested irreducible regions with a selector instead of falling back to the flat `loop { match __slate_state }` state machine; `split_irreducible` in crates/slate/src/frontend/lowerer/structure.rs now recurses into each strongly connected component with its header removed.

Before (tests/fixtures/goto_backward_into_loop.c, `goto L` from a later loop into the body of a nested `for`): the outer cycle had one entry, so the old split (maximal SCCs only) added nothing, the graph stayed irreducible and `structure` returned None. Output: 160 lines, 16 match arms, every block a state.

After: 89 lines. The outer loops and the `for i in 0..3` nest are structured; only the inner multi-entry cycle keeps a two-arm `match __slate_state { 7 => .., _ => .. }` selector.

Rule: `sccs(blocks, members)` runs Tarjan on the subgraph `members`. `split_irreducible` keeps a worklist of regions (starting with all blocks). For each nontrivial SCC: if it has two or more entries, add a selector header and trampolines as before and push the SCC again (its entries are now reached only through the header, which is outside the SCC); if it has one entry, push the SCC minus that header. Each push is smaller, so it terminates.

Shapes in the bead and where they stand (gotos left in IR after `--passes=all`: 52 in 24 files, 3 of them indirect-jump functions):
- goto into a loop body: 20040704-1 lowers to `if false { abort(); } return 0;`; pr123625 (jump into `for(;;);`) structured without state.
- goto into a switch case (goto_into_later_switch_case*.c, 20111208-1): structured by lower_dispatch with join labels, no state.
- backward goto into an if arm (pr43269), Duff's device (case_00143), goto_irreducible*, case_00213: irreducible; selector only. That is the target end state, per the 2026-11-21 design (irreducible stays Goto/Label in IR, no IR state machine).
- VLA re-entry (20040811-1, vla-dealloc-1): selector, as planned.
No IR-side structuring was added: every remaining IR shape would need a state or guard flag, which lower_dispatch already builds.

Measured: the full fallback (structure() == None) now happens 5 times in 4 files: gcc-torture pr112581-1, pr38051 (2), tests/fixtures/goto_dispatch_unreachable_after_trap.c, goto_residual_region.c. These are extractor shape gaps, not irreducibility; e.g. goto_dispatch_unreachable_after_trap has an arm ending in `continue '__slate_break_1` (a jump to a loop outside the dispatch) that `Extractor::terminator` rejects. The fallback stays as the safety net.

Fixture: tests/fixtures/goto_backward_into_loop.c regenerated. slate and merge profiles pass.

Limits: the 5 extractor fallbacks above; a selector could be replaced by node splitting (duplicating small entry blocks) at the Rust level, which is not done.
