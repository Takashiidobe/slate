# Translate tinycc for linux-x86_64 and windows-x86_64

_2026-11-08 22:49:38_

slate-a28e.22 was stale (the tccrun.c #warning predicate no longer blocks). New matrix tools/corpus/matrices/tinycc.json (one-TU tcc.c, ONE_SOURCE=1); merged crate at ~/slate-translated/slate-tinycc.
Fixes found on the way:
- lowerer/values.rs + pointers.rs: PtrToInt of a null-based address (legacy offsetof ((size_t)&((T*)0)->f), incl. constant array indexes via ArrayDecay/PointerOffset) folds to an integer, so static initializers no longer cast pointers to integers in const eval. Fixture fixtures/offsetof_null_static_initializer.c; rustc_rejected_idioms drops its now-unused struct.
- engine/rules/literal_casts.rs: return operands are typed only when the function has a return type. Macro value templates end in return and were stripped to untyped literals (#define FIVE ((size_t)5) -> 5), breaking FIVE!().wrapping_sub(..). Covered by the same fixture; merge template fixtures now keep typed literals.
- lowerer.rs + support/oldnames.rs: every msvc output links oldnames.lib, which cl.exe adds to each object (/DEFAULTLIB:OLDNAMES) and rustc does not; without it open/read/close/stricmp etc. fail to link. 33 msvc and 41 merge FileChecks regenerated.
- lowerer/intrinsics.rs: __clear_cache (aarch64 clang target builtin) maps to llvm.clear_cache. Fixture fixtures/aarch64/clear_cache_libcall.c.
- --merge: c_shim.rs collects shim names through Item::Cfg/InlineMod with their gates, and the generated build.rs compiles slate_long_double.c only where a gate holds (CARGO_CFG_*/CARGO_FEATURE_*), so windows no longer builds the x87 shim. splice.rs refuses to splice functions whose per-target param/return types differ and involve a reference (type aliases cannot hold elided lifetimes).
Validation: tinycc tests2 with -run, translated vs native tcc: linux 138/139 (144_tls is NORUN upstream; as an exe it matches .expect), windows under wine vs a cl.exe-built tcc 139/139, and libtcc1.a is byte-identical. slate profile green after regenerating FileChecks; c23-stdarg-4/6 promoted to gcc-dg.gcc-only. Darwin-aarch64 is out of the matrix until slate-yar4.37 (va_arg on char* va_list).
