# Lower msvc \_\_va_start; add msvc nextest profile

_2026-10-25 09:42:25_

slate-3amj.5.17: ucrt's x64/ARM64 **crt_va_start expands to **va_start(&ap, x), which slate-parser emitted as a call to an extern, so any msvc-flavor printf failed to link (undefined **va_start). Added CustomBuiltin::MsVaStart for clang's MSva_start record (sema/builtins.rs, typer.rs, expression.rs): typing requires a pointer to va_list and calls va_start_context; lowering emits VaStart{convention: Target} on deref of the first argument, so slate's existing lowering transmutes the Rust VaList to char\*; ucrt's va_arg/va_end are plain pointer arithmetic. declares_builtin now keeps a non-library builtin without a checked signature across an external redeclaration, as clang does (ucrt declares void **va_start(va_list\*, ...)). Regenerated parser fixtures msvc/windows/x86_64/sysroot_crt_headers.c and clang windows/aarch64 Sema\_\_microsoft-varargs.c (call -> va_start). New fixture crates/slate/tests/fixtures/msvc/x86_64/msvc_va_start.c: int and double varargs, a 24-byte struct by reference, va_copy, vsnprintf forwarding and printf, run under wine against cl.exe. Added SLATE_DIFF_FLAVOR (differential.rs) and the msvc nextest profile (msvc fixtures of both crates, x86_64 and i686, ~16s); documented in AGENTS.md, crates/slate/CLAUDE.md, differential-fixtures.md and the slate-3amj.5 epic.
