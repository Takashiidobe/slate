# Predeclare size_t under MS compatibility

_2026-10-11 17:09:40_

slate-parser-v74.1.9. clang's Sema::Initialize adds an implicit size_t typedef whenever MSVCCompat is on (windows-msvc default, -fms-compatibility on any target, always for msvc flavor); cl.exe accepts size_t without a header too.
Slate: Preprocessor::predeclared_typedefs parses 'typedef <size type> size_t;' from <built-in> (System header) when StandardFeatures::microsoft_compatibility. Parser::parse_source/parse_file_with_source prepend it before -D/-include processing; preprocess_file (-E) does not, matching clang -E. Reachability prunes it unless used, so only TUs that name size_t print an extra 'type size_t' line (14 MS fixtures regenerated, all one added line).
Size type spelling mirrors CTypes::size_type: unsigned int/long/long long by pointer width.
