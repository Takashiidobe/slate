# Accept unterminated last struct member and qualifier-only members

_2026-11-08 21:16:57_

slate-parser-cxg.18.1: gcc and clang accept a record body whose last member lacks ';' (union { int i; short s } u; struct s { struct { int a; } };) and members of only qualifiers/attributes (const;), with warnings. parse_field_list (parser/declarator.rs) now ends a member at a depth-0 ';' or the closing '}' (decl.rs member_end) outside msvc, and parse_declarator_list/finish_declaration accept an unterminated field. Qualifier-only members (skip_empty_member) become FieldItemKind::ExtraSemi. ast-spec updated. Migrated gcc.dg anon-struct-6/7/8, pr30137-1/2, struct-semi-1..4 to suites/gcc-dg/gcc.
