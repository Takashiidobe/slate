# just regen-filecheck target subdirectories and projects

_2026-09-01 08:32:40_

Extended Justfile FileCheck regeneration to include target fixture subdirectories (bionic, macos, msvc), target check fixtures (fixtures.link), and project fixtures. Added path-aware default target resolution and directory recursion to tools/update_filecheck.py, so running just regen-filecheck without arguments or on specific subdirectories automatically uses the correct target triples (aarch64/x86_64-linux-android, aarch64-apple-darwin, x86_64-pc-windows-msvc, x86_64-unknown-linux-gnu). Unsupported target translations are skipped cleanly with the fixture left unchanged. Validated recipe listing, py_compile, individual target fixture runs, cargo fmt, and cargo clippy.
