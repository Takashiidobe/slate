# caller-side Box return retention (slate-y0qs.4.8.6)

_2026-08-29 19:09:26_

Implements caller-side Box<[T]> retention for owned buffer returns.\n\nThe pass recognizes pre-ZeroInit null-decl/assignment bindings and\nsingle-use result-temp aliases. It retains Box ownership only when every\ncall site for a lifted callee agrees, all uses stay within proven pointer\noffset/deref chains, and exactly one matching deallocation exists.\n\nAccepted callers retype the binding to Box<[T]>, bridge raw indexed uses\nwith as_mut_ptr(), remove the verified free call, and delete its dead cast\naliases. Raw API forwarding, storage/return escapes, mixed caller domains,\nand indirect deallocators fail closed to the existing into_raw bridge.\n\nmalloc provenance and free removal now require resolved\nCallBinding::Known(Malloc/Free), so project functions or shadowed function\npointers with libc spellings cannot authorize ownership rewrites.\n\nExpanded buffer_return_box.c with retained callers plus forwarding,\nall-callers-agree, and shadowed-free rejection coverage.\n\nValidation: focused differential passed; cargo fmt --check and\ncargo clippy --release --all-targets -- -D warnings passed; full rewrites\nprofile passed 110/110.
