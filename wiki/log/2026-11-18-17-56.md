# slate-yar4.49 asm Slot::GlobalMemorySymbol: memory operand through exported alias bound sym to the local item

_2026-11-18 17:56:00_

- bead: slate-yar4.49
- kind: bug
- area: crates/slate/src/frontend/lowerer/asm.rs

Outcome: an x86_64 asm "m" operand addressed through an exported runtime symbol or ELF data alias now prints the literal link name (`crypto_sbox(%rip)`) instead of `sym` of the local item.

## Symptom
`__asm__("movzbl %1, %0" : "=r"(v) : "m"(crypto_sbox))`, where `crypto_sbox` is an exported ELF alias of a static, lowered to `Slot::MemorySymbol` with `{N}(%rip)` and `sym sbox`. The relocation named the local item (`sbox`) instead of `crypto_sbox`, which modpost-style checks reject.

## Reproducer
```c
static const unsigned char sbox[4] = {1, 2, 3, 4};
extern const unsigned char crypto_sbox[4] __attribute__((alias("sbox")));
int read_sbox_memory(void) {
  unsigned int value;
  __asm__("movzbl %1, %0" : "=r"(value) : "m"(crypto_sbox));
  return value;
}
```
Built with `-fPIE`, the unfixed lowering produced `movzbl _RNv...sbox(%rip), %al`-style local-symbol output and the Rust release build failed to assemble.

## Cause
In `lower_asm` (crates/slate/src/frontend/lowerer/asm.rs), the Memory-operand arm for a symbol address always pushed `Slot::MemorySymbol` with a `rust::AsmOperand::Sym` of the local item, even for bindings in `Tables.asm_global_symbols`.

## Fix
New `Slot::GlobalMemorySymbol(BindingId, i64)`. When the symbol binding is in `asm_global_symbols`, the arm pushes it with no Rust operand, and `asm_template` prints `<name>{offset:+}(%rip)` (AT&T) or `<size> ptr [rip + <name>{offset:+}]` (Intel), with the same modifier rules as `MemorySymbol`. Follows `Slot::GlobalSymbol` (slate-yar4.47).

## Regression test
crates/slate/tests/fixtures.release/data_alias_units (impl.c `read_sbox_memory`, compiled with `-fPIE` so the memory-symbol path applies; main.c prints its result). FileCheck shows `movzbl crypto_sbox(%rip)`.

Limits: Intel dialect rendering is not covered by a fixture.
See: slate-yar4.47
