Outcome: under SLATE_IR_POINTERS, a pointer param whose length every call site proves becomes `&[T]` / `&mut [T]`, and its companion length param is dropped and rebuilt as `let n = p.len() as T`. Gate on, fixtures lift 236 params vs 220 with the gate off, and every suite builds and matches C.

Gap and why it mattered: slate-8ge7.6 step 3 skipped length_lattice under the gate, so ptr+len params (ptr_len_worklist, const_table_address_cast, over_aligned_globals, scalar_hint_builtins) went back to raw.

Before (gate on, step 3):

```rust
fn fill_values(values: *mut i32, len: i32)
fn sum_values(table: *const entry, count: i32) -> i32
```

After:

```rust
fn fill(values: &mut [i32]) { let len: i32 = values.len() as i32; for i in 0..len { values[i as usize] = i * 3; } }
fn forward(values: &mut [i32]) { fill(values); }
forward(unsafe { core::slice::from_raw_parts_mut(heap, len as usize) });
bump(local.as_mut_slice());
total(unsafe { core::slice::from_raw_parts(core::ptr::addr_of!(table.0) as *const i32, 4 as usize) })
fn bump(values: &mut [i32]) { ... values[i as usize] += 1; }
```

Implementation (crates/slate-analysis/src/pointer.rs):
- Each call site records a `Shape` per argument: `Array { length, element }` (a sized array decay), `Allocation { pointer, count, element }` (a local initialized once from `malloc(count * sizeof(T))`), `Binding`, `Constant`.
- A pair (function, pointer param, integer param) needs both params unwritten and every call site in the same unit, outside macros, proving it in one of three ways: an array plus a constant equal to its extent, an allocation plus its unwritten count, or the caller's own active pair forwarded.
- A fixed point drops pairs whose pointer has no borrow, or where a pointer or length appears in more than one pair. Covered arguments neither seed nor carry UNPROVEN (their arg->param edges are left out), so `free(heap)` after the call no longer blocks the lift.
- `PointerFact.length: Option<Length { parameter, read }>`. `read` excludes reads that are forwarded length arguments, so `forward` gets no dead `let`.
- Callees declared `[memory=none]` (e.g. `__builtin_prefetch`) no longer escape their arguments.

Lowering:
- functions.rs drops length params and emits the `len()` prologue.
- calls.rs skips length arguments. `lower_sized_borrow` gives `as_slice()` for a safe array or a borrowed binding, and `from_raw_parts[_mut](ptr, len as usize)` otherwise.
- A synthetic `ptr_offset(p, i)` temporary with a constant or plain-read index becomes a view, so `*tmp += 1` lowers to `p[i as usize] += 1`.
- Same-shape borrowed arguments pass the binding (implicit reborrow) instead of `&mut (*p)`.
- remove_mut: an index or field write through a reference-typed binding no longer needs `mut` on the binding.

Fixture: crates/slate/tests/fixtures/pointer_lift_length_pairs.c (gated: allocation, forward, local array, global table, view temp, prefetch, plus the negative case `prefix(window, 2)`, which keeps `len`). pointer_lift_local_copy_chain regenerated: `sum(p: &[i32])`.

Limits: &str was not ported. The Rust-side lift (local_libc_strcmp, ptr_len_str_worklist) passes a `from_raw_parts(x, 3)` slice and then `strcmp(a.as_ptr(), ..)`, which reads the NUL past the slice's provenance (UB). A sound version needs a terminator-including representation (&CStr), tracked separately. Copies of a paired param (`let t1 = p; let t2 = t1;`) are no longer folded, because `p.len()` is a second use.
