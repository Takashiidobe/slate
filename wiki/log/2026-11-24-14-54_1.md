# slate-e36k.26 parser: reject unsupported Clang preserve_most

_2026-11-24 14:54:10_

- bead: slate-e36k.26
- kind: bug
- area: crates/slate-parser/src/parser/attributes.rs
- area: crates/slate/tests/fixtures.dylink.unsupported/preserve_most_boundary

Outcome: The parser diagnoses `preserve_most` before it can become a default C ABI callback.

## Symptom

The native caller seeds r10 with 42 and calls a preserve_most callback.
The callback calls a native function that clears r10. Clang preserves
the caller’s r10, while Slate previously emitted the default C ABI and
printed 0 instead of 42.

## Fix

Reject the convention when parsing a registered attribute. FileCheck covers
function definitions, function typedefs, pointer typedefs, and scoped Clang
attributes.

Fixture: `crates/slate/tests/fixtures.unsupported/x86_64/calling_convention_preserve_most.c`

Native oracle: `crates/slate/tests/fixtures.dylink.unsupported/preserve_most_boundary`

Limits: Native ABI support remains open in slate-e36k.26.
