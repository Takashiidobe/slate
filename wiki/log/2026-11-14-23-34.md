# slate-f2zu.14.34.3 Runtime::Core: freestanding/-nostdinc units skip std rewrites and barrier VLA, alloca, huge-_BitInt main

_2026-11-14 23:34:54_

- bead: slate-f2zu.14.34.3
- kind: feature
- area: crates/slate-parser/src/ir/module.rs
- area: crates/slate-parser/src/compiler_args.rs
- area: crates/slate/src/backend/engine
- area: crates/slate/src/backend/interproc

- target: kernel

Outcome: a unit compiled with -ffreestanding/-fno-hosted or -nostdinc lowers to core-only Rust: std-introducing rewrites silently skip and std-only lowerings (VLA, alloca, huge-_BitInt main) are NeedsStd barriers.

Gap and why it mattered: the kernel target is no_std, but rewrites emitted std::process::exit/abort, print!/println! with std::io::stdout flush, std::env::var, and Box/Vec/String lifts; the lowerer emitted Vec for VLAs, a thread_local/std::alloc side stack for alloca, and a std::thread 1 GiB stack for main with a huge _BitInt. Of the 3005 linux TUs, all pass -nostdinc but only 55 pass -ffreestanding, so the gate is `hosted && !nostdinc` (no system headers means no libc, and std needs libc).

Before (`-ffreestanding`):
```rust
fn release(cell: Box<i32>) {}
println!("sum {}", sum(&values));
std::process::exit(...)
```
After:
```rust
fn release(cell: *mut i32) { unsafe { free(...) }; }
unsafe { slate_support::printf(c"sum %d\n".as_ptr(), sum(&values)) };
unsafe { exit(...) };
```

Implementation:
- slate-parser: `CompilerOptions.nostdinc` (moved from `CompilerArgs`); `ir::Module.hosted` / `Module.nostdinc`, printed `freestanding;` / `nostdinc;` after the target block (ir-grammar updated).
- slate: `rust_ast::Runtime { Std, Core }` on `Program`, from `Runtime::for_module`; the lowerer keeps it in `Tables.runtime`.
- Rewrites: `rules::registry(target, runtime)` drops `GetenvVar` and the libc_call Exit/Abort rules; `engine::apply_local` skips `printf_format::rewrite`; `pointer_lattice::solve` clears `PointerFact.heap_ownership` when any unit is Core, so freed pointers resolve raw (no Box/Vec/String, which also turns off the length lattice's owned buffers).
- Barriers: `Construct::NeedsStd` via `Tables::require_std` in `vla_vec_type`/`vla_buffer`, the alloca builtin lowering, and the main wrapper when `huge_stack`.
- Found along the way: `length_lattice::rewrite_signature_expr` had no `Expr::If`/`Match` arms, so a lifted callee called inside a ternary kept its (ptr, len) arguments (E0061). Added both arms.

Fixtures: crates/slate/tests/fixtures/freestanding_no_std.c, nostdinc_no_std.c, length_lift_call_in_ternary.c (the If/Match fix, hosted), freestanding_void_main.c (regenerated); fixtures.unsupported/freestanding_vla.c, freestanding_alloca.c, freestanding_huge_bitint_main.c; parser fixtures clang/linux/x86_64/freestanding_library_builtins.c and the flag_* fixtures regenerated.

Limits: libc-name rewrites that do not introduce std (strlen on lifted strings, etc.) still fire in freestanding units even though -ffreestanding means those names have no library semantics. The rest of the rewrite_signature_expr walker gap is slate-yar4.44. Crate-root #![no_std] is slate-f2zu.14.34.4.

See: slate-f2zu.14.34.7 (kernel syscall_64/32 alloca via CONFIG_RANDOMIZE_KSTACK_OFFSET), slate-yar4.44.
