# Lower numeric comparisons, logical operators, and bool literals to IR

_2026-09-14 20:30:47_

sema::numeric now lowers `<` `<=` `>` `>=` `==` `!=`, `!`, `&&`, `||`, and C23 `true`/`false` to a bool-typed IR.

- ir gains `Type { Bool, Numeric(NumericType) }`; `Value.ty` is now `Type`. Bool is separate from NumericType, per ir-shape.md.
- New nodes: `ValueKind::Compare { op: CompareOp, left, right, exceptions: Option<Exceptions> }` printing `lt<i32>(..)` with the operand type, and `ValueKind::Logical { op: LogicalOp, .. }` printing `logical_and<bool>`/`logical_or<bool>`. `Number::Bool` prints `const<bool>(true)`. `!` reuses `Unary { Not }` as `not<bool>`.
- Decided with the user: truth conversion is `ne<T>(x, const<T>(0))`, not a `to_bool` node (the spec contradicted itself; the conversions table row was fixed). The zero constant reuses the operand span (NodeId is not used outside the AST).
- Decided with the user: `&&`/`||` are `logical_and`/`logical_or`, not `and`/`or` on bool, because short-circuiting differs from bitwise ops.
- Decided with the user: float comparisons print `exceptions=` only. Clang 22 under -ftrapping-math emits `constrained.fcmps` for relational and `constrained.fcmp` for equality, so the op implies signaling vs quiet.
- Scope limited by the user to comparisons, logical ops, and bool literals: no `?:`/select and no `from_bool`. A bool used as an integer operand returns `unsupported: bool operand used as an integer (requires from_bool conversion)`; that check runs before the mixed-type check.
- sema::numeric split into resolve_binary/resolve_unary_arith/compare/logical/condition helpers. The div/rem why-comment was re-inserted via shell (the hook strips comments from Write).
- Fixtures: new sema/bool.c (-std=c23), float comparisons in flags_exceptions.c, a synthesized-zero span in spans.c, and BOOL_ARITH/BOOL_COMPARE/BOOL_PLUS/MIXED_COMPARE in unsupported.c; LOGICAL_NOT removed and OPERATOR now uses a comma expression.
- wiki: ir-spec.md numeric seed, conversions table, short-circuit names; compiler-flags.md summary.
