# Lower function pointers and indirect calls in the slate frontend

_2026-09-30 20:00:22_

slate-p58o.3.11.

- ptr<fn(..)> (prototyped, non-variadic, C convention) lowers to rust::Type::FnPtr with a new Abi::Rust, printed as Option<unsafe fn(..) -> T>. Defined functions are plain Rust fns (abi: None), so the pointer uses the Rust ABI; the legacy FnPtr users keep C-unwind.
- function_decay of a defined function lowers to Some(f). Decay of an extern function is a lowering barrier: an extern "C" fn cannot coerce to the Rust-ABI pointer type. The lowerer's names map now records is_extern per function.
- null<ptr<fn>> lowers to None; eq/ne against null compare Options.
- Callee::Indirect lowers to unsafe { p.unwrap()(args) }.
- Promoted function_pointers.c and unused_params.c. function_pointer_presence.c and ternary_function_pointer_select.c moved to slate-p58o.3.29; both now block only on conditional.
- Bead cleanup: 3.11 acceptance is raw-lowering differential only; dropped stale deps on 3.10 and 2.
- .beads/issues.jsonl carried 35 bd memories from the slate-parser merge. Auto-export never writes memories, so its shrink guard refused every write. Re-exported once without memories (all 35 are still in the Dolt DB).
