# Fix silent constant-folding defects

_2026-09-17 15:20:12_

const_expr::Parser binary_operator now uses real C precedence (previously shifts/relational/equality/bitwise/logical shared levels, so #if 1 | 2 ^ 3 folded as (1|2)^3). WideInt binary/compare now wrap operands to the combined type first, and evaluate_with_defined uses the wide evaluator with pp_unsigned tracking so #if -1 < 1U is false like clang. Enum initializers and array bounds evaluate through TypeResolver::constant_integer (typed: casts narrow, conditionals/commas supported) instead of the untyped const_expr evaluator that ignored casts. Five gcc fixture AST expectations regenerated via tools/update_filecheck.py after the precedence change; suite green. Probes match clang for #if 1|2^3, #if -1<1U, and enum NARROW=(unsigned char)257 -> 1.
