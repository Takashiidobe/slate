# Elision after designators, flexible array layout

_2026-09-18 18:15:46_

Designated items now take the cursor (fill/designated/apply): a designator whose target is an aggregate and value a bare expression goes through init_subobject/init_expr with the pending value, so '.a = 1, 2, 3' continues elision; fill skips the designator break while cursor.pending is set. Flexible array member: layout_record gives a trailing unsized array in a struct size 0 and element alignment; initializable() excludes it so positional init and zero_fill skip it; '{1, {2,3}}' reports 'flexible array member initializer'. Element initializers remain unsupported (new bead: needs an IR decision for per-object FAM extent). Fixture sema/designator_elision_and_flexible_array.c; ir-spec updated.
