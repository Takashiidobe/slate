# AArch64 vg clobber

_2026-11-01 22:02:44_

slate-3f8g.4.32: a vg clobber was emitted as lateout("vg"), which rustc rejects ('unknown register'). lowerer/asm.rs now drops it unless the function enables sve*/sme* (self.target_features), where it is a barrier 'vg clobber in an SVE function'. clang rejects vg, so the fixture is gcc-only: gcc/aarch64/asm_aarch64_vg_clobber.c. Doc: wiki/concepts/ir/asm.md. Features set only by compile flags (not target attributes) are not seen.
