# structure_goto stage 4: irreducible SCCs get a scoped dispatch loop

_2026-09-03 22:02:10_

slate-04q.85.6. Instead of a second emitter for irreducible regions, the graph
is made reducible up front and stage 3's emitter runs unchanged.

For each SCC with two or more entry points (Tarjan; an entry is a member with a
predecessor outside the SCC, or the graph entry itself), insert a synthetic
header block whose terminator is `Switch(__state, entries)`, then redirect every
edge targeting an entry through a fresh trampoline block that assigns `__state`
and jumps to the header. The header then dominates the whole SCC, its cycles
acquire real back edges, and the existing loop machinery emits exactly the
`loop { match __state { .. } }` the bead asked for — scoped to the SCC, with the
prologue and epilogue as ordinary straight-line code around it.

**Trampolines must be per edge, not per target.** A trampoline shared by all
edges into entry `v` is reachable from outside the SCC, so the header does not
dominate it, so its edge back to the header is not a back edge and the region
stays irreducible. One trampoline per edge gives each a single predecessor:
those on internal edges are dominated by the header (back edges), those on
external edges are not (forward edges). Verified on goto_irreducible before
committing to it — the shared-trampoline version leaves the graph irreducible
and the whole thing falls back to a whole-function dispatch loop.

Internal edges into an entry need redirecting too, not just external ones.
Skipping them leaves cycles whose members are entered from two directions.

The `__state` declaration is kept when a split happens (`keeps_state`), and if
the graph entry itself lands inside an irreducible SCC the header becomes the
new entry with a `__state = <entry>` preamble.

goto_irreducible: 7-arm whole-function dispatch loop -> straight-line prologue,
a 2-arm loop over the cycle, straight-line epilogue. New
goto_irreducible_islands.c has two independent irreducible regions and gets two
separate scoped loops sharing one state variable. Computed goto still bails at
the non-literal state assignment and keeps its whole-function loop.
