# slate-8ge7.24.15 truth-locals: int locals holding only 0/1 lower as bool

_2026-11-22 09:08:11_

- bead: slate-8ge7.24.15
- kind: rewrite
- area: crates/slate-analysis/src/transform
- area: crates/slate/tests/fixtures.transforms/truth-locals

Outcome: C int locals that only ever hold 0 or 1 (flags, stored comparisons) now lower as Rust bool instead of i32 with `as i32` / `!= 0` round trips.

Before (`int lo = a < b; int hi = b <= c; int both = lo && hi; if (!both) ...`):

    let lo: i32 = (a < b) as i32;
    let hi: i32 = (b <= c) as i32;
    let both: i32 = (lo != 0 && hi != 0) as i32;
    if both == 0 {

After:

    let lo: bool = a < b;
    let hi: bool = b <= c;
    let both: bool = lo && hi;
    if !both {

Rule: new IR transform `truth-locals` (crates/slate-analysis/src/transform/truth_locals.rs),
last pass in Slot::AfterMacroStrip, after decl-init. `Scan` counts places/reads/writes/truth uses
per automatic integer `Statement::Let`, records each definition's proof (const 0/1, from_bool,
conditional of proven arms, read of another candidate), then solves an optimistic fixpoint.
`Retype` sets the Let/Place types to bool, folds ne/eq(read, 0) to read/not(read), wraps other
reads in from_bool<int>, and strips from_bool/converts constants in definitions.

Blocked by: any definition not provably 0/1 (calls such as rand(), arithmetic, ++, a stored 2,
no initializer), address-taken, Store/Update, atomic/volatile/register/cleanup/__block, statics,
references in macro regions, nested functions or OpenMP, and macro_values-keyed definitions.
Kept int unless truth uses strictly outnumber integer reads (a tie is neutral, just moves the
cast); a copy into another truth local counts as a truth use.

Fixtures: crates/slate/tests/fixtures/int_truth_locals.c,
crates/slate/tests/fixtures.transforms/truth-locals/{proven,kept}.c. Nine existing fixtures
regenerated (goto_loop_exit_join `done`, object_alignment `ok`, ternary_function_pointer_select
`useAdd`, ...).

Limits: assignment-in-condition (`if ((x = a < b))`) goes through a synthetic temp and stays
int; char/short flags read through an integer promotion count as integer uses; the pass does
not run in the --merge BeforeMacroKeep slot.

See: slate-8ge7.24.6 (truth-canonicalize), wiki/concepts/slate-analysis.md#truth-locals
