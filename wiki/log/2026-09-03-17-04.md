# Port ConstantIndexCasts rule to worklist engine (slate-y0qs.11)

_2026-09-03 17:04:15_

Added constant_index_casts.rs to the arena/worklist engine, mirroring
peel_casts.rs's kind/expr-fold shape. Collapses arr[(N as I1 as I2 ... as
usize)] into arr[N] when N is a nonnegative integer literal representable at
every intermediate signed-cast width in the chain, dropping the cast
entirely rather than retyping it (matches the retired query-engine
ConstantIndexCasts behavior, generalized to peel through multiple
intermediate signed casts instead of only one level).

Fixture: tests/fixtures/constant_index_cast.c. Wired into
src/backend/engine/rules/mod.rs registry() next to peel_casts.

Non-literal index variables (e.g. a let-bound temp not yet inlined) are left
alone, matching acceptance criteria; narrowing-unsafe intermediate casts
(literal too large for an intermediate width) are rejected via a
nonnegative_bound() check per Prim.
