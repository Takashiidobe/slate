# port late_inline_temps to the worklist engine

_2026-08-28 07:23:20_

Ported LateInlineTemps (src/backend/engine/rules/inline_temps.rs), the sibling
of the already-ported EarlyInlineTemps, into the new arena/worklist engine
under slate-y0qs.3. Registered at priority 41 (src/backend/engine/rules/mod.rs),
matching its position in passes.md's pass catalog.

Same matcher/algorithm as EarlyInlineTemps::apply, differing exactly as the old
query-engine's shared `apply(case, binding, phase)` did: (1) drops the extra
`early_effectful_consumer` restriction that only gated effectful producers in
the early phase, and (2) adds `is_allowed_argument_use` (ported from
`is_allowed_argument_use`/`type_stable_arg_init`/`call_or_macro_arg_use`/
`method_arg_use` in the old code, Stmt-based -> NodeKind-based) so late-phase
inlining is also allowed into call/macro arguments when the temp's init is
type-stable, not just into receiver positions.

Validation: cargo nextest --release --profile rewrites, 110/110 (one unrelated
failure on first run traced to a stale target/test-cache dep-info file,
reproduced identically on baseline main with the cache cleared -- not caused by
this change). fmt/clippy clean.

Timing (libexpat, 21 TUs, ~/c-corpus/libexpat/expat/build/compile_commands.json,
translate-project --lib --compile-commands, 3 runs each, wall clock):

- new engine, 5 rules (before this port): ~5.02s
- new engine, 6 rules (with LateInlineTemps): ~5.6-5.8s (+~0.6-0.7s marginal)
- old salsa/query engine, LateInlineTemps alone (wiki/log/2026-08-27-13-38.md's
  per-pass breakdown): 2.0s in isolation

Not a strict apples-to-apples (old number is one pass's isolated full-program
walk under the old engine; new number is the marginal cost of adding a 6th
rule to the new engine's single shared worklist walk), but it's the same
comparison EarlyInlineTemps's port made against its own 4.6s isolated-walk
number, and shows the same qualitative win: adding a rule to the shared
worklist costs a fraction of what a dedicated full-program walk cost under the
old engine, which is the core bet slate-y0qs.3 is making.
