# header-wide oracle declaration probes

_2026-09-08 15:45:04_

Extended the oracle declaration probe from one selected function to every externally linked function exposed by a selected oracle header. The inventory writes canonicalized oracle declarations under target/libc-declaration-probe and emits one shim-only compilation/link probe with per-symbol type assertions and relocations. Typedef aliases are desugared from the oracle AST so private spellings do not hide actual shim compatibility failures. Added a normal glibc x86_64 strings.h integration test, which validates the complete generated header probe. Manual emit and verify runners remain configurable with SLATE_LIBC_DECL_{LIBC,ARCH,HEADER}; fcntl.h now reports its missing *64 declarations and openat2 const mismatch as expected.
