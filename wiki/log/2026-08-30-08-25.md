# pointer-lattice: field-store target must observe write

_2026-08-30 08:25:19_

slate-a28e.2: store through pointer arg cast to *const not *mut. The interproc pointer lattice place() in src/backend/interproc/pointer_lattice.rs did not handle Expr::Field/TupleField. A store out->a = x lowers to a Field target whose base derefs the ptr param; place() fell to the 'other => self.expr(other)' arm which drops is_write, so the write bit was never observed. Param resolved to RawConst and backend emitted (*(arg as *const T)).field = ... (or *const-as-*mut double cast), tripping E0594/E0596 (6x in lz4io.rs). Fix: add Expr::Field | Expr::TupleField => self.place(base, is_write) so field stores propagate write to the base pointer; param now resolves to &mut T with clean (*arg0).field = x. Fixture: tests/fixtures/ptr_param_field_store.c (uses ->). Two pre-existing fixtures (ptr_member_store_unsafe, array_one_past_end_bound) had encoded the buggy &T+double-cast output; FileCheck blocks regenerated to correct &mut T.
