# Remove windows-sys bindings; probe all system declarations in libc-gen

_2026-11-07 13:12:24_

slate-j3by.12: windows-sys record mappings (OPENFILENAMEA, WNDCLASS, STARTUPINFO...) used *mut c_void / *const u8 fields while slate lowers field writes with its own C types (*mut HWND__, *const i8), giving ~40 E0308 in PuTTY plink. Win32 decls are windows-only so the paths never merged cfgs anyway.
Removed: windows-sys provider (providers.rs inventory, features(), system_abi, with_windows_features), windows.h probe, --support-manifest, windows-sys feature discovery in rust_side::prepare_libc, libc_catalog::shape's system arg (extern "system" shapes), vendored windows-sys/windows-link + their embedding (build.rs, main.rs, tests/support, Cargo.toml include list), slate-support's windows-sys dep and slate_support::windows re-export.
The windows.h --all-declarations probe had incidentally covered UCRT CRT functions declared in nested headers (malloc/free/memset/strchr/wcslen/qsort in corecrt_malloc.h, vcruntime_string.h...): the reachability filter only keeps decls physically in the -include'd header. libc-gen now probes every header on every target with --all-declarations (c_side.rs, symbols.rs via parse_module_all_declarations), falling back to the filtered parse if the full parse fails. Catalogs are a strict superset of HEAD on every target except winsock's SOCKET/sockaddr/timeval on Windows (glibc +376, apple +202, android +74, windows CRT 208->220).
Parser: implemented complex machine modes SC/DC/XC/TC (sema/types.rs machine_mode; glibc bits/floatn.h __cfloat128 hit 'not implemented' under all-declarations). Fixture clang/linux/x86_64/complex_machine_mode.c, sizes match clang. Remaining full-parse gaps filed: slate-e36k.9 (SVE types, aarch64 math.h), slate-e36k.10 (xmmintrin convertvector/nontemporal_store, MSVC wchar.h).
Regenerated FileCheck: msvc/windows_sys.c (local decls, no casts), gnu_libc_{algorithms,allocation,platform}.c, fixtures.merge/libc_{spellings,symbol_paths}.c (more shared mappings, fewer cfg variants). macro_calls.c unchanged. parser 8999/8999, msvc 475/475; slate profile failures were only those FileCheck blocks. PuTTY plink: windows-sys E0308s gone; 6 remaining errors tracked in slate-yar4.27/.28.
