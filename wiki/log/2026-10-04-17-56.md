# Fold bit builtins in constant expressions (slate-parser-6x05.38.13, .38.21)

_2026-10-04 17:56:19_

- Kernel ilog2() is 63 - __builtin_clzll(x); struct zone's vmemmap_tails size uses it, so 119 TUs failed with 'nonliteral numeric expression'. .38.21 (ilog2 in a designator) was the same cause.
- constant_value_with_context (sema/types.rs) now folds BitBuiltin calls (sema/builtins.rs): clz/ctz/popcount/parity/ffs/clrsb with l/ll/s forms, bswap16/32/64, bitreverse8..64, clzg/ctzg with optional fallback. Arguments convert to the builtin's parameter type via call_signature; fold::bit_builtin computes the value.
- clz/ctz(0) without a fallback: clang rejects, gcc folds to the width.
- _Static_assert used to skip foldable builtin calls (Shape::Skip), so a false assertion on __builtin_clz was accepted; bit builtins now evaluate.
- Initializers outside constant contexts still keep the call in the IR.
- Fixtures: {clang,gcc}/linux/x86_64/bit_builtin_constants.c (18 enumerators match native clang/gcc output), error/clang bit-builtin-clz-zero.c and static-assert-bit-builtin-false.c; dropped the BUILTIN case from error/clang unsupported.c.
- mm/filemap.c and lib/sys_info.c parse with their kernel compile commands. Parser profile: 7739 passed, plus unsupported.c after the fix.
- Follow-ups: .38.27 popcountg has no typing rule; .38.28 gcc flavor accepts clang-only clzs/bitreverse.
- AGENTS.md: added a Shell section (fish; use scratchpad python scripts for loops and argument lists).
