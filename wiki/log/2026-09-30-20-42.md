# Lower scalar globals and constant initialization in the slate frontend

_2026-09-30 20:42:37_

slate-p58o.3.18.

- Non-string globals lower to static mut items. Initializer: constants, conversions, and aggregates of those (struct/array literal or zeroed-temp block, both const-evaluable); no initializer -> unsafe { std::mem::zeroed() }. Anything else (pointer initializers) is 'initialized global X' -> 3.34.
- Declarations without a definition become ExternDecl::Static in the extern "C" block.
- Barriers kept for Phase 4: thread storage, any non-default SymbolAttributes, volatile/atomic access, and explicit alignment. The x86-64 16-byte large-array ABI alignment is accepted (Rust cannot align a static directly, and it is not a user _Alignas).
- Reads/writes of places rooted at a static wrap unsafe (place_is_unsafe now covers statics as well as derefs). Array decay of a static uses addr_of_mut!(G) as *mut T to avoid edition-2024 static_mut_refs errors.
- Rust let bindings cannot shadow statics, so locals and parameters with a static's name become name_<id>.
- code_units globals still go to the read-only byte-string map (noted on 3.19 for writable char arrays).
- Fixtures: global_vars, static_globals, global_bool, non_int_globals, logical_ops, new global_shadow_extern (local/param shadowing, &global, late-defined extern). Also promoted 15 more local fixtures, 154 gcc-torture, 11 gcc-dg, 4 c-testsuite.
