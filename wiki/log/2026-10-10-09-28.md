# Skip null-pointer-constant folding for non-pointer conversions

_2026-10-10 09:28:53_

Implemented slate-parser-6x05.38.34 (perf of net/mac80211/airtime.c under --flavor=clang).
- Profiled with perf (line-tables debuginfo + frame pointers in a separate target dir).
- record_conversion called null_pointer_constant on every converted operand; for
  integer operands that folds the whole subtree, so nested constant arithmetic
  re-folded at each level (quadratic). Introduced in 4c35e3d9a (2026-09-28).
- classify_conversion only reads the flag for pointer and nullptr_t targets, so
  record_conversion now computes it only for those.

- intel_snps_phy.c (.35): 15.4s -> 11.6s.
- Caching numeric::Context in TypeResolver (to avoid cloning TargetInfo per
  constant_value) measured no gain; perf blamed it via inlined frames. Not kept.
