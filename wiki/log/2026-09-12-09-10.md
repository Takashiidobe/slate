# Replace ad-hoc lex() with a Lexer struct

_2026-09-12 09:10:14_

Reworked lexer::lex into a Lexer struct (pos/mark fields) instead of threading explicit start/end offsets through every token-emit call site. mark is set to pos at the top of each loop iteration (after whitespace/comments are skipped); emit() reads mark..pos to build the token's Loc automatically. lex(file, src) is now just Lexer::new(file, src).tokenize().

This replaced the earlier push(&mut tokens, token, start, end) pattern, which required every branch to track its own start/end locals -- error prone and repetitive. Only lexer.rs changed; still 86 errors in parser.rs + 12 in pp.rs from downstream consumers expecting the old Vec<Token> lex() signature.
