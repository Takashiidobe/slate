# Size void-typed expressions as 1 in sizeof and _Alignof

_2026-10-05 07:54:14_

Closed slate-parser-6x05.38.14. The kernel's 'unsupported scalar storage layout for void' (95 TUs, reported at kmalloc_flex) was not _Generic or __builtin_counted_by_ref: struct_size's __is_constexpr takes sizeof(*(8 ? (void *)(n * 0l) : (int *)8)), which is sizeof of a void expression when n is non-constant (GNU: 1). Reduced to 'sizeof(*p)' with void *p. sizeof(void) already used TypeResolver::sizeof_storage, but the expression forms (operand_layout in typer.rs, SizeOfExpr/AlignOfExpr lowering in expression.rs, constant_value_with_context in types.rs) called qualified_storage directly. All three now use sizeof_storage, which also fixes __builtin_choose_expr over such a size (it surfaced as 'selection not recorded by the checker') and file-scope array bounds. Fixture: clang/linux/x86_64/ir_sizeof_void_expression.c. initramfs.c now stops at __builtin_counted_by_ref, which slate advertises via __has_builtin but does not implement (filed .38.29). Also filed .38.30 (trailing packed attribute on enums ignored) and slate-parser-v74.6 (MSVC: sizeof(void) is 0 and *voidp is C2100 in cl.exe). Parser profile: 7740/7740 pass.
