# libc probe header inventory

_2026-09-08 07:58:00_

Compared ~/standalone_musl with /usr/include and inspected the existing libc-shim surface. Identified shared Linux ABI records to extend (statx, procfs, resource, fanotify, signalfd, inotify, TCP) and libc/header-specific availability records (mount_attr, rseq, pidfd_info, sys/user.h). Recorded the implementation order and the need for explicit presence records because musl has no standard identity macro.
