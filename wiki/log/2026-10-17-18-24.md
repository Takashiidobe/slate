# Fold constexpr reads and byte-array wide constants in static initializers

_2026-10-17 18:24:47_

A read of a C23 constexpr global inside a static initializer lowers to that global's initializer (Tables.constexprs, FunctionLowerer.in_static_initializer), so c = a + b over constexpr \_BitInt(16319) globals is a const expression. The generated crate gets #![allow(long_running_const_eval)] only when such a read is inlined. Wide \_BitInt constants beyond 128 bits now lower to BInt/BUint::from_le_bytes::<bits, bytes>([..]) byte arrays (BigUint::to_bytes_le with a zero pad, BigInt::to_signed_bytes_le) instead of from_decimal_str, which const evaluation could not finish. Promoted gcc-dg bitint-38; regenerated FileChecks for bitint_arith, bitint_storage and goto_into_later_switch_case_bitint.
