# slate-8ge7.2.3 Hoister macro_keep: value MacroExpansion no longer stops hoisting; split expansions inline (hoist_split_region); keep runs once in slate, with_macro_keep removed

Outcome: effect hoisting no longer stops at a `ValueKind::MacroExpansion`, so normalization is the same with and without macro structure; split value expansions stay inline, and macro_keep runs once in slate after sema instead of as a sema callback with a re-normalize fixpoint.

Before: `Hoister::hoist_value` (sema/effects.rs) kept a value expansion's hoisted statements in its `evaluation.statements`, so hoisting depended on which expansions existed. `Sema::with_macro_keep` passed slate's `macro_keep::kept_expansions` into `finish_module`, which normalized, asked keep, restored the unnormalized bodies, stripped the rejected expansions and normalized again until the kept set stopped shrinking (`normalize_kept_expansions`).

After: the hoister pushes a value expansion's effects into the enclosing `out` like any value and records the expansion in `Hoister::split_expansions` when it emitted statements; `effects_statements::normalize` writes those into `Module::macro_rejections` as `hoist_split_region`. Sema always returns the full structure (`MacroKeep`, `with_macro_keep` and `normalize_kept_expansions` removed). `frontend::lower_parsed` calls `kept_expansions` (its own reasons first, `hoist_split_region` only as a fallback) and `strip_macro_structure`. `check_macro_structure` strips everything from a structured build and compares with the plain build.

Example (macro_values.c): `#define NEXT() (*cursor++)`, `r += NEXT();`
  before: `r += NEXT!();` with a `NEXT` block template
  after:  `let __v = cursor; cursor = __v.add(1); r += *__v;` (inline; report `NEXT: 0 lifted, inline: hoist_split_region 2`)

Cost, as slate-8ge7.2.2 measured: merge fixtures lose NEXT, NEXT_FROM, BUMP_AND, ASSIGN_TO, STMT_EXPR, BOTH, EITHER, PICK, TAKE, UPDATE_CHECK and one MIN site; slate fixtures lose START_OR_INDEX, hybrid_var, typecheck/time_after and FIND (statement expressions or calls under `?:`). Some report reasons moved: `argument_reads_macro_local` became `hoist_split_region` or `argument_split_across_holes` because argument temporaries now hoist out of the expansion.

Fixtures regenerated: fixtures.merge/{macro_argument_effects,macro_control_flow,macro_dispatch_locals,macro_values}.c; fixtures/{macro_field_name_and_place_argument,macro_typecheck_const_typeof_local_address,null_deref_macro_args}.c, fixtures/x86_64/null_ternary_dead_arm.c; parser macro_nodes.c (a written-cast `[macro_cast="i64"]` now survives hoisting).

Runs: parser 9330/9330, merge failed only on the four regenerated fixtures, slate generated_differential failed only on the four regenerated fixtures.

Limits: split expansions are not recovered; folding a contiguous hoisted run back into a block template is left for later (slate-8ge7.2.3 notes). Value and place wrapper nodes still exist.
