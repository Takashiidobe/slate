# Drop pure statements and empty blocks left by NDEBUG assert

_2026-10-18 17:56:47_

slate-o3gw.3. New rewrite rules in crates/slate/src/backend/engine/rules/pure_stmts.rs:

- pure_stmts::drop removes expression statements whose expression is pure
  (literals, vars, paths, casts, field reads, !, &raw, bit/compare/logical
  binary ops), plus scopes, unsafe blocks and blocks holding only comments, and
  if statements with a pure condition and comment-only branches. Arithmetic,
  shifts, division, deref, indexing, calls and macros are never pure: they can
  panic or have effects. The function's tail expression is kept.
- pure_stmts::empty_else moves a comment-only else body after the if.
- pure_stmts::empty_then rewrites if c {} else { b } to if !c { b }, flipping
  == and != directly (no other comparisons, because of NaN).
  loop_to_while::negate is now pub(super) and shared.
- Arena::move_comments_after hoists comments behind an anchor.

Removing assert's ((void)0) and cleaning up if c {} else heads left by
control-flow structuring also lets label_elide drop \_\_join blocks that no
longer have a break. Fixture: tests/fixtures/assert_ndebug_pure_stmts.c.
