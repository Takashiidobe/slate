# Fix silent-zero long double aggregate constants; promote c2y-complex-1

_2026-09-06 15:24:31_

slate-i3nv.5.2: fixed the root cause diagnosed earlier (render_const_value_expr's
'_ if matches!(ty, Type::LongDouble)' wildcard arm, src/frontend/lowerer.rs ~2928,
gave up with None whenever facts was empty, discarding an already-correct
Attr::CirFloat/Attr::Float value straight from CIR). Added a fallback arm that
parses that CIR text directly, dispatching on whether it's decimal
(f80_literal_expr, via rustc_apfloat::ieee::X87DoubleExtended -- an exact
arbitrary-precision parser) or raw hex bits (f80_literal_bits_expr) --
mirroring the existing dispatch already used for ConstComplex real/imag parts
a few hundred lines up in the same match.

The hex-bits case was found via a user-requested regression probe: a struct
field holding an f80 literal whose magnitude/precision exceeds f64's 53-bit
mantissa. CIR prints such values as raw hex bits (#cir.fp<0x403B...>), not
decimal -- my first pass only handled the decimal form and silently re-zeroed
the field for this case. Fixed and verified bit-exact against native C
ground truth.

This also incidentally resolved slate-i3nv.5.1's concrete manifestations (the
same wildcard arm handles compiler-synthesized ++/-- constants): un-skipped
tests/fixtures.link/long_double (all 3 link fixtures now pass, KNOWN_BROKEN_FIXTURES
removed from tests/link.rs), regenerated the stale long_double_x86_64_gnu
target-check FileCheck snapshot, and promoted
tests/fixtures.gcc-dg.unsupported/c2y-complex-1.c (_Complex long double ++/--)
to tests/fixtures.gcc-dg/ per gcc_dg_unsupported_tests_still_fail's own
prompt, generating its FileCheck blocks. slate-i3nv.5.1 stays open/blocked --
the underlying upstream ClangIR/MLIR printer gap is unconfirmed as fixed in
principle, just unexercised by any current fixture now.

Added tests/fixtures/long_double_aggregate_increment.c as a permanent
regression fixture: a struct-embedded f80 literal beyond f64 precision,
incremented via ++, dumped byte-exact and diffed against native C.
