# slate-8ge7.2.3 ir: value macro holes and expansions move from MacroArg/MacroExpansion nodes to Module::macro_values overlay

_2026-11-21 14:36:27_

- bead: slate-8ge7.2.3
- kind: parser
- area: crates/slate-parser/src/ir
- area: crates/slate-parser/src/sema
- area: crates/slate-analysis/src
- area: crates/slate/src/frontend

Outcome: value macro holes and value expansions are no longer IR nodes; `Module::macro_values` (`NodeId -> Vec<MacroWrap>`, innermost first) records them, and `ValueKind::MacroArg`, `ValueKind::MacroExpansion` and `Value::without_macro_structure` are gone.

Before (`--show-macros`, `int k = TIMES2(i);`):

    macro_value<i32>(#1, statements=0, mul<i32>(macro_arg<i32>(#1, 0, read<i32>(%i)), const<i32>(2)))

After:

    mul<i32>(read<i32>(%i) [macro_arg="#1.0"], const<i32>(2)) [macro_value="#1"]

Implementation:
- slate-parser `ir::MacroWrap { Value(E), Argument { expansion, argument } }`; sema's `macro_value_holes`/`expr` push wraps instead of building nodes. `written_cast_hole` reads the outermost wrap.
- `ir::walk_body_with_macros` replays wraps around a value (`Visitor::macro_value`, then `enter_expansion`/`enter_value_hole`). `macro_keep` Survey and CallerLocals use it; `argument_split_across_holes` and `void_value` moved to the `macro_value` hook.
- Read-through arms removed from fold, numeric, asm, sequencing, object_size, counted_loops and def_use.
- slate-analysis: `inline_temporaries` treats any wrapped value as nested (temp stays a temp); the pointer analysis counts `MacroWrap::Value` into `macro_depth` (pinned calls) and flags bindings under an argument wrap as `MACRO`. New `Program::unit`.
- effects: `macro_roots` now includes argument wraps, so a hole whose value hoisted statements, or whose root node was replaced, marks its expansion `hoist_split_region`. Without this the hole was silently lost and the expansion lifted as a zero-parameter template with the argument baked in (`CHECK(a && f())` in msvc/conditional_global_initializers).
- Lowerer: `lower_macro_wrap` peels a node's outermost pending wrap (`peeled_macro_wraps`) before the inlined-temp and written-cast checks; an identity written cast (operand is the node itself) lowers before the wraps, as the cast sat outside `MacroArg` before. Promoted/truthiness holes peel the operand's wrap instead of `strip_promoted_hole`. Template check no longer remaps written casts (ids are stable).

Fixtures: 7 parser macro fixtures (printing only); merge macro_values (rejection labels only: `argument_split_across_holes` -> `hoist_split_region`, same lifted counts, since holes no longer print inner expansions' ids); x86_64 asm_immediate_after_inlining (template reuses the identical `branch(&k2, 0)` specialization), x86_header_expanded_builtins{,_2} (SHOW sites whose hole hoisted statements now stay inline).

Limits: `PlaceKind::MacroArg` is still a node because `ir::Place` has no `NodeId` (slate-8ge7.2.4).
