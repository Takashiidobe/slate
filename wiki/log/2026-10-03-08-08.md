# Keep address-taken mergeable functions distinct; rewrites always on

_2026-10-03 08:08:10_

slate-dghn.18. rustc's MergeFunctions aliased redis evalRoCommand to evalCommand (fns are unnamed_addr), breaking eval.c's c->cmd->proc == evalRoCommand.

- Analysis (frontend/distinct_functions.rs, IR -> facts): lowering already visits every function_decay through lower_function_address, so it now records the BindingId (externs included) in Lowered.address_taken: no extra IR walk. mergeable_address_taken runs over all units: a definition is protected iff its address is taken (locally, or via an extern decl of its symbol in any unit) and another defined function shares its signature shape. Shapes: pointers equal, ints by width, f16/f32/f64; any aggregate/f80/_BitInt makes the shape an arity range (n - aggs ..= n + aggs + 1) matched against all definitions. O(functions). ELF targets only; functions with a user section are skipped.
- Rewrite: backend::place_in_distinct_sections adds #[unsafe(link_section = ".text.slate_distinct.<unit>.<name>")]; MergeFunctions never merges across sections. Runs in translate-project and single-file translate (frontend::lower_single_module).
- Rewrites always on: removed translate-lowered, translate-project --raw, SLATE_RAW_LOWER/lowering-profile escape, tools/benchmark/sqlite.py --raw. Differential and corpus suites translate with `translate`. Docs updated.
- Test: tests/fixtures.release/function_identity_merge.c via release_build_differential (translate-project + cargo build --release); failed before (all table entries compared equal), passes now.
- The full backend on all suites exposed 20 rewrite bugs; fixtures demoted to *.unsupported and tracked: dghn.19 dead-store untyped initializer (12), dghn.20 cast as assignment lhs (6), dghn.21 block-expr cast parenthesization (1), dghn.22 scoped_local_bindings miscompile (1).
