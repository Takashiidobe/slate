# Lua e2e: computed goto, label addresses, global visibility (slate-dghn.29)

_2026-10-05 13:55:18_

Lua (34 TUs) now translates with 0 barriers and the translated interpreter passes testes/all.lua (final OK, 4.7s vs 4.5s native).

Lowering:
- Globals ignore ELF visibility like functions already did (hidden/internal/protected only narrow dynamic export); this reverses the slate-dghn.8 decision to keep non-default visibility a barrier. Fixture global_visibility_internal.c.
- label_addr lowers to the constant pointer (label id + 1); label tables and label deltas (&&a - &&b, folded) are constant initializers; void* offsets from a label address use wrapping_offset.
- ComputedGoto forces CFG dispatch; its node matches target as usize against every label in the function, jumping to that label's state, else unreachable!().
- Promoted computed_goto_ops, computed_goto_label_delta, mem2reg_computed_goto, 8 gcc-torture (20040302-1, 20041214-1, 20071210-1, 920501-4/5, 980526-1, 990208-1, pr70460) and gcc-dg split-5.

Harness (tools/corpus/e2e.py): Recipe gains test_dir and test_patches; test commands get a closed-pipe stdin. lua recipe: LUA_O+CORE_O+AUX_O+LIB_O, -Wl,-E -ldl, make -C testes/libs, ../lua all.lua in testes/. files.lua's sh -c 'kill -s HUP $$' row is dropped in the sandbox: bash as /bin/sh reports signal, so it fails natively too. lua_benchmark times five lua -e scripts: geomean 1.56x native, fib 2.78x (filed slate-dghn.31).

_setjmp/_longjmp still lower as plain FFI calls (no returns_twice); errors.lua and coroutine.lua pass at release.
