# Raise record alignment for u64 bit-field units on i686

_2026-11-02 08:08:44_

slate-yar4.9: lower_bit_unit reported a u64 unit as align 8, but Rust u64 is align 4 on i686, so the record skipped align(8) and was smaller than C (flag_ms_bitfields widening: 16 vs 24). It now reports min(unit size, Rust alignment of the backing integer), so record lowering raises the record with align(8). Removed bit_unit_keeps_its_alignment from rust_layout_matches_c since layouts now match. Fixture: i686/ms_bitfield_u64_unit_layout.c (runtime stride and offset); flag_ms_bitfields now emits size_of on i686.
