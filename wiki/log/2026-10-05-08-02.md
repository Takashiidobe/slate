# Implement __builtin_counted_by_ref and model counted_by

_2026-10-05 08:02:10_

Closed slate-parser-6x05.38.29. slate answered __has_builtin(__builtin_counted_by_ref) true but had no lowering, so the kernel's __set_flex_counter (overflow.h) failed in kmalloc_flex: the builtin as a _Generic controlling expression surfaced as 'selection not recorded by the checker'. counted_by(ident) is now Attribute::CountedBy (both flavors; Use::Ignored for applicability). define_tag records each field's counter name in TypeResolver::field_counters, parallel to record_fields. CustomBuiltin::CountedByRef: the checker (TypeResolver::counted_by_ref) takes a parenthesized ./-> member of pointer or array type, finds its counter through anonymous members like member_type, and types the call ptr<counter's declared type> (base qualifiers dropped, as clang does) or void *. Lowering emits addr_of(base->counter) via member(), or null<ptr<void>> without evaluating the argument. Clang-only errors (side effects, result assigned/passed/returned/subscripted/binary) are not enforced: gcc has none, and too permissive is allowed. counted_by_or_null and sized_by stay unmodeled and give void *, matching clang. Fixtures: clang/linux/x86_64/ir_counted_by_ref.c (kernel __set_flex_counter shape, anonymous counter, pointer member, dot base) and error/clang/linux/x86_64/counted-by-ref-not-member.c. Wiki: ir/builtins custom lowering, attributes consumers, compiler-flags late-parse note. init/initramfs.c now parses. Parser profile 7742/7742.
