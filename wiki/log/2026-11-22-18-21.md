# slate-8ge7.24.19.4 pointer Owner::Vec: malloc/calloc byte buffers that never escape lower to Vec<T>, realloc to resize, free to drop

Outcome: a local byte pointer whose only defs are `malloc`/`calloc` (plus `p = realloc(p, n)`) and that never escapes is an owned heap buffer (`PointerFact::owner = Some(Owner::Vec)`): it lowers to `Vec<T>` with `vec![0; n]`, `realloc` to `resize`, `free` to `drop`, null checks fold to a constant, and callees it is passed to can lift to `&[T]`/`&mut [T]`.

Before (C: `char *buf = malloc(n); if (!buf) return -1; memset(buf, 'a', n); buf[0] = 'x'; int r = total(buf, n); free(buf); return r;`):

```rust
let buf: *mut i8 = unsafe { (malloc((n as u64) as usize) as *mut ()) as *mut i8 };
if buf.is_null() { return -1; }
unsafe { core::ptr::write_bytes(.., (97i32 as i32) as u8, ..) };
unsafe { *buf.add(0) = 120; }
let r: i32 = total(buf as *const i8, n);   // fn total(bytes: *const i8, n: i32)
unsafe { free((buf as *mut ()) as *mut core::ffi::c_void) };
```

After:

```rust
let mut buf: Vec<i8> = vec![0; (n as u64) as usize];
if false { return -1; }
buf[0usize..((n as u64) as usize) as usize].fill((97i32 as i32) as i8);
buf[0] = 120;
let r: i32 = total(&buf, n);               // fn total(bytes: &[i8], n: i32)
drop(buf);
```

Rule (`slate-analysis/src/pointer.rs`, `Ownership` in the walker, `owned` in `analyze`):
- Candidate (per function): `NodeKind::Local`, 8-bit pointee (not `void *`), not volatile, `let` initializer is `malloc(n)` or `calloc(a, b)` in a hosted, non-`-nostdinc` unit; every other write to the binding is a statement `p = realloc(p, n)`; no goto, label, label address, computed goto or SEH in the function.
- Frees, no CFG: each `free(p)` is either the last read of `p` in walk order at the `let`'s loop depth, or terminal (a run of frees directly followed by a `return` that does not mention `p`). Leaks are fine: Rust drops at scope end.
- Whole program: the copy class is the node alone (no aliases), not ESCAPE/MACRO, not returned, and no callee parameter it is passed to has FREE. `realloc` argument 0 is now FREE (was ESCAPE).
- Null checks (`p == NULL`, `!p`, `if (p)`) are collected separately and seed NULLABLE only on non-owned nodes, so an owned buffer passed to a callee does not make the callee's parameter nullable. Owned classes are not seeded unproven and are not `lowered_raw` at call sites, so callees can lift.
- Fact: `owner: Some(Owner::Vec)` and `borrow: Some(Borrow { mutable: WRITE || reallocated, many: true })`, so every existing slice-view path (indexing, `mem*` buffers, `as_mut_ptr()` reads for raw libc calls) applies unchanged.

Lowering (`crates/slate/src/frontend/lowerer/heap_buffers.rs`): `lower_owned_let` (`vec![0; n]`, `n * m` for calloc), `lower_reallocation` (`resize(n, 0)`), `lower_release` (`drop`), `owned_null_compare` (`false`/`true`); `lower_borrow` passes `&buf`/`&mut buf` to slice parameters.

Fixture: tests/fixtures/heap_byte_buffers.c (malloc/calloc/realloc, early-return free, leak, loop-scoped buffer, free-then-return in a loop, offset argument, callee that frees and a returned buffer stay raw). Regenerated: gnu_library_builtins (`__builtin_malloc` buffer), mem_safe_slice_idioms (`src_g` becomes fill/copy_from_slice).

Limits: element type is 8-bit only (`Owner` is the extension point for `Vec<T>`/`Box<T>`, slate-8ge7.21); printf/puts and other unmodeled libc callees are escapes; `p = NULL` after free, the `q = realloc(p, n)` two-binding idiom, two non-terminal frees on exclusive branches, and any alias (`char *q = p`) leave it raw; folded null checks stay as `if false { .. }`; no CString/String content levels yet.
