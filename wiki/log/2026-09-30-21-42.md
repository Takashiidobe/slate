# slate-p58o.3.8: store expression values

_2026-09-30 21:42:34_

Closed slate-p58o.3.8 (Lower Store expression values) with no lowering
change.

ValueKind::Store never reaches the slate lowerer. The sema effects pass
(sema/effects.rs store(), effects_statements.rs) rewrites every store into
Statement::Write on a once-evaluated place. When the result is used, the
stored value is first bound to a synthetic temporary, which the lowerer
already handles (Write -> lower_assignment, Temporary -> let).

compound_assignments.c and assign_value_in_branch.c already passed. I added
store_expression_values.c as coverage; it passed on first run, so it does
not demonstrate a fix. It covers a = b = c = f() (f called once), (a += 3)
used as a value, assignment as a call argument, slots[idx()] += 5 and
*slot() = v with the place evaluated once (checked via a call counter),
while ((ch = *p++)), *out++ = v, while ((node = node->next) != 0), stores
in both arms of ?:, and a narrowing store whose value is reused.

Atomic stores and reads (ordering = Some) are a separate gap
(param_spill.c: read<i32, atomic=seq_cst>).
