# Lower pointer difference in the slate frontend

_2026-09-30 20:16:17_

slate-p58o.3.12.

- ValueKind::PointerDifference with a sized element lowers to unsafe { left.offset_from(right as <left ty>) } as <result ty>. offset_from already counts in elements, so scaling comes free; the right operand is cast to the left's type so const/mut mixes type-check.
- void and function elements stay barriers: void lowers to (), and offset_from panics on zero-sized pointees. Filed slate-p58o.4.1 for GNU byte-unit void/function pointer arithmetic, which also covers the existing ptr_offset on ptr<void> silently not moving.
- New minimal fixture pointer_difference.c (uninitialized int array, two element addresses, exit code q - p == 2), promoted to tests/fixtures/.
- The originally named fixtures are blocked elsewhere and moved: address_of_array_element.c -> 3.32 (array aggregate init), pointer_compare_address.c and array_one_past_end_bound.c -> 3.15 (records), ptr_out_param_alloca_frame.c -> 3.22 (switch).
