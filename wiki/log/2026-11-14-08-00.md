# slate-dghn.56.4 builtin_intrinsic: clang x86 header builtins _mm_pause/_mm_lfence/_mm_mfence/_mm_sfence had no lowering

_2026-11-14 08:00:29_

- bead: slate-dghn.56.4
- kind: feature
- area: crates/slate/src/frontend/lowerer/intrinsics.rs
- target: x86_64
- flavor: clang

Outcome: clang's x86 header builtins _mm_pause, _mm_lfence, _mm_mfence and _mm_sfence lower to their LLVM intrinsics instead of stopping at "builtin without a lowering".

Gap: the last barrier in the CPython python binary probe (mimalloc atomic.h mi_atomic_yield in Objects/obmalloc.c). Clang declares these as TARGET_HEADER_BUILTINs in BuiltinsX86.td (emmintrin.h/xmmintrin.h); there is no LLVM ClangBuiltin<> link for the header names, so the generated intrinsic catalog only matched __builtin_ia32_pause/mfence/... Clang's CGBuiltin maps the header names by hand.

Before:
```
spin_until  ...:7:5  function  function _mm_pause: builtin without a lowering
```

After:
```
unsafe extern "llvm-intrinsic" {
    #[link_name = "llvm.x86.sse2.pause"]
    fn __slate_intrinsic_...();
```

Implementation: builtin_intrinsic (crates/slate/src/frontend/lowerer/intrinsics.rs) gains explicit names, mirroring CGBuiltin: _mm_pause -> llvm.x86.sse2.pause, _mm_lfence -> llvm.x86.sse2.lfence, _mm_mfence -> llvm.x86.sse2.mfence, _mm_sfence -> llvm.x86.sse.sfence. Only consulted for c_builtin declarations without a body, and the catalog lookup is x86-only.

Fixture: crates/slate/tests/fixtures/x86_64/x86_header_builtin_pause_fence.c (clang flavor, x86_64).

Limits: other TARGET_HEADER_BUILTINs (_mm_clflush, _mm_prefetch, _mm_getcsr/_mm_setcsr, _ReadWriteBarrier, MSVC _mm_* forms) are still unmapped. Not run: the full slate profile, the i686 fixture, and the CPython barrier re-probe.
See: slate-dghn.56.1, slate-dghn.56.2 (closed stale 2026-11-14).
