# slate-3f8g.4.17.14.5 MS asm implicit return capture

_2026-10-12 09:14:31_

Slate's function lowering ignored Fallthrough::Return, so an MSVC function that falls off after __asm returned () (E0308). functions.rs now appends return <value> when the last statement is not a return, wrapped in unsafe under dispatch since the capture lives in a slot. slate-parser's finish_ms_asm_return now always initializes the EAX/EDX capture locals to 0 (was main-only), so a path that skips the asm reads a defined value; 71 parser fixtures regenerated (declaration line only), main_returns_zero parameter removed. Temporary is now always declared mut because the capture is assigned by each asm block after its initializer. Fixture i686/ms_asm_implicit_return.c: int, 64-bit EDX:EAX, uchar and short truncation, pointer via lea of a global, explicit return bypass; matches clang -m32. Filed a bug: a pointer parameter rewritten to a reference breaks the asm addr_of! operand (E0745).
