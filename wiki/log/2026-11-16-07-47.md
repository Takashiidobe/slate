# slate-f2zu.14.40.2 dispatch_cleanup_guard: Guard closure borrowed __slate_slot_N, E0502/E0506 in 32 kernel shards using &scope or reassigning a __free var

_2026-11-16 07:47:55_

- bead: slate-f2zu.14.40.2
- kind: bug
- area: crates/slate/src/frontend/lowerer/control_flow.rs
- corpus: linux

Outcome: dispatch cleanup guards capture a copy of the slot pointer, so goto functions that take &scope or reassign a cleanup variable compile; the kernel builds 84/84 shards again and relinks with 57 shards swapped.

Symptom: after the scoped_guard cleanup fix (053eb8740), re-translating linux left 32/84 shards failing with 716 borrow errors: E0502 `cannot borrow *__slate_slot_0 as mutable because it is also borrowed as immutable` (class_irq_lock_ptr(&scope) in the scoped_guard condition) and E0506 `cannot assign to *__slate_slot_8 because it is borrowed` (__free pointer assigned after declaration).

Reproducer (minimal C):
```c
for (struct guard scope __attribute__((cleanup(guard_release))) = guard_take(lock, 1);
     guard_lock_ptr(&scope); ({ goto done; }))
  if (0) { done: break; } else { *slot += 1; }
```

Cause: dispatch_cleanup_guard (crates/slate/src/frontend/lowerer/control_flow.rs) built the Guard closure around `__slate_slot_N` itself; the closure's capture borrows the slot place for the whole function, conflicting with &mut and assignments through it.

Fix: emit `let __slate_cleanup_ptr_N = __slate_slot_N;` before the armed Cell and call the handler through that copy, as the structured cleanup_guard already did.

Regression test: crates/slate/tests/fixtures/cleanup_scoped_guard_for_goto.c (locked_by_address, reassigned).

Kernel (e2e.py linux --until link --jobs 2): translate 84/84, build 84/84, link 0 errors, 57 shards swapped. objtool: 33 warnings (29 redundant UACCESS disable, 2 unsupported instruction in callable function, 1 sibling call with modified stack frame, 1 return with modified stack frame). Previous relink (22:46) had 37, all UACCESS-enabled warnings.

Limits: boot under run-qemu.py not yet retried.
