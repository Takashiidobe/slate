# Add gcc -Wtraditional preprocessor warnings (cxg.7.25)

_2026-10-10 18:30:54_

slate-parser-cxg.7.25: new Warning::Traditional (-Wtraditional, off by default, raised for the gcc flavor only) with the seven gcc.dg/cpp/warn-traditional.c diagnostics. New pp/traditional.rs: directive indentation (Directive.indented, computed in pp/syntax.rs; K&R directives warn when indented, all others when not, #elif always), run for skipped groups too; 'U' suffix on integer literals; \x \a \u \U in string and character literals. Literal checks run in read_piece on every emitted token and on the tokens of #if/#elif. Function-like macro name without '(' warns in expand_token. Unary plus in #if is recorded by the const_expr evaluator (EvalContext::unary_plus_uses, evaluate_with_defined gained a parameter) so unevaluated arms stay silent.

Verified against gcc 16: warn-traditional.c output matches; '0 && +1', '1 || +1' and the dead arm of ?: are silent. Fixtures: gcc/linux/x86_64/pp_traditional_warnings.c, pp_traditional_off_by_default.c, clang/linux/x86_64/pp_traditional_ignored.c, error/gcc/linux/x86_64/traditional-werror.c. Parser profile 8099 passed. Wiki: diagnostic-severity.md. Known gaps: a function-like macro defined in a system header still warns; escape locations are the escape for plain source literals and the use site for macro-produced ones.
