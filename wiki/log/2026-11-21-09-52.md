# slate-8ge7.16 slate-analysis effects: per-function effect summary; mutable static arrays prove slices when the callee cannot reach them

_2026-11-21 09:52:45_

- area: crates/slate-analysis/src/pointer.rs

Outcome: a mutable static array passed with its full extent lifts the callee to a slice again when a new per-function effect summary (slate-analysis effects::Effects) proves the callee cannot reach the static during the call.

Before (slate-8ge7.15 made every mutable static unprovable):

```c
static int scratch[4] = {1, 2, 3, 4};
static int calls;
static void note(void) { calls++; }
static void scale_untouched(int *p, int n) { for (int i = 0; i < n; i++) { p[i] *= 2; note(); } }
int main(void) { scale_untouched(scratch, 4); scratch[0] += 1; ... }
```

```rust
fn scale_untouched(p: *mut i32, n: i32) {
```

After:

```rust
fn scale_untouched(p: &mut [i32]) {
```

Rule (pointer.rs `proves`, Shape::Array { object: Some(S) }): S is internal, non-const, not volatile/atomic; S's address
never leaks; the callee is not transitively opaque; the callee does not transitively name S; no other argument at the
site names S or contains a call.

Implementation:
- effects.rs: FunctionEffects { names, opaque, callees } per function from the pointer Summary; Effects::new closes
  opaque over callers; Effects::reaching(S) is a reverse search from S's direct namers, run once per proof static.
- Walker.opaque: indirect calls, undefined calls without a libc identity, undefined calls passing a function pointer,
  asm with a non-empty template, escape_all (OpenMP, nested functions).
- Walker::assign records (node, S) in Summary.derived instead of leaking S; after the solve S leaks only if that class
  escapes, is returned, or is passed to any call. This lets `s[0] += 1`'s synthetic ptr_offset temporary stay local.
- Leaks also come from global initializers naming S and from Summary.leaked (escapes, retained call objects).

Fixture: crates/slate/tests/fixtures/pointer_lift_static_array.c (scale_untouched lifts; sum_mutable, sum_leaked,
sum_indirect, sum_after, sum_alias stay raw). ptr_len_array_sources sum_values regained values: &[i32].
interproc_scaling: ir_pointer still < 3 ms at N=800 on every shape.

Limits: a static whose address is stored anywhere (over_aligned_globals values via `values_tail = &values[2]`) never
proves; needs points-to for the holders. Reads of S by a callee also block, though a shared borrow would allow them.

See: slate-8ge7.15, slate-8ge7.17 (can reuse Effects for refinement 1), wiki/concepts/slate-analysis.md#effect-summaries.
