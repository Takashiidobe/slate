# Port update_filecheck.py for @check-fn regions

_2026-10-16 18:40:13_

slate-5vj0.2: crates/slate/tools/update_filecheck.py regenerates FileCheck blocks for differential fixtures.

- @check-fn-begin/end (renamed from @rewrite-fn) wraps a C function; the tool finds the Rust fn of the same name (main -> \_\_slate_main) and writes an exact CHECK-LABEL / CHECK-NEXT / CHECK {{^}}} body into a trailing SLATE-FILECHECK-BEGIN/END block. Handwritten checks outside the block are kept.
- It reads the Rust the differential harness writes under target/difftest-generated/<group>/ and reruns the harness first (deleting the old .generated.rs so a translation failure is reported, not silently reused). --no-run reuses the last run. This avoids duplicating -std, dg-options, and -target handling in Python.
- Normalized: **v<N>, arg<N>, anon\_\*, **slate*\**<N> (break labels, asm strings). Shadowing renames like count_5 stay literal.
- Statement-level markers dropped; the two in fixtures.multi/library were widened to their functions.
- No arguments regenerates every annotated fixture in tests/fixtures{,/x86_64,/i686}. Idempotent across fresh translations.
- project_control_flow_differential no longer FileChecks: its translate-project output differs from translate (slate-5vj0.3).
- strip-ai-comments hook allowlist now keeps @check-fn markers and multi-segment prefixes like X86_64-UNKNOWN-LINUX-GNU-DAG.
