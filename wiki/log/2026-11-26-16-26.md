# slate-3amj.5.26.3 derive: reject explicit zero array bounds under /Za

_2026-11-26 16:26:51_

- bead: slate-3amj.5.26.3
- kind: feature
- area: crates/slate-parser/src/sema/types.rs
- flavor: msvc

Outcome: MSVC /Za diagnoses an explicit array bound that evaluates to zero.

Gap: cl.exe reports C2466 for zero-size record members under /Za and accepts them in default mode. It reports C2466 for standalone zero-size arrays in both modes. Slate accepted both forms under /Za.

Before: `struct S { int size; int data[1 - 1]; };` was accepted under /Za.

After: /Za rejects the explicit zero bound. Default MSVC still accepts the record. Flexible members and incomplete array declarations are accepted under /Za.

Implementation: `TypeResolver::derive` checks the evaluated constant bound before building a fixed extent. This applies to declarations, members, parameters and type names.

Fixture: `error/msvc/windows/x86_64/za_zero_size_array.c` covers a file-scope array, a folded member bound and a parameter bound.

Limits: default-mode standalone zero-size arrays retain Slate's existing permissive behavior.
