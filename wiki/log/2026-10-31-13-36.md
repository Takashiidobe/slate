# Simplify merged cfgs with target-property atoms

_2026-10-31 13:36:11_

slate-nfq8.13: --merge conditions now use target properties (target_arch, target_os, target_env, target_pointer_width, target_endian, unix, windows) instead of listing full targets. New src/project_cfg.rs: TargetConditions precomputes every target set reachable by a conjunction of literals with its shortest term, then picks the shortest cover by memoised search, and takes not(...) of the complement when that renders shorter. Targets outside the matrix and targets absent from the enclosing gate are don't-cares; the root compile_error guard stays an exact target list because it is what makes out-of-matrix don't-cares safe. Departure from the bead: no Quine-McCluskey over atom bits, since 12 atoms allows 3^12 implicants and nearly all atom combinations match no real target; working over real target sets gives the same don't-care behavior. Greedy cover was tried first and produced not(all(not(freebsd), not(macos))), so it was replaced. When two literals select the same targets the positive one wins even if longer, so all(target_pointer_width = "64", unix) rather than all(not(target_arch = "x86"), unix). Each selected condition is asserted against every care target, and check_config evaluates them with target_properties. New test target_properties_match_rustc compares atoms with rustc --print cfg for all 16 zlib targets. Results on zlib, 16 targets: 77335 to 60234 lines, #[cfg] count 2882 to 2877 (conditions are shorter, not fewer), median condition 37 chars; merge time 100s before and after, so no measurable cost. Longest condition other than the guard is 373 chars, a feature list. slate-nfq8.15: validate_merge --codegen --layouts now runs both and labels each result. --check-projection all now errors up front above 1024 whole-project translations (zlib on 16 targets needs 8192) and asks for a count. Closed slate-nfq8.5: build.rs named cfgs are no longer worth having. Verified: slate profile 33/33 (5 skipped); validate_merge on the merged zlib: codegen 208/208 and layouts 208/208 (16 targets, 13 feature sets), runs on the 6 runnable targets with default (128 checks each) and all features (56 checks each, 37 where C itself exits nonzero, Rust matches), 0 mismatches; projection 8 samples, 128 checked, 0 mismatches. Not verified: darwin, freebsd, android, musl and windows aarch64/arm32 are never executed, only compiled and layout-checked. Fixture: fixtures.merge/target_properties.c, with a target list in target_properties.targets.json because a local hook strips comments from C files edited directly.
