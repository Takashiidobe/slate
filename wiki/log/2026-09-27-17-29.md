# gcc i686 default CPU macros

_2026-09-27 17:29:40_

slate-parser-78x3.6 (decision). Without -march, i686 gcc-flavor output said __pentium4/__pentium4__ while the gcc our i686 snapshot comes from (host multilib gcc 16.2.1, gcc -m32) says __k8/__k8__.
Decision: the gcc flavor's i686 default arch is x86-64, so all gcc-flavor i686 predefines come from one compiler build. Features are identical to pentium4 (MMX, SSE2, FXSR); only CPU-name macros change. Clang keeps pentium4, which is what clang does.
Rejected alternatives: Debian/upstream i686-linux-gnu-gcc defaults to -march=i686 without SSE2, which slate rejects (x87-only float, no _Float16), so it cannot be the default.
X86Arch::default_for takes Rules. tools/gcc_macro_diff.py on i686 is now clean against gcc -m32 (only __SLATE_*) for no flags, -mavx2, -march=x86-64-v3, -mavx512f -mno-fma, -mno-sse3; clang unchanged.
Fixture sema/x86_isa_i686_default_cpu.c; compiler-flags.md x86 bullet records the decision.
