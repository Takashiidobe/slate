Outcome: slate-parser's library and binary fail clippy on unwrap/expect/panic/unreachable/todo/unimplemented and the assert macro family; tests and build.rs are exempt.

- Enforces the parser AGENTS.md rule "never use assert! and friends in parser paths" mechanically.
- Scope: crate-root `#![deny(clippy::unwrap_used, clippy::expect_used, clippy::panic, clippy::unreachable, clippy::todo, clippy::unimplemented, clippy::disallowed_macros)]` in `src/lib.rs` and `src/main.rs`. Inner attributes apply only to those targets, so `tests/filecheck.rs` (harness = false, libtest-mimic) and `build.rs` keep panicking freely. Clippy's `allow-*-in-tests` options were not usable: they only cover `#[test]` fns and `#[cfg(test)]` modules, not harness-less test binaries or build scripts.
- `crates/slate-parser/clippy.toml` lists `std::assert`, `assert_eq`, `assert_ne` and the `debug_` forms as disallowed macros; Cargo.toml sets `disallowed_macros = "allow"` so only the crate-root deny turns it on.
- The 18 existing sites were restructured, not suppressed:
  - `sema/names.rs`: `ScopeStack` (file scope plus nested `Vec`) replaces `Vec<HashMap>` for `ordinary`, `tags`, `local_labels`; `innermost`/`innermost_mut` cannot fail, `lookup` and `innermost_first` replace `iter().rev()` walks, `is_file_scope` replaces `len() == 1`, `file_mut` replaces `ordinary[0]`. OpenMP frame pop uses `then(..).flatten()`.
  - `files.rs` `decode_source_bytes`: `utf8_chunks()` instead of the `from_utf8` error loop.
  - `lexer.rs` octal and hex escapes: `while let` chain on `to_digit`.
  - `sema/ctype/mangle.rs` `substitution`: collect chars, no `String::from_utf8`.
  - `sema/validate.rs` `is_register_variable_type`: recurse through `Grouped`/`Attributed` instead of a loop plus `unreachable!()`.
  - `sema/module.rs`: push one `Produced` per item on each path instead of `last_mut().expect`.
- Validation: parser profile 9329/9329.
