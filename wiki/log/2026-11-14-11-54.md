Outcome: above -O0, asm "i" operands that become constant only after inlining
(always_inline parameters, never-written locals) now select an immediate or
symbol by specializing the always_inline callee per call site.

## Gap and why it mattered

Kernel headers pass always_inline parameters and macro locals to "i":
arch_static_branch(\_jump) `"i"(&((char *)key)[branch])`, **static_cpu_has,
constant_test_bit_acquire, and **WARN_FLAGS
`auto __flags = BUGFLAG_WARNING|(flags); ... [fl] "i"(__flags)`. clang and gcc
accept these only at -O1+ (inlining plus mem2reg); at -O0 both reject them, as
slate still does. This was the largest kernel barrier cluster (11861 functions,
2014 TUs).

## Before

    static inline __attribute__((always_inline)) int branch(struct key *key, _Bool likely) {
        asm goto("# %c0 %c1" : : "i"(&((char *)key)[likely]), "i"(likely) : : yes);
        return 0;
    yes: return 1;
    }
    int f(void) { return branch(&k1, 1); }

`branch: no usable constraint alternative: [AsmRejection { operand: 0, reason: NotConstant }]`

## After (-O2)

`f` calls `branch__const1`, an internal clone whose asm has `sym<offset=1>(k1)`
and `const<bool>(true)`. The original `branch` is dropped once nothing
references it. The Rust output is `sym k1` with `{1}+1` and `const 1 as u8`.

## Implementation

- `Lowerer::constant_asm_operands` (sema/asm_constants.rs) runs in
  `finish_module` when `codegen.optimization != None`.
- Each function first folds its stable, automatic, non-volatile locals and
  reselects its asm (`Lowerer::reselect`, sema/asm.rs).
- Functions that still have rejected asm are propagated up the call graph. The
  always_inline, non-naked ones become candidates.
- Each direct call to a candidate with known arguments (constants, or addresses
  `symbol()` accepts) is cloned as `{name}__constN`, memoized by its argument
  values. Clones resolve nested candidate calls recursively.
- `drop_unreferenced` removes internal unresolved originals that nothing
  references.
- The pass looks through macro structure: `symbol()`/`symbol_place` peel
  `MacroArg`/`MacroExpansion`, and read counting and substitution use
  `Place::without_macro_holes`. Without this, slate's macro-kept IR left calls
  written through a macro unresolved.
- Walker hooks `rewrite_value`/`rewrite_statement` and `walk_value_structure`
  were added in ir/macro_strip.rs.
- The backend widens a bool immediate to u8 (frontend/lowerer/asm.rs).
- pp_diff `SEMANTIC_FLAGS` now keeps `-O`, so the e2e harness passes -O2
  through.

Kernel example TUs (NotConstant before/after): init/main.c 10 -> 0,
kernel/sched/rq-offsets.c 1 -> 0, kernel/bounds.c 1 -> 1 (case C).

Limits: no folding of `__builtin_constant_p` ternaries (bounds.c order_base_2).
Asm with tied inputs or non-memory InPlace operands is skipped, and so are
callees with static locals or nested functions.
