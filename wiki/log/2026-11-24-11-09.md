# slate-yar4.67 lower_stdc_rotate: end-to-end fixture for UINT64_MAX counts

_2026-11-24 11:09:15_

- bead: slate-yar4.67
- kind: bug
- area: crates/slate/tests/fixtures.unsupported

Outcome: The end-to-end unsupported ratchet covers left and right _BitInt rotations with UINT64_MAX as the count.

The fixture rotates the value 1 in an unsigned _BitInt(17). Both results
should be 1 because UINT64_MAX is a multiple of 17. The exit status records
which rotations disagree, with one bit for each direction.

The typed IR preserves the unsigned count. The generated Rust casts it to
i64 before the remainder, producing a shift of 16 instead of 0. The Clang
oracle exits 0 and Slate's compiled Rust exits 3 on x86_64, i686, aarch64,
and armv7 Linux. Each target's unsupported list records that runtime mismatch.

Fixture: crates/slate/tests/fixtures.unsupported/bitint_rotate_unsigned_count.c
