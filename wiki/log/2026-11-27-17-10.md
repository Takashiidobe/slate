# slate-8ge7.24.11.5 lowering: string literal to char pointer emits c"..".as_ptr() from ArrayDecay; cstr_literal rule deleted

_2026-11-27 17:10:46_

- bead: slate-8ge7.24.11.5
- kind: rewrite
- area: crates/slate/src/frontend/lowerer
- area: crates/slate/src/backend/engine/rules

Outcome: the lowerer emits `c"..".as_ptr()` for a string literal decayed to a byte pointer, decided from the IR `ArrayDecay` of a string binding, and the `cstr_literal` Rust rule is deleted; static initializers, which the rule never visited, now get the c-string form too.

Before (C: `static const char *names[] = {"zero", "one", "two"};`, `printf("%u\n", x)`):

    [b"zero\0".as_ptr() as *const i8, b"one\0".as_ptr() as *const i8, b"two\0".as_ptr() as *const i8]
    slate_support::printf(b"%u\n\0".as_ptr() as *const i8, x)   // in fns, rule then recovered c"%u\n".as_ptr()

After:

    [c"zero".as_ptr(), c"one".as_ptr(), c"two".as_ptr()]
    slate_support::printf(c"%u\n".as_ptr(), x)

Rule: `FunctionLowerer::string_literal_pointer` (lowerer/values.rs) takes the literal bytes and the lowered pointer type. If the bytes end in exactly one NUL (no embedded NUL) and the type points at a byte (`CLib(CHAR)`, i8, u8; `is_byte_ptr`), it emits `c"<bytes>".as_ptr()`, else `b"..".as_ptr()`. The cast is dropped only when the type is `*const` of Rust's own `c_char` (`tables.rust_layout.char_signed`, from the triple, not `-funsigned-char`; `is_c_char_const_ptr`), else kept (`as *mut u8`, `as *const u8`, ...). Wide literals point at u16/u32 and keep `b"..".as_ptr() as *const T`.

Both lowering sites use it: `ValueKind::ArrayDecay` of a string binding, and `Convert{PointerCast}` of such a decay (not a macro value), which now builds the literal pointer for the final type instead of retyping the decay cast. The rule saw through nested byte-pointer casts; the second site covers that (`(const char *)"x"` would otherwise keep `as *const i8`).

Measured: cstr_literal.rs (126 lines) removed, plus its now-unused `NodeKindTag::ALL_EXPRS` const helpers in arena.rs (39) and the `registry(target)` parameter; lowerer values.rs +61/-6. Net src -7 lines. cstr_literal fires 0 (rule gone).
