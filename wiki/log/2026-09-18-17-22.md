# Post-C89 constructs recorded as extensions

_2026-09-18 17:22:11_

Swept C99/C11/C23 constructs against clang 22.1 and gcc 16.2 across c89..c23 (plain and -pedantic). Everything except digit separators is accepted by both compilers as an extension before its introducing standard (gcc -std=c89 rejects // comments and for-init declarations; the latter is already gated by control_statement_scopes). Recorded the table in wiki/concepts/ast-spec.md. Digit separators are hard-rejected by both before C23 (the ' lexes as an unterminated char constant), split into slate-parser-47s.10. 0b literals stay an extension. No code changes.
