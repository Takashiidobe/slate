# slate-8ge7.24.4 const-fold transform: implicit integer conversions of constants fold on the IR; const_fold and constant_index_casts deleted, user constant arithmetic kept

_2026-11-21 16:40:30_

- bead: slate-8ge7.24.4
- kind: feature
- area: crates/slate-analysis/src/transform
- area: crates/slate/src/backend/engine/rules
- area: crates/slate/src/backend/codegen.rs
- area: crates/slate/src/frontend/lowerer

Outcome: implicit integer conversions of constants (and the sign of a negative literal) fold on the IR in the `const-fold` transform; the Rust rules `const_fold` and `constant_index_casts` are deleted, and constant arithmetic the C wrote is no longer folded.

Gap and why it mattered: `const_fold` guessed types from Rust `as` wrappers (`settle` treated bare literals as untyped) and also folded user arithmetic (`60 * 60` -> `3600i64`, `FE_ALL_EXCEPT` -> `61i32`). The IR has `truncate<i8, reason=assign>(const<i32>(97))` with exact C types, so the fold is a C conversion, not a guess.

Before (`char c = 'a'; long l = -1; int64_t big = 60 * 60;`):
  IR   let c: i8 = truncate<i8, reason=assign>(const<i32>(97));
  Rust let big: i64 = 3600i64;            (const_fold folded the user's product)
After (`emit-slate-ir --passes=const-fold`):
  IR   let c: i8 = const<i8>(97);  let l: i64 = const<i64>(-1);
  Rust let c: i8 = 97;  let l: i64 = -1;  let big: i64 = (60i32 * 60i32) as i64;

Implementation:
- `transform/const_fold.rs`, slot `AfterMacroStrip` only: `widen`/`truncate`/`reinterpret` with reason other than `explicit` over an integer constant (any width <= 128, `_BitInt` included) becomes `const<T>` wrapped to T; signed `neg(const)` becomes a negative constant. Skips kept expansions, value holes and macro-valued operands (`walk_body_with_macros`, new `walk_value_with_macros` for global initializers). The node keeps the conversion's NodeId.
- Spelling that `const_fold` did as a side effect moved: codegen `suffixed_literal` prints `Cast(literal, iN/uN)` (and a same-type cast of one) as `97i8` when it fits; `literal_casts::bare_initializers` replaces `fold_initializers` and only drops the suffix of a static whose declared type matches; `is_simple_literal` packs suffixed literals.
- `FunctionLowerer::lower_index` writes a constant array/lane index bare when it fits the target's usize (replaces `constant_index_casts`).
- `representable_literal` (now `rules/representable.rs`) checks each cast against its real range and sizes usize/isize from `target.pointer_width` (was u64/i64 caps, wrong on i686); `ptr_offset` also requires the literal to fit isize.

Measured (3067 fixtures): Rust output changed in 422 files, all exit codes unchanged. literal_casts 27487 -> 24417 fires (2823 -> 2820 fixtures); const_fold 14201 -> 0; constant_index_casts 2071 -> 0; no other rule moved by more than 17. Visible changes: user arithmetic stays (`(2i32 << 8i32) + 3`, `0..(1000i32 * 1000i32)`, `(1i64 << 53i32) + 1i64` in a static), explicit casts stay (`(char)255` -> `255i32 as i8`), bitint constants lose `from_bint(from_i128(..))` wrappers, constant arguments no longer need `__t` temps. 127 FileCheck blocks regenerated.

Fixture: `crates/slate/tests/fixtures.transforms/const-fold/` conversions, arithmetic_kept, explicit_kept, macro_body.

Limits: u128/i128 constants print as `340282366920938463463374607431768211201 as u128` (codegen suffixes only 8-64 bit types). A label delta the lowerer folds itself in a static stays `1i64 as i32` (computed_goto_label_delta.c). Unkept header macros now show their expansion (`32i32 | 4i32 | 16 | 8 | 1`).
