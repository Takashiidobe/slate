# gnu_libc_stdio promoted to tests/fixtures

_2026-09-04 07:58:36_

tests/fixtures.unsupported/gnu_libc_stdio.c moved to tests/fixtures/. It was the last of the five slate-3f8g.5 completion targets still parked, blocked on slate-2o6o.18 (extern fn decls dropped llvm.byval on non-variadic struct params, corrupting fopencookie's ABI so the cookie write/close callbacks never fired). That landed, so the fixture now translates, compiles, and matches C exactly: `9 8 6 1`, exit 0.

Coverage: asprintf, open_memstream, __fwriting/__fpending/__freading/__fbufsize, fmemopen, getdelim/getline, fopencookie with a cookie_io_functions_t whose write/close are set at runtime, and parse_printf_format.

Whole-file FileCheck blocks generated with tools/update_filecheck.py, matching the convention the sibling gnu_libc_* fixtures already use (no region markers -- they assert the entire generated file). lowering and rewrites both pass.

Overlaps but does not duplicate tests/fixtures/gnu_cookie_stdio.c, which is the narrow fopencookie regression fixture slate-2o6o.18 landed with; this one is the broad GNU stdio surface.

All five epic targets (strings, stdio, algorithms, allocation, platform) are now in tests/fixtures.
