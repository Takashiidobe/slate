# MSVC oracle via msvc-wine

_2026-09-19 08:55:56_

Installed real cl.exe under native Wine with mstorsjo/msvc-wine (MSVC 14.51, SDK 10.0.26100.0) into ~/.local/share/msvc-wine/opt/msvc. Added tools/cl.exe, a wrapper over the generated bin/x64/cl that honours MSVC_WINE_ROOT and MSVC_ARCH. Chose native Wine over Docker: Windows containers cannot run on a Linux host, so Docker would only wrap Wine. Verified /Zs, /E and /d1reportAllClassLayout (C++ only) and _Static_assert with /std:c11. Not hooked into fixtures yet. See wiki/concepts/msvc-oracle.md.
