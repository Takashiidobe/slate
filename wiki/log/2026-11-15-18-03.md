# slate-f2zu.14.34.21 folded_branches, Inlining: unanswered llvm.is.constant folded the BUILD_BUG_ON if true, always_inline not emitted; **compiletime_assert_N and **bad_mask undefined in vmlinux

_2026-11-15 18:03:50_

- bead: slate-f2zu.14.34.21
- kind: bug
- area: crates/slate-parser/src/sema/fold.rs
- area: crates/slate-parser/src/sema/folded_branches.rs
- area: crates/slate/src/frontend/lowerer/functions.rs
- corpus: linux

Outcome: an `if` guarded by an unanswered `llvm.is.constant` is no longer marked
`[folded=true]`, and slate emits `#[inline(always)]`/`#[inline(never)]` for the
parser's `[inline=always]`/`[inline=never]`, so kernel
`BUILD_BUG_ON(!__builtin_constant_p(x))`, `min()`/`__types_ok` and `FIELD_GET`
asserts are answered after inlining instead of keeping calls to undefined
`__compiletime_assert_N`/`__bad_mask`.

Symptom: the vmlinux relink after .20-.26 still had 30 undefined
`__compiletime_assert_N` (rhashtable_lookup family in 7 units, inet_frag_find,
tcp_write_xmit, icmp_ext_append, ...) and 1 `__bad_mask` (agg_rx `u8_get_bits`).

Reproducer:

```c
void __compiletime_assert_1(void);
enum freq { NORMAL, LIKELY };
static inline __attribute__((always_inline)) int retry(const enum freq fr, int *slot, int n) {
  int tries = 0;
  if (!__builtin_constant_p(fr))
    __compiletime_assert_1();
restart:
  if (fr == LIKELY && *slot < n && ++tries < 3) { (*slot)++; goto restart; }
  return *slot + tries;
}
int likely_retry(int *slot, int n) { return retry(LIKELY, slot, n); }
```

Before (-O2): IR
`if not<bool>(intrinsic<bool, llvm.is.constant>(...)) [folded=true]`; Rust
`__compiletime_assert_1();` unconditionally before the goto loop (link:
undefined symbol). After: no `[folded]`; Rust `#[inline(always)] fn retry` with
`if !__slate_intrinsic_...(fr as u32) { __compiletime_assert_1(); }`, dead after
inlining.

Cause:

- `folded_branches` used `fold::evaluate`, which answers an `llvm.is.constant`
  with a non-folding argument as 0 (kept for asm dead-arm pruning). `!0` marked
  the `if` folded true. Clang's `EmitIfStmt` does not fold it. In functions with
  a goto (`__rhashtable_lookup`'s `goto restart`) the dispatch lowering trusts
  `folded` and keeps only the assert arm. The `min()` sites in tcp_output/icmp
  were unconditional the same way.
- slate never lowered `Inlining` to an attribute. rustc inlines a plain fn only
  inside its own codegen unit, so callers in other CGUs got an out-of-line
  `u8_get_bits.llvm.*` whose `field` is not constant.

Fix:

- `fold::branch_integer_with_objects` (Env `defer_queries`): an unanswered
  `llvm.is.constant` makes the value unknown. `folded_branches`
  (`Lowerer::branch_integer`) uses it for `if` and `switch`; asm pruning keeps
  the 0 answer.
- `lower_function` (crates/slate/src/frontend/lowerer/functions.rs) maps
  `Inlining::Always`/`Never` to `Attr::Inline`. The pinned nightly accepts it
  with `#[target_feature]` and on C-variadic fns, so there are no exclusions.
- Spec: wiki/concepts/ir/builtins.md, wiki/concepts/ir/control-flow.md.

Fixtures:

- crates/slate/tests/fixtures.release/constant_p_after_inlining.c (`retry`;
  failed to link before).
- crates/slate/tests/fixtures.release/noinline_return_address.c: `noinline` fn
  returning `__builtin_return_address(0)` from two sites prints `1 1` like
  clang; without `#[inline(never)]` it prints `0 1`.
- crates/slate-parser/tests/fixtures/clang/linux/x86_64/ir_constant_p_after_inlining.c
  (`query_branch_not_folded`).
- 34 generated fixtures regenerated; every change is an added `#[inline(...)]`
  line.

Verified on single kernel TUs (ioam6, inet_fragment, tcp_output, icmp): asserts
are guarded now. Limits: no shard rebuild/relink yet; `[inline=hint]` (plain
`inline`) still emits nothing.
