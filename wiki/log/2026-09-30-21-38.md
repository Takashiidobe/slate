# slate-p58o.3.40: over-aligned globals

_2026-09-30 21:38:01_

Closed slate-p58o.3.40 (Lower over-aligned globals).

Rust has no align attribute on statics, so lowerer.rs now emits one generic
wrapper per distinct alignment:
  #[repr(C, align(N))] struct __SlateAlignN<T>(T);
- Context.over_aligned maps static definitions whose declared alignment
  exceeds the type's natural alignment (storage_of) to N. The existing
  x86_64 large-array ABI alignment exemption is unchanged.
- lower_static gives those statics type __SlateAlignN<T> and wraps the
  initializer (or zeroed) in __SlateAlignN(..).
- lower_place projects a wrapped binding as name.0, so reads, writes,
  decays, address-of, and address constants all go through the wrapper.
  The address of .0 is the wrapper's address, so the alignment is honored.
- Extern declarations stay unwrapped (the defining TU owns alignment); an
  alignment on a type storage_of cannot size is still refused.

Fixtures: over_aligned_globals.c (new; failed with 'global counter
attributes') checks the alignment of _Alignas and aligned(N) scalars, arrays,
a struct, a 4096-aligned array, a function-scope static, and pointer
initializers into aligned globals. global_array_pointer_decay.c (the named
3.34 fixture) is promoted.
