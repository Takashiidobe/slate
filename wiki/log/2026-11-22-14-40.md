# slate-8ge7.24.12 libc_calls lowering: strlen/strcmp/atoi/memcpy forms from Known identity and constant_string fact; delete libc_call rule

_2026-11-22 14:40:20_

- bead: slate-8ge7.24.12
- kind: feature
- area: crates/slate/src/frontend/lowerer/libc_calls.rs
- area: crates/slate-analysis/src/constant_strings.rs
- area: crates/slate/src/backend/engine/rules

Outcome: libc calls (exit, abort, str*, ato*, mem*) get their Rust form in lowering from the callee's Known identity plus a new slate-analysis constant_string fact; the Rust-side libc_call rule (16 rules) is deleted.

Gap and why it mattered: libc_call re-derived argument facts on the Rust AST (literal inits through raw-pointer locals, local arrays, lifted slices) after lowering, the layer split wiki/concepts/slate-analysis.md forbids. Running after lowering also left `use slate_support::memcpy` style imports for calls it replaced, and it missed calls in some statement shapes (atoi_atol_prelude_dynamic kept a plain `atoi` FFI call).

Before (libc_call_nested.c, `const char *s = "lengthy"; return (int)strlen(s) > 4;`):
    (((("lengthy".len() as i32) as u64) as i32) > 4) as i32
After:
    ((7u64 as i32) > 4) as i32
strcmp/strspn/strcspn/atoi/atof of constants fold to literals, so the slices and closures are gone. strncmp with a runtime bound becomes `b"ab"[0usize..n.min(2usize)].cmp(&b"abz"[..])`.

Implementation:
- slate-analysis `constant_strings.rs`: `BindingFacts::constant_string` for a plain automatic pointer local that `DefUse::written_once` (one write, only reads otherwise, so an address escape blocks it) and whose initializer resolves through PointerCast/Copy and other such locals to a `.str` literal global. `counted_loops::collect_locals` became the shared `for_each_let`.
- Lowerer `libc_calls.rs`: `known_callee` requires the Rust name to be the Known symbol, optionally with `__builtin_`. `__builtin_bcopy` maps to MemMove with swapped arguments and broke mem_bcopy_overlap.
- `fold_known_call` runs before arguments are lowered: lowering a literal argument marks its `__slate_strN` static for emission, and a fold would orphan it. It refuses when an argument is a macro argument, since folding `#define TEXT_LENGTH(s) strlen(s)` erased the parameter.
- `lower_known_call` runs after argument lowering: exit/abort, the `__slate_ato*` helpers, mem* safe slice forms for decayed local byte arrays (otherwise core::ptr copy/write_bytes), and memcmp on borrowed &[u8]. A used memcpy result binds a non-duplicable dst to a temp and casts it to the C return type (gcc-torture memcpy-1).
- The discarded-call flag `FunctionLowerer::discarded_call` is set by expression statements.
- Deleted rules/libc_call.rs and the `runtime` parameter of `rules::registry`.

Fixtures: 59 FileCheck blocks regenerated (folds, dropped dead imports, `__builtin_mem*` now core::ptr). New tests/fixtures/libc_constant_string_escape.c guards the slate-gbgp.8 escape: `pick(&word)` keeps the strcmp/strlen calls while the stable alias folds. A SLATE_RULE_TRACE run with both active showed 0 residual rule fires over 3258 fixtures before the rule was deleted.

Limits: memset/memcpy through a pointer alias of a local array (`char *p = buf`) now uses core::ptr instead of `fill` (peel_casts_ptr_chain.c); filed slate-8ge7.24.18.
