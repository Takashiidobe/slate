# Lower file-scope asm to global_asm! with sym rewriting of textual C names

_2026-10-10 08:26:56_

slate-3f8g.4.17.9. Removed the Construct::ModuleAsm barrier. Module::asm entries join into one core::arch::global_asm! item (rust_ast Item::GlobalAsm; InlineAsm.naked became kind: AsmKind {Statement, Naked, Global}; codegen's asm printer moved to Printer::inline_asm). Naked bodies and module asm share FunctionLowerer::lower_asm_block (const/sym operands, att_syntax for AT&T).
Templates that name C items textually (gnu_basic_asm_value(%rip)) are handled differently from the bead's plan: instead of forcing the Rust item to keep its C symbol (no_mangle would make statics global and collide across TUs), Tables::asm_names maps each defined function/static symbol (asm_name or C name) to its binding, and AsmNames rewrites matching words in template text to {N} with a trailing sym operand. Skips: the first word of each statement (mnemonic/label; so a C function named add does not hijack the add mnemonic), %-prefixed registers, quoted strings, digit-led words, thread-locals, imported commons, and duplicate names. Basic asm now escapes braces instead of using the raw option; AsmOption::Raw was removed.
Promoted gnu_inline_asm, x86_64/gnu_basic_asm; added x86_64/gnu_toplevel_asm_symbols (static var and static fn referenced from global_asm, add mnemonic vs C add, braces in a comment, two top-level asm blocks). Full slate profile green.
