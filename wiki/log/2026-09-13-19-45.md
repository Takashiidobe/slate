# Declaration = shared specifiers + declarator list

_2026-09-13 19:45:40_

Declaration is now { specifiers, declarators: Vec<InitDeclarator { declarator, asm_label, attributes, initializer }> }. DeclarationSpecifiers gained attributes. FieldDecl is { specifiers, declarators: Vec<FieldDeclarator { declarator, bit_width, attributes }>, provenance }.

- Parser: parse_declaration_tokens splits into parse_declaration_specifiers + parse_declarator_list. The comma-split-and-reprefix hacks are removed at file scope, in typedef lines, in blocks (Stmt::Block of Decls), and in record bodies. declaration_prefix_end, parse_typedef_line, and build_tag_alias_decl are removed.
- GNU prefix attributes after a comma (void a(void), **attribute**((x)) b(void)) attach to that declarator only.
- Decl::Typedef removed: typedefs are Declarations with storage Typedef. Decl::name() became names().
- Tag definitions still emit Record/Enum first, then one Declaration over all trailing declarators. It keeps storage, qualifiers, initializers, and function-pointer declarators, which fixes lh7.1.11. Anonymous tag identity waits for TagId (lh7.3.4).
- Vector attributes still fold into specifiers.ty from all attributes (interim until TypeSpecifier split).
- sema/reachability/filecheck oracle iterate declarators; apply_abstract_declarator is re-exported for the oracle typedef summary.
- New fixture declarator_lists.c; all fixtures regenerated.
- ast-spec migration table updated. New row: declarators lack provenance.
