# slate-dghn.46 macro templates: identifier argument of a nested or hoisted-local macro call expanded to an unbound name

_2026-11-13 16:09:39_

- bead: slate-dghn.46
- kind: bug
- area: crates/slate/src/frontend/macro_keep.rs
- area: crates/slate/src/frontend/lowerer/macro_sites.rs
- area: tools/corpus

Outcome: `python3 tools/corpus/e2e.py oniguruma --mode clang` translates libonig, builds it, and the 7 upstream `test/` programs pass translated (4565 checks, 0 failures), matching native.

Two bugs found by the oniguruma run, one fixture (`fixtures.merge/macro_name_arguments.c`):

1. Nested macro with an identifier argument. `FIND_ENTRY` (st.c) calls `PTR_NOT_EQUAL(table, ptr, hash_val, key)` where `key` is a caller local and PTR_NOT_EQUAL uses its parameter as a member name (`(ptr)->key`). The member use makes the parameter a `$key:ident` template parameter, so the outer template passed the literal text `key`, which Rust hygiene hides from the outer macro body (E0425). Fix: `Survey::enter_expansion` in `macro_keep.rs` rejects a nested expansion whose `MacroCover::Name` spelling no enclosing expansion also has as a name cover (`name_argument_in_template`; `NESTED_FIELD` forwarding its own `$name` still templates), so it stays inline and the caller local flows through the outer's hidden place parameter.
2. Identifier parameter on a hoisted local. `STACK_PUSH_CALLOUT_NAME(name_id, mem, func)` in regexec.c uses `func` as member name and value; in a dispatch function `func` is hoisted into `MaybeUninit<Option<fn>>` plus a slot pointer, but the `$func:ident` parameter expanded to the raw `MaybeUninit` (E0308). Fix: `finish_macro_site` in `macro_sites.rs` only makes the ident parameter when the lowered value argument prints as exactly the spelled identifier; otherwise the field name stays literal and the value is a normal expression hole (`*__slate_slot_N`).

Reproducer (second bug):
```c
#define PUSH(s, func) do { (s)->num = 1; (s)->func = (func); } while (0)
/* func is a local in a function with goto */
PUSH(&s, func);
```
Before: `PUSH!(addr_of_mut!(*slot), func)` with `func: MaybeUninit<..>`. After: `PUSH!(addr_of_mut!(*slot), *__slate_slot_1)`.

Also: `oniguruma` Recipe in tools/corpus/e2e.py. Upstream CMake registers no tests, so `oniguruma_suite` runs `test/test_utf8`, `test_syntax`, `test_options`, `testc`, `testcu`, `test_regset`, `test_back` natively and translated and compares exit code and stdout. README trophy case updated.

Limits: `testp` (POSIX API) is not built by the corpus configuration. A nested name-cover expansion whose name comes from a caller local is no longer templated.
