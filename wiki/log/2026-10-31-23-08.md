# Skip gdb in guality fixtures

_2026-10-31 23:08:22_

slate-5q63.11.1: fixtures guality__{example,guality,inline-params-2,pr41447-1,pr41616-1} embed guality.h. It starts gdb, which never set guality_attached, so the binary counted down a 32-bit counter (about 2s) and aborted with 'gdb: took too long to attach', in both C and Rust. The differential only compared that abort, and every run also produced 10 core dumps. gcc_dg_suite.rs guality_args passes --guality-skip to any fixture containing that string; they now take 2ms, exit 0 and run guality_main. Saves about 20 core-seconds per run. The perf figure of 23.6% that prompted this was misleading: the profile captured about 498G user cycles, roughly 110 of about 690 user core-seconds, so all its shares are unreliable. Filed a re-profile bead under slate-5q63.11 and corrected the affected descriptions. Why gdb never attaches was not investigated (ptrace_scope is 1).
