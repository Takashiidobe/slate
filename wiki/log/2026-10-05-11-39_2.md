# __builtin_popcountg has a typing rule and folds

_2026-10-05 11:39:20_

slate-parser-6x05.38.27. The Popcountg catalog record had no derived signature, so calls failed as unsupported and constants as nonliteral. DerivedSignature::BitCount gained a fallback flag: Clzg/Ctzg keep the optional int fallback, Popcountg takes exactly one integer operand and returns int (clang rejects a second argument). BitBuiltin::of_call maps __builtin_popcountg to Popcount, which folds at the operand's own width. crates/slate's Rust lowering does not map the generic bit builtins (clzg/ctzg/popcountg) yet. Fixture: clang/linux/x86_64/builtin_popcountg.c.
