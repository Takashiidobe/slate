# x86_64/ fixture directory + doc trim

_2026-09-07 09:56:08_

Extended the arm/aarch64 fixture-directory convention to x86_64: moved all
27 x86_64-exclusive fixtures (asm/intrinsics/x87-long-double) from the
shared root into tests/fixtures/x86_64/. tests/differential.rs now also
collects that dir, gated on cfg!(target_arch = "x86_64") so it's a
compile-time no-op on non-x86_64 hosts, not just a runtime filter.

tools/update_filecheck.py's default_targets_for_path recognizes the
x86_64/ path component and emits single-target X86_64-GNU checks, same as
arm/aarch64/bionic/macos/msvc. Regenerating all 27 moved fixtures was
behavior-preserving (4 were already single-target-tagged and produced
byte-identical output; the rest only gained an explicit X86_64-GNU tag
where they'd previously had a bare tag that happened to collapse from the
old dual-target generation).

Removed the now-redundant `// { dg-do run { target x86_64-*-* } }` markers
from the 15 moved fixtures that had them, and deleted the corresponding
skip-list entries in differential_arm.rs (whole match arm, 12 fixtures).
Net effect: differential_aarch64.rs went from 13 failing fixtures to 1
(f128_intrinsics, pre-existing and unrelated) since 12 x86-only fixtures
were previously un-skip-listed there and silently failing every run.

Also trimmed wiki/concepts/inline-asm-support.md's AArch64/ARM sections
per feedback -- terse supported/limitations statements instead of
narrating the investigation, and collapsed the fixture-directory
explanation to one paragraph.
