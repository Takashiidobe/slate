# Lower record type definitions in the slate frontend

_2026-09-30 20:29:24_

slate-p58o.3.15.

- Type::Defined resolves typedef aliases to their target and lowers struct records to #[repr(C)] #[derive(Clone, Copy)] Rust structs (Item::Record). Records are lowered on first use and memoized, so only records reachable from lowered functions are emitted and an unlowerable record is a barrier for the functions that use it, not the module. Self-referential records resolve through an in-progress marker.
- Naming: the C tag when unique among records, tag_<id> on collisions, __SlateRecord<id> for anonymous records. #[expect(non_camel_case_types)] only when the name is not camel case.
- Layout guard: field offsets, size and align are recomputed as natural repr(C) from target storage and must equal the IR RecordLayout; packed/aligned records (which the IR does not flag) are refused as 'layout of record X'. Bitfields, anonymous members, volatile/atomic fields, and unions stay barriers.
- Minimal PlaceKind::Field for non-bitfield struct fields (needed for structs.c); reads/writes wrap unsafe when any place in the field chain dereferences. Address-of fields and array fields remain 3.33.
- Uninitialized struct locals lower to unsafe { std::mem::zeroed() } so field-by-field writes type-check.
- names/bindings/strings and the new type state are bundled in a Context passed through the lowerer.
- Fixtures: structs.c and new record_types.c (typedef'd struct, nested record fields, -> chains, self-referential list, incomplete-struct pointer field). Also promoted alloca_frame_const_ptr_param, buffer_cursor, int128_struct, ptr_param_field_store, typedefs. nested_structs.c and pointer_compare_address.c now block on 3.16 aggregates; array_one_past_end_bound.c on 3.33 field array decay.
