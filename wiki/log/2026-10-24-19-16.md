# SCIP browsable site across crates; drop post-commit hook

_2026-10-24 19:16:28_

Ported sbe's tools/scip_site.py to tools/scip/site.py. It reads target/scip/index.db (no scip CLI) and writes .scip/site/ (gitignored): one highlighted page per indexed .rs file (pygments if installed), clickable identifiers, a side panel with the definition and references grouped by crate (references from other crates highlighted and counted), callers/callees to depth 5, and an SVG call graph (graph.html?s=<symbol>) whose nodes from another crate get a different outline. index.html has symbol search, files grouped by crate, and a cross-crate table (crates/slate -> slate-parser: 6913 refs to 747 symbols; -> slate-sysroots: 55 refs to 27). data.js uses numeric symbol/file ids (4 MB for 218 files, built in about 7 s).
scip.py: occurrences gained end_col (needed for clickable spans), and meta records schema=2; indexed_tree ignores an index with an older schema, so build no longer skips a rebuild just because the tree is unchanged.
Removed tools/scip/post-commit and the .git/hooks symlink; rebuild by hand with scip.py build when status says the index is stale. AGENTS.md updated to say so and to point at site.py.
