# Lower inline asm memory operands

_2026-10-09 19:44:13_

slate-3f8g.4.17.4. Memory-selected asm operands pass their address in(reg): InPlace as &raw const, memory Out/InOut as &raw mut, and an unaddressable In(value) spills to a let temp first. Template references render AT&T ({N:r}) or Intel <size> ptr [{N:r}] (size from the operand width); %H adds a +8 displacement; %a on a register operand renders the same reference. Unused memory operands get a {N} assembler comment.

Parser: V resolves to Memory and p to reg. clang accepts p only under %a and marks the asm memory(none), so the pointer in a register (nomem) matches clang; bare %N on p is rejected by clang anyway. asmlet keeps the remaining letters (X, l, A, Y*).

Promoted asm_memory_operand, asm_memory_variant_operand, asm_address_operand_p, and six gcc-dg fixtures (guality pr36728-2/3/4, pr68860-1/2, torture fp-compare). Regenerated gcc-dg asm-4.c parser checks.
