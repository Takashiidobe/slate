# slate-dghn.52: curl e2e passes its test suite at native speed

_2026-10-09 18:32:28_

tools/corpus/e2e.py curl: libcurl (196 TUs) and the curl tool translated, built,
and run against curl's own tests/runtests.pl (~flaky ~timing-dependent).

Results (clang, release):
- translate 4.9 s vs native -O3 compile 1.9 s: 2.58x (budget 5x)
- suite: translated 1690/1690 OK (native 1689/1690, flaky 1583), 48.0 s vs 47.4 s
- bench (5 alternating samples, translated/native): file:// 20000 small 0.882,
  HTTP 20000 small keep-alive vs local nginx 0.956, file:// 1 GiB 0.986,
  HTTP 1 GiB 0.999; geomean 0.955

Slate bugs fixed on the way:
- C names crate/self/Self/super became r#super, which Rust rejects; struct fields
  were emitted bare. Bindings and fields now get a trailing underscore
  (names.rs path_keyword_free). Fixture path_keyword_names.c; also promoted
  gcc-torture 920810-1 (field super) and pr101188 (param self).
- translate-project overflowed rayon's default 2 MiB worker stack on curl while
  single-TU translate (8 MiB main thread) did not. Worker pools and the global
  pool now use 64 MiB stacks (reserved, committed on touch).
- va_arg(ap, long double) as a unit's only long double use never set
  dependencies.long_double, so __slate_f80_* shims were undeclared (mprintf.c).
  Release fixture long_double_va_arg_only (two TUs).

Harness: curl recipe with a suite hook (runtests.pl native vs -c translated
curl, LD_LIBRARY_PATH -> translated libcurl.so.4 so libtests exercise the
translated library) and an nginx-backed benchmark. A translate_tests cdylib now
links the native library's NEEDED libs, and executable relinks keep absolute
external .so paths (/usr/lib/libssl.so) instead of dropping them.
