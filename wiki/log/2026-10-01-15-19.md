# Directive translation runs on slate-parser

_2026-10-01 15:19:54_

slate-p58o.6.2. directive_translate::translate_one now parses with slate-parser and lowers with the slate lowerer; no clang, cir-opt, or AST dump at translate time (strace: only the slate binary executes).

- Sanitizing kept: #error/#warning/unsupported pragmas in the main file are blanked byte-for-byte and the blanked text is parsed under the real path via the new slate-parser Parser::parse_file_with_source / Preprocessor::parse_file_with_source, so includes and spans are unchanged.
- item_lines come from lowerer::definition_items: functions with bodies (fn:<rust name>, plus fn:main for the wrapper) and defined statics (static:<global_names name>), at their IR definition span, filtered to the main file. Statics are new; CIR only keyed functions.
- --targets: each target adds --target=<triple> to the slate-parser args; cfg atoms come from TargetInfo::for_triple (family/os/environment). toolchain::with_target_override and target_is_host_default are gone.
- api: the slate path auto-expands target-macro #if chains; the CIR path no longer does. On the plain slate path, active #error/#warning come from slate-parser's DirectiveDiagnostic (new text field holding the raw directive spelling) and become compile_error!/deprecated-const items, as CIR did. parse_module_with_source returns those diagnostics; parse_module_with_args still rejects errors.
- main.rs: --targets works with --frontend=slate. Directive output uses prettyplease.
- tests/directive_translate.rs drives --frontend=slate and passes compiler args on the command line.

fixtures.cfg on slate: 21 of 24 sources translate (error_unconditional and sanitized_input then fail rustc by design). directive_translate tests: 12/21 pass. Failures filed: slate-4j2r (short triples like x86_64-linux-gnu), slate-parser-cxg.7.10 (#import), slate-fqku (GCC poison), slate-wtx5 (reject active unsupported pragmas without clang), slate-rpkp (#embed missing message). With canonical triples, target_and_macro_divergence merges and runs (20 295).

Parser profile 7528 passed; slate profile 10 passed.
