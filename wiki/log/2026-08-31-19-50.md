# requeue consumer producers so format-string temps inline

_2026-08-31 19:50:42_

## Fixes
slate-8gmb: printf/puts format-string temps now inline into the call.

## Root cause
Worklist ordering. For `printf(fmt_temp, add_temp)`, the effectful `add_temp`
sits between `let fmt_temp = ...` and the call. LateInlineTemps (prio 41) tries
fmt_temp first while add_temp is still intervening (MovablePure branch requires
all intervening siblings pure -> fails). EffectfulTempForward (prio 42) then
forwards add_temp into the call and removes it, but nothing re-queued fmt_temp's
`let`, so it was never retried.

## Change
New opt-in NodeRule hook `requeues_consumer_producers()` (mod.rs). After a rule
applies, for each def-use consumer neighbor still alive, re-queue the producers
of that consumer's current reads. Set on EffectfulTempForward and
InlineConstArgTemps. So when add_temp is forwarded into the call, fmt_temp
(producer of a var the call still reads) gets re-queued and LateInlineTemps
inlines it.

## Blast radius / verification
~160 fixtures now inline format-string (and cascaded arg) temps. rewrites
differential (generated_differential) passes for all; spot-checked diffs are
pure temp-inlining. Regenerated add.c rewrites FileCheck; remaining ~160 stale
REWRITES snapshots tracked as follow-up (they are silent no-ops while REWRITES
enforcement stays disabled).
