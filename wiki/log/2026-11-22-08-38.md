# slate-8ge7.2.4 ir: PlaceKind::MacroArg place holes and caller-local hidden arguments move to the Module::macro_values overlay via Place::id; Module::macro_provenance query

_2026-11-22 08:38:01_

- bead: slate-8ge7.2.4
- kind: parser
- area: crates/slate-parser/src/ir
- area: crates/slate-parser/src/sema
- area: crates/slate-analysis/src
- area: crates/slate/src/frontend

Outcome: place macro holes and slate's caller-local hidden arguments are `MacroWrap::Argument` entries in `Module::macro_values` keyed by a new `Place::id`; `PlaceKind::MacroArg` and `without_macro_holes` are gone, so no macro wrapper node is left in the value or place tree, and `Module::macro_provenance(id)` answers "where did this node come from".

Before (`--show-macros`, `#define ASSIGN(l, r) ((l) = (r))`, `ASSIGN(r, l);`):

    write<i64>(macro_arg(#4, 0, %r), read<i64>(%l) [macro_arg="#4.1"])

After:

    write<i64>(%r [macro_arg="#4.0"], read<i64>(%l) [macro_arg="#4.1"])

Implementation:
- `ir::Place` gains `id: NodeId` (`#[debug(skip)]`); every construction goes through `Place::new(ty, kind, access)`, which takes a fresh `NodeId::next()`. Rebuilds that keep the same place (`Hoister::place`/`stable_place`) use `Place { kind, ..place }` so the id, and its provenance, follows.
- sema `macro_place_holes` pushes the wrap for `place.id` instead of building a node; `written_cast_hole` reads the place's outermost wrap.
- `Walker::place` replays a place's wraps (`enter_place_hole`/`leave_place_hole`) like `Walker::value`. Place printing takes `Annotations` and prints the place's metadata after it.
- `macro_keep::CallerLocals::rewrite_place` records hidden-argument wraps per place id (first visit wins, clones share an id) and `pass_caller_locals` splices them innermost after the walk.
- Read-through arms deleted: effects place/stable_place/place_effects, sequencing, object_size, fold, asm, c_types, def_use, counted_loops, pointer (store/rebase/read/address sources; `place` now flags bindings under an argument wrap as before), inline_temporaries (a wrapped place scans as nested). Lowerer: `lower_macro_place_wrap` peels the pending wrap like `lower_macro_wrap`; `places::without_macro_holes` removed.
- `Module::macro_provenance(id) -> MacroProvenance`: wraps, written cast, `expansions()` with their definitions, `hidden_argument(wrap)`. No consumer migrated yet.

Fixtures: parser clang/linux/x86_64/macro_{holes,nodes}.c (printing only); fixtures.transforms/{const-fold/macro_body,do-while-zero/macros,inline-temps/macro_body}.c now dump the plain place (`write<i32>(%x, ..)`), same transform decisions. fixtures.merge/macro_{templates,values}.c regenerated for a loop-shape change from slate-8ge7.24.11.4 that the merge profile had not been run on (`while !c` -> `loop { if c { break; } }`; slate-8ge7.24.11.8); kept/inline counts unchanged.

Limits: hoisting a place hole's base is still not reported as `hoist_split_region` (same as before). Provenance is lost when a transform replaces a node (slate-8ge7.2.5, slate-8ge7.2.6). Span `macro_nesting` is not reachable from an id alone.
