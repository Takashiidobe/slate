# slate-e36k.29 __builtin_elementwise_bitreverse: fold integer and vector constants

_2026-11-24 20:37:51_

- bead: slate-e36k.29
- kind: parser
- area: crates/slate-parser/src/sema
- area: crates/slate-parser/tests/fixtures

Outcome: Clang's __builtin_elementwise_bitreverse folds in required C constant contexts and emits typed constants for static initialization.

## Before

```c
_Static_assert(__builtin_elementwise_bitreverse((unsigned char)0x12) == 0x49,
               "wrong byte");
```

The assertion was skipped. Static initializers using the builtin reached
Slate as ordinary calls, which failed global lowering.

## Fix

ConstantBuiltin recognizes the unary call. TypeResolver uses the
operand type and the parser's constant evaluator. The bit folder
reverses the declared width, restores signedness, and uses arbitrary
precision beyond 128 bits. Fixed-size vectors built from constant
lanes, including integer arithmetic and scalar splats, become
aggregate initializers with a typed constant per lane.

## Fixtures

elementwise_bitreverse_constant.c covers an enumerator, constexpr,
static scalars and vectors, and signed and unsigned _BitInt(257).
elementwise_bitreverse_static_assert_false.c now reports
"static assertion failed: wrong byte".

See: slate-e36k.28 for runtime lowering, slate-e36k.30 for
`__has_constexpr_builtin`, and slate-e36k.31 for constant shuffle
and lane-conversion operands.
