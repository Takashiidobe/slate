# Expression typer covers calls, builtins and the checker

_2026-09-28 18:26:33_

slate-parser-cc94.4.2. The expression typer (sema/typer.rs) now types calls
(builtin_callee, custom builtins, derived signatures, atomics via
AtomicBuiltin::result, choose_expr, constant_p, source location, va builtins),
sizeof/alignof/offsetof, va_arg, bit casts, convertvector, label addresses,
__real__/__imag__, statement expressions, pointer and void ?:, and struct
assignment. type_expression has no catch-all arm any more.

Rules were moved out of lowering rather than copied: builtin_callee,
declares_builtin, derived_signature, chosen_expr (also replacing the copy in
constant folding), real_floating_component, complex_of and
statement_expression_parts. TypeResolver gained function_references so
builtin_callee no longer needs the Lowerer's NameResolution.

The checker's assertion_operand_type is gone; expression_type asks the typer,
and resolve() types a typeof operand the same way, so typer::type_name no
longer refuses unprepared typeof operands. Fixes too-strict rejections of
sizeof(opaque()) in static assertions (static_assert_validation VALID now
lowers) and makes int r[_Generic(__atomic_compare_exchange_n(...), ...)] a
fixed array, as clang does (atomic__pr71675).

Only successes are memoized: the checker types an enum body before its
enumerators exist, and a cached failure broke c23-enum-1.

c23-unreachable-1 changed because __typeof__(unreachable()) is no longer
lowered speculatively; the old output reused %5 for both __builtin_unreachable
and exit's parameter. Unanswered nodes across the gate fell from ~29k to ~600;
the rest (vectors, __func__, statement-expression locals, folded null pointer
constants) is slate-parser-cc94.4.4.
