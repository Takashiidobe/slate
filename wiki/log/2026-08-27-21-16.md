# Converge remaining project-translation entry points onto phase-1 fan-out (slate-9an4.3)

_2026-08-27 21:16:37_

Closes slate-9an4.3, the last child of slate-9an4. Parallelized the pass-1
fact-gathering loop in the three remaining translate-project entry points
that had the same per-TU-then-merge shape as .1/.2's target
(translate_project_lib_crate_with_compile_commands):

- translate_project_lib_crate_with_manifest: new ProjectModule struct +
  load_project_module/load_project_modules_parallel. Closest to .2's
  shape (no per-target cfg dimension, single default-args emit).
- translate_project_with_targets: new ProjectFactModule +
  load_project_fact_module(s)\_parallel. Parallelized only "pass 1" (cross-
  module fact gathering with default args: defined symbols, root/main
  detection, record/enum occurrence counting for shared-type promotion).
  Deliberately did NOT touch "pass 2" (the later loop that re-emits CIR
  per target variant for actual lowering) -- that's a separable, bigger
  effort (order-sensitive shim/diagnostic accumulation, per-target error
  handling), matching .3's own scoping note not to force-fit mismatched
  loop shapes into one pool.
- translate_project_with_compile_commands: same split, new
  CommandFactModule + load_command_fact_module(s)\_parallel, args sourced
  from each module's primary compile-command variant instead of `&[]`.

Did not unify all three phase-1 result types into one shared struct --
each function's per-TU shape genuinely differs (warning_items vs
anon_records vs neither; args source; which preprocess/parse calls apply)
and forcing a single type would have been the premature abstraction
CLAUDE.md warns against. All three reuse the same slate_job_count()
knob from .2.

Validated: rewrites 110/110, lowering 10/10 (exercises translate_project\*
via cross_tu fixtures), fmt/clippy clean. Not re-benchmarked separately --
these entry points don't have a standing large-corpus benchmark the way
--lib --compile-commands has libexpat; the win is structurally identical
to .4's measured ~2x on libexpat's fan-out.
