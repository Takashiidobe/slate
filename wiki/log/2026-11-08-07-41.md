# ARM32 register pairs, %Q/%R/%H/%B/%L/%m, early clobbers

_2026-11-08 07:41:37_

slate-3f8g.4.17.13.3: a 64-bit r/l operand on ARM32 is the new AsmRegisterClass::RegPair (sized_class now takes the family). Slate pins the first free even/odd pair of r0/r1, r2/r3, r4/r5, r8/r9 as two explicit u32 halves through asm_pair (now also the ARM u64/u32 split, bridging via asm_encode/asm_decode so doubles work); %Q/unmodified print the low register, %R/%H the high. %B (~imm) and %L (imm & 0xffff) print the folded number, %m prints a memory operand's base register. gcc prints a bare symbol as #sym: the parser rewrites that reference to '#' text plus %c, so Slate lowers symbols with or without %c. Thumb-only h/N/O stay Unresolved: clang and gcc both reject them on armv7 (ARM and Thumb-2).
Bug fixed on every target: register clobbers were lateout("r") _, which lets rustc put an input in the clobbered register (an armv7 pointer input landed in a clobbered r1 and segfaulted). Clobbers are now out("r") _; regenerated 8 x86_64/i686/aarch64/arm FileCheck blocks.
Fixtures: arm/asm_arm_register_pairs.c, gcc/arm/asm_arm_gcc_register_pairs.c; parser clang armv7 ir_asm_classes.c (pairs), gcc armv7 ir_asm_modifiers.c. Docs: wiki/concepts/ir/asm.md, ir-grammar.md.
Validation: parser 9034/9034, slate 36/36, slate-aarch64 and slate-i686 green, slate-arm green except the known slate-xw0x.8 msvc fixture.
