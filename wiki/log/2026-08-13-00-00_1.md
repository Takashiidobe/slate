# frontend fixup batch

_2026-08-13 00:00:00_

A batch of narrow regression fixes in `src/frontend/lowerer.rs` and its submodules, landing right after the `0c840a7a`/`3b578ff7` module split moved lowering code from the old monolithic `lower.rs` into `frontend/`. Several of these read as "this behavior existed before the split and needs restoring/re-verifying in the new module layout":

- **`15f05d31`**: record definitions could be emitted more than once when the same record type was reachable through multiple paths (direct field, pointer, array, function-pointer param/return). Added `collect_record_dependencies`/`required_record_defs` to walk the full dependency graph and compute a single de-duplicated emission set (128-line rework of the record-emission path).
- **`d5e3f59b`**: preserved the semantic (source) name for CIR record aliases instead of falling back to a synthesized name when a record was only referenced through an alias.
- **`919993f3`**: retained records that exist only in CIR (not in the Clang AST fact layer) rather than dropping them as if they were dead.
- **`cfaa2243`**: retained records whose only use is being layout-queried (`sizeof`/`alignof`-style), which previously could be pruned as apparently-unused.
- **`94f7f155`** / **`23485fb4`**: distinguished _hoisted_ VLA (variable-length array) declarations from ordinary ones in the dispatcher, and deferred their actual allocation to where the hoisted declaration is used rather than allocating eagerly at the hoist point — `storage.rs` gained ~39 lines to track the deferred-allocation state.
- **`4f7f3268`** / **`ef7aec7b`**: preserved `va_list` forwarding when one variadic function calls another with its own `va_list` (not restarting variadic collection), and restored boxing for internal (non-parameter) varargs storage that had been lost.
- **`7871b04f`**: fixed BitInt overflow-checked arithmetic (`+`/`-`/`*` with overflow flags on arbitrary-width `_BitInt(N)`) lowering — 139 lines in `arithmetic.rs` plus `memory.rs` changes for the overflow-result storage.
- **`af8fd90f`**: parameter names that collide with a Rust keyword or another binding in scope are now allocated a collision-free name deterministically (36-line addition), rather than the earlier ad hoc renaming.
- **`5d25c57d`**: routed f80 (long double) unary builtins (e.g. `fabsl`) through the `c_shim.rs` shim table instead of inlining ad hoc lowering per builtin in `arithmetic.rs`.
- **`fb0ab213`**: preserved function-pointer _types_ (not just the pointer value) through storage/memory lowering, needed for correct `Type::FnPtr` propagation in cast/transmute sites.
- **`7e5fac5d`**: build fixtures for the differential test harness now omit debug info (`tests/support/mod.rs`), trimming compile time for the frontend-only test loop.

Most of these fixes are single-digit-to-tens-of-lines and paired with no new fixture — they're regressions caught by the existing corpus (gcc-torture/c-testsuite/chibicc) re-running against the freshly split module tree, not new C-language features.
