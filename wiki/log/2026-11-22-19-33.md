# slate-8ge7.24.22 Option borrows: null checks lower to if let Some / let-else (Expr::Let, Stmt::LetElse)

_2026-11-22 19:33:26_

- bead: slate-8ge7.24.22
- kind: feature
- area: crates/slate/src/backend/rust_ast.rs
- area: crates/slate/src/backend/engine
- area: crates/slate/src/frontend/lowerer/optional.rs

Outcome: null checks on unwritten nullable borrows lower to `if let Some(p) = p` / `let Some(p) = p else {..};`, so reads inside need no `unwrap()`.

Gap: slate-8ge7.24.20 lowered nullable borrows as `Option<&T>` but every check
stayed `p.is_none()` and every read `*p.unwrap()`.

Before:
    if hit.is_none() { return -1; }
    *hit.unwrap()

After:
    let Some(hit) = hit else { return -1; };
    *hit

Implementation:
- rust_ast: `Expr::Let { pattern, expr }` (if-let and edition-2024 let-chains)
  and `Stmt::LetElse { pattern, init, else_body }`, threaded through codegen,
  arena `NodeKind::LetElse`, walk visitors, inline_temps, raw_ptr_alias,
  branch_init, unsafe_placement (never wraps a let condition in `unsafe`) and
  shadow (if-let scopes cond + then; let-else binds after its else).
- `Expr::is_let_condition()` guards `EmptyThenInvert` (no `!let`).
- lowerer/optional.rs: `presence` recognises `p != NULL`, `p == NULL`, `!p`
  on a nullable borrow whose mutability fact has `required == false` and no
  argument escapes. `lower_if_let` (also `p && x`), `lower_if_let_value`
  (`?:`), `lower_let_else` (then-body ends in return/break/continue, no
  else). `FunctionLowerer::present` makes `borrow_of` return the
  unwrapped borrow; `lower_statement_list` scopes it.
- `&mut`: scrutinee is `p.as_deref_mut()`.
- shadow::restore: a pending inner shadow of the same name now forces a
  `_N` rename only if the inner scope mentions the outer binding. Fixes
  `let mut out_1 = out;`; also keeps scoped_local_bindings' nested blocks
  with C names instead of flattening with `x_1`.
- functions.rs: a reassigned borrow param rebound as `let mut p = p;` no
  longer also gets `mut` on the param (the rebinding stays: it lets `p = q`
  pick a shorter lifetime).

Fixture: crates/slate/tests/fixtures/nullable_option_borrows.c (lookup,
either, optional, store; new `chained` let-chain and `rebound`
write-after-check case that keeps `is_none`/`unwrap`).

Limits: only direct null comparisons of a binding; `p || ...`, checks on
fields, and bindings passed to callers that may write stay as before.
See: slate-8ge7.24.20
