# Corpus e2e harness

_2026-10-02 20:51:48_

slate-dghn.1. New tools/corpus/e2e.py (redis recipe) takes a project from native build to its own test suite. Reports go to target/corpus/<project>/<mode>/ (summary.json plus logs).

Stages:
- native: --setup reruns crates/slate-parser/tools/c_corpus_setup.py for build-<mode>. The target's object lists and libraries come from make -pn (REDIS_SERVER_OBJ, REDIS_VEC_SETS_OBJ, FINAL_LIBS). TUs are taken from the build database with pp_diff.kept_args, keeping the first existing source per object, so the -MM-only src/*.c entries and the vpath'd vector-sets files both resolve.
- barriers: per-TU lowering-barriers, aggregated into barriers.{json,md}.
- translate: translate-project. Also times the native compile of the same TUs with their original flags (-O3 etc.), run in parallel. Per the guiding principle, translation should cost about the same as compiling the C; cargo build time is deliberately not compared.
- check / build: cargo check, then cargo build --release with the native archives and libs as -C link-arg (warnings allowed so linker notes stay visible).
- bench: the project's benchmark against the native and translated binaries, one warmup each then alternating samples, medians and ratios (as in tools/benchmark/sqlite.py). Redis uses pipelined redis-benchmark.
- test: the project's tests in a sandbox copy of its test tree. Redis links redis-server/redis-check-* to the translated binary and redis-cli/redis-benchmark to the native ones.

Redis results: 120 TUs, 0 barriers; translate 3.3-3.7 s vs native compile 1.9-2.3 s (1.6-1.7x); links once __rdtsc is expanded in sema to intrinsic<u64, llvm.x86.rdtsc>() (fixtures x86_64/rdtsc_builtin.c, parser ir_vector_builtin_expansion.c). Bench geomean 0.988x native over 15 commands. ./runtest starts and passes early units, then the server crashes in crccombine.c because slate drops the x86-64 16-byte large-array alignment (slate-dghn.17, now blocking .10).

Filed slate-dghn.16: the 'builtin without a lowering' barrier only covers __builtin_*, so __rdtsc-like builtins reach the linker.
