# Lower GNU nested functions with by-reference captures

_2026-11-02 12:46:36_

slate-parser-dyd.56.1: under --flavor=gcc a nested function definition lowers to Statement::NestedFunction { function, captures } instead of Unimplemented.
Parser:
- sema/nested.rs scans each gcc function for nested definitions; captures (enclosing automatic locals/params, by reference) are closed transitively over calls to siblings/inner nested fns at lowering time, so mutual recursion and multi-level nesting work.
- names.rs binds nested definitions with file-scope-style linkage (no sharing with a same-named global/outer nested fn) and records each nested fn's binding range; block-scope 'auto int f(int);' forward-declares a nested fn (no linkage, not emitted).
- assertion.rs/module.rs exempt the auto forward decl from linkage checks.
- Printer: nested_fn %id @name(params) -> ret [captures=%a: T, ...] { ... }.
Slate:
- lowerer/nested.rs emits each nested fn as a private module fn {parent}__{name} with leading *mut T capture params; captured bindings read through shared_pointers; direct calls prepend capture addresses.
- Address of a capturing nested fn is a barrier (dyd.56.2); capture-free ones are ordinary internal fns.
