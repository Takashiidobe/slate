# Lower \_Float16 va_arg on i686

_2026-10-17 09:31:39_

slate-kih1.7. float16.c failed on i686 because f16 va_arg was a barrier off x86_64/aarch64. i386 passes \_Float16 in a 4-byte stack slot (clang: load half from the cursor, advance 4), so the i686 path now reads f16 directly through \_\_slate_i386_va::arg, which already reads size_of::<T>() bytes and rounds the step up to 4. x86_64/aarch64 keep the f64 read and bit truncation; f128 va_arg stays a barrier off x86_64. Removed float16 from fixtures.unsupported/i686-unknown-linux-gnu.txt (its sum_variadic reads three \_Float16 varargs). slate-i686 profile green.
