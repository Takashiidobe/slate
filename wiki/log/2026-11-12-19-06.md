# slate-dghn.41.1 lowerer: size_t and void* fields of libc-canonicalized records (iovec, msghdr) cast to libc field types

_2026-11-12 19:06:43_

- bead: slate-dghn.41.1
- kind: bug
- area: crates/slate/src/frontend/lowerer

Outcome: reads and writes of size_t-typed and void* fields on records canonicalized to slate_support (libc crate) now cast to or from the libc field type, so libuv's generated crate passes cargo check and builds.

Gap: slate_support::iovec/msghdr come from the libc crate (iov_base: *mut c_void, iov_len/msg_iovlen/msg_controllen: usize or size_t), but the frontend types a field access from the C header (*mut (), u64). rustc rejected every use in libuv (27 errors in stream.rs, udp.rs, fs.rs).

Before (libc_iovec_msghdr_fields.c):
  total.wrapping_add(unsafe { vec[i].iov_len })        // expected u64, found usize
  out.0[0].iov_base = first.as_mut_ptr() as *mut ();   // expected *mut c_void
After:
  total.wrapping_add(unsafe { vec[i].iov_len as u64 })
  out.0[0].iov_base = (first.as_mut_ptr() as *mut ()) as _;
  out.0[0].iov_len = (...) as _;

Implementation: FunctionLowerer::support_scalar_field (lowerer/places.rs) is true for a non-bit-field Field place whose base record has a support_record_path and whose type is a void pointer or an integer whose C typedef is size_t/ssize_t/ptrdiff_t/intptr_t/uintptr_t (known_c_name on the field's c_types node). Reads (values.rs ValueKind::Read) wrap the place in a cast to the IR type; assignments (statements.rs lower_assignment) cast the value `as _`. Narrowed to those C names because other fields (tv_nsec, tm_year) already agree with libc and casts changed 5 existing fixtures.

Fixture: tests/fixtures/libc_iovec_msghdr_fields.c (writev-style sendmsg/recvmsg over a socketpair). Slate profile 36/36.

Limits: address-of a retyped field (&msg.msg_iovlen) is not cast. libuv's uv_run_tests_a still fails to translate (duplicate uv__idna_toascii), tracked separately.
See: slate-dghn.41.1, slate-dghn.41.2.
