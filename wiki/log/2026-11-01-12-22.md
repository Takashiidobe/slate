# Lift macros that write through arguments by passing place parameters by address

_2026-11-01 12:22:09_

slate-f2zu.9.5.12.6: place holes are now kept when plain. During the rules a place parameter is passed as &raw mut or &raw const by whether the template writes it, and the body uses *$*n(), so remove_mut, slot_promote, inline_temps and the lattices need no summary table. finish_holes prints the body; finish_place_arguments strips the address last, after the final remove_mut. Mixed read and write parameters become place parameters. remove_mut now treats plain template arguments as reads, dropping the spurious mut callers had after .5.
Pointer lifting: any pointer named in a template argument stays raw; deref-only refinement filed. Project function calls stay gated (filed), deviating from the note on this ticket.
Bug from .5 fixed: length_lattice walkers skipped macro arguments, so a lifted callee inside an argument was not rewritten and did not compile.
