# VLA locals in slate

_2026-10-02 20:23:39_

slate-dghn.6. Block-scope VLAs now lower in the slate frontend (new lowerer/vla.rs).

- `vla<T, %e>` lowers to `[T; 0]`, used only behind raw pointers (like incomplete arrays).
- A variably modified local (`Tables::variably_modified`: a VLA, or a fixed array of one) becomes `let mut v: Vec<E>`, built in a block as `Vec::with_capacity(count)` plus `write_bytes(0, count)`. E is the innermost fixed element, and count multiplies the captured extent bindings and the fixed lengths. Storage is freed when the Rust block ends, so a VLA in a loop body is reallocated each iteration. The only accepted initializer is an empty zero-fill aggregate (C23 `{}`), which the zero fill already covers.
- `vla_address(place)`: a binding becomes `v.as_mut_ptr() as *mut [T; 0]`, and a deref becomes the pointer value. It is used by lower_place (as a deref), lower_address, `addr_of` and `array_decay`, so no reference to the zero-length array is formed. place_is_unsafe holds for VLA bindings.
- `ptr_offset` / `ptr_diff` with a variably modified element use `byte_offset` / byte `offset_from` with `runtime_stride` (extents * size_of::<E>() as isize).
- Extent reads go through the new `lower_binding(id)`, factored out of lower_place, so dispatch slots and over-aligned tuples still apply.
- A VLA local in a goto-dispatched function is a barrier: a `MaybeUninit` slot would never drop the Vec.

Fixture vla_locals.c covers the redis shapes (robj objects[argc] / argv[argc], char buf[length + 1], const-int bound), a 2-D VLA with row pointers and a pointer difference, per-iteration VLAs, and a pointer-to-VLA parameter.
