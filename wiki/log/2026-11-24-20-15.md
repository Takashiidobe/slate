# slate-78pa.12 __builtin_bswap128: lower runtime unsigned 128-bit byte swaps

_2026-11-24 20:15:22_

- bead: slate-78pa.12
- kind: bug
- area: crates/slate/src/frontend/lowerer/intrinsics.rs
- area: crates/slate/tests/fixtures/gcc

Outcome: GCC's __builtin_bswap128 lowers on targets with unsigned __int128.

## Symptom and reproducer

```c
unsigned __int128 swap128(unsigned __int128 value) {
  return __builtin_bswap128(value);
}
```

The typed IR already declares a u128-to-u128 builtin call. Translation
reported "builtin without a lowering" for it on x86_64 and AArch64.

## Fix

builtin_intrinsic maps __builtin_bswap128 to the existing llvm.bswap
adapter. The overload resolver uses the argument width to select
llvm.bswap.i128.

## Regression test

crates/slate/tests/fixtures/gcc/builtin_bswap128.c checks the two halves
of the result using distinct bytes on x86_64 and AArch64. It guards the
128-bit test with __SIZEOF_INT128__ for 32-bit targets.

The GCC-only gcc.dg fixture builtin-bswap-11.c also passes and moved
to fixtures.gcc-dg.gcc-only.
