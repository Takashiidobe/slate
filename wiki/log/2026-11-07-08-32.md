# Bridge calls through variadic long double function pointers

_2026-11-07 08:32:11_

slate-yar4.22: an indirect call through a variadic function pointer passed long double variadic arguments as Rust LongDouble (INTEGER class), so printf through int (*)(const char *, ...) printed garbage; a variadic pointer whose signature holds f80 was a barrier.
