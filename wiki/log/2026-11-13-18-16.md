# slate-dghn.55 nginx e2e: translated nginx passes nginx-tests (2584 tests) matching native

_2026-11-13 18:16:43_

- bead: slate-dghn.55
- kind: feature
- area: tools/corpus/e2e.py
- area: README.md

Outcome: the translated default nginx build passes the upstream nginx-tests suite (2584 tests in 176 files, 336 files skipped for modules not configured), identical to native, and `tools/corpus/e2e.py nginx --until test` runs it.

Gap: the nginx recipe stopped at `check`; nginx has no in-tree tests, its suite lives in the separate nginx-tests Perl repo (Test::Nginx, TEST_NGINX_BINARY).

Implementation: NGINX_TEST in tools/corpus/e2e.py clones nginx-tests into `${SLATE_CORPUS:-~/c-corpus}/nginx-tests` if missing, then runs `prove -j$(nproc) .` from that directory (tests `use lib 'lib'`) with TEST_NGINX_BINARY pointing at the sandbox's `build-clang/objs/nginx`, which the recipe links to the translated binary (native sandbox: the native one). Extra e2e test args go to prove.

Result: translate 5.9s vs native compile 1.6s; test wall time 50.4s translated vs 50.2s native.

Limits: default configure only (no ssl, http_v2/v3, stream, mail, perl modules), so those test files skip. A wider configure is follow-up work.
