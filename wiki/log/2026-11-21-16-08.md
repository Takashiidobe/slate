Outcome: inline temporaries are an IR -> IR transform (`slate_analysis::transform`, pass `inline-temps`) run in `lower_parsed` before macro_keep and again after the macro strip; the lowerer no longer knows about them, and `emit-slate-ir --passes=` plus `tests/fixtures.transforms/` test IR transforms with FileCheck.

Gap and why it mattered: the inline decision was a fact (`Facts.inline_temporaries`) that the lowerer applied by stashing initializers in `FunctionLowerer::inlined` and substituting at reads, with extra filters in the goto dispatch lowering. That is the first step of slate-8ge7.24: canonicalizations live on the IR so lowering is a mechanical mapping.

Before: `int sum(int *p, int n) { int s = 0; while (n-- > 0) s += *p++; return s; }` reached lowering with
  let %21: i32 [synthetic] = add(read(%20), read(%13)); write(%10, read(%21));
After (`emit-slate-ir --passes=inline-temps`):
  write<i32>(%s, add<i32>(read<i32>(%s), read<i32>(deref(read<ptr<i32>>(%old_p)))));

Implementation:
- `transform/mod.rs`: `Slot` (`BeforeMacroKeep`, `AfterMacroStrip`), `Pass { name, slots, run }`, `PASSES`, `Passes::{default, none, named, run}`. `frontend::lower_parsed` takes `&Passes` and runs both slots; `parse_module_with_passes` and `api::slate_ir_with_passes` thread it to the CLI.
- `transform/inline_temporaries.rs`: the old decision code unchanged (Scan, Summary, 32-sibling window); the driver is mutable. Each list is processed in order and the initializer is moved (same NodeId) into the read site the decision found (`Site::Following(distance)` or `Site::Tail`), so chains collapse in one pass and a later temporary's producer summary includes the reads moved into it. If the read is not found the temporary stays.
- Both slots: in slot 1 an unkept macro body is still a `MacroExpansion` and is skipped; the slot 2 run covers temporaries inside expansions macro_keep dropped (`x86_header_expanded_builtins*` regressed with slot 1 only).
- Removed: `Facts.inline_temporaries`, `UnitFacts::inline_temporary`, `FunctionLowerer::inlined`, `record_inlined`, the `lower_value_node` substitution and the three dispatch filters.
- Lowering gates `element_view`, `borrow_of`, `c_string_of`: a temporary counter over 3067 fixtures saw 10670 candidates and zero blocked by any gate, so they were dropped instead of reproduced.

Measured (3067 fixtures: tests/fixtures, gcc-torture, gcc-dg, c-testsuite, chibicc):
- Rust output: one file changed, `fixtures.chibicc/supported/control/control.c`, only `__v<n>` numbering (removed temporaries no longer take a number); identical after normalizing.
- Rule fires: inline_temps::late 89 -> 89; slot_promote 503 -> 489, dead_store 791 -> 777, remove_mut 8282 -> 8268 (Rust-side cleanup of the same final output); everything else unchanged.
- fixtures.merge: no diff, so no macro expansion flipped to kept.

Fixtures: `crates/slate/tests/fixtures.transforms/inline-temps/` single, chain, blocked (call moved past a memory read), read_twice, macro_body (kept expansion untouched), goto. Test `transform_filecheck` (slate profile), cached by `translation_key` under `target/difftest-generated/transforms/`; regenerate with `crates/slate/tools/update_filecheck.py`, which now loosens IR binding/type numbers into FileCheck variables for that directory.

Validation: slate and merge profiles pass. clang, gcc and msvc profiles were not run.

Limits: `--print-facts` from the design notes is not implemented. No pass uses a whole-target slot yet.
