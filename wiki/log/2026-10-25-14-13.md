# Build-only aarch64-pc-windows-msvc differential fixtures for the msvc profile

_2026-10-25 14:13:54_

The msvc profile now also targets aarch64. Wine cannot run ARM64 PE binaries on an x86_64 host ('Bad format'), so CrossTarget gained build_only (set by windows_msvc_with_root for aarch64): compare_batch_with_jobs_for_target compiles the C with the arm64 cl.exe (MSVC_ARCH=arm64, msvc_oracle_arch), builds the translated Rust for aarch64-pc-windows-msvc with lld-link against msvc-wine's arm64 libs, FileChecks it, and runs neither. msvc_arch_name maps x86_64/i686/aarch64 to x64/x86/arm64. rust-toolchain.toml adds aarch64-pc-windows-msvc; .config/nextest.toml's flavor-msvc adds aarch64-unknown-linux-gnu to SLATE_TEST_TARGETS. New fixtures crates/slate/tests/fixtures/msvc/aarch64/{msvc_windows_target,flag_msvc_arch_armv8_3,flag_msvc_feature_rcpc2}.c check at compile time (#error, \_Static_assert under /std:c11) since nothing runs; the 8 target-independent msvc/ fixtures also build for arm64 now. Found: slate accepts \_Static_assert without /std:c11 where cl rejects it (slate-3amj.5.24). Docs: AGENTS.md, crates/slate/CLAUDE.md, wiki/concepts/differential-fixtures.md.
