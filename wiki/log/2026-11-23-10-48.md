Outcome: `pointer::analyze` now runs separate summary, flow, representation proof, and fact emission stages.

Before, a single file held the IR walk and the program-wide solve. The latter interleaved graph construction, capability propagation, return eligibility, static escapes, ownership, length and string proofs, and cross-unit fact copying.

`pointer/summary.rs` builds the summaries in parallel. Its walker separates IR traversal, call evidence, pointer sources, and local heap evidence. `pointer/flow.rs` owns alias classes, value edges, raw-node state, and return and escape propagation. Ownership and C-string proofs read the solved flow. The length proof reevaluates borrow coverage before accepting each set of length pairs. `pointer/emit.rs` builds lowering facts and copies signature facts to resolved declarations.

`heap_ir` shares binding and release matchers with guarded heap. `constant_strings::literal_code_units` shares synthetic string recognition while the CStr proof still rejects interior NULs.

Validation: Slate release nextest profile, slate-analysis Clippy, formatting, and 16 byte-identical fixture translations compared against the preceding release binary.
