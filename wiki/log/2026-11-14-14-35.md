# slate-f2zu.14.12 static initializers: constant conditional folds to its selected arm; &weak_extern.field lowers via __slate_weak_address alias and global_asm .weak

_2026-11-14 14:35:59_

- bead: slate-f2zu.14.12
- kind: parser
- area: crates/slate-parser/src/sema/expression.rs
- area: crates/slate/src/frontend/lowerer
- corpus: linux

Outcome: static initializers accept a constant conditional whose unselected arm is not constant (folded in the parser to the selected arm), and the address of an `extern __weak` object or its field on ELF targets (lowered through a plain alias declaration plus `global_asm!(".weak")`). These were the 17 rows left in 11 kernel TUs after slate-f2zu.14.11.

Diagnostic or IR fact that was wrong:
- `static int v = sizeof(long) == 8 ? 64 : runtime();` kept a `conditional` with a `call` arm, which slate rejects as `non-constant initializer`. gcc and clang fold the selected arm. Kernel sources: `bin2bcd` (hcd.c USB descriptors), `ilog2` (nl80211.c, rcu tasks.h, context_tracking.c), DRM_IOCTL_DEF size checks, and `__SIP_HDR`'s `(__search) ? sizeof(__search) - 1 : 0` with a string-literal or NULL test.
- `&efi_attr_fw_vendor.attr` (`extern __weak`) was rejected by `is_constant_address`, because the `extern_weak` static holds the address and Rust cannot read an extern static in a static initializer.

Before (`static int v = 1 ? 3 : runtime();`):
```
global %3 v: i32 [storage=static] = conditional<i32>(ne<i32>(const<i32>(1), const<i32>(0)), const<i32>(3), call<i32, signature=fn() -> i32>(%0))
```
After:
```
global %3 v: i32 [storage=static] = const<i32>(3) [linkage=internal]
```

Fix:
- Parser: `Lowerer::lower_expr` Conditional arm (sema/expression.rs). Under `in_constant_initializer`, `Lowerer::constant_condition` evaluates the test via `TypeResolver::constant_value` (integer or `fold::pointer_address`), or as true for a string literal. Only the selected arm is lowered, through `converted(e, Slot::Then|Else)`. GNU `?:` is covered too.
- Slate: `Tables.weak_address_globals` holds the weak, non-thread-local extern objects on Linux, Android and FreeBSD. `is_constant_address` accepts them. With `in_static_initializer` set, `lower_binding` (lowerer/places.rs) emits `__slate_weak_address_<name>` and records the id in `Dependencies.weak_addresses`. `declare` prepares `#[link_name = "<sym>"] static mut __slate_weak_address_<name>: T` and `global_asm!(".weak {}", sym ...)`. `assemble` emits only the recorded ones. Runtime uses keep the `extern_weak` pointer static.
- Why the second declaration: a lone `.weak` fails when another codegen unit holds a strong reference (strong `U` wins, so the link fails; checked with 256 CGUs and save-temps). rustc keeps a module's non-generic items in one CGU, so the only strong reference sits next to its `.weak`. Undefined: `&w.b == 4` and `W == null`, as in C. Defined in another object: both resolve.
- Specs: wiki/concepts/ir/operations.md (conditional operator), wiki/concepts/ir/declarations.md (symbol attributes).

Fixtures:
- crates/slate-parser/tests/fixtures/{clang,gcc}/linux/x86_64/conditional_fold_static_init.c (an automatic local and a runtime test keep the conditional)
- crates/slate/tests/fixtures/static_init_constant_conditional.c
- crates/slate/tests/fixtures/static_init_weak_extern_address.c

Limits: a weak thread-local, and weak objects on Darwin and Windows, still block. A conditional whose test is the address of a non-weak object (`&x ? a : b`) is not folded. Float tests are not folded.

See: slate-f2zu.14.11, slate-f2zu.10.3 (extern_weak data), slate-9ox1.4.5 (why a lone `.weak` was rejected).
