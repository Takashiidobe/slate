# slate-8ge7.4 shadow mode: SLATE_SHADOW compares IR-side and Rust-side pointer_lattice decisions per binding; tools/shadow_report.py groups differences

_2026-11-20 18:08:20_

- bead: slate-8ge7.4
- kind: feature
- area: crates/slate/src/backend/shadow_diff.rs
- area: crates/slate/src/backend/interproc/pointer_lattice.rs
- area: tools/shadow_report.py

Outcome: `SLATE_SHADOW=<pass>` compares an IR-side analysis's decisions with its Rust-side pass per binding, and `tools/shadow_report.py` sweeps fixtures or a project and groups the differences; pointer_lattice reports its side today.

Gap and why it mattered: slate-8ge7 ports switch only after every difference against the Rust-side pass is triaged. There was no way to see both sides' decisions for the same C entity.

Before: no comparison; pointer_lattice's decisions were visible only through the emitted Rust, after length_lattice and plan validation.

After (crates/slate/tests/fixtures/pointer_lift_reassigned_local.c):

```
$ SLATE_SHADOW=pointer_lattice slate translate pointer_lift_reassigned_local.c
slate-shadow pass=pointer_lattice kind=rust_only unit=0 fn=pick binding=a rust=Ref ir=-
slate-shadow pass=pointer_lattice kind=rust_only unit=0 fn=pick binding=b rust=Slice ir=-
slate-shadow pass=pointer_lattice summary agree=0 differ=0 rust_only=2 ir_only=0
```

Implementation:
- `rust_ast::Program.shadow: Vec<ShadowDecision { pass, function, binding, decision }>`: the IR side's decisions, pushed by lowering (empty until slate-8ge7.6) and rendered with lowering's name tables.
- `backend::shadow_diff::{enabled, compare}`: `SLATE_SHADOW` read once (`OnceLock`); unset, `compare` returns at once. Keys are `(unit, Rust fn name, binding name)`: interproc runs on lowering's output before any per-function rule renames, so names match the C entity on both sides.
- `pointer_lattice::apply` reports `solve`'s `Representation` per binding (`Slice`, `RefMut`, `RawConst?`; `?` = nullable), before length_lattice and `validate_plans`.
- `tools/shadow_report.py`: paths (non-recursive) or `--project compile_commands.json`, `--pass`, `--json`; applies `dg-options`, lists inputs that fail to translate.

Measured: tests/fixtures (722 files) in 4.4 s, 429 pointer_lattice decisions, all rust_only; 6 fixtures fail to translate because their flags come from the test harness (c23_*, long_double, misc_language_survey). gcc-torture: 1 failure (pr117432.c).

Triage seed for slate-8ge7.6: the solver decides `pick::a = Ref` although `a` is indexed through `q` (q = a; q[i]); it is not applied today, but the IR port must decide `Slice`. `sum::p = Slice` in pointer_lift_local_copy_chain.c shows that fixture's give-up is downstream of solve (length_lattice indexes `t2`, not `p`).

Fixture: none (env-gated debugging aid; normal output unchanged).

Limits: decisions compare per binding only; per-call-site and per-field decisions get keys when a pass needs them. Harness-only flags are not reproduced by the report.

See: slate-8ge7, slate-8ge7.6, wiki/concepts/slate-analysis.md#shadow-mode.
