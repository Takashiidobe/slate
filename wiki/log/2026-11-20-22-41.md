# slate-8ge7.12 IR underaligned field fact: &local.field and &__real__ local prove borrows; record_pack reads the IR

_2026-11-20 22:41:58_

- bead: slate-8ge7.12
- kind: feature
- area: crates/slate-parser/src/sema/types.rs
- area: crates/slate-analysis/src/pointer.rs
- area: crates/slate/src/frontend/lowerer

Outcome: the IR record layout carries a per-field `underaligned` fact from sema; slate-analysis proves `&local.a.b` and `&__real__ local` borrows from it, and lowering's `record_pack` reads it instead of re-deriving packing from Rust layouts.

Gap and why it mattered: `proven()` accepted only `&x` and decayed automatic arrays, so `pick(&z.re)` (complex_lvalue) and every `f(&s.field)` kept the callee raw. Lowering knew packing only from Rust-side `storage_of`, so the analysis could not tell an aligned field from a packed one.

Before:

```rust
fn pick(p: *mut f64) -> f64 { unsafe { *p = *p + 5.0f64; } unsafe { *p } }
let r: f64 = pick(core::ptr::addr_of_mut!(z.re));
```

After:

```rust
fn pick(p: &mut f64) -> f64 { *p += 5.0f64; *p }
let r: f64 = pick(&mut z.re);
```

Implementation:
- slate-parser: `RecordLayout::underaligned: Vec<bool>`, printed `underaligned=[i, ..]` when any. `underaligned_fields` (sema/types.rs, both Itanium and Microsoft layouts): a non-bit-field member whose offset is not a multiple of its type's alignment (`member_storage`, before typedef reduction), or whose type's alignment exceeds the record's final alignment. The first cut (placed alignment < type alignment) wrongly marked `struct { double a; } __attribute__((packed, aligned))`, giving Rust packed+align (gcc-torture packed-aligned).
- slate-analysis: `Program::field_aligned`; `Walker::aligned_local_part` walks Field (bits: None, not underaligned, no access.align) and ComplexPart to an automatic binding. `CallSite::parts` records part proofs; a part proof fails if the parameter's class has OFFSET, because C's `container_of` from a field pointer leaves a Rust borrow's provenance (offsetof_fallback `value_of` had become `&[i32]` and walked back to the owner: UB).
- Lowering: `lower_borrow` accepts Field places, wraps union-field borrows in `unsafe` (`through_union`), and raises a Place barrier when `misaligned_in_rust` (a level whose Rust alignment exceeds its record's Rust pack). `record_pack` packs when the IR says underaligned, or for x87 types (`holds_x87`), whose Rust f80 is 16-aligned when C says 8 under -malign-double; any other Rust/C mismatch is `Invariant::AlignedFieldMisplaced`.

Fixture: crates/slate/tests/fixtures/pointer_lift_field_address.c (lifted: nested field, double field, char in packed record, union field; raw: packed int, pack(2) int, aliased swap, container_of). crates/slate/tests/fixtures.unsupported/x86_64/flag_align_double_long_double_borrow.c (f80 field borrow barrier, slate-yar4.59). Regenerated: complex_lvalue; ~108 parser layout fixtures; msvc/x86_64 pragma_merge and pragma_section (stale `&CStr` blocks from c59dddfce); 11 parser error fixtures with stale miette context lines.

Limits: leak checks stay flow-insensitive per root object, so any other `&o.x` escape pins every `f(&o.y)`. `&s.arr[i]` and decayed field arrays are not proofs yet.
