# Wire raw_ptr_alias into the pointer-lattice param-type plumbing

_2026-08-28 12:09:59_

Follow-up to the previous raw_ptr_alias session. Threaded param types into
Arena (arena::build now takes &[FnParam], populates a param_types map,
exposed via Arena::param_type) so per-function NodeRules can finally see
what pointer_lattice::apply() lifted a parameter to -- the first plumbing
of whole-program interproc facts into the per-function arena stage.

raw_ptr_alias now uses it two ways:

1. bare_replacement(): when eliding `let mut p: *mut T = arg0 as *mut T;`
   and arg0's param type is &mut T' with T'==T, substitute uses of p with
   a bare `arg0` instead of re-wrapping in the cast -- so a lifted
   reference actually stays a reference through to the use site instead
   of being immediately cast back to a raw pointer one line later (the
   `let mut p: *mut i32 = arg0 as *mut i32;` idiom this session's earlier
   fixture exposed).

2. Extended elision eligibility past the Let-based pure-rename temp
   (`let _v0 = p;`) to also see through the Assign-based zero-init-then-
   copy idiom (`let mut q = null; q = p;`) -- deferred last session
   because naively trusting `q = p` isn't safe unless q is provably
   single-assignment (a `let`-declared temp gets that for free from CIR's
   declaration convention; a pre-existing mutable local doesn't). Turns
   out def_use_neighbors already carries what's needed: arena.rs's
   own_reads collects an Assign's target unconditionally, so
   def_use_neighbors(q) already includes every rebind of q, not just
   reads through it. Added is_bare_rebind_of/is_single_assignment to
   filter that index for "is this the only place q is ever reassigned."

Hit one real bug while wiring this up: all_uses_deref_transitively's
recursion into q's own uses re-examined the very `q = p` node that
established the alias (it's simultaneously p's reader and one of q's own
def-use entries), and rejected q against itself. Fixed by threading an
`except: Option<NodeId>` through the recursion to skip the edge that
established the rename.

Validated: cargo run -- translate + rustc + diff against clang on two
fixtures (a static fn matching the RefMut/bare-arg0 path, and the original
q=p bare-copy case) -- both now fully eliminate the intermediate raw-
pointer local, output matches C exactly (exit codes 11 and 42). cargo
nextest --release --profile rewrites: 110/110, --profile lowering: 10/10.
fmt/clippy --all-targets clean.
