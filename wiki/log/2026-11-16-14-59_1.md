# slate-f2zu.14.40.11 hoist*section_statics: .set alias left in unit after its target static moved to crate root, \_\_pi*\* SYM_PIC_ALIAS undefined

_2026-11-16 14:59:00_

- bead: slate-f2zu.14.40.11
- kind: bug
- area: crates/slate/src/project/link_order.rs
- corpus: linux

Outcome: when `hoist_section_statics` moves a static to the crate root, any
`.set` alias global*asm in the same unit whose `sym` operands all name moved
statics moves with it (operands rewritten to `sym
crate::\_\_slate_link_order*<k>`), so alias and target share a CGU.

Symptom: vmlinux link after slate-f2zu.14.40.9: 12 undefined references to
`__pi_pgdir_shift`, `__pi_ptrs_per_p4d`, `__pi_next_early_pgt`,
`__pi___pgtable_l5_enabled`, `__pi_boot_cpu_data`; link.md listed them as
exports missing from arch_x86_kernel_r0.

C (arch/x86/kernel/head64.c, arch/x86/include/asm/linkage.h):

```c
unsigned int pgdir_shift __ro_after_init = 39;
SYM_PIC_ALIAS(pgdir_shift);   /* extern typeof(pgdir_shift) __pi_pgdir_shift __alias(pgdir_shift) */
```

Before (head64.rs):

```rust
core::arch::global_asm!(".globl __pi_pgdir_shift\n.set __pi_pgdir_shift, {}", sym pgdir_shift);
pub use crate::__slate_link_order_2 as pgdir_shift;
```

Cause: `__ro_after_init` is a section shared by several units, so the static
moved to the root CGU; the alias stayed in head64's CGU (slate-f2zu.14.40.9
keeps .set asm out of hoist_global_asm), where its target is undefined, and the
assembler dropped the alias. Mirror image of .40.9.

Fix: `hoist_section_statics` (crates/slate/src/project/link_order.rs) records
moved names per unit and moves `aliases_only` asm (has a `.set`, all sym
operands moved) into the root after its target. `defines_alias` now splits
statements on `\n` and `;`.

Regression test: link_order_asm_cgu (u2 `alias()` of a shared-section static)
verified the alias half links; the fixture was dropped because its label half
still fails (slate-f2zu.14.40.12) and returns with slate-f2zu.14.40.13.

Kernel check: arch_x86_kernel_r0/r2 retranslated; vmlinux links with 0 errors.

Limits: stopgap that reads asm text; superseded by slate-f2zu.14.40.13 (one CGU
per unit, hoisting removed). See: slate-f2zu.14.40.9, slate-f2zu.14.40.12,
slate-f2zu.14.40.13
