# Statement expressions skip trailing pragmas when finding their result

_2026-10-05 11:39:15_

slate-parser-6x05.38.24. statement_expression_parts skipped trailing comments but not pragmas, so ({ x; _Pragma("clang diagnostic pop") }) had no result and typed as void ('conversion from void'). Kernel context_unsafe() ends in enable_context_analysis() = __diag_pop() when WARN_CONTEXT_ANALYSIS is set (include/scsi/scsi_host.h:794). clang and gcc both take the last non-pragma statement. Trailing pragmas are now skipped when picking the result and returned separately; lowering applies them after the value so floating-pragma state still sees them in order. Fixture: clang/linux/x86_64/statement_expr_trailing_pragma.c.
