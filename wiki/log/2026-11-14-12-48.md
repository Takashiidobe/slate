# slate-f2zu.14.4 is_constant_initializer: static initializer copying a compound literal or comparing constant pointers folds (DEFINE_SPINLOCK, STATIC_KEY_FALSE_INIT, is_signed_type)

_2026-11-14 12:48:42_

- bead: slate-f2zu.14.4
- kind: feature
- area: crates/slate/src/frontend/lowerer/globals.rs
- area: crates/slate/src/frontend/lowerer/values.rs
- corpus: linux

Outcome: a static initializer that copies a compound literal (`T x = (T){...}`,
or one nested as a field or element) or compares integer-constant pointers
(`is_signed_type(T *)`) folds to a constant; kernel non-constant-initializer
rows drop from 3742 (740 TUs) to 97 (30 TUs).

Gap and why it mattered: DEFINE_SPINLOCK, STATIC_KEY_FALSE_INIT,
DEFINE_TRACE/tracepoint.h:371, rwlock and completion initializers all write
`(struct T){...}` inside static initializers, and trace_events.h:263 fills
`.is_signed = is_signed_type(_type)` for pointer fields.
`Tables::is_constant_initializer` (lowerer/globals.rs) accepted the address of a
static compound literal but not a read of one, and rejected every `Compare` with
pointer operands.

Before:

```c
struct lock { unsigned raw; const char *name; };
static struct lock spin = (struct lock){.raw = 1, .name = "spin"};
static int s = ((struct cred *)(-1)) < (struct cred *)1;
```

`global spin: non-constant initializer copy<...>(read<...>(compound_literal %N [storage=static] = aggregate<...>))`
and the same for `s` with `lt<ptr<...>>(int_to_ptr(...), int_to_ptr(...))`.

After: `static mut spin: lock = { ... raw = 1u32 ... }` with the literal's
initializer inlined (no `__slate_compound_*` static for it), and
`is_signed: false as i32`.

Implementation:

- `is_constant_initializer` accepts
  `Read { place: CompoundLiteral { storage: Static | Automatic, initializer }, ordering: None }`
  when the initializer is constant. Automatic covers block-scope `static` locals
  initialized from a literal (DEFINE_RATELIMIT_STATE: 341 rows), a GNU extension
  that gcc and clang fold.
- `lower_value` (lowerer/values.rs), while `in_static_initializer`, lowers that
  read as the literal's initializer, next to the existing constexpr-binding
  fold. A copy only observes the value, and each occurrence has its own object,
  so folding is exact. `&(T){...}` still emits its own static.
- `Tables::fold_pointer_compare` folds `Compare` whose operands are `Null` or
  `IntToPtr` of a `fold_integer` constant (through `PointerCast`/`Copy`), masked
  to the target pointer width; it lowers to a bool literal because Rust const
  eval cannot compare pointers.

Fixtures: crates/slate/tests/fixtures/static_init_compound_literal.c (direct,
nested field, array, union, block-scope static from an automatic literal,
address-of literal), crates/slate/tests/fixtures/static_init_pointer_compare.c.

Promoted: c-testsuite case_00216, gcc-dg gcc-only gnu89-init-1.c.

Limits: thread-storage literal reads still block. The 97 rows left are builtins
with constant arguments (`__builtin_bswap32` via htonl, `__builtin_ffsll` via
REG_FIELD_PREP) and one `&weak_extern.field` (efi.c:172), filed as
slate-f2zu.14.11.

See: slate-f2zu.14.8 (automatic compound literal places in EFI_GUID).
