# slate-8ge7.24.10.2 structure-goto transform: forward gotos to labeled blocks, functions leave lower_dispatch; fill_holes ident argument in expression hole

Outcome: forward gotos whose label is a later sibling of the goto's enclosing statement become `break` out of an IR labeled block, so those functions lower structured instead of through lower_dispatch.

Gap: every goto or label forced the whole function through lower_dispatch, which hoists locals into `MaybeUninit`/`zeroed()` slots, wraps the body in one `unsafe`, and relies on the Rust structure_goto rules to recover shape. Facts saw an unordered function.

Before (goto_return_value.c, Rust):

    let mut result: i32 = unsafe { core::mem::zeroed() };
    unsafe { result = mark(6i32); result += mark(7i32); ...; return result; }

After:

    let mut result: i32 = mark(6i32);
    '__slate_break_0: { break '__slate_break_0; result = mark(9i32); }
    result += mark(7i32);
    ...
    result

Implementation (crates/slate-analysis/src/transform/structure_goto.rs, pass `structure-goto`, slot AfterMacroStrip, runs first):
- Per function, skip when it has computed goto, a label address, asm goto labels or asm entry labels.
- Post-order over statement lists. For a `Label` at index j: count gotos to it inside earlier siblings along jumpable paths (block, loops and their condition/increment statements, if, switch/case, labels; not macro bodies, SEH, OpenMP, nested functions). If that count equals all gotos to the label in the function, wrap siblings [first goto statement, j) in `block %fresh`, retarget those gotos to `break %fresh`, and splice the label's body in its place. Labels in increasing order nest the blocks (error ladders become nested blocks).
- A label with no gotos is dissolved.
- Bail (label stays) when the range declares a binding read after the label, declares a cleanup or variably modified local, or holds a case/default of a switch outside the range.
- A `break` out of a cleanup variable's scope runs its guard (structured lowering's Drop guard), checked by `with_cleanup` in the fixture.

Also: `macro_templates::fill_holes` now fills an ident-shaped argument into an expression hole as `Expr::Var`, as `macro_rules!` expands it. Exposed by fixtures.merge/macro_name_arguments.c, whose `run` used to dispatch: PUSH(&s, func) with `->func` made the parameter `$func:ident`, and the template check compared `MacroName("func")` with the site's `Var(func)`.

Fixture diffs: 17 tests/fixtures and 3 fixtures.merge blocks regenerated. Mostly better (no zeroed/MaybeUninit, scoped unsafe, `for i in a..b`, `match`).

Limits:
- Dead code after an unconditional goto is kept (`break 'b; x = 99;`); transforms never drop source.
- Diamonds (`if (c) goto A; ... goto end; A: ...; end:`) become nested labeled blocks where the dispatch rules used to recover if/else (goto_nested_if.c, goto_switch_forward.c).
- A declaration in the range that is read after the label blocks the label (`used_after` in the fixture); hoisting is follow-up work.
- Backward gotos are slate-8ge7.24.10.3.
