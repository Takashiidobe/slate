# Lower record aggregates and initialization in the slate frontend

_2026-09-30 20:35:58_

slate-p58o.3.16.

- ValueKind::Aggregate on structs and fixed arrays: a complete, in-order, non-zero-fill aggregate lowers to a struct literal (Name { f: v }) or array literal; otherwise to { let mut __slate_aggregate: T = unsafe { std::mem::zeroed() }; __slate_aggregate.f = v; __slate_aggregate[i] = v; __slate_aggregate }. Nested subobjects lower recursively and carry their own zero_fill. GNU Range members and unions stay barriers.
- Uninitialized local arrays whose element is not a scalar/raw pointer (records, nested arrays, fn pointers) now use mem::zeroed instead of a broken 0 as T repeat.
- ArrayDecay accepts any place, not only bindings, so field arrays (w.data[i]) decay through as_ptr/as_mut_ptr, unsafe when the place chain dereferences.
- Direct calls to any extern function are wrapped in unsafe (previously only printf). This was the zero_init.c blocker and unblocked most of the corpus: abort/exit/getchar calls compiled as safe calls before.
- Promotions: struct_init, zero_init, aggregate_value_member_ops, array_of_structs, nested_structs, pointer_compare_address, array_one_past_end_bound, new aggregate_zero_fill (partial arrays, {0}, designated array of structs, nested partial arrays) plus 70 more local fixtures, 291 gcc-torture, 5 gcc-dg.
- uchar_conversions.c (mbstate_t) and non_int_fields.c block on unions -> 3.17.
