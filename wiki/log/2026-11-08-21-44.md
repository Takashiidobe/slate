# Close fenv-aware float rewrites as won't-do

_2026-11-08 21:44:22_

slate-os0h.3.1.76 closed without implementation. __slate_fenv_* shims (lowerer/values.rs lower_environment_arith/int_to_float) already run hardware FP that honors the live rounding mode behind an opaque call. rustc_apfloat/arpfloat are soft-float, so an APFloat fallback is slower than the shim. Proving default fenv state needs interprocedural tracking of fenv mutators and sticky flag readers (fetestexcept/fegetenv), and FENV_ACCESS code nearly always calls fesetround, so it would rarely fire. f80 has no native rustc type (long double stays in long_double.c). Decision: no APFloat dependency, shims remain the lowering for Rounding::Environment ops.
