# Lower MSVC __movs* and __stos* string intrinsics through slate-support

_2026-11-07 18:59:30_

slate-j3by.15: MSVC intrin.h declares __movsb/w/d/q and __stosb/w/d/q; the IR keeps them as calls to the header decl, so slate emitted extern decls nobody defines (LNK2019 __movsb in MinHook trampoline.c). No asm or parser change: libc_catalog.rs gains a hand-maintained MSVC_INTRINSICS table (libc_symbols_table.rs is generated by slate-libc-gen) mapping them to slate_support helpers on i686/x86_64-pc-windows-msvc (__movsq/__stosq x64 only); lookup chains it after SYMBOLS.
slate-support (vendor, cfg windows + x86/x86_64): movs<T> copies with ptr::copy unless src < dst < src+n, where rep movs replicates a pattern and a forward element loop runs instead; the test is one (dst-src) wrapping_sub >= n*size_of::<T>(). __stosb is ptr::write_bytes; wider __stos* are fill loops. Helpers take usize because support-function shapes render size_t as usize.
Fixture: msvc/string_intrinsics.c covers disjoint, dst<src overlap, dst>src pattern replication and no-op copies per width plus each fill (x64, i686; aarch64 builds the #else stub). MinHook not re-run per the user; the fixture is the validation.
Validation: msvc profile 475/475, slate profile 36/36.
