# ARM32 glibc struct stat was musl-shaped: fixed bits/arm/stat.h and bits/types.h ILP32 typedefs

_2026-09-07 13:36:17_

libc-shim/bits/arm/stat.h was a verbatim copy of musl's arch/arm/bits/stat.h (verified byte-identical against /home/takashi/musl/arch/arm/bits/stat.h), applied unconditionally to glibc too since bits/stat.h's dispatch only branches on arch. Real glibc arm (confirmed against the ARM GNU 15.2.rel1 cross toolchain under qemu-arm-static) uses a simpler non-LFS struct: single 32-bit ino_t/off_t/blkcnt_t, XOPEN2K8 timespec fields, two trailing __glibc_reserved longs -- sizeof 88, not musl's 128, and ino_t at offset 12, not 96.

Root cause was two-fold: bits/arm/stat.h itself (now split on __SLATE_LIBC_GLIBC, musl branch untouched), and bits/types.h's shared 32-bit ILP32 else-branch (covers arm, x86 i386, riscv32) which hardcoded off_t/ino_t/blkcnt_t/fsblkcnt_t/fsfilcnt_t to musl's always-64-bit widths per real glibc bits/typesizes.h's SLONGWORD/ULONGWORD (32-bit). Split that branch on __SLATE_LIBC_GLIBC too; off64_t/ino64_t/blkcnt64_t/blksize_t/nlink_t were already correct.

Verified by compiling a sizeof/offsetof probe against both the real sysroot headers and libc-shim headers with --target=armv7-unknown-linux-gnueabihf -- exact byte match (88 for glibc, 128 for musl unchanged). Unskipped stat_struct and stat_mtime_member in tests/differential_arm.rs; both pass under arm-lowering and arm-rewrites, full suites otherwise unaffected (only the pre-existing, separately-tracked abi_unadjusted failures remain: slate-3f8g.4.16.19).

Noted but did not fix: tests/libc_shim_suite.rs's linux_stat_layout_matches_architecture can't validate Arm today since TestConfig::target() returns None for Glibc/Musl, so those probes compile under the host's x86_64 target rather than a real armv7 one -- attempting to add an Arm case there produced sizeof=144/offset=28, i.e. host ABI leaking through, not the real arm one. Tracked as slate-k89h.9.6 (closed as fixed for the actual bug; this test-harness gap is a separate, smaller follow-up if ever wanted).
