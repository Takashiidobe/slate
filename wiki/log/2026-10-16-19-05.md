# FileCheck runs after the runtime check

_2026-10-16 19:05:19_

Supported single-file suites now run FileCheck only after the C/Rust runtime comparison passes (slate-5vj0.4).

- translate_slate no longer runs FileCheck. RunConfig.filecheck_target (set only for supported buckets via support::translation_target) makes compare_batch run it after compare_runs succeeds.
- Unsupported buckets never run FileCheck, so the ratchet is decided by runtime alone; a promoted fixture gets checks generated afterwards.
- compare_batch writes <name>.runtime-ok next to <name>.generated.rs when the runtime matches C and removes it first on every run.
- update_filecheck.py refuses to regenerate a fixture without that marker ("Rust did not build or did not match C; checks left unchanged"), so checks are only ever updated over runtime-correct output.
- update_filecheck.py accepts bare fixture names; an ambiguous name (longlong is in fixtures and gcc-torture) is an error asking for a path.
- support::failure_report ends each supported suite's panic with 'N failing fixtures: a b c', pasteable into update_filecheck.py.
- Removed the now-unreachable 'filecheck' class from first_barrier.

Verified: a bogus CHECK on buffer_return_lift fails after the runtime passes and is listed; the tool updates by name, rejects the ambiguous name, and refuses without the marker. slate profile 17/17 in 37s.
