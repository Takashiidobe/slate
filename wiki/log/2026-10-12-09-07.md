# slate-3f8g.4.17.14.4 MS asm entry labels and C label jumps

_2026-10-12 09:07:54_

A C goto into an MSVC \_\_asm label used to end the function silently: the label binding had no Statement::Label, so Graph::label left a Node::End. Graph::statement now gives every EntryLabel piece an extra Node::AsmGoto (new Option<BindingId> field) that the label jumps to; lowering it runs the same asm! with 'jmp Nf' prepended (numeric_local_labels takes the entry binding and treats EntryLabel as a definition). Jumps from asm to C labels already lowered through the asm goto dispatch. Clang cannot compile either direction, so the harness gained RunConfig.expected_stdout: a sibling <name>.expected replaces the C build and run. fixture i686/ms_asm_entry_labels.c (dg-options --flavor=msvc, now a semantic flag) has expected output recorded with cl.exe x86 under wine: asm to C label, C into asm label, a loop through an entry label, entry plus asm goto in one block.
