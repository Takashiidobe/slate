# Per-function AVX level in SysV64 vector ABI

_2026-10-17 20:11:57_

slate-parser-3bbf: target("avx"/"avx512f"/arch=) on a function now widens the SysV64 vector register width used by AbiClassifier, as clang trunk's per-function AVX ABI (llvm-project 315c8bba) does. Declarations and definitions use their own features; calls use the calling function's (Lowerer.function_target), except calls to builtin declarations. The TU level is a floor. X86Isa::function_vector_register_bytes resolves the attribute's features with the existing implication tables. No installed clang implements this yet (23.1.1 and the local trunk build predate it), so expectations follow the upstream test. Regenerated CodeGen\_\_sysv_abi.c, builtin_pointer_to_vector_param.c and ir_vector_builtin_expansion.c; new target_attribute_vector_abi.c.
