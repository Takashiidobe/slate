# Classify libc calls from slate-parser header provenance

_2026-10-16 19:34:12_

slate-5vj0.5.1. Since the clang-ir frontend went away, the lowerer bound every direct call with CallBinding::unknown() and classify_function had no callers, so no call was ever Known: all 16 libc_call rules, printf_format, getenv_var and pointer_lattice's libc facts were dead.

FunctionName now carries an identity: for a bodiless declaration, classify_function(name, file name of Span.provenance.system_header), the outermost system header slate-parser records (slate-parser-crw.2). lowerer::lower takes &Files for the lookup. Direct calls and extern decls carry that identity. classify_function lost its canonical_type/Provenance parameters (macro-dump plugin leftovers); Provenance and CallBinding::unknown were removed.

Turning the rules on exposed four bugs, all fixed:
- long-double printf bridges (__slate_printf__r..._f80) were Generated, so printf_format did not flush around them and println! output overtook libc output. call_c_bridge now takes the callee identity.
- printf in expression position (if printf(..) != 5) was neither converted nor flushed. printf_format is now all-or-nothing per program: any stdout writer referenced outside a statement-level call disables the rewrite.
- strlen on a VLA (Vec with len 0) became buf.len(). Vec is no longer a slice in the libc predicates; strlen uses len() only for str/String and a NUL scan for byte slices; strcmp on byte slices compares NUL-truncated prefixes.
- strnlen/strspn/strcspn returned usize into a u64 let; shared size_result cast.
Adjacent duplicate stdout flushes are collapsed.

Coverage after: abort 31 fixtures, memset 19, memcpy 24, exit 18, memmove 3, atoi 2, strlen 1, strnlen 1; println! in 369 fixtures (was 0). strcmp/memcmp/getenv still idle because calls sit inside expressions (slate-5vj0.5.8). Triage of the other idle rules filed as slate-5vj0.5.2-.7. slate profile 17/17; 58 fixture checks regenerated.
