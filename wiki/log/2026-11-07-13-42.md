# Move clang oracle to 23.1.4; fix convertvector bitcast operands and add nontemporal builtins

_2026-11-07 13:42:20_

slate-e36k.10: MSVC wchar.h --all-declarations failed on xmmintrin.h inline bodies.
- __builtin_convertvector of a vector bitcast hit 'internal error: elementwise conversion': elementwise_conversion's probe reused the operand node, so per_lane unwrapped the operand's own bitcast. The probe now carries a Void placeholder node (sema/numeric.rs). Fixes a doubled vector_bit_cast in gcc-dg dfp__pr104557.c.
- __builtin_nontemporal_load/store: CustomBuiltin::NontemporalLoad/Store. The typer checks clang's pointee rule (integer, floating, pointer or vector) and records the store's assign conversion; lowering is a plain read/write through deref (the hint is dropped).
- Unresolved __builtin_ia32_tmmultf32ps_internal came from version skew: compiler headers and predefines were clang 22.1.8, the builtin table a 23-dev snapshot, the oracle clang 23.1.4. Everything clang-side now matches 23.1.4: clang_builtins.rs and clang_aarch64_builtins.rs regenerated from llvmorg-23.1.4; slate-sysroots pins libclang-common-23-dev_23.1.4-2 (installed); the 17 clang predefine snapshots were renamed to clang-23.1.4_* with refreshed values plus the macros new in 23 (__SIG_ATOMIC_MIN__/TYPE__, __WCHAR_MIN__, __WINT_MIN__, TARGET_OS_FIRMWARE); has_checks/clang.rs and attribute_support/registered.rs regenerated.
- Clang 23 ships arm64_neon.h, which includes arm_neon.h. Removed suites/clang-test/.../CodeGen__arm64-neon-header.c (needs clang NEON builtins, slate-e36k.11); aarch64-msvc wchar.h now trips slate-e36k.12 (neon_vector_type ignored), so the libc-gen fallback stays.
Fixtures: clang/linux/x86_64/{convertvector_bitcast_operand,nontemporal_builtins}.c, error/clang/linux/x86_64/nontemporal_{record_pointee,non_pointer}.c; target_registry.c regenerated (clang_major 23). x86 MSVC wchar.h now parses fully.
