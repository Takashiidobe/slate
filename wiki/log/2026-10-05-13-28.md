# glibc clang fortify: pass_object_size overloads and FILE-typed builtins (slate-parser-6x05.39)

_2026-10-05 13:28:14_

With -O and _FORTIFY_SOURCE, glibc's clang path (__fortify_use_clang) defines static __attribute__((overloadable)) fprintf/printf/snprintf/... wrappers whose first parameter has pass_object_size, and calls __builtin___vfprintf_chk from them. Since overloads landed (6x05.38.15), 103 libsodium TUs failed 'redeclaration of an overloadable function'; past that was the bead's original 'expression without a typing rule'.

- names.rs: NameResolution::passes_object_size records functions with a pass_object_size parameter (attributes on specifiers, the parameter, or any declarator layer; new Declarator::layer_attributes covers Pointer layers).
- assertion.rs: an overload of compatible type is a redeclaration only when both agree on pass_object_size (clang treats it as a function-level part of the signature).
- typer resolve_overload: on equal ranks, a candidate with pass_object_size beats one without (clang's isBetterOverloadCandidate tie-break).
- builtins.rs: Opaque FILE/jmp_buf/sigjmp_buf/ucontext_t take the file-scope typedef of that name (NameResolution::builtin_typedefs), clang flavor only (ASTContext::setFILEDecl). gcc flavor stays as before: enabling it there matched a user siglongjmp(sigjmp_buf,int) to clang's noreturn library builtin, which gcc doesn't apply (gcc-dg Winfinite-recursion{,-2}). Builtin prototype array params now decay, as in clang.
- Not modeled: the hidden object-size argument clang passes; in the callee __builtin_object_size of the parameter is an ordinary query, so it's unknown and _chk never traps.
- Fixture: clang/linux/x86_64/ir_pass_object_size_overload.c (call targets the overload, as clang's _ZL7fprintf...U17pass_object_size1...).
- libsodium: 142 -> 245/247 ok. The last 2 (randombytes_sysrandom.c, randombytes_internal_random.c) hit glibc fcntl2.h's extern inline gnu_inline overloadable open(); filed slate-parser-6x05.50 (inline-only extern overloads need no mangling) beside 6x05.41.
- Parser profile: 7774/7774 pass.
