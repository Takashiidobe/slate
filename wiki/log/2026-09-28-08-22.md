# Fixture directories set compiler and target

_2026-09-28 08:22:14_

Fixtures now live at tests/fixtures/[error/ | suites/<name>/]<flavor>/[<os>/[<arch> | <triple>]]/, and the path is the only source of --flavor and --target (slate-parser-9rau). sema/ is gone, and nothing sits at the root.

- fixture_placement in tests/filecheck.rs and placement in tools/update_filecheck.py resolve the path the same way: required compiler dir, OS dir (default windows for msvc, linux otherwise), arch through CANONICAL_TRIPLES (default x86_64), or a full-triple dir for anything irregular (armv7 gnueabi/gnueabihf, i386-unknown-linux-gnu). Unknown dirs fail test-list creation.
- SLATE-FILECHECK-FLAVOR is removed. A valid --target/--flavor in ARGS/PREFIX-ARGS must match the path; invalid values stay for option-error tests.
- Migration was scripted from each fixture's effective (flavor, target). Every fixture sits at a full leaf; the old root files are clang/linux/x86_64. error/ holds only fixtures where every config errors (21 moved in, 2 moved out). gcc-dg, gcc-torture and clang-test moved to suites/. Five multi-target fixtures were split one file per leaf (target_registry.c into 30).
- Compiler/arch/OS name suffixes were stripped (ms-winnt-keywords-msvc.c is msvc/windows/x86_64/ms-winnt-keywords.c). sema/bool.c became bool_operators.c to avoid a collision.
- Headers reached through directive paths moved to tests/fixtures/inputs/. Quoted-relative ones sit beside their fixtures, copied where two leaves share one.
- Verified: the old CHECK lines passed unchanged except diagnostics that print the fixture path, and two declspec_support blocks that were already stale and passing only because FileCheck matches partially.
- gcc-torture now also runs as gcc (1591 copies in suites/gcc-torture/gcc/). IR differs from clang for about a quarter. The 46 blocked on <limits.h> are listed on cxg.13.
- corpus_sweep, check_record_layout and llvm_lit_sweep --migrate use the resolver. Wiki, bd memories and open bead paths were rewritten. New page: wiki/concepts/fixture-layout.md.
- Gate: 6170/6170.
