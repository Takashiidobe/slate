# Resolve x86 asm letters X, l, A, Yi/Yt/Y2/Ym/Yk; lower the A register pair

_2026-10-09 21:32:04_

slate-parser-asmlet.

Parser: l is reg; Yi/Yt/Y2 are xmm_reg (gcc rejects them, clang accepts); Ym mmx_reg; Yk kreg. X offers imm | sym | reg | xmm_reg | mem; both compilers put floats/vectors in xmm, integers in a GPR, constants as immediates, big aggregates in memory (gcc puts =X outputs in memory; we follow clang's register). A scalar float now ranks GPR classes below other registers, so rx/X pick xmm as gcc does while r/g keep the GPR. New AsmOperandClass::Pair { low, high } (printed {dx:ax}): A offers it for an operand of twice the word width, else {ax}; probes show both compilers use only rax for a 64-bit =A on x86-64 and rdx:rax for u128.

Slate: a Pair operand splits the u128 into ax/dx halves (in/out/inout explicit operands) and recombines outputs into the place; template references name the low register at 64 bits.
