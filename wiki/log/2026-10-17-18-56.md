# Lower __builtin_stdc_* bit builtins on integers and _BitInt, promoting builtin-stdc-bit-1

_2026-10-17 18:56:25_

slate-parser: sema types the fourteen stdc bit builtins (leading/trailing zeros/ones, first_leading/trailing zero/one, count zeros/ones, has_single_bit, bit_width, bit_floor, bit_ceil) from the generated clang records: unsigned integer or unsigned _BitInt operand, unsigned int result (bool for has_single_bit, operand type for bit_floor/bit_ceil). fold.rs evaluates them in constant expressions up to 128 bits, and __has_builtin reports them. BIT_INT_MAX_WIDTH is raised to 8388608 to match clang's __BITINT_MAXWIDTH__. c23_library FileCheck regenerated because <stdbit.h> now takes the builtin path instead of the inline fallbacks.

slate: lower_stdc_bit (bitint.rs) builds each builtin from the existing leading_zeros/trailing_zeros/count_ones helpers over plain prims, odd-width small _BitInt (via bit_count_expr and narrow_integer) and wide BUint. bit_floor/bit_ceil shift with checked_shl (plain/small) or shl_bits (wide). When any wide _BitInt of 64 KiB or more is lowered, the generated main wrapper runs __slate_main on a 1 GiB-stack scoped thread, since 8M-bit values overflow the default stack. New fixture bitint_stdc_bits passes on x86_64, i686 and aarch64; promoted gcc-dg builtin-stdc-bit-1, which closes slate-6uvv.12 and the slate-6uvv epic.
