# Lower selectany globals that are /alternatename or /include targets

_2026-11-09 09:49:43_

slate-j3by.20: ucrt wchar.h '__declspec(selectany) int _Avx2WmemEnabledWeakValue = 0;' plus '#pragma comment(linker, "/alternatename:_Avx2WmemEnabled=_Avx2WmemEnabledWeakValue")' was the last barrier in System Informer phlib/base64.c. sema marks the alternatename target (and any /include: symbol) include; lower_selectany (frontend/lowerer/selectany.rs) rejected every attribute besides selectany. It now accepts include: the comdat global_asm already defines the .globl decorated symbol, and it appends a .drectve ' /include:<symbol>' so the linker keeps an otherwise unreferenced comdat, as cl's /include does.
lower_static (globals.rs) also drops fallback (the /alternatename source), as functions already did since slate-j3by.7: the .drectve /alternatename resolves it at link time, so 'extern int a;' aliased to selectany data is a plain extern.
