# Store __block initializers after the byref header

_2026-11-02 12:15:02_

slate-3amj.42.5: a __block variable referenced in its own initializer (__block intfn fib = ^(int n){..fib(n-1)..}) failed to build: the capture named the Rust let from inside its own initializer, and the block body called the byref pointer instead of *value(fib) because lower_byref_let lowered the initializer before marking the binding byref. Now, as in clang, the header exists before the initializer runs: support byref(slot) writes only the header, init(slot) (goto dispatch) releases the previous incarnation and returns the header, and store(x, init) writes the value through forwarding after the initializer is evaluated, so an initializer that Block_copys the variable moves it to the heap first and the value lands there. lower_byref_let marks the binding byref first and puts the header let in pending. Fixtures: block_byref.c (recursive fib, self-referential Block_copy), block_goto.c (self-referential copy under a backward goto; previously crashed). All block FileCheck blocks regenerated; slate profile passes.
