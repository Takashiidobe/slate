# format generated Rust before file writes

_2026-09-01 07:09:11_

Added backend::format_rust and write_rust. Generated project modules, lib.rs files, build.rs/support sources, vendored support copies, and emitted fixture .rs files now pass through rustfmt --emit stdout --edition 2024 before std::fs::write. Program::emit remains pure and FileCheck strings remain raw. SLATE_RUSTFMT overrides the executable. Formatting or parse failure is returned before the destination write. A translate-project smoke crate was generated successfully and every emitted .rs passed rustfmt --check.
