# slate-yar4.45 lower_fallthrough_switch: folded switch case loop kept dead arms, instantiating invalid asm at -O0

_2026-11-17 14:00:27_

- bead: slate-yar4.45
- kind: bug
- area: crates/slate/src/frontend/lowerer/switch.rs

Outcome: a `[folded=V]` switch with fallthrough arms that keeps the case-loop lowering now emits only the live arm and the arms it falls into. Dead arms (asm invalid for the operand width, calls to undefined functions) are no longer instantiated at -O0.

Symptom: in a folded switch with fallthrough whose shared tail is longer than StructureDispatch's MAX_DUPLICATED_STMTS (24), `lower_fallthrough_switch` kept every arm in `loop { match case { ... } }`. rustc at -O0 then assembled the dead `case 1` asm for a u64 operand: "invalid operand for instruction".

Reproducer (crates/slate/tests/fixtures/x86_64/asm_folded_fallthrough_switch.c):

```c
switch (sizeof(*(p))) {
case 1: __asm__("movzbl %1, %k0" : "=r"(x) : "q"(*(p)));
case 2: TAIL(x) break;                     /* 28 statements */
case 4: __asm__("movl %1, %k0" : "=r"(x) : "r"(*(p)));
case 8: TAIL(x) break;
default: __bad_size();
}
```

Cause: `lower_switch` passed `folded` to `lower_fallthrough_switch` only as a bool, so `lower_switch_arms` used it just for the const layout of the discriminant. `lower_case_loop` lowered every arm. The match path is pruned by rustc through the `const { size_of }` scrutinee, but the loop variable hides the constant.

Fix (crates/slate/src/frontend/lowerer/switch.rs):
- `lower_switch` and `lower_switch_arms` take `Option<&ir::Number>`.
- `live_arm` resolves the folded value with `folded_case`: the first matching arm, else default, else none. It gives up when a case value is not a plain integer.
- `lower_fallthrough_switch` then starts the case variable at that index (no discriminant evaluation). `lower_case_loop` takes a `reachable` range: from the live arm through the first arm that does not fall through. Unreachable arms are not lowered.

Regression test: x86_64/asm_folded_fallthrough_switch.c, run through fixtures.unsupported first (it failed to build), then promoted. Checks cover widen_u8.

Limits: `lower_indexed_switch` (>128-bit discriminants) is not pruned. Folded switches never carry labels (parser rule), so dropping arms cannot drop a goto target.

See: slate-f2zu.14.34.8, wiki/concepts/ir/control-flow.md (folded branches).
