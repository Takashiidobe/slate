# Share MSVC comdat inline definitions across units in --merge

_2026-11-09 12:12:31_

slate-j3by.21: slate-j3by.1 shared weak_odr and discardable MSVC inlines across units only in translate-project; --merge lowers each unit alone (compile_isolated), so a comdat inline defined in two units of a merged Windows crate kept a body (and exported it) in each, and its static locals stayed per unit. The projection check reported the difference (48 mismatches on the new fixture). merge.rs: shared_comdats (index-keyed) became comdat_owners -> ComdatOwners (function name -> owning unit stem, plus __slate_odr_ symbols when every definition is discardable); translate_units takes it as a parameter. prepare_target computes it from the default-configuration parse, like CommonOwners, stores it on TargetBuild, and compile_isolated strips non-owner bodies and passes odr_symbols per row. Limitation: ownership comes from the default configuration, the same as commons; a comdat defined only under some feature set is not shared. Fixture: fixtures.merge/inline_odr.c (+ units/inline_odr.h, inline_odr_helper.c).
