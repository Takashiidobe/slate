slate-3f8g.4.17.13.1: lower_asm/lower_asm_block no longer barrier on aarch64 (arm32 still does, blocked on slate-5vj0.8.1).
Parser: clobbers, register asm labels and {reg} constraints were decoded with the x86 table on every target (aarch64 "r9" became x86 r9). New target::decode_register(family, name) dispatches; aarch64 uses target/aarch64.rs (added lr->x30, fp->x29); arm32 stays Other. Fixture clang/linux/aarch64/ir_asm_clobbers.c.
Slate (lowerer/asm.rs): reg/vreg/vreg_low16 classes; vreg_low8 (y) pins v0-v7 and prints by name. aarch64_register_modifier maps views to Rust w/x and b/h/s/d/q; unmodified references print full x/v like clang and gcc (verified with both) and are emitted explicitly to silence asm_sub_register. Q memory prints [{N:x}], immediates print bare, unused operands go in // comments. 16-byte vectors bridge through core::arch::aarch64::uint8x16_t. Barriers: explicit-register operands, x19/x29/sp clobbers, non x/v clobbers (SVE etc.), memory modifiers, >128-bit vectors. naked/global asm get no att_syntax off x86.
