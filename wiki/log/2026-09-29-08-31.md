# cxg.22: gcc-accepted conversions, transparent unions, header tag pruning

_2026-09-29 08:31:27_

cxg.22 (gcc.dg sweep): 46 of 48 files now accepted; all verified against gcc and clang.

- reachability.rs: the first file-scope declaration that references a tag
  (struct S; / extern struct S *x;) is kept when the tag is reached. Pruning it
  made a later struct S in a prototype a new tag (glob_t's gl_stat/gl_lstat
  had two distinct struct stat types; strftime rejected the caller's tm).
- builtins.rs: gcc declares __builtin_setjmp/longjmp with void * (clang void **).
  Under gcc, an unprototyped redeclaration of a builtin (double cabs();) is
  called as declared when an argument cannot convert to the builtin prototype.
- Null pointer constants: (enum e)0 counts; a C23 constexpr integer object is an
  ICE; from C99 on, an unevaluated ?: arm may hold a comma (C90 keeps the old
  rule, as gcc and clang do); a cast only yields an NPC to unqualified void *.
- _Atomic T * <-> void * converts silently.
- Arrays initialize from a compatible array compound literal (int d[] =
  (int[3]){1} gets length 3) and from a parenthesized string literal.
- transparent_union: typer picks the first member the argument converts to
  without a diagnostic (transparent_arguments), lowering wraps it in an
  aggregate, abi.rs classifies the parameter as the first member. Float/vector
  first members or differing sizes drop the attribute; typedefs accept it.
- C23 tag compatibility: join_compatible_tag is a greatest fixpoint, so
  mutually nested same-name redefinitions three deep are compatible.
- Conditional lowering converts enum/int operands through the usual arithmetic
  conversions instead of failing Internal.

Remaining in cxg.22: redecl-6.c and Warray-parameter-10.c. A redeclaration
must compose only with a visible prior declaration; slate keeps one type per
linked entity and needs a restore at block exit.
Fixtures: 27 gcc-dg migrations, transparent_union_call.c and
gnu_libc_algorithms.c now lower to IR.
