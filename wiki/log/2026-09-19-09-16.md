# x86 ISA feature flags drive predefines and vector ABI

_2026-09-19 09:16:29_

slate-parser-qiy. New src/target/x86_isa.rs: X86Feature (26 features, clang 22 implication graph), X86Arch (pentium4/k8 defaults, -march=x86-64[-v2|-v3|-v4]), X86IsaRequest (ordered -m/-mno- flags folded into enabled/disabled masks, which gives the same result as applying them in sequence), X86Isa (resolved arch + features).

Parsing: compiler_args accepts -m<feature>, -mno-<feature>, -msse4/-mno-sse4 (enable sse4.2 / disable sse4.1), and -march=. Rules: rejected on non-x86 targets and for MSVC flavor; rejected if the result lacks SSE2 (that would change the float ABI and \_Float16). The target rules are now separate entries in the top-level pipeline, because nesting them added an extra 'all rules failed:' prefix to the diagnostics.

Predefines: stripped **MMX**, **SSE**, **SSE2**, **SSE_MATH**, **SSE2_MATH**, **FXSR**, **LAHF_SAHF**, and the CPU macros (**k8\*, **tune_k8**, **pentium4\*) from the clang x86_64-linux, i686-linux, and x86_64-windows-msvc headers. Preprocessor::configure regenerates them from TargetInfo.x86_isa, next to the long-double predefines. Clang rules that aren't obvious: POPCNT/CRC32 follow SSE4.2 and XSAVE follows AVX unless explicitly disabled, even when set by a later flag; -march=x86-64-vN defines no CPU macro; i686 always has **LAHF_SAHF** and never CX16. GCC flavor sets **BIGGEST_ALIGNMENT** to 16/32/64; clang does not.

ABI: sysv64 passes a vector byval only when it is wider than the widest vector register (16, 32 with AVX, or 64 with AVX-512F). Checked against clang 22 IR.

Checked against clang -dM on 34 flag combinations (x86*64, i686, windows-msvc): no mismatches. Fixtures: x86_isa*_ (baseline, mavx, march v2/v3/v4, flag order, gcc avx512f, i686 baseline/v2, no-sse2 error), aarch64 and msvc rejection, ir_vector_abi_avx/avx512f.
Follow-up: slate-parser-d2e (ARM ISA flags, GCC \_\_FP_FAST_FMA_).
