# Lower switches as match with folded case patterns

_2026-10-01 09:02:58_

Follow-up to slate-p58o.3.41.

- Switches without fallthrough now lower to '__slate_break_<id>: { match <discriminant> { v1 | v2 => ..., _ => <default or empty> } }' instead of a selector temp plus an if-else chain. Patterns come straight from the IR's folded case constants (Pattern::I64, falling back to I128/U128); a non-constant case value is InvalidIr (Invariant::NonConstantCase).
- The fallthrough trampoline computes its case index with 'let mut case: i64 = match <discriminant> { pats => i, _ => default or -1 }'.
- Stacked labels were already one arm: the IR nests 'case 1: case 2:' (a label labels one statement) and switch_label folds the nesting. New: merge_empty_arms folds an arm whose body is only null statements or empty blocks ('case 1: ;', 'case 1: {}', '[[fallthrough]];') into the next arm's values, so it stays an or-pattern and does not force the trampoline. This replaces what structure_dispatch's empty-arm folding did as a rewrite in the old pipeline.
- New fixture switch_empty_label_or_pattern.c (passed before via the trampoline; this is a shape change), including u64 cases above i64::MAX.
