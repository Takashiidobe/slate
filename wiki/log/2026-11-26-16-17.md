# slate-3amj.5.26.1 define_new_tag: reject nameless record members with /Za

_2026-11-26 16:17:20_

- bead: slate-3amj.5.26.1
- kind: feature
- area: crates/slate-parser/src/sema/types.rs
- flavor: msvc

Outcome: MSVC /Za rejects nameless struct and union members during semantic analysis.

Gap: cl.exe reports C2467 under /Za for inline, tagged and typedef'd records without member declarators. Default mode accepts those declarations with C4201.

Before: `struct S { struct { int x; }; };` was accepted in both modes.

After: /Za reports that a nameless struct or union member is unavailable. Default MSVC accepts the declaration, and both modes accept named members.

Implementation: `TypeResolver::define_new_tag` uses the existing anonymous-member recognition before checking the MSVC extension flag.

Fixtures: `error/msvc/windows/x86_64/za_nameless_{struct,union,record_typedef}.c`.
