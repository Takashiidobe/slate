# Re-enable REWRITES FileCheck; convert all fixtures to marker scaffolding

_2026-09-04 13:23:08_

Removed the Profile::Rewrites early-return in tests/support/filecheck.rs that
silently no-op'd all REWRITES-DAG/-NOT assertions. Regenerated ~30 stale
fixtures found failing under --profile rewrites --no-fail-fast.

update_filecheck.py: added resolve_paths() (glob + fixture-root fallback) and
infer_mode() (auto project/library detection from path), so `just
regen-*-match <pattern>` can forward globs directly instead of hardcoding
paths in the justfile. Fixed two bugs blocking legit regen: empty-region
crash in extract_generated_regions, and ASCII-only identifier regex in
c_function_definition_name (rejected e.g. `π`).

Per user direction ("everything using the markers so we can see in code
review when a change is bad"), converted every remaining fixture — 6 with
declare-fold/region-boundary issues and 18 with legacy hand-written
REWRITES lines — to @lowering-fn-begin/@rewrite-fn-begin marker scaffolding,
eliminating hand-written FileCheck assertions fixture-wide. Extern-decl
signature checks (memcpy/memcmp/memmove/timespec_get) and whole-file NOT
checks were dropped since they aren't fn-scope-capturable; the exact
generated shape is now the source of truth instead.

Found macos/redirect_facts.c had two stray hand-written directive lines
blocking auto-regen, masking a stale assertion (expected `return`, actual
output uses a tail expression). Fixed.

Filed slate-w31k: function_pointer_presence.c shows the Option-comparison
fixup normalizes `if (op)` to .is_some() inside a callee but leaves
`op != 0`/`op == 0` as literal != None/== None in main() — a real fixup
scoping gap surfaced by re-enabling the check, not a regression from this
change.

cargo fmt and clippy clean. Full rewrites-profile suite passes.
