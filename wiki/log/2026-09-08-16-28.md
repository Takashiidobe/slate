# Fuse glibc declaration matrix probes

_2026-09-08 16:28:19_

The glibc x86_64 declaration matrix now writes one shim-header-matrix.c per header. It combines function type/link checks, renderable external object type/link checks, type-surface assertions, and macro-presence checks before compiling once. The ignored diagnostic matrix remains intentionally red against the incomplete shim; the normal libc profile is green.
