# slate-3amj.5.26.5 parse_decls: warn on standalone file-scope semicolons with /Za

_2026-11-26 16:35:22_

- bead: slate-3amj.5.26.5
- kind: feature
- area: crates/slate-parser/src/parser/decl.rs
- area: crates/slate-parser/src/diagnostics.rs
- flavor: msvc

Outcome: MSVC /Za reports one level-4 warning for each extra file-scope semicolon.

Gap: cl.exe reports C4019 under /Za /W4 for the second semicolon in `int x;;`. Default MSVC and /Za /W3 are silent.

Before: Slate accepted `int x;;` silently at all warning levels.

After: /Za /W4 reports “empty statement at global scope”. Empty statements inside a function remain valid and unaffected.

Implementation: `Parser::parse_decls` emits `Warning::ExtraTopLevelSemi` when it skips a standalone semicolon. The existing diagnostic severity resolver uses MSVC warning level 4.

Fixture: `msvc/windows/x86_64/za_extra_file_scope_semi.c` checks /Za /W4, /Za /W3 and default /W4.
