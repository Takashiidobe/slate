# Lower x86 vector asm operands (xmm/ymm/zmm/kreg)

_2026-10-10 08:59:25_

slate-3f8g.4.17.6. asm_scratch_type dispatches the vector classes to asm_vector_scratch_type: values of up to 4 bytes use a u32 scratch (xmm classes reject 8/16-bit types), 8 bytes u64, and 16/32/64-byte values core::arch::x86_64::__m{128,256,512}i (asm_bits_type now returns those for 16/32/64-byte storage). kreg keeps the exact width. asm_encode/asm_decode skip the 'as' cast when the bits type is not primitive. asm_full_storage accepts Vector. register_reference prints {N} for vector classes ({N:x}/{N:y}/{N:z} for 128/256/512 views) and keeps the GPR modifiers otherwise.
Rust needs avx for ymm_reg and avx512f for zmm_reg/kreg (avx512bw for 32/64-bit kreg). The parser widens x/v to ymm/zmm by width alone, so FunctionLowerer now carries target_features (Tables::enabled_target_features, split out of target_feature_attr) and asm_require_feature barriers when the function lacks the feature.
Promoted x86_64/asm_sse_register_operand and asm_sse_vector_operand; added x86_64/asm_avx_vector_operands (scalar float in x, ymm vaddps under target(avx), zmm vpaddd with Yk zero-masking and a =k compare under target(avx512f), guarded by __builtin_cpu_supports). Full slate profile green; builds ran with RUSTC_WRAPPER= (sccache still wedged).
