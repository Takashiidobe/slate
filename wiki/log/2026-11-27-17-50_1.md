# slate-8ge7.24.23.2 loop lowering: break-at-head loop folds to while !(c) via loop_or_while; loop bodies scoped only when they bind

_2026-11-27 17:50:26_

- bead: slate-8ge7.24.23.2
- kind: rewrite
- area: crates/slate/src/frontend/lowerer

Outcome: a C loop whose body starts with `if (c) break;` lowers to `while !(c) { .. }` (and `if c { .. } else { break }` as its only statement to `while c { .. }`), because lowering no longer wraps loop bodies in Rust scopes that bind nothing.

Before:

```c
static int forever(int a) { for (;;) { if (a > 9) break; a++; } return a; }
```

```rust
fn forever(mut a: i32) -> i32 {
    loop {
        if a > 9 {
            break;
        }
        a += 1;
    }
    a
}
```

After:

```rust
fn forever(mut a: i32) -> i32 {
    while !(a > 9) {
        a += 1;
    }
    a
}
```

Rule (crates/slate/src/frontend/lowerer/statements.rs, structure.rs):
- The For body with no increment and the While body after a hoisted exit test extend the loop body directly: nothing follows them in the iteration, so the loop's own block scopes them.
- `push_continue_block` (was `continue_block`, For with increment and DoWhile) uses `structure::push_scoped`, which pushes `Stmt::Scope { body }` only when `structure::binds(body)` (a top-level `Let`, `LetElse`, `LetIf`, or one inside `Cfg`), because the increment or exit test that follows must not see the body's C names.
- For with an empty init returns the loop itself instead of `Scope { [loop] }`.
- While(true), For with no head, and DoWhile build through `structure::loop_or_while(label, body)`, which calls the existing `header_test` on the plain first statement. No helper looks through a scope: a body that binds before its head test (`for (;;) { int b = ..; if (b > 50) break; .. }`) stays `loop`.
- DoWhile: `do { if (c) break; X } while (d)` -> `while !(c) { X; if !d { break; } }`.
