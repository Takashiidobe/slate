# Slate lowerer phase structs and structured barriers

_2026-10-01 07:20:23_

slate-p58o.10. The slate frontend lowerer is now ModuleLowerer (new = index into Tables, declare, lower_bodies, assemble) plus FunctionLowerer { tables, dependencies, temps }; topic files are impl blocks and every Cell/RefCell is gone. Dependencies (renamed from the bead's 'Needs') accumulates long_double, bridges, align_wrappers, and lazily built records; failed records are still dropped silently at assembly.

Errors: lower(module, &LowerOptions) -> Result<Lowered { program, barriers }, InvalidIr>. A Barrier is an unsupported Construct (coarse: ModuleAsm, Global, Function, Statement{kind}, Value{kind}, Place, Type, Record, Switch, LongDouble) plus a Site { node: NodeId, spelling, expansion }. Inside the lowerer a Failure carries an optional site; each spanned IR node (value, statement, record field, type definition, global, function) attaches its site on the way out only if none is set, so the innermost node wins without mutable tracking. InvalidIr (UnknownCallee, UnresolvedType) aborts lowering and can never become a barrier; support::translate_slate panics on it so no ratchet suite can absorb it. No parser change was needed: NodeId plus the rendered IR in the construct identify the op.

Deleted: Report, report(), module_barrier, function_barrier, Error::Unsupported(String). lowering-barriers prints function, construct kind, message. Follow-up: render sites as file:line:col (driver must keep the file map).
