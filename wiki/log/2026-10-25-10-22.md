# Pin the nightly toolchain and test targets

_2026-10-25 10:22:04_

Added rust-toolchain.toml pinning nightly-2026-09-07 (rustc 5a2be9f5f, the toolchain already in use), rustfmt, clippy, and the five rustup targets the tests build for: x86_64/i686/aarch64-unknown-linux-gnu and x86_64/i686-pc-windows-msvc. Other installed targets (musl, darwin, freebsd, android, wasm, riscv, armv7) were not used by any test; slate-parser only needs sysroots for those. With i686-pc-windows-msvc installed, i686 msvc fixtures now build for windows and run under wine, so flag_msvc_define.c, flag_msvc_std_c11.c, flag_msvc_std_clatest.c and i686/ms_asm_entry_labels.c pin i686-pc-windows-msvc instead of i686-unknown-linux-gnu (output unchanged). Documented the pin and how to bump it in AGENTS.md (## Toolchain), referenced from crates/slate/CLAUDE.md. msvc profile: 280/280.
