# slate-yar4.72 weak x87 callback: address of undefined function emits undeclared Rust name

_2026-11-24 14:10:08_

- bead: slate-yar4.72
- kind: bug
- area: crates/slate/src/frontend/lowerer
- target: x86_64

Outcome: The unsupported ratchet covers taking the address of an undefined weak x87 callback.

The fixture assigns an optional long double function to a local
callback and checks that its address is null. Clang links and
exits 0. Slate emits a reference to optional_step without a
declaration. Rustc reports E0425.

The typed IR preserves both the weak declaration and the function
decay. A two-unit probe with a strong definition present produces
the same build error. The callback needs a nullable address of
the native entry so the existing x87 trampoline can call it.

Fixture: crates/slate/tests/fixtures.unsupported/x86_64/long_double_weak_callback_address.c
Limits: Weak native entry lowering remains open in slate-yar4.72.
