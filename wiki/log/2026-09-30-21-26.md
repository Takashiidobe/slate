# slate-p58o.3.34: pointer-valued global initializers

_2026-09-30 21:26:29_

Closed slate-p58o.3.34 (Lower pointer-valued global initializers).

Change (lowerer.rs): is_constant_initializer accepts address constants.
- AddressOf and ArrayDecay of a place for which is_constant_address holds:
  a static or string binding, a field of one, a constant-index element of
  a constant base, or a deref of a constant pointer.
- PointerOffset of a constant pointer by a constant amount.
pointer_cast is a Convert and was already accepted. The existing value
lowering (addr_of_mut!, as-casts, .offset) is const-evaluable, so no
global-specific emission was needed.

Fixture: global_address_initializers.c (failed with 'initialized global
counter_ptr' before) covers &x, array decay, &a[i], a + n, &array,
2-D row decay, &s.field, &s, char-array decay with offset, const pointer,
pointer-to-pointer, pointer arrays, and pointer fields in a struct array.

Promoted: mem2reg_pointer_ssa; gcc-torture 20001027-1, 20031215-1,
20080522-1, 20120919-1, 921019-1, 980223, 991201-1, longlong, pr43438,
pr53084, pr57568, pr57860, pr57861, pr57877, pr58564, pr59387, pr69320-1,
pr97695.

global_array_pointer_decay.c now blocks only on _Alignas(32) on a static;
filed slate-p58o.3.40 for over-aligned globals.
