name containing '**', since bridge symbols use '**' as a separator
(**slate_ld**{entry}**r{tags}, **slate*{callee}**r{tags}). Bridge tags are
alphanumeric and never contain '**', so the name round-trips if c_shim splits
from the right: render_trampoline and header_for_shim_name now use rsplit_once.

(names*shim_family: ld**, ldv**, vcall**, icall**, ldfp*, cb*); cb* was already
a latent misdispatch, as c*shim still treats \_\_slate_cb*\* as callbacks
although nothing emits them. Fixtures: fixtures.library/long_double_dunder
(cross-unit **ld_scale/**ld_twice, called from the C driver too),
