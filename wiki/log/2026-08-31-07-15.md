# Implement Darwin time and signal ABI

_2026-08-31 07:15:46_

Implemented the AArch64 macOS time and signal declaration profile for
slate-sfzn.6.7.

Added macos-time-signal-headers.txt for time.h, sys/time.h, signal.h, setjmp.h,
and sys/ucontext.h. Darwin overlays model clock and time records, signal
records and alternate stacks, public ucontext_t, and 192/196-byte AArch64
jmp_buf/sigjmp_buf.

The public context scope is sys/ucontext.h for signal delivery. ucontext.h
process-context operations and private Mach exception state remain unavailable.

Added the macOS time_signal cross-target fixture with layout, constant, and
signature assertions plus generated Rust checks for clocks, interval timers,
handlers, masks, alternate stacks, and jumps. Extended standalone manifest
checks and SDK probes. Availability and cancellation suffix identities remain
redirect-ticket inputs.
