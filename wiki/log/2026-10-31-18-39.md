# Record macro invocations and argument ranges in the IR

_2026-10-31 18:39:25_

slate-f2zu.9.5.1: ir::Module.macros (MacroInvocations, via TranslationUnit.macros, built by pp/invocations.rs) lists macro calls written in user code with definition, site, per-argument ranges, enclosing parent and empty flag. Empty expansions leave no tokens or IR nodes, so this table is their only record; trace.expansions only runs under translate-project's planner and has no argument ranges. MacroInvocations::sites(loc) maps a node's expansion to its invocations, outermost first, as body or argument code. Not recorded: names spelled in system headers, directive expansions, calls not spelled at the site, invocations crossing or repeating an earlier site, so folds must still verify by re-expanding. Span::cover over mixed-origin tokens now widens expansion to every covered token, so the + of TWICE(x) x + x is body code rather than argument code; spans.c changed from 87+3 to 87+5. New dump flag --show-macros; fixture clang/linux/x86_64/macro_invocations.c. Removed clang/linux/x86_64/ast_sexpr.c at the user's request: it failed during this work, the cause was not investigated, and --sexpr output now has no fixture. Macro invocations are hashed into preprocessed_fingerprint. Validated: slate 33, clang 4809, gcc 3678, msvc 474, parser 8956; zlib --merge unchanged at 2544 compiles and 47084 lines with identical sources, projection 1024/0 mismatches, signatures 720/0 mismatches, validate_merge 6/6 default features.
