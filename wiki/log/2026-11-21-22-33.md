# slate-8ge7.24.11.7 switch lowering: label and case-final break only when needed; label_elide fires drop

_2026-11-21 22:33:51_

- bead: slate-8ge7.24.11.7
- kind: rewrite
- area: crates/slate/src/frontend/lowerer

Outcome: switch lowering emits its 'sw label and case-final break only when needed, so label_elide no longer cleans up after most switches.

Before (lowerer output): `'sw: { match i { 0 => { out += 1; break 'sw; } 1 => { continue 'brk; } .. } }`; tail_break_drop, drop_label, then drop_loop_label removed the label and breaks.
After (lowerer output, same final Rust): `{ match i { 0 => { out += 1; } 1 => { continue; } .. } }`.

Rule (crates/slate/src/frontend/lowerer/switch.rs, structure.rs):
- structure::drop_tail_break removes a break to the switch label that ends the match (through trailing if/match/scope).
- The switch keeps a LabeledBlock only when structure::uses_label_or_exprs still finds a jump; else a Scope. It does not unlabel jumps: an unlabeled break inside a labeled block would target the enclosing loop.
- case_loop (fallthrough switches) labels its loop through structure::label_needed.

Measured (SLATE_RULE_TRACE, 3070 files, after slate-8ge7.24.11.4): tail_break_drop 554 -> 135, drop_label 450 -> 160, drop_loop_label 35 -> 13; break_to_else 21 and loop_tail_break 13 unchanged. No FileCheck changed: the lowerer now produces what the rules produced.

Limits: no label_elide rule reaches 0, so none is deleted. Remaining fires are likely IR LabeledBlock from goto structuring and the dispatch loops (control_flow.rs), not yet checked.

See: slate-8ge7.24.11.4.
