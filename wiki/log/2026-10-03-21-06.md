# Website build uses platform header directories

_2026-10-03 21:06:30_

Removed SLATE_ROOT from www/build.sh; the Cargo manifest is relative to the script in this repository.
SLATE_HEADERS overrides the directory containing compiler-headers/ and sysroots/.
Defaults match Slate local data paths: absolute XDG_DATA_HOME or ~/.local/share on Linux, ~/Library/Application Support/Slate on macOS, LOCALAPPDATA/Slate/data on Windows Bash environments.
Windows paths are converted with cygpath when available; relative XDG_DATA_HOME is ignored.
Documented the override, defaults, and GNU utility requirements in www/README.md.
Validation: bash -n, git diff --check, and 13 simulated path-resolution checks passed. Full WASM build was not run; Rust was unchanged.
