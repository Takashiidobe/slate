# SQLite differential fuzzer prototype

_2026-10-16 17:58:09_

Added tools/fuzz/sqlite_differential.c and tools/fuzz/sqlite.py (build|seeds|fuzz). Native SQLite is compiled with -fsanitize=fuzzer-no-link and linked into a libFuzzer binary; the Slate translation from tools/benchmark/sqlite.py --build-only is dlopened with RTLD_LOCAL|RTLD_DEEPBIND. Each input runs as SQL on an in-memory db in both libraries and a trace of open/prepare/step/finalize codes, error messages, changes and typed column values (doubles as %a, text and blobs as hex) is compared. Determinism: PRNG_SEED test control per input, wrapped VFS with fixed clock and randomness that refuses named files, progress handler stops after a fixed step count, heap limits reset per input, authorizer denies global pragmas and compile_options. SLATE_SQLITE_DIVERGENCES=<dir> records divergent inputs instead of aborting. Results: native-vs-native self-check and native-vs-translated replay of 35,896 fuzzdata seeds both clean; 10 minutes on 12 workers (~975k execs) found no divergences. Tracked in slate-o8s4.
