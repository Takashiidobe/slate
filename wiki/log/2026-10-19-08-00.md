Change: new engine rule const_fold (late registry, priority 48, after literal_casts) evaluates integer constant trees with Rust semantics over i8..u64: casts wrap, + - * / % bail on overflow or div-by-zero, shifts need amount < width, wrapping_add/sub/mul wrap, ! and unary - respect signedness. Untyped literals adopt the other operand's type only if they fit; all-untyped trees, usize/isize, i128/u128 and floats are left alone. A foldable tree becomes a suffixed literal (500u64, -3i8). const_fold::fold_initializers also folds Static/Const initializers, emitting bare literals when the declared prim (or array element) type matches, so tab[4] = [0, 1, 2, -3].
