# Emulate gcc x86 ISA feature flags

_2026-10-26 09:45:09_

slate-3amj.23: the gcc flavor accepted only the x86-64 levels and 27 original features (GCC_FEATURES). Now it accepts every x86_isa_tables.rs feature gcc 16 accepts (all but invpcid, rdpru, retpoline-external-thunk; -m80387 for x87). gcc's enable/disable sets are not transitive nor inverses (-mamx-bf16 enables amx-tile but no xsave; -mno-xsave keeps sha512/sm3/sm4/vaes; -mno-sse keeps aes/pclmul/sha; -mno-avx512dq keeps vp2intersect), so tools/generate_x86_isa_gcc.py measures them from gcc -dM into src/target/x86_isa_gcc_tables.rs (gcc_enables, gcc_disables, gcc_macros) and X86Feature::enables/disables apply them directly for Rules::Gcc; clang keeps closure/dependents over clang_implies. Also for gcc: MMX follows SSE late unless set explicitly, levels carry no CRC32 of their own (-march=x86-64-v2 -mno-sse4.2 drops it), __USER_MSR__ spelling, fma4 defines __FP_FAST_FMA*. tools/x86_isa_diff.py --gcc compares against gcc: levels, each flag on x86_64/i686, each -mno- with every flag on, and orderings: 345 cases, 0 mismatches. Fixtures: gcc/linux/x86_64/x86_isa_gcc_features.c (new), error fixture now -minvpcid, promoted slate gcc/x86_64/flag_gcc_isa_features.c.
