# slate-yar4.69 lower_value_node: __builtin_assume_aligned drops offset effects

_2026-11-24 11:19:05_

- bead: slate-yar4.69
- kind: bug
- area: crates/slate/tests/fixtures.unsupported

Outcome: The unsupported ratchet covers effects in the optional
offset to __builtin_assume_aligned.

The fixture passes buffer + 1 and an offset function that increments
a counter and returns 1. The buffer is 16-byte aligned, so the
alignment promise holds. lower_value_node returns the pointer and
discards the remaining operands even though the typed IR retains
the offset call. On all four Linux targets the C oracle exits 0
and translated Rust exits 2 because the counter stays at zero.
