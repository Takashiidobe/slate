# Lower weak extern globals and ?: in static initializers

_2026-11-07 10:10:23_

slate-f2zu.10.3: two musl global barriers. (1) 'extern weak hidden' linker-provided symbols (__ehdr_start, _DYNAMIC, __init_array_start, __fini_array_start) hit 'attributes' because lower_static rejected symbol.weak. Weak declarations (not definitions) are now accepted: Tables.weak_globals records them, the extern decl becomes '#[linkage = "extern_weak"] static X: *mut T' (rustc requires a pointer type and yields the address, null when undefined), lower_binding dereferences it, and is_constant_address excludes it since an extern static cannot be read in a Rust static initializer. Weak definitions stay a barrier. Visibility on declarations was already ignored. (2) is_constant_initializer had no Conditional arm, so '?:' in initializers (musl sysconf values, __fsmu8 bittab, getaddrinfo lo4) was non-constant; it now accepts a conditional whose three operands are constant and whose type is not (complex) long double. Fixtures: fixtures/weak_extern_globals.c, fixtures/static_conditional_initializer.c; promoted gcc-dg gcc-only torture__pr90020.c and torture__pr116835.c (weak undefined globals). musl barriers 9 -> 1 (slate-f2zu.10.4).
