# slate-f2zu.14.19 static initializer: pointer offset on integer address (LIST_POISON1) or past extern unsized array (SYSCTL_ONE) failed const eval; use wrapping_offset

_2026-11-14 17:34:53_

- bead: slate-f2zu.14.19
- kind: bug
- area: crates/slate/src/frontend/lowerer/pointers.rs

Outcome: pointer arithmetic in static initializers lowers to `wrapping_offset`,
so rustc const-evaluates offsets on integer addresses (LIST_POISON1) and past an
extern array of unknown size (SYSCTL_ONE).

## Symptom

Kernel shards failed const eval (98 errors, 37 shards):

- `((256i32 as *mut ()) as *const u8).offset(16045481047390945280u64 as isize)`:
  "in-bounds pointer arithmetic failed ... 0x100[noalloc] which is a dangling
  pointer (it has no provenance)" (LIST_POISON1/2, TIMER_ENTRY_STATIC, ...).
- `addr_of!(sysctl_vals) as *const i32).offset(1)`: "beyond the end of the
  allocation of size 0" (`extern const int sysctl_vals[];` declared as
  `[i32; 0]`, defined in another TU; SYSCTL_ONE in sysctl tables).

## Reproducer

    #define LIST_POISON1 ((void *)0x100 + 0xdead000000000000UL)
    static struct list_head poisoned = {LIST_POISON1, LIST_POISON1};
    extern const int sysctl_vals[];
    static void *one = (void *)&sysctl_vals[1];

## Cause

`FunctionLowerer::lower_pointer_offset` (frontend/lowerer/pointers.rs) always
emitted `.offset`, whose const-eval check requires an in-bounds pointer with
provenance. Neither an integer address nor an offset into a zero-length extern
declaration satisfies it.

## Fix

When `in_static_initializer` is set, the default and `void *` arms emit
`.wrapping_offset(n)` (no unsafe block). The address computed is identical for
every C program whose arithmetic stays valid; runtime code keeps `.offset`.

## Regression test

- crates/slate/tests/fixtures/static_init_pointer_offset_constant_address.c
  (poison addresses, char/int/negative offsets on integer addresses,
  sysctl-style table).
- crates/slate/tests/fixtures.library/static_init_extern_unsized_array_offset
  (extern unknown-size array defined in another unit).
- FileCheck regenerated for 6 fixtures whose static initializers now show
  `wrapping_offset`.

Limits: an integer poison stored in a function-pointer field
(bpf_tail_call_proto.func = BPF_PTR_POISON) still fails rustc's fn-pointer
validity check; split to slate-f2zu.14.24.
