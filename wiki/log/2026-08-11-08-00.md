# goto lowering and c-testsuite fixture batch

_2026-08-11 08:00:00_

Closed out arbitrary-`goto` support and a wide c-testsuite fixture batch.

- **`4803019b`** / **`edcb801b`**: reworked goto lowering to reach 100% libexpat compilation. Added `emit_generic_with_args_flattened` (`src/cir/emit.rs`) as an opt-in second CIR emission path that runs `cir-opt` with `--cir-flatten-cfg --cir-goto-solver`, turning a function's nested structured CIR into a plain multi-block CFG (`cir.switch.flat`/`cir.brcond`/real `cir.br` edges) instead of ClangIR's usual nested form. Deliberately only applied to functions that actually need it — flattening every function unconditionally would still be correct but would degrade goto-free functions from native Rust `if`/`loop` into an ugly `loop { match state { .. } }` dispatch.
- **`c2bf5f10`**: extended `cir/flatten.rs` to support `goto` jumping across nested local scopes (not just within one block), needed once the flattened-CFG path was live.
- **`7344b53f`**: lowered Duff's device (a `switch` whose `case` labels sit inside a nested loop body) — 145 lines in `lower.rs` to walk case labels through nested control constructs instead of assuming labels are always direct children of the switch.
- **`53fcd7cf`**: `preprocess.rs` macro-state tracking now follows state correctly through nested `#if`/`#ifdef` directives (132-line rework), fixing macro expansion that previously reset or leaked state across directive nesting.
- **`7ce236e6`**: separated C's tag namespace (`struct Foo`) from its ordinary/value namespace (`Foo` as a variable or typedef name) in `codegen.rs`/`program_recipe.rs` — C allows the same identifier in both namespaces simultaneously, which Rust's single namespace can't represent without disambiguation.
- **`21a63070`**: preserved variadic function-pointer type signatures through lowering (previously variadic-ness could be dropped between the pointer type and its target).
- **`511b07b6`**: `inline_temps.rs` was losing the concrete pointer type of a null function pointer once it was cast — fixed the temp-inlining fixup to retain the casted type instead of falling back to a generic null.
- **`534f306e`**: preserved C's enum _object_ representation (the underlying integer type C compilers actually choose, not always `i32`) through 77 lines of `lower.rs` changes.
- **`903cd15a`**: unsigned integer literal types (e.g. `0U`, `1UL`) now round-trip through `codegen.rs`/`effects/support.rs` instead of being widened/narrowed to a default signed type.
- **`13c47c90`** / **`4127a44c`**: further c-testsuite fixture cleanup, including a `facts/goto.rs` fix for goto-target fact collection.
- **`df30e063`**: anonymous structs/unions declared in a header weren't being re-exported when a second header included the first one two hops away — fixed in `lower.rs`, `anonymous_header_two_hop.c`.
- **`8c5ea662`**: sprintf-format fixup (`sprintf_format.rs`) now recovers loop-driven zero-padded buffer writes instead of bailing out of the rewrite.
- **`95c0e069`**: stabilized nested-aggregate initialization ordering between `program_recipe.rs` and `lower.rs`.
- **`34235242`**: fixed a flaky chibicc TLS test (`tls.c`) that depended on thread-scheduling-sensitive output ordering.

Each c-testsuite fix removed its case from `tests/fixtures.c-testsuite.unsupported/TRIAGE.md`, moving it to the supported/passing corpus.
