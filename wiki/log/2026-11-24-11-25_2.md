# slate-e36k.16 pure_update: __atomic_fetch_udec logical OR rejected

_2026-11-24 11:25:04_

- bead: slate-e36k.16
- kind: bug
- area: crates/slate/tests/fixtures.unsupported

Outcome: The unsupported ratchet covers unsigned atomic decrement at its reset boundaries.

__atomic_fetch_udec returns the old value and resets the stored
value to the limit when old is zero or exceeds the limit. An old
value equal to a nonzero limit decrements normally. Lean verifies
these fixture values in a 32-bit model, including the case with
both high bits set. Clang executes the complete fixture. Slate
builds the right conditional IR, but update_children rejects its
logical OR, so pure_update blocks the operation on all four Linux targets.
