# slate-8ge7.24.11.2 lowering: pointer eq/ne null emits is_null() from IR types; null_compare rule and peel_ptr_cast deleted

_2026-11-27 17:01:29_

- bead: slate-8ge7.24.11.2
- kind: rewrite
- area: crates/slate/src/frontend/lowerer
- area: crates/slate/src/backend/engine/rules

Outcome: the lowerer emits `p.is_null()` / `!p.is_null()` for eq/ne of an object or block pointer against a null constant, decided from IR types, and the `null_compare` Rust rule (with `peel_ptr_cast`, which guessed pointer types from Rust casts) is deleted.

Before (C: `if (head->next == NULL)`, `wcschr(s, 'n') != NULL` with a `const wchar_t *` result):

    if unsafe { ((*head).next as *mut ()).is_null() } {
    total += !unsafe { (wcschr(const_month, 110i32) as *const i32).is_null() } as i32;

After:

    if unsafe { (*head).next.is_null() } {
    total += !unsafe { wcschr(const_month, 110i32).is_null() } as i32;

Rule: `FunctionLowerer::raw_null_operand` (lowerer/optional.rs) picks the non-null side of an eq/ne whose other side is `null_value` (Null or a pointer-typed constant, through Copy/Convert), peels pointer casts (`peel_pointer_casts`), and takes the peeled operand if it is an object pointer or `BlockPointer`, else the unpeeled one. Function pointers are not matched (they lower to `Option<fn>` and compare with `None`). `lower_null_check` emits the method call. The arm sits after the nullable-borrow `null_check` (`is_none`/`is_some`) and `opaque_null_operand` (`-fno-delete-null-pointer-checks`) arms, so those still win.

`not<bool>(eq/ne(p, null))` lowers to the flipped check directly, unless the comparison is a macro hole. truth-canonicalize folds that shape outside macros but stops at macro bodies, so `#define UNLESS(c) (verbose > 1 && !(c))` would otherwise render `!(!$c.is_null())`; the deleted rule used to collapse `!!x.is_null()`.

Measured: null_compare.rs (137 lines) removed, lowerer +64 lines; null_compare fires 0 (rule gone).

Fixtures: crates/slate/tests/fixtures/c23_library.c, null_compare_is_null.c (`null_mut::<u8>() != null_mut::<u8>()` becomes `!null_mut::<u8>().is_null()`), null_deref_macro_args.c (casts before is_null gone). Block fixtures and merge fixtures unchanged.
