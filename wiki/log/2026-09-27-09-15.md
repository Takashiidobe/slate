# Sweep gcc.dg against gcc and migrate 1,147 feature fixtures

_2026-09-27 09:15:44_

Added tools/gcc_dg_sweep.py. It runs every gcc.dg C test through slate-parser parse --flavor=gcc --dump-ir and gcc -fsyntax-only, using the test's -std/-D/-Wno- options. With no dg-options it applies the default the directory's .exp file uses: -ansi for gcc.dg itself, cpp, tls, weak, ipa, tree-ssa and a few others; -std=gnu99 for dfp; nothing elsewhere. gcc must not get -w: it silently downgrades GCC 14+ permerrors (int-conversion, incompatible-pointer-types, implicit-int), which overstates what gcc accepts.

Result over 18,457 files: 13,875 both accept, 2,742 only gcc accepts (1,305 outside optimizer-only dirs), 1,490 both reject, 346 only slate accepts, 4 hangs, 0 panics. The 1,305 were clustered into epic slate-parser-cxg (27 children); each bead lists its repro files and which to migrate on fix. Largest real bugs: under --flavor=gcc #include <limits.h> always fails (the vendored gcc-16.1.0 headers lack the generated limits.h/syslimits.h that glibc include_next's), block-scope _Float32/__uint128_t declarations parse as expressions, sema hangs on zero-length array initializers (init-excess-1.c), and the debug build overflows its stack on a 2,160-term + chain (inline-24.c).

Migrated 1,147 passing tests into tests/fixtures/gcc/gcc-dg/ (<dir>__<name>.c, FLAVOR gcc, explicit STD). They come from language-feature families: c2y/c23/c11/c99/c90/gnu*, bitint, attr, builtin, vla, init, atomic, asm, cpp/, dfp/, tls/ and others. Excluded: optimizer dirs, torture/, tests with quoted includes or additional sources, auto-init-*, and outputs over 4,000 lines. Also dropped: embed tests that #embed __FILE__ (the output depends on the fixture's own bytes), source_date_epoch (depends on __DATE__/__TIME__), and cpp/include3 and cpp/embed-6/7 (they need their original filename or directory).

Cargo.toml now has [profile.test] with release codegen settings, so plain cargo nextest run is optimized while the dev profile stays fast to build. Verified: cargo nextest run passes 4,199/4,199.
