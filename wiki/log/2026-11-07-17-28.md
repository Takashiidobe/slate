# Lift list-argument macros as one macro_rules repetition

_2026-11-07 17:28:24_

slate-f2zu.9.5.12.31 (still open, blocked by .32): finish_macro_site now calls macro_templates::make_repeat_parameter for each f args list parameter. It finds the call whose last argument is the list's last element, and walks back over elements that are bare holes used once. That run becomes one MacroParamShape::Repeat parameter, always last, with matcher $(, $x:expr)* (or $($x:expr),* when it is the only parameter). Earlier elements and converted ones stay $x__N. If the last element is wrapped (a promotion cast), the repetition is appended empty, so arities still share. At most one list repeats per template. fill_holes splices the repetition back for the self-check and expand_template_calls. Codegen prints it as __slate_macro_list_<name>, and format.rs restores $($x),* or $($x,)* before a comma, so a zero-element call becomes f(a, ). zlib sample (linux-x86_64): Tracev 3, Tracevv 2, Tracecv 2 templates, differing only by ($x__N) as i32 promotions, which .32 owns. Fixture: fixtures.merge/macro_repetition.c (Tracev at arities 1-8 shares one name; the u8 site is Tracev__2). Regenerated flush_streams, macro_arguments, macro_boundaries, macro_fold, stdio_bindings (TRACE__2 and LOG__2 merged away). Documented in slate-architecture.md. Ran project_merge 5/5 (differential plus template self-check). Not run: slate and parser profiles, since templates exist only under --merge (deferred to .14).
