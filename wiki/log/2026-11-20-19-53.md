Outcome: with SLATE_IR_POINTERS=1, lowering emits &T / &mut T / &[T] / &mut [T] for params and locals straight from slate-analysis Borrow facts and skips the Rust-side pointer_lattice; every fixture, gcc-torture and gcc-dg case builds and matches C, and the default output is unchanged.

Gap and why it mattered: steps 1-2 of slate-8ge7.6 only reported IR pointer capabilities in shadow mode. The give-up oracles (pointer_lift_local_copy_chain, pointer_lift_reassigned_local) still stayed raw.

Before (gate off, oracle):

```rust
fn pick(mut q: *const i32, b: *const i32, n: i32, which: i32) -> i32
    s += unsafe { *q.offset(i as isize) };
fn sum(t2: *const i32, n: i32) -> i32
```

After (gate on):

```rust
fn pick(a: &[i32], b: &[i32], n: i32, which: i32) -> i32 {
    let mut q: &[i32] = a;
    if which != 0 { q = b; }
    ... s += q[i as usize];
pick(a.as_slice(), b.as_slice(), 2i32, 0i32)
fn sum(t2: &[i32], n: i32) -> i32   // called as sum(a.0.as_slice(), 4i32)
```

Implementation:
- slate-analysis pointer.rs: `Borrow { mutable, many }` on `PointerFact`, from `PointerCapability::borrow()`. An UNPROVEN class flag is seeded by call arguments lowering can't turn into a borrow (raw/temporary/return roots, void pointee, mutable or unborrowable local roots, calls inside macro expansions). It propagates forward along arg->param flows. A MACRO flag marks bindings named in macro arguments. Cleanup handlers and functions named in global initializers count as address-taken. Retyped casts and Temporary/Return sources make the destination raw.
- lowerer/borrows.rs (new): borrowed params/locals; `*p` / `p[i as usize]` places; any other value read falls back to a raw pointer (`p as *const T`, `p.as_ptr()`), so every existing lowering path stays valid. `lower_borrow` turns arguments into `&x`, `arr.as_slice()`, reborrows, `core::slice::from_ref`, or if/else. A packed pointee keeps the raw form.
- calls.rs: with a borrowed argument, the non-trivial siblings are hoisted into lets (borrowck). Function pointers are not hoisted (fn-item coercion).
- param_spills::fold no longer folds a `let mut q: &T = param`, which would force equal lifetimes on `q = b`.
- interproc: pointer_lattice::apply is skipped under the gate.
- tests/support: translation_key hashes SLATE_IR_POINTERS. A fixture line `// SLATE-ENV: K=V` sets the translate environment; both oracles use it.

Fixture: crates/slate/tests/fixtures/pointer_lift_{reassigned_local,local_copy_chain}.c (gated). Ungated locks: pointer_lift_{prefetch_arg,returned_to_opaque,join_two_sources,aliased_params_written}.c.

Limits: gate on, fixtures lift 222 params vs 216 off, but 17 fixtures lose lifts and 143 FileChecks differ. Losses: companion lengths and &str (slate-8ge7.10), cross-unit pub functions in fixtures.release (slate-8ge7.11), returned params, void pointee, Box, and the conservative oracles (slate-8ge7.12).
