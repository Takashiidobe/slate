# sanitize_ident mangles Ok/Err/Some/None

_2026-08-25 14:41:00_

translate-project --lib on giflib (~/giflib -> ~/giflib-rs, slate-2ppd epic) failed to compile: a local C variable named Err (gif*err.c, qprintf.c) lowered verbatim to 'let mut Err: \*mut i8', which rustc rejects with E0530 (let bindings cannot shadow tuple variants). Raw identifiers (r#Err) do NOT fix this - raw-ident syntax only escapes keyword collisions, not value-namespace collisions with prelude tuple/unit variants, confirmed with rustc directly. Fixed by extending sanitize_ident (src/frontend/lowerer/constants.rs) to append an underscore to Ok/Err/Some/None the same way it already does for crate/self/Self/super/*. Plain type names (Result, Option, Box, Vec) don't need this - they only live in the type namespace, so shadowing them with a local value binding is legal (verified: only a warning, not an error). Added tests/fixtures/local_named_err.c as regression coverage. Fixes slate-2ppd.1; the sibling anon_0 cross-module union bug (slate-2ppd.2) is still open.
