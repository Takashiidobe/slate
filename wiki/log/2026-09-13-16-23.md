# Preserve bit-field width expressions

_2026-09-13 16:23:10_

Added FieldDecl.bit_width as an optional spanned expression and taught both top-level and nested record parsers to retain bit-field widths instead of skipping them. Width parsing uses ConstExpr parse_one so comma-separated fields and trailing attributes remain correctly delimited. Added focused coverage for literal, identifier, binary, sizeof, unnamed zero-width, comma-separated, and nested bit-fields, and regenerated every affected fixture. Verified the focused fixture against clang's AST.
