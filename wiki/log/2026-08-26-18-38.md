# Lower cir.freeze (slate-3i0x.8)

cir.freeze is reachable via \_\_builtin_nondeterministic_value. Clang folds the operand to #cir.poison at CIR emission regardless of source initialization, so the op's true value is compiler-defined, not something a differential test can pin to a specific number. lower_freeze in arithmetic.rs treats it as an identity passthrough (result = operand_expr(input)), which is correct freeze semantics: pick one arbitrary-but-fixed value and use it consistently. tests/fixtures/freeze_builtin_ops.c tests the invariant that matters (frozen == frozen is true, i.e. the same frozen SSA value is reused consistently) rather than a specific bit pattern, avoiding a flaky comparison against unspecified behavior.
