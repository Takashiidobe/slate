# slate-8ge7.24.10.7 labeled-blocks: goto diamonds lower as if/else and match arms instead of nested labeled blocks

_2026-11-21 21:52:31_

- kind: rewrite

- area: crates/slate-analysis/src/transform/structure_goto.rs

Outcome: goto diamonds (`if (c) goto A; ... goto end; A: ...; end:`) lower to nested if/else and plain `match` arms again; the new IR pass `labeled-blocks` (crates/slate-analysis/src/transform/labeled_blocks.rs) recovers them from the labeled blocks structure-goto builds.

Before (tests/fixtures/goto_nested_if.c, after .10.2):
```rust
'__slate_break_0: {
    '__slate_break_1: {
        '__slate_break_2: {
            if a > 0 { if !(b > 0) { break '__slate_break_2; } } else { break '__slate_break_1; }
            r = 1;
            break '__slate_break_0;
        }
        r = 2;
        break '__slate_break_0;
    }
    r = 3;
}
```
After:
```rust
if a > 0 { if b > 0 { r = 1; } else { r = 2; } } else { r = 3; }
```
goto_switch_forward.c: `match x { 1 => { r = 10; } 2 => { r = 20; } _ => { r = 30; } }` (the dispatch rules used to give an if/else chain on a temp).

Rule (runs after do-while-zero, Slot::AfterMacroStrip, fixpoint per function):
- sink: `block L { ..jump }` with exactly one `break L` (not inside an evaluation) takes the statements after it, up to the first jump or up to the end of an enclosing block or loop body (plus that `break P` / `continue loop`), in place of the break. Blocked by: cleanup/VLA Let or SehTry in the block; a named Let in the block whose C name occurs elsewhere in the function, its parameters, globals or functions (lowering keeps C names, so the moved tail could read the shadowing one); a Label/Case/Default in the moved tail; a moved Let read after the tail.
- else arm: `if c { A; break X } B..` -> `if c { A } else { B.. }` when the list's end reaches X, or the list ends in `break X` (kept). Also moves the rest into the arm that falls through when the other arm ends in `break X`. A then arm left empty is swapped under `transform::negation`. Continue exits are deliberately not used: `if (c) continue; rest` stays an early continue (trying it nested 16 loop fixtures).
- trailing `break P` at P's end dropped; blocks with no breaks dissolve (kept as `Block` when they declare); case siblings move into the Case body; then case arms ending in `break P` with the switch at P's end become `break switch`.
- diverges() treats a switch with a default whose last case diverges and that has no break of its own as a jump.
- structure_goto::jump_lists is now pub(super).

Measured (fires.py, SLATE_RULE_TRACE, same fixture set as .10.9): label_elide::break_to_else 61 / 34 -> 30 / 16; tail_break_drop 559 / 92 -> 548 / 86; drop_label 2015 -> 1976. The remaining break_to_else fires are lowering spelling: `continue` in a `for` with increment (lowered as a labeled body block), switch fallthrough duplication in switch.rs (switch_torture 7), and cleanup-guarded loops; they go with slate-8ge7.24.11, so the rule stays.

Fixtures: new fixtures.transforms/structure-goto,labeled-blocks/diamonds.c (nested, cases, skip, exits, shadowed and cleanup bail). Regenerated goto_nested_if, goto_switch_forward, goto_return_value, goto_lift_into_nested, goto_multi_exit_loop, cleanup_always_inline_handler (guard numbering only), merge macro_name_arguments (`!(n > 5)` -> `n <= 5`), merge splice_statements.

Limits: the tail moves, never duplicates (transform invariant: no cloned nodes), so a label with two gotos keeps its block. In --merge this can split variants: splice_statements.c shifted_names has two `goto found` under ALPHA and one otherwise, so the non-ALPHA variant sinks and the merged Rust gains cfg arms.
