Seven name-routed Phase 4 fixtures were really common semantics and became Phase 3 children: switch fallthrough, compound literals, pointers to extern C functions, anonymous members.

Fixes (slate lowerer):
- globals.rs: Unary/Arith over constant operands and FunctionDecay are constant initializers (sema does not fold -1 in static int x = -1).
- pointers.rs/values.rs: Convert involving a function pointer transmutes (fn<->ptr, fn<->fn) or goes through usize (fn<->int); Option<fn> has no as-cast.
- names.rs: locals and parameters named Some/None/Ok/Err get name_<id>, since let patterns cannot shadow prelude variants.
- functions.rs/lowerer.rs: the Rust main wrapper builds argc/argv from std::env::args for main(int, char **). Other arities above 0 get no wrapper, so a 3-arg main fails loudly instead of receiving a null envp.

Fix (slate-parser compiler_args.rs): accept -O, -O0..-O3, -Os, -Oz, -Og for gcc/clang. Above -O0 it undefines __NO_INLINE__ and defines __OPTIMIZE__ (+ __OPTIMIZE_SIZE__ for s/z), matching clang/gcc -dM. -Ofast is rejected (fast-math not emulated); msvc rejects all. Documented in compiler-flags.md, FileCheck fixtures for accept/reset/reject.
