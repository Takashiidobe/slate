# Bidirectional declaration-matrix: shim extraction, header diff, reverse probes

_2026-09-08 21:51:02_

Implemented slate-b66b.14.9.1/.2/.3 in tests/support/libc_declaration_probe.rs.

Refactored the AST-walking collectors to take an is_public predicate instead
of a hardcoded oracle-file check, then added a shim-side mirror of the oracle
extraction pipeline (shim_header_ast, shim_header_preprocessor_output,
shim_record_layout_dump, extract_shim_header_functions/objects/macros,
extract_shim_type_surface), a public-header-file-set diff (extract_*_header_files
+ diff_header_files), and compile_and_link_oracle_probe so the existing
renamed-decl + _Static_assert probe generators can run shim-derived
declarations against the real oracle sysroot instead of the reverse.

Validated against the live bug (libc-shim/include/arpa/nameser.h leaking
getopt.h/pthread.h/sched.h/signal.h/time.h/unistd.h/features.h under musl):
the file diff names every leaked header, and the reverse probe fails to
compile against real musl with "use of undeclared identifier 'getopt'/'pipe'".
Both give the specific, actionable diagnostics the epic asked for.

Fixed a real bug in is_public_shim_header_file along the way (it excluded
bits/ paths, dropping libc-shim's own macro-generated stdint.h typedefs).
Tried and reverted a declaration_file() change (using loc.includedFrom.file
as a fallback) that looked plausible but is semantically wrong - that field
names the parent that included the current file, not the current file -
confirmed by a regression in unistd_environ_object_matches_glibc_oracle.

Known residual gap, not introduced here: declarations that are not the first
node dumped from their file have no directly-attributable file in this
module's stateless per-node lookup. Causes one cosmetic false-positive
(stdint.h shows as "missing" from shim in the file diff even though its
content is present via bits/types.h). Fixing this generally needs stateful
current-file tracking during the AST walk, same as clang's own dumper does;
out of scope for these three chunks.
