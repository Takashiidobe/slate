# slate-e36k.28 __builtin_elementwise_bitreverse: lower integer scalars and vector lanes

_2026-11-24 20:28:19_

- bead: slate-e36k.28
- kind: bug
- area: crates/slate/src/frontend/lowerer/vectors.rs
- area: crates/slate/vendor/bitint
- area: crates/slate/tests/fixtures

Outcome: Clang's elementwise bit reversal lowers for scalar integers, fixed-size integer vectors, and scalar _BitInt values.

## Symptom and reproducer

```c
unsigned char reverse_byte(unsigned char value) {
  return __builtin_elementwise_bitreverse(value);
}
```

Translation reported "builtin without a lowering" despite the typed IR
preserving the builtin operand and result types.

## Fix

FunctionLowerer::lower_elementwise_bitreverse emits primitive reverse_bits
for scalar values and maps it over vector lanes. Narrow _BitInt values
shift the reversed primitive to remove the extra carrier bits. The vendored
BInt and BUint reverse_bits methods reverse both limb order and bits within
each limb, then shift away padding. BInt rebuilds the signed representation
from the reversed bits.

## Regression test

crates/slate/tests/fixtures/elementwise_bitreverse.c covers signed and
unsigned scalars, four-lane signed and three-lane unsigned vectors, narrow
and wide signed/unsigned _BitInt, and a side-effecting operand. It passes on
x86_64, i686, aarch64, and armv7 Linux.

See: slate-e36k.29 tracks constant expression evaluation.
