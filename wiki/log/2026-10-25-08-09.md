# Fill automatic locals for -ftrivial-auto-var-init

_2026-10-25 08:09:44_

slate-3amj.4: zero and pattern now reach the IR as Variable::auto_init (ir/declarations.rs: AutoInit::Zero | Pattern(PatternFill)), set in sema/module.rs for automatic lets with no initializer and no __attribute__((uninitialized)) (new Attribute::Uninitialized). TypeResolver::auto_init (sema/types.rs) resolves the flavor into bytes so consumers need no flavor rules. Oracles (clang 23, gcc 16): clang memsets the whole object 0xAA (padding too) then 0xFF per float scalar; gcc writes 0xFE per scalar leaf (floats too), leaves padding, zeroes a standalone _Bool, and fills each run of adjacent bit-fields with the repeating byte truncated to the run width. Slate: lowerer/auto_init.rs paints a per-byte image from the type layout and emits in-place write_bytes after the let (lower_statement appends after_declaration, renamed from self_initializer) because a typed move drops Rust padding; the goto dispatch path in control_flow.rs writes through the slot pointer. Zero needed no lowering change (locals were already zeroed). VLA pattern and over-512-run arrays are barriers (follow-up beads).
