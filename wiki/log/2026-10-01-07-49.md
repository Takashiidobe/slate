# Slate lowering barriers site parameter failures at the parameter

_2026-10-01 07:49:52_

slate-p58o.15: in lower_extern and lower_function, a parameter's lower_type failure is wrapped with used_at(Site::of(parameter)).

- A type that fails without a site (e.g. _Complex double) is now sited at the parameter, so the miette report underlines the parameter inside the prototype, with "in function"/"in declaration of" on the prototype's first line.
- A failure already sited elsewhere (a record definition) keeps that site and gets a "used here" label on the parameter.
- Return types have no Span in the IR and still fall back to the function site.
