# Lower GNU case ranges in the slate frontend

_2026-10-01 09:12:00_

slate-p58o.4.9.

- 'case lo ... hi:' lowers to an inclusive range pattern (lo..=hi) in both the plain switch match and the fallthrough trampoline's dispatch match. SwitchArm values carry an optional range end (CaseValue).
- Endpoints use i128 ranges when both fit, else u128 (InclusiveRangeU128). An empty range (lo > hi) matches nothing, so it contributes no pattern; Rust rejects lo > hi range patterns (E0030).
- slate-parser folds unsigned _BitInt(128) case constants as Number::SignedInteger even above i128::MAX; case_number falls back to u128 for those.
- gnu_case_ranges.c gains classify_empty for the empty-range case.
- Promoted: gnu_case_ranges, switch_torture, switch_case_u128_values, and gcc-torture pr34154.
