# slate-8ge7.24.6 truth-canonicalize: IR transform for from_bool/ne(_,0), not(not), ?: 1 : 0 and || temporaries; delete bool_simplify and bool_ternary

_2026-11-21 17:52:49_

- bead: slate-8ge7.24.6
- kind: rewrite
- area: crates/slate-analysis/src/transform
- area: crates/slate/src/frontend/lowerer
- area: crates/slate/src/backend/engine/rules

Outcome: truth values are canonicalized on the IR by the `truth-canonicalize` transform; the Rust rules `bool_simplify` and `bool_ternary` (fold, int_arms) are deleted.

Before (Rust rules over Rust shapes, with an is_bool guess and a VarTypes map):
  `(c as i32) != 0` -> `c`, `!(a == b)` -> `a != b`, `if c { true } else { false }` -> `c`,
  `1i32 != 0i32` -> `true`, `let t = if a { true } else { f() != 0 }` -> `a || f() != 0`.

After, on the IR (crates/slate-analysis/src/transform/truth_canonicalize.rs, slot AfterMacroStrip, before inline-temps):
- `ne(from_bool(b), 0)` -> `b`; `eq(from_bool(b), 0)` -> `not(b)`; `not(not(b))` -> `b`; `not(const<bool>)` folds.
- `not(eq|ne)` inverts for any operand type (exact under NaN); `not(lt|le|gt|ge)` only for integer, bool, pointer operands.
- `conditional<int>(c, 1, 0)` -> `from_bool(c)`; `(c, 0, 1)` -> `from_bool(not c)`; `(c, 1, from_bool(y))` -> `from_bool(c || y)`; `(c, from_bool(y), 0)` -> `from_bool(c && y)`; bool arms likewise without from_bool.
- sema's `let t: bool; if a { t = true } else { t = f() != 0 }` -> `let t = a || f() != 0` when `t` is a bool `Temporary`; inline-temps then moves it into the `if`. A user variable keeps its `if`.
- const-fold: a comparison of two integer constants is `const<bool>` (`_Bool f = 1` -> `true`).
Blocked by: `explicit` conversions/comparisons, `Module::macro_values` nodes, kept expansions.

  int f(void) { if (g() || h()) return 1; return 0; }
  before: let __v0: bool = (unsafe { g() }) != 0 || (unsafe { h() }) != 0; if __v0 { return 1; }
  after:  if (unsafe { g() }) != 0 || (unsafe { h() }) != 0 { return 1; }
  int s(int a, int b) { return a < b ? 1 : 0; }
  before: if a < b { 1 } else { 0 }
  after:  (a < b) as i32

Lowering (crates/slate/src/frontend/lowerer):
- `lower_number` spells a bool constant without `as bool`.
- `lower_exit_condition` negates loop exits through `transform::negation` (same rules) for do-while, and for while/for when the condition has hoisted statements (`while (n--)` -> `if __v0 == 0 { break }`). A bare head test keeps `!c` so `LoopToWhile` recovers `while c`; `loop_to_while::negate` folds `!true`/`!false`.

Why value-preserving everywhere: sema types every condition and `&&`/`||`/`!` operand as `bool`, so no rewrite depends on being in a truth context.

Measured: 3067 fixtures, 220 translations changed, all exit codes unchanged; 212 with a net line change (the rest are macro variant renumbering). `c ? 0 : 1` gives `from_bool(not c)`, and that new `not` is simplified at once (`exit(twice(21) == 42 ? 0 : 1)` -> `exit((twice(21i32) != 42) as i32)`).

Fixture: crates/slate/tests/fixtures.transforms/truth-canonicalize/{from_bool,conditional,temporary,kept}.c, fixtures.transforms/const-fold/comparison.c, and regenerated FileCheck blocks.

Limits: negations built by the backend's goto structuring stay as `!(i < 5)` (goto_sibling_loops.c), and a do-while(0) exit inside a kept macro body is `if !false` in a few x86_64 asm fixtures; deferred to a fixture scan at the end of slate-8ge7.24. An int-typed `?:` temporary (`a ? 1 : g() != 0`) keeps its `if`.
