# slate-xw0x.16 slate-mutate: add typed strategies and an isolated mutation profile

_2026-11-24 09:38:00_

- bead: slate-xw0x.16
- kind: feature
- area: crates/slate-mutate
- area: crates/slate/tests
- area: .config/nextest.toml

Outcome: The mutation profile compares typed expression and statement edits on existing C fixtures and removes its generated executables after each run.

Before
The opt-in generated_differential mode could only replace integer constants.

After
Run `SLATE_DIFF_FIXTURE=peel_casts SLATE_MUTATE_RULES=string,statement cargo nextest run --release --profile mutation` to replace a byte string or delete a standalone puts call. The normal slate profile uses its original differential path.

Implementation
- Each candidate carries a typed edit and the source edit to give the C oracle. Select strategy groups with SLATE_MUTATE_RULES and sample reproducibly with SLATE_MUTATE_SEED.
- Replace operators on simple unsigned wraparound expressions and negate observable integer comparisons. Negate an if only when both branches return constants.
- Mutate float and double constants, character literals, bounded reads of initialized arrays, and object pointers in equality comparisons.
- Resize the literal global, array decay and C type metadata together for strings. Exercise empty, embedded NUL, invalid UTF-8, a malformed UTF-8 sequence, the euro sign and 4096 ASCII bytes.
- Stage C oracle executables, Rust Cargo outputs and runtime files in temporary directories. Save source artifacts and arguments on a finding.

Fixture
Eight existing fixtures covered all strategy groups. Clang, GCC and MSVC agreed with Slate on 147 selected comparisons. The slate profile passed its 44 tests with mutation excluded.

Limits: Clang and GCC provide the builtins for infinity and NaN fixtures. Array extent, allocation length, pointer alias and flag matrices remain in slate-xw0x.17.
