# slate-8ge7.24.10.4 lower_dispatch: dispatch only the residual goto region; structure-goto threads goto-to-break

_2026-11-21 20:27:16_

- bead: slate-8ge7.24.10.4
- kind: feature
- area: crates/slate/src/frontend/lowerer/control_flow.rs
- area: crates/slate-analysis/src/transform

Outcome: lower_dispatch runs only on the residual goto region (the lowest statement list holding every remaining goto/label, trimmed to the statements that contain them); code before and after it, and around it, lowers structured. structure-goto also threads `goto L` to `break t` when `L:` is `break t`.

Gap: one irreducible goto sent the whole function through lower_dispatch: every local became a `zeroed()`/`MaybeUninit` slot, the body went into one `unsafe` state machine, and the Rust structure rules had to recover everything.

Before (goto_residual_region.c `irreducible`, prefix loop + irreducible region + suffix loop):

    let mut total: i32 = unsafe { core::mem::zeroed() };
    ... whole body as match __slate_state { ... }

After:

    let mut total: i32 = 0;
    for i in 0i32..3i32 { total += i; }
    let mut __slate_state: usize = 3usize;
    unsafe { ...two-state loop for a:/b: ... }
    for i in 0i32..2i32 { total *= 2; }
    total

Implementation:
- `control_flow::residual(list)` (crates/slate/src/frontend/lowerer/control_flow.rs): statements for which `needs_dispatch` holds; none -> structured. A single such statement that is Block, LabeledBlock, If, While/DoWhile (condition statements clean) or For (init/condition/increment clean) is "transparent": lowering recurses into it. Otherwise the range first..=last dispatches; if it declares a cleanup variable the range runs to the end of the list (its cleanup must not fire at range exit).
- `lower_statement_list` = structured prefix + `lower_dispatch(range)` + structured suffix. The three callers (functions, blocks, openmp) no longer choose; params moved to `FunctionLowerer::dispatch_params`. `dispatching` is saved and restored around the region.
- Graph: `Break`/`Continue` whose target is outside the region become an exit node (`Node::Statement(statement, None)`, after unwinding active region cleanups), lowered as the structured `break 'label` / `break '__slate_continue_N`.
- Locals declared in the region keep their slots (declared before the dispatch loop, same Rust scope), so suffix uses still work.
- structure_goto.rs `scan_threads`/`thread`: a label whose first statement is `break t` gets every goto to it that sits inside `t` (not in a For init) rewritten to `break t`, unless a cleanup variable is declared between `t` and the label. This is the kernel `scoped_guard` shape (`for (...; ({ goto L; })) if (0) { L: break; } else`), which otherwise left the `for` in a nested dispatch region.

Fixtures: crates/slate/tests/fixtures/goto_residual_region.c (prefix/suffix loops, region inside a for with break/continue to the outer loop, a region-declared local used after the region); crates/slate/tests/fixtures.transforms/structure-goto/thread.c. 20 tests/fixtures blocks regenerated: `zeroed()` slots 33 -> 2, `MaybeUninit` slots 12 -> 0, `__slate_state =` 38 -> 36.

Limits:
- Rust structure rules do not recover a nested region with outer exits (goto_residual_region.c `nested` keeps its state machine); .10.5 decides rule fate by fire count.
- Threading is conservative: a cleanup declared before the label in t blocks it even when the goto is inside that scope.
- split_irreducible on the Rust side is not deleted yet (.10.5).
