# Emit exported function alias symbols

_2026-11-09 08:56:03_

slate-2o6o.5.7: alias("t") on a function now resolves in-unit (slate-2o6o.5.3), but an exported alias was never a symbol, so other units failed to link. ModuleLowerer::lower_function_alias emits global_asm!(".globl|.weak name[ .hidden|.protected]\n.set name, {}", sym <target>) for a bodiless function whose alias resolved to a same-unit definition and that exports_symbol accepts, on ELF targets (Linux, Android, FreeBSD; clang rejects alias on Darwin). sym keeps static targets and Rust names working. Fixture tests/fixtures.release/function_alias_units/: impl.c defines strong, static-target and weak aliases; main.c calls them across units. Cross-unit pointer equality is not checked: LLVM folds distinct external functions as unequal in the C oracle. slate profile: 36/36 passed.
