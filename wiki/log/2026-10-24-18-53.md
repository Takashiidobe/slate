# SCIP index for Rust navigation

_2026-10-24 18:53:46_

tools/scip/scip.py indexes the workspace with rust-analyzer scip (about 90 s, 39 MB .scip) and loads it into target/scip/index.db (SQLite, about 3 s): files, symbols (name, kind, crate, signature, docs), occurrences (line, col, is_definition, enclosing function from definition enclosing_range). Locals are dropped. Queries: def, refs, callers, hover, outline, search, status; names can be qualified (Preprocessor::reject_poisoned) or filtered with --crate. build takes a flock; a build requested during one sets rebuild-requested and the running build loops once more. tools/scip/post-commit (symlinked into .git/hooks) runs build-background detached, main worktree only, logging to target/scip/build.log. session-context prints SessionStart hook JSON with the index status and starts a build when none exists. scip.proto is vendored from sourcegraph/scip v0.5.2; protoc generates scip_pb2.py into target/scip. Navigating code in CLAUDE.md/AGENTS.md now puts SCIP first, LSP for files edited this session or changed since the index.
