# Lower %= asm labels to numeric local labels

_2026-10-10 08:51:18_

slate-3f8g.4.17.15. %= (GCC per-instance id; clang ${:uid}) has no Rust form: rustc escapes $, and a Slate-side counter breaks when LLVM duplicates the asm. Verified that numeric local labels survive duplication: a Rust asm! with 2:/2f/3b (3b pointing into .pushsection .rodata), inlined and unrolled to 30 copies, assembled and ran correctly.
unique_labels() in lowerer/asm.rs flattens the pieces (sentinel chars stand in for %= and for operand pieces). Each %= label name (the run of symbol chars around it) gets a number not already used as N: in the template, skipping 0/1-only numbers. The definition prints N:, and each reference prints Nf or Nb by position. Then it re-splits the text into pieces before normal rendering, so symbol substitution and operand slots are unchanged. definitions is a BTreeMap so numbering is deterministic.
Stopping point (barriers, follow-up slate-3f8g.4.17.22): no single name: definition (bare $%=, .set/.equ symbols, duplicate defs), names used by symbol-requiring directives (.globl/.type/.size/...), two %= in one name.
Fixture x86_64/asm_unique_id.c: loop with backward ref, forward skip in an always_inline fn called twice per loop iteration, .rodata string via .pushsection, and a template with its own 2: label. Full slate profile green.
