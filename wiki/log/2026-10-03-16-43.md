# Codegen parenthesizes transmute/copy_nonoverlapping cast operands

_2026-10-03 16:43:24_

slate-dghn.21: Expr::Transmute and Expr::CopyNonoverlapping print as 'unsafe { ... }' but starts_with_brace_expr in backend/codegen.rs did not list them, so a cast or binary left operand at statement start came out as 'unsafe { transmute::<..>(x) } as i32', which Rust parses as a block statement followed by a stray 'as'. Added both variants to starts_with_brace_expr; Cast and Binary already parenthesize such operands.

Promoted gcc-torture 20050316-1. Full slate profile otherwise green.
