# slate-8ge7.24.17.3 rust_ast unsafe markers: Deref(Pointee), Var/Call/MethodCall unsafe_ (Unsafe ignores cmp), Field union (UnsafeCmp)

_2026-11-22 11:01:48_

- bead: slate-8ge7.24.17.3
- kind: feature
- area: crates/slate/src/backend/rust_ast.rs
- area: crates/slate/src/frontend/lowerer
- area: crates/slate/src/backend/engine

Outcome: every unsafe operation in the Rust AST now carries a marker set by the lowerer (and by the rules that build unsafe calls), next to the existing Expr::Unsafe/Stmt::Unsafe wrappers; output is unchanged.

Gap and why it mattered: placement (slate-8ge7.24.17.4) needs to know which operations need unsafe without types; only the lowerer knows (wiki/concepts/rewrite-engine-v2.md#unsafe-placement).

Implementation:
- UnaryOp::Deref(Pointee::Ref | Pointee::Raw); every Deref site chose one.
- Expr::Var { name, unsafe_ } (Expr::var builds the safe case); Call, MethodCall, MethodCallGeneric gain unsafe_.
- unsafe_ is rust_ast::Unsafe(bool), which is always equal under Eq/Ord/Hash, so a static read still compares equal to Expr::var(name). Field gains union: UnsafeCmp(bool), which compares normally.
- Lowerer marks: raw derefs, static mut/extern static reads (tables.statics minus tables.read_only), unsafe callees and fn-pointer calls (calls.rs), raw-pointer methods (add/offset/read*/write*/write_bytes/offset_from/next_arg), atomic from_ptr*/volatile, core::ptr/slice/hint/mem calls, block support calls (all but scope), SVE arch intrinsics, union fields including bit units.
- values.rs unsafe_op(expr) marks the top op through casts and wraps; unsafe_wrap only wraps. In .4 both stop wrapping.
- Rules: printf_format fflush, prelude CStr::from_ptr, slot_promote zeroed.
- engine/unsafe_marks.rs: needs_unsafe (op-level predicate placement will use) and a temporary SLATE_UNSAFE_MARK_CHECK report of wrapper blocks with no marked op. 149 remain over tests/fixtures, all spurious today (immutable statics, addr_of!, structured-goto function-wide block). Delete the check in .4.

Fixture: none new; slate profile passes with no FileCheck diffs.

Limits: the check proves one mark per wrapper, not every op; E0133 after placement is the real test.
See: slate-8ge7.24.11.9 (design), slate-8ge7.24.17.4, slate-8ge7.24.17.5.
