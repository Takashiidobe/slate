# slate-8ge7.7 interproc: delete Rust-side pointer_lattice, length_lattice, SLATE_IR_POINTERS gate and shadow harness; lifts come only from slate-analysis facts

_2026-11-21 09:37:26_

- bead: slate-8ge7.7
- kind: rewrite
- area: crates/slate/src/backend/interproc
- area: crates/slate/src/frontend/lowerer.rs
- area: crates/slate-analysis/src

Outcome: pointer, length and C-string lifting come only from slate-analysis IR facts; the Rust-side pointer_lattice.rs (2.7k lines), length_lattice.rs (4.4k lines), the SLATE_IR_POINTERS gate and the shadow harness are deleted (-7.7k lines).

Before: lowerer::ir_pointers() read SLATE_IR_POINTERS; =0 skipped the slate-analysis Borrow/length/c_string facts and ran
pointer_lattice::apply (which called length_lattice) on the Rust AST inside interproc::run. SLATE_SHADOW=pointer_lattice
made lowering push rust_ast::ShadowDecision into Program.shadow and pointer_lattice diff them via backend::shadow_diff.

After:
- interproc::run is the link step only (export_candidates, link::rust_bound, bind_calls, SharedTypes::hoist); the
  "slice or CStr extern param left unbound" assert always runs. Exports::Fixed returns immediately.
- Lowering always reads facts.pointer (borrow_of, c_string_of, borrowed_parameters, c_string_parameters).
- Deleted with their only users: Program.shadow/ShadowDecision, backend::shadow_diff, tools/shadow_report.py,
  interproc CallGraph/scc_order/run_worklist, PhaseTimer::count, macro_templates::child_exprs_of,
  slate-analysis UnitFacts::pointer_bindings, PointerFacts.functions, PointerFact.capability (PointerCapability is now
  private to slate-analysis), and the SLATE_IR_POINTERS term of tests/support translation_key.
- The peelers (peel_cast, peel_cast_and_unsafe, peel_value, peel_unsafe_blocks) and method-name matching lived in the
  deleted files.

Default output is unchanged: the deleted code ran only with SLATE_IR_POINTERS=0.

Measured (tools/benchmark/interproc_scaling.py, N=800, tools/benchmark/results/interproc-scaling-2026-11-21.json):
wall time equals the IR default before the deletion (e.g. hub_kill 139.9 -> 143.2 ms, noise); with the gate off the
Rust-side interproc phases cost 2.4-18 ms per shape, now gone. slate 43/43 and merge 1/1 pass.

Limits: known lift losses vs the old Rust side stay open on the IR side: slate-8ge7.12 (void pointee, macro-pinned
calls, nested functions), .13 (&CStr for const char x[] = "..." locals), .20 (returned params), .21 (heap/Box).
The shadow harness must be restored from git (parent of this commit) for the next port that needs it.

See: slate-8ge7.14 (default flip), slate-8ge7.6, wiki/concepts/slate-analysis.md#shadow-mode.
