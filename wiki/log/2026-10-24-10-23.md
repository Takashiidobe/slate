# Fold branch-assigned locals into let-if

_2026-10-24 10:23:39_

slate-o3gw.9: a local declared without a value (or with a dead constant init) and followed by an if whose branches each end in 'x = v' now becomes 'let x = if c { .. v } else { .. v }'. New rule branch_init::BranchInitFold (engine/rules/branch_init.rs, priority 6) is keyed on the If node and turns it into NodeKind::LetIf, retiring the preceding Let; keyed on If because ScopeFlatten requeues the If, not the earlier Let. Requires the cond not read x, each branch's closing stmt be the assign, and no earlier branch stmt touch x. BoolTernaryFold then collapses simple arms to a plain let. LetIf was a second-class node, so it is now covered by literal_casts (typed-literal strip), const_fold, libc_call, bool_ternary INT_KINDS and remove_mut (was treated as an unconditional borrow, which also blocked demoting mut on params). update_filecheck.py: quoted globs expand and also match subdirectories. Fixture: branch_init_let_if (folds plus one-armed and read-before negatives). 23 existing fixtures regenerated; all were FileCheck-only diffs, runtime parity held. Not done: the trailing 'let r = ..; r' is not yet a tail expression, and else-if chains do not fold.
