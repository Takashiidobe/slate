# slate-78pa.1.1 gcc aarch64 arm_sve_vector_bits: SVE typedef sized fixed vector with scalable ABI and sizeless conversions

_2026-11-19 15:26:29_

- bead: slate-78pa.1.1
- kind: parser
- area: crates/slate-parser/src/sema/types.rs
- area: crates/slate-parser/src/sema/ctype
- area: crates/slate-parser/src/ir
- flavor: gcc
- target: aarch64

Outcome: gcc aarch64 `arm_sve_vector_bits(N)` typedefs of SVE sizeless types are sized fixed vectors in sema and the IR, matching gcc 16.2 layout, conversions and diagnostics.

Diagnostic or IR fact that was wrong:
`typedef svint32_t fixed_i32 __attribute__((arm_sve_vector_bits(256)));` was an
unknown attribute, so `fixed_i32` stayed sizeless and `sizeof`, struct members
and arrays of it were rejected.

Before:
  sizeof applied to sizeless type 'svint32_t'

After (`-march=armv8.2-a+sve -msve-vector-bits=256`):
  type fixed_i32 = vector<i32, 8, svint32_t>   ; 32 bytes, align 16
  abi aapcs64(scalable) -> scalable

Fix:
- AST: `Attribute::ArmSveVectorBits(Expr)` (gcc flavor only) maps to
  `VectorSize::SveBits` on the typedef's vector type.
- `CTypeKind::Vector` and `ir::Type::Vector` gained `scalable: Option<..>`
  naming the sizeless type; printed as the vector's third argument.
- `TypeResolver::sve_fixed_vector` (sema/types.rs): sized only when N equals
  `-msve-vector-bits` (`AArch64Isa.sve_vector_bits == Fixed(N)`), else
  warning `unsupported SVE vector size` and the sizeless type, as gcc. Lane
  element per sizeless name; `svbool_t` is N/64 `i8` lanes, align 2.
- `svbool_t` lanes are `i8` because gcc reads a predicate lane as the signed
  byte. gcc stores braced-initializer elements one bit per lane, which the byte
  model cannot express, so a braced initializer is rejected
  (`subobject_type` in sema/initializer.rs).
- Conversions: sizeless <-> fixed of the same name and fixed <-> same-size
  GNU vector are implicit `vector_bit_cast`; other sizeless conversions are
  `incompatible SVE types`. Mixing GNU and SVE vectors in a binary op is
  rejected. Compare masks and shuffles are GNU vectors.
- ABI: `AbiPass::Scalable` for AAPCS64 arguments and results.

Fixture: crates/slate-parser/tests/fixtures/gcc/linux/aarch64/sve_fixed_vectors.c,
sve_fixed_vectors_ignored.c, error/gcc/linux/aarch64/sve-fixed-*.c (non-SVE,
tuple, already sized, wrong sizeless, GNU mix, bool initializer).

Limits: gcc's per-operator restrictions on fixed `svbool_t` are not checked.
Clang flavor does not model the attribute.
