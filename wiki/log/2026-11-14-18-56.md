# slate-f2zu.14.23 main_wrapper: void main(void) shim returned unit from -> i32 (E0308, arch/x86/boot)

_2026-11-14 18:56:12_

- bead: slate-f2zu.14.23
- kind: bug
- flavor: clang
- area: crates/slate/src/frontend/lowerer/functions.rs
- area: crates/slate/src/frontend/lowerer.rs

Outcome: a translation unit defining `void main(void)` (freestanding code such as arch/x86/boot) gets a C `main` shim that calls it and returns `0i32`.

Symptom: linux arch_x86_boot main.rs:862 expected `i32`, found `()` (E0308): the shim was `unsafe { __slate_main() }` in a `-> i32` function.

Reproducer:
```c
/* { dg-options "-ffreestanding" } */
void main(void) { step(3); printf("%d\n", counter); exit(0); }
```

Cause: `main_wrapper` always returned the `__slate_main()` call.

Fix: `main_wrapper(arity, huge_stack, returns_void)` takes `main.return_type.is_none()` from `lowerer.rs`. For void it emits the call as a statement, then `return 0i32` (`RustValue::TypedInt(0, Prim::I32)`).

Regression test: crates/slate/tests/fixtures/freestanding_void_main.c
