# Lower bit-field records in the slate frontend via the vendored bitfields crate

_2026-10-01 09:51:15_

slate-p58o.4.11: build_record rejected any field with a bit width, so glibc struct \_IO_FILE (int \_flags2:24, field 15) blocked every FILE\* user, including all 27 remaining chibicc functions.

Records: each IR bit unit (layout.bit*units) becomes a field \_\_slate_bits*<u> whose type is a #[bitfields::bitfield] wrapper **SlateBits<id>U<u>. Backing is uN for naturally aligned 1/2/4/8/16-byte units no larger than the record alignment, else [u8; N]. Gaps and unnamed bit-fields are #[bits(N, access = na)] **slate*pad*<k> members. The record builder now places fields at the IR offsets, inserting [u8] padding where natural repr(C) offsets fall short and repr(align) when byte-array units lower the alignment; layouts that need packing still barrier. Big-endian targets barrier.

Access: read<T>(bitfieldN(..)) lowers to base.**slate_bits_u.**get*<c name>(), Write to .\_\_set*<c name>(v); static bases go through \*addr_of!(..). Aggregate initializers of bit-field records always use the zeroed temp with setters (wrapped in unsafe for unions).

Vendored bitfields-impl: new c*names = true bitfield argument. Every per-field identifier becomes \_\_<kind>*<unraw name> (**get\_, **set*, \_\_checked_set*, **bits\_, **offset*), so C names never collide (x vs set_x, a vs A, type, \_flags2), and *-prefixed fields are ordinary fields. Generated items carry #[allow(non_snake_case, non_upper_case_globals)]. Default behavior is unchanged.

Odd-width integer conversions (truncate<u3b> from the value of a bit-field assignment) are carried in the next standard container inside Convert only, masked or sign-extended; arithmetic on \_BitInt(N) still barriers.

chibicc: every TU now lowers with no barriers (-std=c11).

Validation: full slate profile green apart from the promotions.
