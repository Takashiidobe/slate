# NodeId on Span for AST node identity (slate-parser-ixa.10)

_2026-09-14 13:27:11_

Added Span<T>.id: NodeId, a globally unique id allocated by NodeId::next() (atomic counter) in Span::new/Span::cover; Span::with_value/map keep the source span's id since they relabel the same node rather than build a new one. Debug output for Span<T> conditionally prefixes #<id> when a thread-local flag (ast::set_show_node_ids) is set. Renderer gained with_show_ids, main.rs gained --show-ids, and tools/update_filecheck.py + tests/filecheck.rs gained a per-prefix // SLATE-FILECHECK-SHOW-IDS <prefix> directive to enable it for a fixture config. New fixture tests/fixtures/node_ids_macro_expansion.c (the SQUARE(x) repro from the bead) shows the two macro-expanded Identifier("x") nodes get distinct ids despite sharing one expansion Loc. Updated wiki/concepts/ast-spec.md's Span description accordingly.
