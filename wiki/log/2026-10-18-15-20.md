# gcc-only torture and dg corpora under --flavor=gcc

_2026-10-18 15:20:56_

Added gcc-flavor corpora to the gcc-torture and gcc-dg suites. Each suite now has a Corpus { dir, gcc } pair: the clang one (unchanged dirs) and a gcc-only one (fixtures.gcc-{torture,dg}.gcc-only[.unsupported]). Gcc-only cases translate with --flavor=gcc and use gcc as the oracle (new RunConfig.cc override, threaded through compile*c_with_args_for_target). New tests: gcc*{torture,dg}\_gcc_only_supported_tests_match_c and \*\_gcc_only_unsupported_tests_still_fail; the triage reports print gcc-only rows with a 'gcc-only' prefix. collect_cases treats a missing dir as empty (fixtures.gcc-torture.unsupported is now empty and git drops it).

Admission: reran tools/filter-gcc-torture.sh and filter-gcc-dg.sh with gcc against ~/gcc. Torture: gcc admits 99 execute tests clang rejects (0 the other way); 14 pass and go in gcc-only, 85 in gcc-only.unsupported. Dg follows the original import rule (only failing tests): gcc admitted 1740, 1503 were not already in the corpus, 1175 pass under gcc flavor and were dropped, 328 kept. Also copied the shared fixtures that fail only under gcc flavor (ieee**unsafe-fp-assoc, torture**bitint-21: gcc float.h spells DBL_MAX/DBL_MIN as (double)...L, so static initializers hold an f80 narrowing; pr98219-1 x2: **builtin_ia32_slwpcb; pr68037 x6: -mgeneral-regs-only is rejected by slate-parser and dropped for the oracle). Left out arm-fp16-ops-3/4 (gcc x86 has no **fp16) and pr126458-1 (gcc 16.2.1 miscompiles it).

Without the gcc oracle, the shared corpus fails only those 13 under gcc flavor. Triage of the 423 gcc-only failures is left to a child bead of slate-parser-cxg; its notes carry the first-pass clusters.
