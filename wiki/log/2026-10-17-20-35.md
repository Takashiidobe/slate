# Lower weak undefined functions as extern_weak statics

_2026-10-17 20:35:06_

slate-9ox1.4.5 (torture\_\_pr53922): a weak function declaration with no body was an ordinary extern fn, so an unresolved reference failed to link instead of being null. lower_extern now declares it as #[linkage = "extern_weak"] static NAME: Option<fn...> in the extern block and requests #![feature(linkage)]. Calls become NAME.unwrap()(...) and taking its address reads the static in unsafe, so the usual null checks work. FunctionName.weak_extern carries the flag. global_asm .weak was rejected: a weak and a strong undefined reference in different codegen units resolve strong. New fixture weak_undefined_function.c; pr53922 promoted. Docs: ir/declarations.md ifunc line now describes the slate lowering.
