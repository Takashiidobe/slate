# __builtin_bit_cast

_2026-09-18 20:09:04_

slate-parser-lh7.2.12 (slice). New ConversionKind::BitCast printed bit_cast<T, reason=explicit>(x), distinct from reinterpret, which stays a value-level same-width integer sign change with fits= semantics. bit_cast copies an object representation between any equal-sized types (float<->int, struct<->int, pointer->int). Lowering checks both storage sizes are equal and rejects array or void targets as Invalid. Fixture sema/ir_bit_cast.c (clang accepts it); ir-grammar conversion list and ir-spec conversion table updated.
