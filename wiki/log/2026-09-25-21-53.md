# Lower GNU casts to union types

_2026-09-25 21:53:52_

slate-parser-dyd.63: '(union U)x' is a GNU extension that clang (CK_ToUnion) and gcc both accept. slate rejected it with 'conversion between a struct or union and an unrelated type'.

- TypeResolver::union_cast_member picks the member. Matching follows clang: lvalue, array and function conversion first, which also drops qualifiers; then the first named member whose unqualified type is exactly the operand's. Typedefs are transparent. enum and int don't match, and there is no null-pointer or void* leniency. Unnamed bit-fields and members of anonymous structs are skipped. A same or compatible union keeps the plain copy path.
- A bit-field member can match. clang accepts this and gcc rejects it; we take the permissive side.
- No match is Invalid('cast to union type from type not present in union'), clang's wording.
- The Cast arm lowers a match to the rvalue aggregate<@U>(fieldN = x), the value shape __builtin_complex already uses. It works in static initializers too.
- Checked the accept and reject cases against clang and gcc -fsyntax-only.
- New fixture: tests/fixtures/union_cast.c. gnu_init_designator_survey.c (dyd.53's target) and gcc-torture 960416-1.c now lower.
- ir-spec documents the lowering.
