Outcome: Unused C declarations survive Rust dead-store cleanup, and an unused synthetic result can be dropped while evaluating the original expressions at the same points.

Gap: the Rust dead-store rule treated every unused let alike. A discarded conditional also reached the Rust AST with synthetic result storage and two writes that existed only to populate it.

Reproducer:
```c
void example(int c) {
    int dead = 1 + 2;
    c ? f() : g();
}
```

Before: Rust omitted dead and bound the result of the if expression to a synthetic local.
After: Rust retains let dead: i32 = 1 + 2 and evaluates the selected call in an if statement.

Implementation: dead-temporaries runs after canonicalization and macro stripping. It only considers explicitly synthetic scalar bindings and checks all uses against ordinary direct writes and type captures. Removed writes and initializers preserve their RHS as expressions with their existing NodeIds. Kept macro regions are excluded. Lowering passes the synthetic flag through Rust lets and the rewrite arena. The Rust dead-store rule uses that flag, including after slot promotion and declaration sinking.

Fixtures: fixtures/dead_store.c checks an unused source local and a synthetic-looking source name, as well as conditional and short-circuit call order. fixtures.transforms/dead-temporaries/discard.c checks discarded and used conditional results and a captured VLA extent.

Limits: Existing branch initialization remains available. This pass handles synthetic storage and leaves general reachability and source-expression cleanup to the existing pipeline.

Validation: release nextest profiles slate (44), parser (9330), and merge (1) passed. Regenerated changed checks and corrected one stale truth-canonicalize check.
