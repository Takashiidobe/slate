# slate-3amj.5.26.6 object_rules: suppress the block-scope function warning with /Za

_2026-11-26 16:40:32_

- bead: slate-3amj.5.26.6
- kind: feature
- area: crates/slate-parser/src/sema/assertion.rs
- area: crates/slate-parser/src/diagnostics.rs
- flavor: msvc

Outcome: default MSVC warns for a function first declared at block scope at warning level 4, and /Za suppresses the warning.

Gap: cl.exe reports C4210 at /W4 for `void f(void) { int g(void); }` under default MSVC. /Za /W4 and default /W3 are silent.

Before: Slate compiled the declaration silently at all warning levels.

After: the checker reports “nonstandard extension used: function given file scope” at /W4 with MSVC extensions enabled. It reports only the first declaration of a function, including a declaration through a function typedef.

Implementation: `Checker::object_rules` identifies function declarations from their resolved type and uses the seen function names and entity state to identify a first declaration. `DiagnosticContext` applies the level-4 threshold.

Fixture: `msvc/windows/x86_64/za_block_scope_function_warning.c` checks default /W4, /Za /W4 and default /W3.

Limits: name visibility and block-scope static function linkage are tracked in slate-3amj.5.30.
