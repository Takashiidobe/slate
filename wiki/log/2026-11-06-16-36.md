# Lift macros that declare locals in goto functions

_2026-11-06 16:36:39_

slate-f2zu.9.5.12.22: macro_keep rejected every expansion that declared a local in a function with a goto (local_in_dispatch_function), assuming dispatch lowering hoists them. It does not: lower_dispatch's graph keeps a kept Statement::MacroExpansion as one opaque node, so only top-level locals reach graph.locals and dispatch_bindings; the body's temporaries lower inside the template. Sema strips non-kept expansions first, and a label inside an expansion is already control_transfer. Removed the rule. The only remaining hoist is FunctionLowerer::reserve, which moves __block (byref) storage and capturing block literal slots to the function top while dispatching; an expansion containing either, in a function with a goto or asm goto, is now rejected as storage_in_dispatch_function. asm goto now counts as a jump for that check (the old rule missed it).
