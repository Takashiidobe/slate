# gcc-dg vectors, long double and lowering gaps (slate-9ox1.6)

_2026-10-18 08:50:43_

slate-9ox1.6, all ten children closed.
- New lowerer/float_fold.rs: generic rustc_apfloat folder for real and complex float constants (any IEEE format), including C11 Annex G complex mul/div mirroring clang's HandleComplexComplex{Mul,Div}. Complex Arith/Unary in static initializers fold to literals (Rust statics can't call c_mul/c_div). The f80-only folds in f80.rs now delegate to it.
- vendor num-complex div_f32/div_f64: the infinite-denominator branch was missing compiler-rt's logbw > 0 check, so (1+i)/(0+NaN i) returned 0 instead of NaN. complex-2/5/7 torture fixtures now pass.
- Aggregates: Range designators ([a ... b]) lower to a const-evaluable while loop over a value bound once; an empty zero-filled scalar aggregate (C23 = {}) lowers to zeroed.
- is_constant_initializer accepts Copy (constexpr struct copies).
- PlaceKind::Temporary (member access on a struct rvalue) reuses the automatic compound-literal path.
- __builtin_powi/powif always, and __builtin_{powi,ceil,floor,trunc,round,rint,nearbyint}l when long double is not binary128, map to llvm intrinsics, which reach the __slate_f80_* shims. __builtin_powi previously linked to a user-defined powi.
- Vectors that std::simd can't represent (i128/u128 lanes, or lane counts other than 1..64 powers of two) use the new support module __slate_vector::__SlateVector<T, N, AlignK>: a [T; N] plus a zero-length alignment marker, wrapping elementwise ops, Index, from_array/splat/to_array. Shuffles and lane casts that involve one go through arrays.
- slate-parser storage_of: vector alignment is capped like clang's MaxVectorAlign (AArch64 16, Arm32 8, x86 uncapped). New parser fixtures aarch64/ and armv7-gnueabihf/vector_max_alignment.c. The missing FileCheck header on x86_64/typedef_alignment_access.c is fixed.
- torture__builtin-fp-int-inexact-c23 moved to fixtures.gcc-dg.ignored: round/roundf resolve to compiler_builtins' copies, which raise FE_INEXACT. This depends on the compiler runtime, like pr68264.
- New fixtures: complex_static_arith_init, designated_range_empty_init, constexpr_struct_copy_init, struct_rvalue_array_member, long_double_rounding_builtins, builtin_powi, vector_wide_lanes, x86_64/vector_int128_lanes.
- Promoted nine gcc-dg fixtures plus c11.c, chibicc struct, and gcc-torture 20020320-1, 20070614-1, 950628-1, complex-2, complex-5, complex-7, pr30185.
- aarch64 list adds builtin_powi (no f128 powil, follow-up filed) and c11 (CMPLX unresolved in aarch64 sema, follow-up filed).
