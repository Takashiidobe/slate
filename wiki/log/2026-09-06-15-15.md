# g3 Slate translation backend

_2026-09-06 15:15:16_

Created sibling slate-server deployment: a localhost-only Axum gateway with an origin-token boundary and one-job admission, plus a rootless Podman translation image. The image bundles the minimal x86_64 CIR toolchain, matching macro plugin, Slate, libc shim, and rustfmt runtime dependencies rather than the 6.5 GiB Clang build tree. g3 runs each translation in a disposable no-network, read-only job with 3 GiB memory, one CPU, 64 PIDs, 64 MiB tmpfs, output/file caps, and a five-second compiler limit. Verified a real localhost translation, 413 source cap, tmpfs exhaustion, and CPU kill while the gateway stayed active. Cloudflare integration remains deferred.
