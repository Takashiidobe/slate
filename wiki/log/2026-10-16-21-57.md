# Whole-file FileCheck for every fixture

_2026-10-16 21:57:16_

The differential harness now fails a tests/fixtures fixture (supported, x86_64, i686) that has no SLATE-FILECHECK block. update_filecheck.py defaults to checking the whole generated Rust: CHECK on the first line, CHECK-NEXT for the rest, and a trailing CHECK-NOT: {{.}} so appended output fails. The harness now attaches a global CHECK-NOT to the preceding global chain instead of running it alone. @check-fn-begin/end markers still narrow a fixture to specific functions; the 112 marked fixtures keep their blocks. With no arguments the tool now regenerates every fixture. Generated blocks for 435 fixtures (~41k lines). Full slate profile green on a second, independent run, so the output is deterministic.
