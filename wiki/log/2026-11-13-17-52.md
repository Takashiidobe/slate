# slate-dghn.55.2 libc_catalog Symbol shape: _GNU_SOURCE setitimer/strerror_r signatures no longer bound to slate_support

_2026-11-13 17:52:05_

- bead: slate-dghn.55.2
- kind: bug
- area: crates/slate/src/frontend/lowerer/libc_symbols.rs
- area: crates/slate/src/libc_catalog.rs
- area: crates/slate-libc-gen/src/symbols.rs
- flavor: gnu

Outcome: lowering binds a system function to its slate_support path only when the unit's Rust signature equals the one slate-libc-gen probed, so _GNU_SOURCE declarations (setitimer, getrlimit, GNU strerror_r) keep local externs instead of failing cargo check or miscompiling.

Symptom: translated nginx failed cargo check with 2 `expected i32, found u32` at setitimer. Worse, a _GNU_SOURCE call to strerror_r (GNU: returns char*) was bound to slate_support::strerror_r, which links __xpg_strerror_r and returns c_int; the result was cast `as *mut i8` and compiled, crashing at runtime.

Reproducer:
```c
#define _GNU_SOURCE
#include <string.h>
#include <sys/time.h>
char *f(int e, char *b) { return strerror_r(e, b, 64); }
int g(struct itimerval *t) { return setitimer(ITIMER_REAL, t, 0); }
```

Cause: slate-libc-gen probes headers without feature-test macros and libc_catalog::Symbol was keyed by name and target only. bind_libc_symbols computed the unit's shape but never compared it to the probed one. 15 x86_64 glibc functions change signature under _GNU_SOURCE: 7 enum which/resource params (get/setitimer, get/setpriority, get/setrlimit, getrusage), 7 __SOCKADDR_ARG transparent unions (accept, bind, connect, getpeername, getsockname, recvfrom, sendto), and strerror_r.

Fix: Symbol gains `shape: Option<&'static str>`; symbols::table writes each function's probed shape (rows split by shape, same 24834 name/path/target mappings). bind_libc_symbols requires `symbol.shape == actual` (None for the MSVC intrinsic tables). Catalog regenerated; records table unchanged.

Regression test: crates/slate/tests/fixtures/gnu_source_libc_signatures.c.

Limits: a mismatch falls back to a local extern rather than a canonical variant; picking per-mode and per-libc canonical bindings is slate-dghn.55.3. nginx still blocked by in6_addr (slate-dghn.55.1).

See: slate-dghn.55, slate-dghn.55.1, slate-dghn.55.3
