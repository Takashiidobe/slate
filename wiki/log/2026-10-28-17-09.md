# Close slate-3f8g.4.30 as not a bug

_2026-10-28 17:09:26_

slate-3f8g.4.30: clang flavor accepts gcc-only AArch64 clobbers (ffr, ffrt, sfp, ap, vg, fpmr, lowering, tpidr2_*, sme_state, za_free, za_saved) that clang rejects. Closed without code change, same reasoning as slate-5exy.6. Swept every name in target/aarch64.rs plus aliases (r/w/b/h/s/d/q/z/pn, numeric) against aarch64-linux-gnu-gcc and clang: slate never rejects a name either compiler accepts, and out-of-range names (v32, r31, pn16) decode as Register::Other rather than a wrong register. Note: slate-parser accepts any unknown clobber string on aarch64, even 'foo'.
