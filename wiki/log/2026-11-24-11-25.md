# slate-yar4.70 lower_pointer_offset: GNU atomic pointer updates scale byte offsets

_2026-11-24 11:25:04_

- bead: slate-yar4.70
- kind: bug
- area: crates/slate/tests/fixtures.unsupported

Outcome: The unsupported ratchet covers byte offsets in GNU atomic pointer arithmetic.

The fixture adds one to an int pointer with __atomic_fetch_add
and subtracts one with __atomic_sub_fetch. It checks both stored
addresses and the builtins' old and new return values. Clang and
GCC use a byte stride. The typed IR records element=u8, but
lower_pointer_offset emits wrapping_offset on *mut i32, taking a
four-byte step. Lean confirms that the one-byte and four-byte
steps differ for every base in the 32- and 64-bit address models.

Clang exits 0 and the generated Rust exits 3 on all four Linux targets.

Limits: The lowering fix remains open in slate-yar4.70.
