Outcome: crates/slate-analysis exists; every lowering entry point builds a one-target `Program`, runs `analyze`, and passes each unit's read-only `UnitFacts` into `lowerer::lower` (empty for now).

Gap and why it mattered: slate-8ge7 moves analyses from Rust-AST rewrites onto the IR. Ports need a crate, a program-wide key for facts, and a path from analysis to lowering before any analysis can land.

Before: `lowerer::lower(module, files, options)`; interproc facts were re-derived from `rust_ast` after lowering, keyed by `FnKey { unit, name: String }`.

After: `lowerer::lower(module, files, options, facts.unit(unit_id))`, with the store in `Tables.facts` (`#[expect(dead_code)]` until the first analysis reads it).

Implementation:
- `Program::new(units)`: dense `FunctionId` over the defined functions of one target's units (after `without_definitions`). `Program::callee(unit, &Callee)` resolves a direct call in its own unit, or through an external declaration to the strong external definition with the same link name (`asm_name`, else the C name). Weak, alias, weakref, ifunc and `inline_only` bodies and indirect calls are `None` (opaque, always sound).
- `Facts { bindings: (UnitId, BindingId) -> BindingFacts, values: NodeId -> ValueFacts }`, built once by `analyze`; no public mutators.
- Wired at `project::merge::translate_units` (all units, before the parallel lowering), `frontend::lower_single_module`, and `main::lowering_barriers`.
- `#![register_tool(slate)]` so `slate::sensitive` applies.

IR id audit:
- `Value`, `Statement`, `Function`: `NodeId` through `Span`, from one process-wide atomic counter, so they are unique across units and targets.
- Params, locals, globals, temporaries: `BindingId`, a dense per-unit counter (`Resolver::new_entry`), so the program key is `(UnitId, BindingId)`.
- `Place`: no id. Facts key on the enclosing value or statement's `NodeId` plus the root binding. No IR change is needed for the locals and params scope.

Validation: build and clippy clean; fixture pointer_lift_local_copy_chain and a two-unit translate-project (cross-unit `leaf(const int *, int)` still lifts to `&[i32]`) pass. Full slate profile not run: the facts are empty, so output cannot change.

Limits: places have no ids; add them only if a place-level fact cannot key on its enclosing node. Nested functions and block literals are not in `Program::functions`.
