# slate-dghn.54 sema Hoister::branch: ternary on null==null kept a dead (*NULL).field arm that rustc deny(deref_nullptr) rejects (mimalloc)

_2026-11-13 17:20:40_

- bead: slate-dghn.54
- kind: bug
- area: crates/slate-parser/src/sema/effects.rs
- area: tools/corpus/e2e.py

Outcome: `python3 tools/corpus/e2e.py mimalloc --mode clang` translates, checks, builds and passes 5 of 5 runnable ctest cases; a `?:` whose condition compares two null constants now lowers only the taken arm.

Symptom: `cargo check` of the translated mimalloc failed with `src/arena.rs: error: dereferencing a null pointer` (rustc `deref_nullptr`, deny by default) in `_mi_arenas_visit`.

Reproducer:
```c
unsigned long start(void);
typedef struct arena_s { unsigned long idx; } arena_t;
unsigned long f(void) { return (NULL == NULL) ? start() : ((arena_t*)NULL)->idx; }
```

Cause (verified): mimalloc's `mi_forall_arenas(NULL, ...)` macro expands `req_arena==NULL ? mi_arena_start_idx(..) : ((mi_arena_t*)req_arena)->arena_idx` with `req_arena` = NULL. The else arm has a call-free read but the then arm has a call, so `Hoister::branch` (slate-parser `sema/effects.rs`) emitted a statement `if null == null { .. } else { (*null).idx }`; Slate printed both arms and rustc's lint rejects the dead one.

Before: `let __v0: u64 = if null_mut::<()>() == null_mut::<()>() { start() } else { (*null_mut::<arena>()).idx };`
After: `let mut __v0: u64; __v0 = start();`

Fix: `null_comparison_outcome` in `sema/effects.rs` recognises `Compare{Eq|Ne}` of two null constants (through `Convert` and `MacroArg`); `branch` then emits only the taken arm's statements and no `If`.

Fixture: `crates/slate/tests/fixtures/x86_64/null_ternary_dead_arm.c` (macro form and direct form, runs against native).
Recipe: `CMakeLibrary(library="libmimalloc.so", variants=["libmimalloc.a"], translate_tests=True)` in `tools/corpus/e2e.py`.
Limits: only null-vs-null conditions fold; a constant integer condition (`1 ? a : (*(int*)0)`) still emits both arms. A dead arm containing a label (statement expression) is dropped with the arm.
See: slate-dghn.33, slate-dghn.34
