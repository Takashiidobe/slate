# slate-5q63.22.4 c_shim: backend::c_emit typed C items (Function, Prototype, FnPtr casts, structs) render slate_long_double.c instead of format! templates

_2026-11-18 15:57:06_

- bead: slate-5q63.22.4
- kind: feature
- area: crates/slate/src/backend/c_emit.rs
- area: crates/slate/src/frontend/c_shim.rs

Outcome: src/slate_long_double.c is built as a `backend::c_emit::Unit` of typed C items (functions, prototypes, structs, directives) printed by Display, instead of format! templates in frontend/c_shim.rs.

Gap and why it mattered:
c_shim.rs rendered four near-identical shapes (direct/callback/exported trampolines, indirect `icall`, variadic `vcall`, `ldv` va_list exports) and the aligned `struct __slate_m<size>a<align>` aggregates with format! strings; braces, semicolons, `void` parameter lists and function-pointer casts were each spelled per site. An empty parameter list printed `()` (an unprototyped declaration before C23) and a `vcall` with no variadic tags would have printed a trailing `, `.

Before:
    format!("{ret} {name}(void *_f, {params}) {{\n    {body}\n}}\n")
    format!("(({ret} (*)({}, ...))_f)({args})", fixed.join(", "))
After:
    Function { ret, name, params: once(function_pointer_param()).chain(named_params(..)), body: vec![result(&ret, call)], .. }
    call_through_f(ret, fixed, true, args)   // Expr::Call { callee: Cast { ty: Type::FnPtr {..}, expr: _f }, args }

Implementation (crates/slate/src/backend/c_emit.rs, not a C AST):
- `Type` {Named, Struct, Pointer, FnPtr{ret, params, variadic}} with declarator printing (`char *_0`, `T (*)(A, ...)`); empty lists print `void`.
- `Expr` {Name, Call, Cast, Deref}; a non-name callee is parenthesized.
- `Stmt` {Expr, Return, Decl}; `Param`, `Field {align, ty, name, len}`.
- `Item` {Define, Include, Raw (the long_double.c / fenv.c support sources), Struct, Prototype {asm_label}, Function}; `Unit` separates items with blank lines except directive runs and prototype+function pairs.
- c_shim: c_type_for_tag/native_c_type return `Type`; render_* return `Vec<c::Item>`; render_shim_c_source_for_names builds a Unit.

Verified: rendered 282 shim names (harvested from translating 137 long double/variadic/_Complex/fenv fixtures for x86_64, i686, aarch64, msvc, plus names in tests and synthetic cb_/undeclared/no-arg/aggregate cases) through the old and new renderers via a scratch crate; `diff -wB` shows only `foo()` -> `foo(void)` for a zero-argument export and its prototype. 280/282 blocks pass `cc -fsyntax-only -Werror=strict-prototypes`; the 2 failures are synthetic names with output identical to HEAD (`icall__rv__` casts to C23 `(...)`; `cb_` with a `pcf80` arg is not a shape slate emits). dylink/project_plan/project_select/build_filecheck/differential(non-generated): 25 passed; long_double_va_arg, long_double_variadic_libc_name, complex_long_double_function_pointer, c89 pass.

Limits: the bead's later users (slate-parser sema/builtins.rs typedef injection, slate-libc-gen symbols.rs probes) live in other crates and are not moved onto c_emit.
