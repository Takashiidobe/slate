# Lower naked functions to #[unsafe(naked)] + naked_asm!

_2026-10-09 21:36:48_

slate-3f8g.4.17.10.

FunctionSemantics::naked functions lower to #[unsafe(naked)] extern "C-unwind" fn with immutable params (naked fns reject mut bindings) and a single core::arch::naked_asm! joining every asm statement's template with newlines. Operands must be const (Immediate) or sym (Symbol); slots continue numbering across statements. Basic templates escape braces rather than using raw so they mix with extended ones; AT&T adds att_syntax, mixed dialects are a barrier. Null statements and comments are skipped; any other statement is a barrier (gcc accepts them, Rust cannot).

rust_ast::InlineAsm gained naked: bool; codegen prints naked_asm! for it.

New differential fixture x86_64/asm_naked_functions.c (basic, multi-statement, const operand, naked-on-prototype, function pointer). chibicc asm/asm.c now lowers its naked functions but stays unsupported on main's unprototyped definition (slate-p58o.7.11).
