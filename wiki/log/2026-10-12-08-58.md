# slate-3f8g.4.17.14.2 MS asm memory operands

_2026-10-12 08:58:34_

lower_asm handles AsmOperandKind::Memory as in(reg) of addr_of/addr_of_mut (mutable unless access is Read) and asm_template renders AsmPiece::Address as '<size> ptr [{N}+base+index*scale+disp]'. Clobbers of an unconstrained asm (any operand with no constraint alternatives, i.e. MSVC \_\_asm) are now early outs instead of lateouts, because Rust lets a lateout share a register with an input and the block writes eax/ecx before reading later address registers. Fixture i686/ms_asm_memory.c: params, struct field s.y, arr[8], byte ptr bytes[2] with movzx, and arr[ecx*4]; output matches clang -m32. Same early-clobber hazard exists for GNU lateout clobbers; not touched.
