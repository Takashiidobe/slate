# Add normalized Linux libc ABI probes

_2026-09-07 20:36:03_

Implemented tools/probes/linux-libc-abi.c and tools/libc-abi-probe.py. The probe records compiler data-model macros, typedef widths, type alignment, struct sizes, and field offsets across filesystem, time/signal, networking, and pthread headers.\n\nThe runner compiles and executes the same source against a real target sysroot or libc-shim with explicit Slate target defines, emits schema-versioned JSON with a source hash, and compares records without mixing metadata.\n\nNative x86-64 musl oracle and shim outputs match. The glibc x86-64 comparison reports real current gaps: msghdr/cmsghdr, sched_param, ucontext_t, and pthread opaque-type alignment. The probe source compiles for both oracle and shim on x86-64, i686, ARM32, and AArch64.
