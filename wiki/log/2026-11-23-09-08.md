# slate-xw0x.14 ARM differential: guard implicit_intrinsics stdlib.h with the x86 checks

_2026-11-23 09:08:12_

- bead: slate-xw0x.14
- kind: bug
- area: crates/slate/tests/fixtures/msvc/implicit_intrinsics.c

Outcome: The MSVC implicit_intrinsics fixture translates on ARMv7 Linux, where its x86-specific checks are inactive.

Symptom

The ARM differential profile failed before lowering with a missing stdlib.h
while translating fixtures/msvc/implicit_intrinsics.c.

Reproducer

SLATE_DIFF_FIXTURE=implicit_intrinsics cargo nextest r --release --profile arm

Cause and fix

The ARM profile includes shared MSVC fixtures and uses the Linux triple when
there is no Windows MSVC target for the architecture. The fixture included
stdlib.h unconditionally, although only its x86 checks call abort. Place the
include inside the existing _M_IX86 or _M_X64 guard.

Regression test

The same fixture now passes on ARMv7. Its x86 branches still include stdlib.h
and retain their intrinsic checks.
