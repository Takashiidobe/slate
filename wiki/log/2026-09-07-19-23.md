# i686 differential runner

_2026-09-07 19:23:47_

Added i686-lowering and i686-rewrites nextest profiles and a differential runner using Clang as both compiler and linker driver. The runner passes --target=i686-linux-gnu and -m32 for C and Cargo build-script compilation, injects target-specific Rust linker flags, uses /usr multilib plus qemu-i386-static, and collects shared/i686 fixtures. Isolated add, sizeof, longs, pointers, structs, and varargs pass; the full profile exposes existing ClangIR 32-bit frontend verification failures.
