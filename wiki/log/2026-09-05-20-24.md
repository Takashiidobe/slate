# selective FileCheck regeneration

_2026-09-05 20:24:52_

Added tools/regen-failed-filecheck.sh with lowering and rewrites modes. It runs the requested release nextest profile with no capture, extracts only filecheck/<fixture>/checks-N.txt failures, regenerates the uniquely matching C fixture with the matching update_filecheck profile, and returns the original test status. Documented usage in tests/fixtures.gcc-dg/README.md. Validated both modes against full profile runs; each selected the five ordinary changed fixtures plus bf-ms-layout-5, leaving runtime-only failures untouched.
