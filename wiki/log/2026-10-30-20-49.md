# Search the NDK per-triple include directory on Android

_2026-10-30 20:49:11_

slate-e36k.2: Android TUs reaching <linux/types.h> failed on <asm/types.h>, which the NDK installs under usr/include/<triple>. Added SysrootLayout::AndroidNdk (target_registry.rs), which sysroot::include_paths_at probes as usr/include/<triple> then usr/include, the order clang uses. Both Android targets use it. Kept separate from Unix { multiarch } because that probes usr/<triplet>/include and the Linux sysroots' usr/include holds every architecture's directory. corpus_sweep.py's copy of the list is updated. clang/android/{x86_64,aarch64}/nullability_headers.c now includes <stdio.h> and <stdlib.h>. zlib on Android now stops at bits/ioctl.h, slate-e36k.4.
