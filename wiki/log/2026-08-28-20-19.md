# Attribute writes through offset temps back to the base pointer (y0qs.4.10)

_2026-08-28 20:19:29_

Fixed slate-y0qs.4.10: place() in pointer_lattice.rs only set a pointer's
write bit for `*var = val` when var itself was in the tracked-alias map.
Offset temps from CIR's usual `let _v7 = _v5.offset(i);` pattern were
never added to that map (try_alias only handles Var-to-Var aliasing;
`.offset()`/`.add()`/etc are MethodCalls, so try_alias's source_var()
returns None and the Let falls through to a plain expr() walk that
records the offset but never tracks _v7). A later `*_v7 = val` then hit
place()'s untracked-var fallback, which reads but never calls
observe_write -- so a genuinely-mutated buffer could resolve to
ResolvedPtrType::Slice (read-only) instead of SliceMut.

Added try_offset_alias(): when a Let/Assign's RHS is (peeling through
Expr::Unsafe's empty-stmts/tail wrapper, since CIR always wraps these
offset calls) a MethodCall to add/offset/wrapping_add/sub/wrapping_sub
on a tracked Var, register the bound name in `tracked` pointing at the
same canonical as the receiver, plus observe_offset (matching the
existing expr()-driven behavior it now supersedes for tracked names).
No disprove_unique call, since an offset is a derived view of the same
object, not a separate alias to it. Wired into both Stmt::Let and
Stmt::Assign before their existing try_alias check.

Note: lift_kind() still excludes Buffer (LiftKind::Buffer is dead_code,
per slate-y0qs.4.8), so this has no visible codegen effect yet --
verified the fact directly via SLATE_PTR_LATTICE_DEBUG=1 (write flips
false->true, resolved base flips Slice->SliceMut for a `p[i] = val`
loop). length_lattice.rs, the one live Buffer-shaped consumer, already
had its own independent write scan (is_written_through) guarding this
exact case, so this bug never miscompiled anything -- it was a latent
soundness gap for future Buffer-kind consumers, as the ticket predicted.

Added tests/fixtures/ptr_lattice_offset_temp_write.c as a differential
regression (no REWRITES lines -- no codegen delta to assert yet).
Full rewrites (110/110) and lowering (10/10) profiles green, fmt/clippy
clean.
