# slate-8ge7.24.11.9 unsafe placement design: Deref(Pointee), Var unsafe_ flag, placement pass replaces nested_unsafe

- kind: bookkeeping
- area: wiki/concepts/rewrite-engine-v2.md

Outcome: unsafe in the Rust AST is decided as a per-operation marker placed by one pass before codegen; recorded in wiki/concepts/rewrite-engine-v2.md#unsafe-placement.

Decisions: raw deref is UnaryOp::Deref(Pointee::Raw) (not Raw(Deref): Raw(_) means &raw address-of and pure_stmts/nested_unsafe treat it as pure/place); static reads carry an unsafe_ flag on Expr::Var with an Expr::var constructor for the safe case; Call/MethodCall carry unsafe_; Field carries union. No side table: rust_ast exprs have no ids.
Placement: after rules and interproc/link, per function, statement-level when an assignment target is marked, else LCA per expression slot, never a whole body; a separate post-pass merges adjacent whole-statement blocks with no let.

See: slate-8ge7.24.17.3 (markers), slate-8ge7.24.17.4 (placement, delete nested_unsafe/peel_unsafe), slate-8ge7.24.17.5 (link clears flag, slate-o3gw.18).
