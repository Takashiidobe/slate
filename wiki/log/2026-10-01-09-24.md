# Lower anonymous members and compound literals in the slate frontend

_2026-10-01 09:24:37_

slate-p58o.3.44 and slate-p58o.3.42.

Anonymous struct/union members: build_record no longer requires a field name.
types::field_name gives an unnamed field the reserved name __slate_anon_<index>,
and record layout, Field places, and aggregate literals all name fields through
it. The IR already resolves member access into nested field paths, so nothing
else changed.

Compound literals (PlaceKind::CompoundLiteral, alignment None):
- automatic: FunctionLowerer.hoisted collects let mut __slate_compound_<id>: T =
  zeroed() at function entry (a superset of the C block lifetime). The place
  lowers to *{ __slate_compound_<id> = init; addr_of_mut!(__slate_compound_<id>) },
  so the initializer runs where C evaluates it and a loop reinitializes the same
  object each iteration.
- static (file scope): Dependencies.compound_literals collects static mut
  __slate_compound_<id>: T = init items, deduped by id. is_constant_address
  accepts a static literal with a constant initializer, place_is_static treats
  it as a static.
- _Alignas'd literals stay a place barrier.
