# File multi-target zlib epic

_2026-10-30 18:13:33_

slate-mbr2.1 (P0): make multi-target zlib feasible by cutting about 5 million naive TU compiles (16 features x 6 targets x 15 TUs = 5,898,240) to a few hundred with greedy set cover over configurations. Measured on preprocessed zlib, 9 features x 14 targets: 264 compiles per target with only relevant features, 142 with greedy over declarations, 34 with greedy over statements (476 total; true minimum 30-34 per target). Whole-function merging is insufficient: zlibCompileFlags forces 64 compiles at function level and 2 at statement level. The preprocessor trace must supply #[cfg] conditions because set cover removes the evidence a diff would need.
