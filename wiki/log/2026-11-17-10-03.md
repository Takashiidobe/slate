Outcome: `tools/corpus/kernel_selftest.py` (and the `e2e.py linux` `kselftest` stage) runs the kernel's userspace selftests on the native and translated defconfig bzImages under QEMU and diffs per-test TAP results; a 10-collection subset matches native exactly.

Gap: the boot stage only proved the translated kernel reaches /init. KUnit needs a config change (CONFIG_KUNIT etc.), which forces a full retranslation; kselftest tests the already-booting kernel through syscalls with no rebuild.

After:

    python3 tools/corpus/kernel_selftest.py ~/slate-translated/slate-linux \
        --only kcmp,futex,pidfd,signal,ptrace,clone3,core,pipe,mincore,sync
    {"marker": true, "tests": 31, "regressions": 0, "subtests": 205,
     "subtest_regressions": 0, "flaky": 0, "kernel_failures": 0}   # 2m15s wall

Implementation:

- 35 selftest collections (221 tests) built with O=/INSTALL_PATH= under
  <out>/kselftest; `git clean -fdX` on target dirs first because prctl/uevent
  build TEST_PROGS in the source tree.
- TCG has no AVX-512 and the host (CachyOS) glibc/bash/coreutils are x86_64_v4:
  host crt1.o tags binaries ISA_1_NEEDED v4 (ld.so: "CPU ISA level is lower
  than required", exit 127) and host libc.a gives SIGILL in static tests. Fix:
  download generic Arch core/extra/multilib packages (pacman -Qoq maps host
  files to packages), link with `gcc -B<generic glibc>/usr/lib/` plus a
  usr/lib/32 -> ../lib32 link for -m32, and pack the generic shared libraries.
- /init runs the list itself instead of run_kselftest.sh: the upstream runner
  hung on pidfd_setns_test because a failed assertion left a child in pause()
  holding the runner's sed pipe. Output goes to a file, `timeout -k`, then
  `kill -KILL -1` per test; selection comes from `kselftest=` on the kernel
  command line (--only), so subsets need no initramfs rebuild.
- Native boots twice (flaky results excluded), translated once, in parallel.
  Regression = stable native result the translated run differs from, unless
  native fails. kernel_boot.write_cpio factored out for reuse.

Limits: the full 221-test run has not been done (mm allows 900 s per test).
size and fchmodat2 are not built. Subtests are compared one level deep.

See: wiki/concepts/kernel-selftests.md, slate-f2zu.14.36 (KUnit, depends on this),
slate-f2zu.14.38 (boot stage).
