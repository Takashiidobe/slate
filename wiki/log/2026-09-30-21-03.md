# Lower simple switch and id-based loop control in the slate frontend

_2026-09-30 21:03:00_

slate-p58o.3.22 (also closes 3.21).

- switch lowers to '__slate_break_<id>: { let __slate_switch_<id> = discriminant; if-else chain }'. The discriminant is evaluated once; stacked labels OR their values; default (anywhere) becomes the final else.
- Refused for Phase 4: fallthrough (an arm not ending in break/continue/return, looking through a trailing block), case ranges, statements before the first case, and case labels nested below an arm's top level (Duff's device, goto into a case).
- break/continue now use the IR's loop/switch ids: every loop is labeled '__slate_break_<id>' and its body wrapped in '__slate_continue_<id>'. The old continue-label stack is gone. This fixes a pre-existing bug: an unlabeled break inside a for/do-while body sat inside the continue labeled block and failed with E0695.
- A function marked fallthrough=ub_if_used whose body does not end in return now ends with return unsafe { std::mem::zeroed() }, so loops that only exit via return type-check. C only makes that path UB if the caller uses the value.
- New fixture switch_dispatch_shapes.c: stacked labels, default in the middle, braced arms, no-default char switch, nested switch, enum switch in while(1) with continue and return, discriminant with a side effect, break out of a for.
- Promoted: the four named switch fixtures, ptr_out_param_alloca_frame, switch_dispatch_shapes, 7 more local fixtures (including break_for, loop_break_continue, while_switch_continue) and 36 gcc-torture.
