# Arm32 gcc asm flags verified

_2026-09-27 08:37:04_

Correction to the Arm32 asm options log. Verified with arm-none-eabi-gcc 16.2 -fdump-rtl-expand:
-march=armv7-a -marm, -march=armv7-a -mthumb, -march=armv6 -marm and -march=armv6-m -mthumb all
emit (clobber (reg:CC cc)) only when "cc" is written; basic asm gets only the memory clobber.
The earlier note that gcc Thumb-1 clobbers CC on every asm was wrong (thumb1_md_asm_adjust only
rejects =@cc flag outputs). preserves_flags = no "cc" is correct for every 32-bit ARM mode.
The bare-metal toolchain is enough for this: asm clobbers come from the ARM backend, not the OS.
