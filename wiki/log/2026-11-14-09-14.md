# slate-dghn.56.7 pointer lattice: pointer param stored in a struct/array literal lifted to &T, cast back to *const for a *mut slot (E0308)

_2026-11-14 09:14:35_

- bead: slate-dghn.56.7
- kind: bug
- area: crates/slate/src/backend/interproc/pointer_lattice.rs

Outcome: a pointer parameter stored into a struct, array or tuple-struct literal now counts as escaping in the pointer lattice, so it stays a raw `*mut T` instead of becoming `&T` and being cast back to `*const T` for a `*mut T` slot.

Symptom: cargo check of translated cpython: E0308 "types differ in mutability" in instrumentation.rs (8x, `_PyMonitoring_Fire*Event`) and initconfig.rs (`PyConfig_SetWideStringList`). Rewrite, not lowering: the pointer lattice lifted `PyObject *retval` to `retval: &_object`, then `PyObject *args[4] = {NULL, NULL, NULL, retval}` became `retval as *const _object` in a `[*mut _object; 4]`. Same for `PyWideStringList list2 = {.length = length, .items = items}` with `items: &*mut i32`.

Reproducer:

    static int fire(struct obj *retval) {
        struct obj *args[2] = { NULL, retval };
        return sum(args, 2);
    }
    static long wrap(long length, int **items) {
        struct list l = {.n = length, .items = items};
        return count(&l);
    }

Before: `fn fire(retval: &obj)` with `retval as *const obj` in the array; `fn wrap(.., items: &*mut i32)` with `items: items as *const *mut i32`.
After: `fn fire(retval: *mut obj)`, `fn wrap(.., items: *mut *mut i32)`, values stored unchanged.

Cause: ClassifyCtx::expr in backend/interproc/pointer_lattice.rs walked StructLit / TupleStructLit / ArrayLit / VecLit / ArrayRepeat / VecRepeat elements as plain reads. A bare tracked pointer stored there is a copy the analysis no longer follows (the field assignment path, Stmt::Assign to a non-var place, already observed escape). The fact stayed (W=0, E=0) -> `&T`, and rewrite_expr's Var fallback converted it back with the plan's own (immutable) pointer type. Beyond the type error, writes through the stored copy would go through a `&T`.

Fix: ClassifyCtx::stored observes escape for an element whose source_var (peeling casts) is tracked, then walks it; every aggregate-literal element goes through it.

Regression test: crates/slate/tests/fixtures/ptr_lattice_aggregate_escape.c. slate profile 39/39, no other fixture output changed.

See: slate-dghn.56.8, slate-dghn.56.9 (same cpython check run).
