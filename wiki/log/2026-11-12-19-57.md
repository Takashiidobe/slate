Outcome: `python3 tools/corpus/e2e.py quickjs --mode clang` translates, builds and passes the 9 upstream JS tests (test_closure ... test_builtin) with the translated qjs.

Three bugs found by the quickjs run, each with a differential fixture:

1. Dispatch (goto) functions: a hoisted local named like a parameter (`unsigned func_name = fd->func_name;` in an inner scope of js_parse_function_decl2) captured the parameter's uses, giving MaybeUninit type errors. Fix: `parameter_free_name` in lower_dispatch renames the storage. Fixture: dispatch_shadows_param.c. Limit: OpenMP region dispatch passes no params.
2. `raw_ptr_alias::elide` substituted `p0` (alias of `p1`) by `p1` although `p1` is reassigned before p0's use (JS_FreeAtomStruct list unlink: `p0 = p1; p1 = arr[i]; p0->next = ...`), producing `p1->next = p1->next` and a crash at JS_FreeRuntime. Fix: `source_stable_through_uses` requires every rebind of the source to sit in a later sibling than the last alias use. Fixture: raw_ptr_alias_source_reassigned.c.
3. quickjs recipe in tools/corpus/e2e.py; c_corpus_setup.py builds only qjs/qjsc/run-test262/libquickjs.a, because `make all` captured the CONFIG_CHECK_JSVALUE `.check.o` entries for quickjs.c and qjs.c (bear dedupes by file) and that build cannot run.

Limits: gcc mode, run-test262 and microbench not run.
