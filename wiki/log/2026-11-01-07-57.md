# Bind errno and ctype to slate-support

_2026-11-01 07:57:52_

slate-f2zu.9.5.8.4: added slate_support::errno_location (link_name per libc) and bound __errno_location, __errno, __error and _errno to it. Bound the ctype functions to libc's exported functions, replacing header inline bodies on Darwin and Android. New lowerer/ctype.rs recognizes the macro forms: glibc's table test on __ctype_b_loc by mask, FreeBSD's __sbistype by mask (__sbtolower and __sbtoupper bind directly), and musl's 0 ? isX(a) : range form, which also checks the range constants and that both arms use the same operand, so a hand-written 0 ? isgraph(c) : 7 is left alone. Calls use one FunctionIdentity on every target, since merge compares bindings and textually identical calls otherwise stayed in separate cfg blocks. The unreachable-helper prune now runs for units with any bound function and also covers unused system-header extern globals, removing FreeBSD and Darwin rune locale statics; this also drops unused externs from non-merge output (for example snprintf in long_double_classify). Taking the address of a bound function still re-lowers the unit without bindings. Fixture: fixtures.merge/libc_spellings.c with units/libc_spellings_address.c; 12 fixture baselines regenerated, diffs sampled. Zlib 40140 to 39745 lines. Validation: projection 1024/0, signatures 676/0, validate_merge 78/78, slate, slate-targets and msvc profiles green, cargo check on 15 targets default and zlib-debug. Not checked: thumbv7a-pc-windows-msvc has no rustup target. Darwin, FreeBSD, Android and musl are compile-checked only, so their exported ctype functions matching the header forms comes from reading headers and libc source knowledge, not from running them. Remaining splits filed as sibling beads: errno constants, hoisting differences, stdio call identity.
