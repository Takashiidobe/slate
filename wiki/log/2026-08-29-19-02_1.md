# libc-shim headers C89-clean via **inline/**restrict

_2026-08-29 19:02:17_

cJSON builds with -std=c89, under which bare 'inline'/'restrict' in shim headers are parse errors (stdlib.h:46 etc). features.h already defines **inline/**restrict (GNU extension keywords valid in any -std, upgraded to standard spellings when **STDC_VERSION**>=199901L). Replaced bare inline/restrict with \_\_-prefixed forms in stdlib.h, uchar.h, threads.h, search.h, string.h, pthread.h, netinet/if_ether.h; added #include <features.h> to uchar.h (only one lacking it). These were over-eager copy-paste from real glibc. libc profile passes 19/19.
