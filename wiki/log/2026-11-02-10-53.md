# Lower -fblocks to a hand-written Blocks ABI

_2026-11-02 10:53:18_

slate-3amj.42.3: block literals, calls through block pointers, __block variables and global blocks now translate and run against the vendored BlocksRuntime. Block pointer type lowers to *mut c_void. frontend/support/blocks.rs (__slate_blocks, emitted only when blocks appear) has Block<C> header+captures, new/invoke/captures/cell/global; lowerer/blocks.rs lowers each ValueKind::Block to a captures struct plus an extern C-unwind fn lowered by a child FunctionLowerer, and block calls to a transmuted invoke pointer. __block vars are ir::Variable::byref (printed [byref]) lowered as leaked heap cells dereferenced by lower_binding; place_is_unsafe sees them. Capture-less literals in static initializers become static Block<()> with _NSConcreteGlobalBlock. ir::BlockCapture gained ty. translate-project writes the slate-blocks crate and dependency only when a unit emitted __slate_blocks. Parser fix: assigning a function-local static inside a block no longer errors. No block2: it needs Encode impls and cargo deps the rustc harness cannot resolve. Fixtures: block_basic, block_more, block_globals, fixtures.release/block_units. Doc: wiki/concepts/blocks-lowering.md. Known gaps: blocks never freed, captured blocks not retained, variadic blocks, self-referential __block initializers.
