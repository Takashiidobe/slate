# Fold translate-directives into translate, gate multi-config on host target + real target macros

_2026-09-06 14:27:37_

Completed slate-i3nv.4: removed the translate-directives subcommand.
slate translate (src/api.rs::translate_with_args) now auto-detects
whole-item #if regions gated solely by clang-builtin target/arch/os macros
(known_cfg in preprocess.rs) and expands them into the existing
plan_configs/translate_one/merge_variants multi-config pipeline
automatically; everything else (feature macros, in-body conditionals,
literal/opaque predicates with no macro to pin) falls back to plain
single-config translation, silently.

Two correctness fixes found by running the full corpus, not just the
directive_translate.rs suite:
- should_auto_expand requires non-#else branches to reference at least one
  macro. Without it, `#if 0 / #elif 1` (chibicc/c-testsuite fixtures) looked
  "trivially target-safe" (no atoms to fail the macro check) and hit
  plan_configs' pre-existing UnselectableBranch path, since a literal branch
  can't be selected via -D/-U pinning.
- Auto-expansion is now gated on SLATE_TARGET being unset/host-default
  (toolchain::target_is_host_default) and excludes Slate's own __SLATE_*
  macros from the target-macro allowlist. Under an explicit non-host
  SLATE_TARGET, target_args() re-asserts __SLATE_* and the real triple's
  ABI facts (va_list layout, struct sizes) regardless of -D/-U pins, so
  bionic/macos differential fixtures broke in ways unrelated to their
  content. Cross-target builds stay on translate-project --target, which
  spawns one real clang invocation per target instead of pinning macros on
  one triple.

tests/directive_translate.rs: rewrote ~15 tests off the removed CLI onto
plain `translate`; deleted tests whose whole point was explicit multi-config
over feature macros or CLI-level rejection promises now made moot by the
silent-fallback design (per acceptance criteria: no support for project
feature-flag macros). Deleted now-orphaned fixtures.cfg files; restored
reject/system_macro_feature.c after wrongly deleting it (still used by
tests/preprocess.rs, unrelated to directive_translate).

Verified: full rewrites profile 83/83 green; fmt/clippy clean.
