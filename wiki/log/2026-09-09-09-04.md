# Reconcile glibc elf.h relocation/macro superset

_2026-09-09 09:04:36_

Added elf.h to all eight Linux glibc/musl declaration manifests for
slate-b66b.14.2.25. musl already matched the shim's musl-derived elf.h
unchanged. glibc's elf/elf.h carries no arch/wordsize conditionals at all, so
its extra public surface (554 macros beyond musl's) is identical across all
four glibc architecture descriptors: whole extra relocation namespaces
(TILEPRO/TILEGX, ARC, METAG, MIPS/MICROMIPS additions, MN10300, NDS32,
RISC-V attrs, CSKY) plus scattered newer additions to existing families
(AT_*, DT_*, NT_*, GNU_PROPERTY_*, SHF_GNU_RETAIN, PT_GNU_SFRAME, STO_*).

Reconciled by aligning glibc's macro-name sequence against the shim's
existing (musl-derived) sequence and anchoring each contiguous missing run
right after its nearest preceding shared macro, wrapped in
`#if defined(__SLATE_LIBC_GLIBC)`. A naive whole-file difflib diff produced
too many false-positive "insert" ops from upstream reordering; anchoring
against the oracle-probe-verified missing-macro set (not diff opcodes) was
the reliable signal.

Wrote tools/extract_missing_macros.py (name-ordered oracle extraction) as a
reusable follow-up for future large-header ports.

All eight declaration_matrices descriptors pass; full `libc` profile (48/48),
cargo fmt, and cargo clippy --all-targets -- -D warnings are clean.
