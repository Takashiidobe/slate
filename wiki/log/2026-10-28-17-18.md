# Reject unknown GNU asm clobber registers

_2026-10-28 17:18:13_

Any aarch64/x86 asm clobber string used to be accepted as Register::Other (even 'bogus'). parser/asm.rs decode_clobber now errors "unknown register name 'X' in asm" for x86/aarch64 (Arm32 has no table, still accepts). Swept every table name/alias against gcc and clang: added x86 sil/dil/spl, aarch64 x31/w31, and an AsmClobber::Redzone variant (gcc 'redzone', no Rust equivalent). Known gap: clang accepts arbitrary numeric registers up to ~100+ on aarch64 (95, 96, 200); we follow gcc's range. Removed bogus 'not_a_register' clobber from clang x86_64 asm-statement.c/ir_asm.c. New error fixtures: error/{gcc,clang}/linux/{x86_64,aarch64}/asm-clobber-unknown-register.c.
