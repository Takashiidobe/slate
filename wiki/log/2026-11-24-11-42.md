# slate-5exy.13 GNU atomic flags: test-and-set and clear overwrite neighboring bytes

_2026-11-24 11:42:14_

- bead: slate-5exy.13
- kind: bug
- area: crates/slate/tests/fixtures.unsupported

Outcome: The unsupported ratchet covers GNU atomic flags on wider objects.

Set byte 1 of an unsigned word and leave byte 0 clear. Test-and-set
must report the first byte clear, then set it and preserve byte 1.
Clear must zero only byte 0. Lean bv_decide compares a little-endian
32-bit byte-update model with whole-word replacement and finds
0xffffff00 as a counterexample. The fixture uses the confirmed
witness 0x100 to isolate one neighboring byte.

Slate parser emits update<u32> and write<u32> for the two builtins.
The generated AtomicU32 swap and store replace all four bytes.
The Clang oracle exits 0 and generated Rust exits 3 on x86_64, i686,
aarch64, and armv7 Linux. Native GCC also exits 0.
