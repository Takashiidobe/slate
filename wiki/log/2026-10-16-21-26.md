# Skip the NUL scan for lifted string literals in libc_call

_2026-10-16 21:26:28_

slate-5vj0.5.11: strncmp/strnlen/strspn/strcspn/strcmp byte paths sliced every lifted argument with as_bytes()[0..iter().position(nul).unwrap_or(len)], even for a string literal whose length is known.

- rules/libc_call.rs: literal_len recognizes '"text".as_bytes()' when the text has no NUL (a ByteStr can keep an interior NUL after its terminator is stripped). c_string_len returns the literal length (min a constant bound, or '(bound as usize).min(len)'). New c_string_bytes returns the bytes unsliced when the literal fits the bound, else slices to c_string_len; strcmp/strncmp/strspn/strcspn use it. slice_to no longer casts a usize literal end.
- Fixture libc_call_nested.c: same_prefix and spans drop the scan; new embedded(n) covers an interior-NUL literal (scan kept) and a runtime strncmp bound.
