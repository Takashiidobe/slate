# slate-dghn.55.1 slate-libc-gen macro_members: in6_addr/fd_set reached through reserved fields by public macros stay local, containers cascade

_2026-11-13 18:10:03_

- bead: slate-dghn.55.1
- kind: bug
- area: crates/slate-libc-gen/src
- area: crates/slate/src/backend/clib_records_table.rs

Outcome: slate-libc-gen keeps a record local when a public header macro reads one of its reserved fields the provider lacks (glibc in6_addr via s6_addr/IN6_IS_ADDR_*, fd_set via FD_SET), cascading to records that contain it, so translated nginx passes cargo check with 0 errors (was 73).

Symptom: nginx cargo check failed with 73 `no field __in6_u on type in6_addr`. nginx itself never names `__in6_u`; glibc's public macros expand into it (`#define s6_addr __in6_u.__u6_addr8`, `IN6_IS_ADDR_V4MAPPED` reads `__a->__in6_u.__u6_addr32[i]`), and the libc crate's in6_addr only has `s6_addr`, so no canonical rewrite exists for the u32 view.

Reproducer:
```c
#include <netinet/in.h>
int f(struct sockaddr_in6 *a) { return IN6_IS_ADDR_V4MAPPED(&a->sin6_addr) + a->sin6_addr.s6_addr[0]; }
```

Cause: decide_one treated a record whose fields are all reserved (in6_addr: `__in6_u`) as an opaque candidate and ignored unmirrored reserved fields; nothing looked at which members header macros reach.

Fix:
- c_side::macro_members preprocesses each probe header, reads every #define body from its source (joining continuations), and collects reserved names after `.`/`->` (member access only; designators like `{ .__data = ...}` skipped) in macros reachable from public, non-underscore macros through the macros they expand into. Internal helpers alone (`__getc_unlocked_body`) do not count.
- decide_one excludes a record when such a field is not mirrored by the provider, except provider-incomplete types (FILE, DIR stay canonical).
- decide::exclude_containers cascades, to a fixpoint, to records whose fields (direct, array or pointer, via c_side Field.records) refer to a macro-excluded record. Functions and globals using them drop out through the signature-shape check (slate-dghn.55.2).

Catalog effect: in6_addr, sockaddr_in6, ipv6_mreq local on glibc and freebsd (plus in6_pktinfo on freebsd); fd_set local on glibc and freebsd; freebsd sigset_t/__sigset and cpuset_t/_cpuset local. select, pselect, in6addr_any/loopback, freebsd sig*/cpuset_* functions become local externs.

Regression test: crates/slate/tests/fixtures/glibc_in6_addr_macros.c; libc_symbols.c and fixtures.build/freebsd/abi_defaults.c FileCheck regenerated.

Limits: the cascade only follows macro-reached exclusions; canonical records that contain records excluded for other reasons (ucontext_t -> local stack types) are unchanged. Provider-incomplete FILE/DIR on BSD still break if a TU uses getc_unlocked/dirfd macros. Mapping s6_addr back to the provider field belongs to slate-dghn.55.3.

See: slate-dghn.55, slate-dghn.55.2, slate-dghn.55.3
