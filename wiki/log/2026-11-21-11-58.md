Outcome: IR built with macro structure and fully stripped now equals the IR built without it (1071/1071 slate fixtures), and `SLATE_CHECK_MACRO_STRUCTURE=1` checks it in every `project_merge` compile.

Feature: invariant check. `frontend::lower_parsed` runs `check_macro_structure` when the env var is set: it lowers the unit with `Sema::new` and with `with_macro_structure(true).with_macro_keep(|_| empty)`, prints both with metadata and fails with `Error::MacroStructureChangedIr` on the first differing line.

First sweep found 25 fixtures differing, two causes:

1. `sema::operand::kept_integer_conversion` kept an explicit integer cast over a hole as `ConversionKind::IntCast` (so templates share one `$x as T`). Plain IR has `widen`, `reinterpret`, or no node for an identity cast, so `LONG(i)` was `int_cast<i64>` with structure and `widen<i64>` without; stripped expansions also printed redundant `c as i32` (glibc isgraph).
2. `macro_value_holes` / `macro_value_expansion` recorded the C type on the inner node before `finish_expr`, which then recorded on the wrapper; after strip the inner kept the stale spelling (`[c="atomic_int"]` instead of `int`, `__m256i` on vector reads).

Before (`#define LONG(x) ((long)(x))`, `long c = LONG(i);`):
  with structure: macro_value(#0, int_cast<i64>(macro_arg(#0, 0, read<i32>(%1))))
  without:        widen<i64>(read<i32>(%1))
After: with structure `widen<i64>(macro_arg(...)) [macro_cast="i64"]`; stripped equals plain.

Fix:
- Casts over holes lower like any cast. `Sema::apply_conversion` records `Module::macro_written_casts[result node] = WrittenCast { expansion, ty, operand: hole node }`. The lowerer (`lower_written_cast` in lowerer/macro_sites.rs) peels the conversions between result and operand and prints one `operand as T`; `check_macro_template` remaps ids through the pairs `strip_all_macro_structure` now returns. `strip_macro_structure` drops facts of stripped expansions.
- Sema finishes an expression before wrapping it and records the C type on each wrapper; `strip_macro_structure` moves a removed wrapper's `c_types.nodes` entry onto the node replacing it (new `Visitor::unwrapped_value` hook).
- `ConversionKind::IntCast` and `Value::is_macro_hole` removed (no producer left).

Rejected: keeping every explicit integer cast as `int_cast` (673 parser fixtures, loses widen/truncate kinds) and keeping identity explicit casts as `reinterpret` (adds a wrapper node analyses must look through: the same bug class).

Fixtures: crates/slate-parser/tests/fixtures/clang/linux/x86_64/macro_written_casts.c (new); regenerated macro_nodes.c, fixtures.merge/libc_spellings.c (classify/hand_written no longer split per target), x86_64/x86_header_expanded_builtins_{2,3,4}.c (redundant identity casts gone).

Runs: parser 9329/9329 (after regen), merge 1/1 with both checks, slate 42/43 before regenerating the 3 x86 fixtures, then each passes alone. Not rerun after removing IntCast (no producer; compiles).

Limits: value nodes (MacroArg, MacroExpansion, PlaceKind::MacroArg) still exist; the check only proves sema makes the same value decisions. Next: slate-8ge7.2.2, slate-8ge7.2.3.
