# MSVC /manifestdependency linker pragma

_2026-11-09 07:44:31_

slate-j3by.6.6: '/manifestdependency:...' now passes through .drectve (added to the allowlist in sema/pragmas.rs). Its value contains spaces inside quotes, so linker_comment now unescapes the pragma string and splits on whitespace outside double quotes (it used split_whitespace, which cut the option at the first space); it returns Vec<String>. Not runtime-observable in the harness: cl.exe writes an external .exe.manifest, and lld-link rejects '/manifest:' in .drectve, so an embedded-manifest probe cannot be made to match; the fixtures (slate msvc/{x86_64,i686}/pragma_manifestdependency.c, slate-parser msvc/windows/x86_64/pragma_manifestdependency.c) check the emitted directive with FileCheck and that the exe still runs under wine. msvc and parser profiles green.
