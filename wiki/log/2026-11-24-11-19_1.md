# slate-yar4.68 lower_value_node: __builtin_expect drops expected operand effects

_2026-11-24 11:19:05_

- bead: slate-yar4.68
- kind: bug
- area: crates/slate/tests/fixtures.unsupported

Outcome: The unsupported ratchet covers calls in the expected-value
argument of both branch-hint builtins.

Both wrappers pass a runtime long as the hinted value and a
counter-incrementing function as the expected value. Clang and GCC
keep the hinted value and increment the counter once per invocation.
Slate's typed IR retains the call, but lower_value_node returns
the first operand and drops the call. Lean's one-step model
captures the difference in the counter even though the values agree.
On all four Linux targets the C oracle exits 0 and translated Rust
exits 3, with one failure bit per builtin.

See: slate-04q.47.3 covers effects in the first argument.
