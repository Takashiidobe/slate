# Render slate lowering barrier sites as file:line:col

_2026-10-01 07:24:05_

slate-p58o.11. parse_module_with_args now returns (Module, Files) instead of dropping the parser's file map. Site::render(&Files) prints the expansion location as path:line:col (1-based, via Files::position) and appends '(spelled at path:line:col)' when a macro moved the spelling, e.g. atomics report the use site plus stdatomic.h. Barrier/InvalidIr Display no longer embeds the raw site; slate_parser_frontend::lower_module(&module, &files) owns the first-barrier-is-the-error policy and renders it into Error::Unsupported/Invalid { location }. lowering-barriers prints function, location, construct kind, message. Construct::Place now uses Place's Display instead of Debug. Statements still render as Debug because ir::Statement has no public printer (filed).
