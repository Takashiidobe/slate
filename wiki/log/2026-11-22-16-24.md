# slate-8ge7.24.19.2 libc_calls buffers: memcpy/memmove/memset/memcmp lift to copy_within/copy_from_slice/fill/cmp on array, offset, slice-param and ArrayAlias views

_2026-11-22 16:24:17_

- kind: rewrite
- area: crates/slate-analysis/src/byte_buffers.rs
- area: crates/slate/src/frontend/lowerer/libc_calls.rs

Outcome: memcpy/memmove/memset/memcmp on any byte-buffer view (local array, constant offset into it, lifted byte-slice param, or a mem*-only pointer alias) lower to copy_within/copy_from_slice/fill/cmp chosen by whether both sides share a root, with runtime lengths allowed.

Before (C: `char buf[8]; char *s = buf + 1; memmove(s, buf, 6); memcpy(buf + 4, buf, 2); memset(buf + 1, 9, n);`):

```rust
let shifted: *mut i8 = buf.as_mut_ptr().add(1);
unsafe { core::ptr::copy(buf.as_mut_ptr() as *const u8, shifted as *mut u8, 6) };
unsafe { core::ptr::copy_nonoverlapping(buf.as_mut_ptr() as *const u8, buf.as_mut_ptr().add(4) as *mut u8, 2) };
unsafe { core::ptr::write_bytes(buf.as_mut_ptr().add(1) as *mut u8, 9, n as usize) };
```

After:

```rust
buf.copy_within(0usize..6usize, 1usize);
buf.copy_within(0usize..2usize, 4usize);
buf[1usize..(1usize + ((n as u64) as usize))].fill(9i32 as i8);
```

Rule (`frontend/lowerer/libc_calls.rs`, `buffer` + `Buffer`/`Length`):
- Buffer roots: decayed local byte array (not static/literal), `borrow.many` byte param (length unknown, mutability from the borrow), `ArrayAlias` local; constant 8-bit `PointerOffset` adds to the offset.
- Same root -> `copy_within` (memcpy too: C forbids overlap, the borrow checker needs one object). Different roots -> `copy_from_slice`. Otherwise raw `ptr::copy*`/`write_bytes`.
- Blocks: element types differ, dst not mutable, constant n past the known length, runtime n not duplicable where used twice, memcmp on non-u8 elements (C compares unsigned bytes; `[i8]::cmp` is signed).
- `slate-analysis/src/byte_buffers.rs`: `ArrayAlias { array, offset }` on a plain written-once non-escaping pointer local initialized from a local byte array (+ constant offset), only when every read is a mem* buffer argument at macro depth 0 and the array name is not redeclared in the function. Lowering drops its let and lowers reads to the initializer.

Why the alias rule is narrow: `p = buf.as_mut_ptr()` kept live across `buf[..].fill()` is UB under Stacked/Tree Borrows (the fresh &mut disables p's tag), so `char *p = buf; memset(p, 0, 8); return p[0];` (peel_casts_ptr_chain.c, slate-8ge7.24.18) stays raw.

Fixture: tests/fixtures/mem_buffer_views.c (alias fill, offset copy, same-object move, runtime length, u8 memcmp, shadowed array stays raw, unknown src stays raw). Regenerated: gnu_builtins_memory, local_libc_mem, local_libc_memcmp, mem_safe_slice_idioms, memcmp, memcpy, memmove, memset, string_libc_fixup (runtime all OK).

Limits: &str/&CStr and literal sources (`memcpy(buf, "abc", 4)`) are not buffers yet; mixed-use aliases stay raw until stage 3 gives `p` an index view; arrays whose only remaining use was the dropped alias keep `let mut` (unused_mut warning).
