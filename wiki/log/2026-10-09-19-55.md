# Lower explicit-register asm operands, register variables, and rbx

_2026-10-09 19:55:37_

slate-3f8g.4.17.5 + slate-parser-asmrv.

Parser: an asm operand naming a register variable selects Explicit(reg) when the chosen register class holds it (clang's {r10}); the Lowerer keeps a BindingId -> AsmRegister map from declarators. The printer shows '-> {reg}' when a letter class was pinned this way. Fixture ir_asm_register_variables.c; asm-hard-reg-error-1 checks regenerated.

Slate: explicit GPR operands become in("ax")-style operands placed after all positional operands (Rust rejects positional after explicit); template references print the register name at the view/width since Rust forbids {N} for explicit registers. reg_legacy (R) pins the first free of ax/cx/dx/si/di. rbx is LLVM-reserved: a b operand rides in a scratch reg exchanged into rbx with xchg around the template (inputs inout => _, outputs early); an rbx clobber is saved/restored with mov through an early out(reg) _. rbp/rsp remain barriers. Register-local operands are no longer barriers once pinned; global register variables still are.

Promoted asm_fixed_register_cpuid, asm_ebx_output_cpuid, inline_asm_demo, gnu_asm_register_variable, new asm_reg_legacy_operand and asm_rbx_register_variable, and six gcc-dg fixtures (guality param-6, pr45003-1/2/3, two vect early-break).
