# Select one build target from a multi-variant compile database

_2026-10-30 20:36:28_

slate-mbr2.1.2: translate-project rejected databases with different commands for one file. compile_commands::read now groups entries by the directory of their object file (output field or -o; CMake's x.dir and Meson's x.p lose the suffix). On a conflict it picks one target: no main, then most files, then no -fPIC, then first name. It prints the choice, and --build-target overrides it. Without a conflict or the flag, behaviour is unchanged. main is detected by scanning source with comments and strings removed, so a macro-defined main is missed and a main in #if 0 counts. Fixtures: fixtures.select (project_select). zlib build-clang: 37 entries select zlibstatic, 15 files, cargo check passes. The 18-entry root database has no conflict, so it still fails with 'multiple units define main' unless given --build-target zlib, which passes cargo check. Same-stem sources stay with slate-a28e.16.
