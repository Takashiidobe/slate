Outcome: `_mm*_fpclass_p{s,d}_mask` and the AVX-512VL masked gathers/scatters (`_mm256_mmask_i32gather_epi32`, `_mm256_mask_i32scatter_epi32`, ...) translate; NumPy's barrier report has no builtin barriers left (56 blocked, all SVML, slate-dghn.58.5).

Gap: NumPy's X86_V4 `loops_exponent_log.dispatch.c` (frexp/ldexp) used `__builtin_ia32_fpclass{ps,pd}512_mask`, `gather3siv8si` and `scattersiv8si`. They were hidden behind the SVML barrier in the same TU, so the 58.1 sweep missed them.

Before:
```

help: function __builtin_ia32_gather3siv8si: vector C ABI
```

After: fpclass is pure lane compares + `slate.vector_sign_bitmask`; gathers lower to `#[link_name = "llvm.x86.avx512.gather3siv8.si"]` externs.

Implementation:
- sema/builtins.rs: all 32 VL `gather3{si,di}v{2,4,8}{df,di,sf,si}` / `scatter{si,di}v*` map to `Expansion::Intrinsic` with the i8-mask LLVM names (`llvm.x86.avx512.gather3siv8.si`), which already had stdarch overrides on the Rust side. New `Expansion::FloatClassMask` for `fpclassp{s,d}{128,256,512}_mask`.
- sema/x86_vector_builtins.rs `float_class_mask`: no masked 512 LLVM intrinsic exists and the unmasked one returns `<N x i1>`, so the expansion follows Intel's CheckFPClass pseudo-code on the lanes bit cast to unsigned: bit 0 QNaN `abs >= inf|quiet`, 1 +0, 2 -0, 3 +Inf, 4 -Inf (equality on the raw bits), 5 denormal `abs != 0 && abs < min_normal`, 6 negative finite `bits >= sign && abs < inf && abs != 0`, 7 SNaN `abs > inf && abs < inf|quiet`. Selected classes are OR'd; imm 0 gives zero. The operand is bound once; each compare re-reads it.
