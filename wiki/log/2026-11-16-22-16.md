# slate-f2zu.14.34.37 structure_goto: unreachable_unchecked jumps from .36 kept tcp_collapse as goto dispatch, dead BUILD_BUG_ON __compiletime_assert_N undefined at vmlinux link

_2026-11-16 22:16:56_

- bead: slate-f2zu.14.34.37
- kind: bug
- area: crates/slate/src/backend/engine/rules/structure_goto
- area: crates/slate/src/frontend/lowerer/control_flow.rs
- flavor: clang

Outcome: goto functions whose transitions jump into a `__builtin_unreachable` block restructure again, so the kernel vmlinux links with 0 errors (it had 2 undefined `__compiletime_assert_N` references after slate-f2zu.14.34.36).

Symptom: relink of the translated kernel at 6e2d31b1c:

    tcp_collapse+0xb47: undefined reference to `__compiletime_assert_1641'
    tcp_write_xmit+0x157d: undefined reference to `__compiletime_assert_1485'

The second comes from `tcp_tso_should_defer`, inlined into `tcp_write_xmit`.
Both functions hold `min()`, whose `BUILD_BUG_ON(!__types_ok(x, y))` calls a
noreturn `__attribute__((error))` extern that must never survive codegen.

Reproducer (shape of the fixture): a goto function with `restart:`/`end:`
labels and a kernel-style `BUG_ON` (`do { asm; } while (0); __builtin_unreachable();`)
in a loop.

Cause (bisected 0b807da49..6e2d31b1c on tcp_input.c; first bad 6e2d31b1c):

- .36 lowered a jump into an unreachable block as
  `Expr::Var("core::hint::unreachable_unchecked")`. `is_exit_path` in
  structure_goto/reducible.rs matches only `Expr::Path`, so the arm did not
  count as diverging.
- Even as a path, `Extractor::target` rejected a branch arm that was only a
  diverging statement: `terminator` returns `Term::Diverge` with prefix length
  1, and `target` requires 0.
- StructureReducible gave up, so the whole function stayed a
  `match __slate_state` dispatch. LLVM folded `__types_ok` so nothing ever
  stored the assert state, but it did not drop that switch case. Switch
  lowering then sent "state != 18" straight to `call __compiletime_assert_1641; ud2`.
  The structured form folded the dead `if` away.

Fix:

- `lower_dispatch` (lowerer/control_flow.rs) emits the jump as
  `Expr::Path(core::hint::unreachable_unchecked)`.
- `Term::Escape(Vec<Stmt>)` in reducible.rs: `Extractor::target` maps an arm
  whose tail diverges, and has no state writes or dispatch escapes, to
  `Escape` with its statements. It has no edges and `emit_term` emits the
  statements.

Verified: `e2e.py linux --from translate --shards net_ipv4 --until link`:
link ok, 0 errors, 2 objtool warnings (`amd_mce_usable_address` noinstr,
recursive UACCESS enable; both predate this change).

Regression test: crates/slate/tests/fixtures/goto_structured_bug_on.c
(FileCheck shows the structured loops, no `__slate_state`). Regenerated
computed_goto_ops, freestanding_dispatch_unreachable, mem2reg_computed_goto,
x86_64/gnu_language.

Limits: a function that stays a real dispatch can still keep a dead
`__compiletime_assert_N` arm; LLVM does not prune never-assigned states.

See: slate-f2zu.14.34.36, slate-f2zu.14.34.34.
