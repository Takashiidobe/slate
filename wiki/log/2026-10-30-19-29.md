# Add a greedy configuration planner with --plan

_2026-10-30 19:29:47_

slate-mbr2.1.5: translate-project --plan --matrix <file> [--matrix-target <name>] <project> prints, per target and TU, the feature configurations to compile, before any Rust lowering. crates/slate/src/project_plan.rs explores with Parser::preprocess_file_traced: it starts from no features, flips toward conditional arms not yet reached (including the implicit else of a conditional with no #else), and tries each relevant feature alone, all relevant features together, and every pair of features touching one top-level item. Greedy cover then picks configurations over elements, where an element is one statement chunk (split at ; { } outside parens) keyed by source site and spelling. Configurations that reach #error are excluded; chosen ones go through parse, sema and IR lowering, and failures are rejected and re-planned. Each unit is capped at 4096 runs. --plan-exhaustive also tries every subset (at most 16 features) and reports what the plan missed. PreprocessTrace gained conditional_dependencies; Matrix gained command and is_invalid_combination; token_spelling is now pub.
Results on zlib: 29 compiles per target from about 100 preprocessor runs instead of 7,680, on the 10 targets that plan fully. Enumeration needs 28 and the plan missed 0 elements on linux-x86_64, windows-x86_64, linux-arm32 and linux-musl-aarch64. With the epic's original nine features: 36 compiles on linux-x86_64 and windows-x86_64, 36 by enumeration, 0 missed; the epic estimated 34 using a different element definition (not reconciled). Darwin (13 of 15 TUs) and FreeBSD (5) fail with expected RParen in declarator, Android (15) on <asm/types.h>. All 16 targets plan in 26s. Output is deterministic and independent of SLATE_JOBS.
Tests: tests/fixtures.plan pins whole --plan output through SLATE-FILECHECK blocks; plan_filecheck in tests/project_plan.rs; update_filecheck.py regenerates them. Limits: element coverage is by tokens, so a statement whose tokens match but whose types differ between configurations is not separate, and statement text from three or more macros can have combinations pairs do not reach. The projection check in slate-mbr2.1.6 must catch both.
