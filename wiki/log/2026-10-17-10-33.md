# Wire vendor/bitint into the lowerer for _BitInt(N>64) with C layout (slate-j844)

_2026-10-17 10:33:56_

_BitInt storage now matches C byte for byte on x86_64, i686 and aarch64.

Representation:
- N <= 64: next native int container (_BitInt(9) -> i16), normalized with shl/shr (signed) or a mask (unsigned) on conversion via narrow_integer.
- N > 64, and N == 128 where clang's alignment is not 16 (x86_64 A8, i686 A4): bitint::BInt/BUint<BITS, LIMBS, BYTES, bitint::A{align}>.
- _BitInt(128) on aarch64 stays i128.

vendor/bitint changes:
- Structs are now repr(C) { _align: [A; 0], bytes: [u8; BYTES] } over an Alignment param (aligned crate), so size/align follow clang's BitIntMaxAlign.
- Signed values are sign-extended into the padding bits (from_limbs, from_le_bytes, from_buint, from_bint), matching what clang and gcc store.

Lowerer (new lowerer/bitint.rs):
- Constants use from_u128/from_i128, or from_decimal_str when wider than 128 bits.
- Conversions use from_bint/from_buint, from_i128/from_u128, and to_i128/to_u128 + narrow_integer.
- Unary neg/not use the const fn methods wrapping_neg/bitnot. std operator traits are not const, so every wide operator must use the crate's const fns (noted on slate-2o6o.16).
- A switch on a wide discriminant <= 128 bits matches on to_i128()/to_u128(). Wider discriminants work on the CFG path (BInt ==) and are a barrier on the match paths.
- A wide _BitInt bit-field is a record barrier (slate-6uvv.8).
