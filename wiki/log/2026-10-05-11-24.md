# asm goto targets resolve __label__ local labels by binding

_2026-10-05 11:24:12_

slate-parser-6x05.38.22. The asm goto jump-scope check in sema/validate.rs collected labels into a map keyed by name, so two statement expressions that each declare __label__ failed (kernel snd_pcm_sync_ptr_get_user/put_user) collided: the last failed: won, and an earlier asm goto looked like it jumped into a different statement expression. Clang accepts. The collector now keys label definitions by BindingId (NameResolution::label_definitions) and each asm label operand resolves through TypeResolver::references, so __label__ scoping comes from the name resolver. Fixture: clang/linux/x86_64/asm_goto_local_label_shadowed.c. sound/core/pcm_native.c now parses under --flavor=clang.
