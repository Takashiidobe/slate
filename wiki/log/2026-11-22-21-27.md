# slate-8ge7.21 guarded heap: lift nullable integer malloc buffers and constant cursor offsets

_2026-11-22 21:27:11_

Outcome: Slate lifts guarded fixed-extent integer malloc buffers to
`Option<Vec<T>>` with fallible allocation and safe indexing.

## Before and after

```c
int *p = NULL;
if (flag) p = malloc(sizeof(int) * 4);
if (p) {
  p = p + 1;
  *p = 41;
  printf("%d\n", *p);
  free(p - 1);
}
```

Before: Rust kept the nullable raw pointer, advanced it with `p.add(1)`,
and passed `p.sub(1)` to `free`.

```rust
let mut p: Option<Vec<i32>> = None;
if flag != 0 {
    p = Vec::try_filled(4, 0);
}
if let Some(p) = p.as_mut() {
    p[1] = 41;
    println!("{}", p[1]);
}
```

## Implementation

- `guarded_heap::analyze` checks the constant extent and every def-use.
  It proves bounds, initialization before loads, and offset zero at release.
- `VecExt::try_filled` and `try_resize` return `None` on reservation
  failure. The resize preserves the old buffer on failure.
- Both heap lowering paths share the release-elision rule. A release before
  later work still emits `drop(p)`.

Fixtures: `option_box_local_arith_bailout.c` and `option_box_local_guarded.c`.
A generated project matched C output. Fault injection exercised both
helpers and confirmed that failed growth preserves the original vector.

Limits: direct and runtime-sized typed allocations and scalar Box lowering
are tracked in slate-8ge7.24.19.12. See slate-knus for interprocedural ownership
and slate-8ge7.24.19.10 for a fallible two-binding realloc lift.
