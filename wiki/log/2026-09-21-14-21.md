# Flavor-aware default severity: int-conversion and incompatible-pointer-types become errors

_2026-09-21 14:21:09_

slate-parser-dyd.43. The severity model had no notion of a default-error
warning, so -Wint-conversion and -Wincompatible-pointer-types were reported
as warnings and their translation units accepted. Both are default errors in
clang 22.1.8 and gcc 16.2.1.

Measured 2026-09-21 across clang / gcc / MSVC 19.51:

| | clang | gcc | MSVC |
| --- | --- | --- | --- |
| int-conversion | error, every -std | error, except c89/gnu89 -> warning | warning C4047 |
| incompatible-pointer-types | error, every -std | same c89/gnu89 demotion | warning C4133 |

Flags, clang and gcc agreeing: -Wno-X silent, -Wno-error=X warning, -WX still
error, -Werror error.

src/diagnostics.rs gains DefaultSeverity {Ignored, Warning, Error} -
clang's DefaultError, gcc's permerror - replacing enabled_by_default's bool.
default_severity() takes the flavor as well as the standard; gcc's c89/gnu89
demotion keys off the same stdc_version().is_none() predicate c99-compat
uses. DiagnosticContext {options, standard, flavor} now carries the three
inputs, so Warning::diagnose takes one argument instead of threading standard
(and now flavor) through TypeContext, LiteralContext and Lowerer::warn
separately. All 15 rows of the matrix reproduce.

This overturns the consensus-rule paragraph in diagnostic-severity.md, which
kept both as warnings because MSVC only warns. That rule assumed one global
severity; with a flavor axis each flavor matches its own compiler, so nobody
gets a severity their compiler would not give. The page now states the
three-way taxonomy the rule was really expressing: correct per compiler and
flags, permissive, or too strict for all three - with permissive an accepted
cost rather than the right answer, and too-strict the only bug.

slate-parser-hdt reverses a second time: dropping _Atomic from a pointee is
an error under clang and gcc flavors. MSVC's "silent acceptance" was it
failing to parse _Atomic at all, which is not a vote.
