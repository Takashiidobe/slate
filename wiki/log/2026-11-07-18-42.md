# Lower volatile atomic RMW and CAS for MSVC Interlocked

_2026-11-07 18:42:56_

slate-f2zu.2: InterlockedCompareExchange/Exchange/*Pointer and _interlockedbittestandreset take volatile pointers, so their IR update/compare_exchange places are volatile; lower_atomic_update and lower_compare_exchange (frontend/lowerer/atomics.rs) rejected volatile. Rust has no volatile RMW or CAS (atomic_volatile only adds load/store), so volatile RMW/CAS now lower through the plain AtomicX::from_ptr APIs. An atomic RMW is never elided or merged, so volatile adds no observable guarantee here. Volatile atomic loads/stores still use load_volatile/store_volatile.
Also fixed a rewrite bug the fixture exposed: pointer_lattice lifts a pointer param to &T and casts it back at a return using the return type's mutability, but only when the return was a bare Var. A lifted param in an if/match/block tail of a return got the plan's const cast (*const T for a *mut T return: E0308). rewrite_returned now descends into if/match/block/unsafe tails.
Fixtures: msvc/interlocked_volatile.c (i32 CAS/exchange/inc/dec/add/or/and/xor, pointer CAS/exchange, bit test-and-set/reset; x64, i686, aarch64), lifted_param_returned_from_branch.c. Promoted gcc-dg atomic__c11-atomic-exec-3.c and -4.c.
MinHook x64: translates with no barriers; staticlib builds; a driver exercising init/create/enable/disable/API hooks/queued apply/remove/uninit matches native cl.exe output under wine (19 lines), linked with a temporary __movsb shim. __movsb/__stos* intrinsics are not lowered: new bead under slate-j3by.
System Informer phlib (6 units): no atomic barriers remain; only selectany globals (slate-f2zu.4).
Validation: msvc profile 475/475, slate profile 36/36.
