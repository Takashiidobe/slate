# AArch64 za/zt0/fpmr clobbers and sme/fp8 features

_2026-11-01 21:58:26_

slate-3f8g.4.31: lowerer/asm.rs drops za, zt0 and fpmr clobbers on aarch64 (rust asm! cannot name them, generated Rust never keeps values there). target_features.rs maps sme, sme2 and fp8 to rustc's features; they are unstable on the pinned nightly, so Feature::Aarch64UnstableTargetFeature (aarch64_unstable_target_feature) is emitted when a function uses one. Fixture: aarch64/asm_aarch64_sme_state_clobbers.c (smstart za/zero {za}/smstop za, fpmr msr/mrs; qemu -cpu max; gcc and clang accept). Dropping is sound only while SME-state functions fail to parse; once they do, a sibling bead must refuse them. Doc: wiki/concepts/ir/asm.md.
