# Libc oracle strategy

_2026-09-07 20:18:03_

Created epic slate-b66b for extending libc-shim validation with explicit libc oracles.\n\nThe oracle matrix is target plus libc: real target glibc sysroots for glibc cases and locally built musl sysroots for musl cases. Musl is a portability baseline for API decisions, not a substitute for glibc ABI layouts.\n\nThe work is split into musl sysroot bootstrap, normalized ABI probes, matrix runners with host-leakage rejection, nextest integration, musl runtime differential checks, and documentation. The provisional probe task slate-001g was superseded by slate-b66b.2.
