# chibicc compile bring-up

_2026-08-08 00:00:00_

Started the push to get chibicc itself compiling through slate, working commit-by-commit through lowering gaps chibicc's own sources hit.

- **Directives choking on `__SLATE_*` cfgs**: `src/preprocess.rs` grew `slate_target_cfg`, mapping `__SLATE_ARCH_*` / `__SLATE_VENDOR_*` / `__SLATE_KERNEL_*` / `__SLATE_LIBC_*` macros to Rust `cfg(target_arch/vendor/os/env)` predicates so translated conditional directives compile per-target instead of choking on slate's own internal feature macros.
- **Interprocedural pointer hoisting**: added a rule that hoists pointer parameters through call chains (new `docs/writing-a-fixup.md` written alongside it as the fixup-authoring entry point, plus `docs/facts.md` for the read-only fact layer).
- **Dead-code cleanup ordering**: added a rerun of the `unused_items` pass after `unused_params`/`prune_unused_definitions`, since dropping a last reference to a struct/enum only becomes visible once those two passes have already run — closes a class of leftover-dead-record bugs (`docs/passes.md` pass 65).
- **Anonymous enum typedefs**: `c_ast.rs`'s `collect_enum_typedefs` only matched enums with a tag name; added `next_anonymous_enum_typedef_name` to key anonymous enums by AST node id so `typedef enum { ... } foo_t;` resolves a name too.
- **Cross-TU variadic safety**: `unsafe_defined_functions` in `lower.rs` now also marks a function unsafe when its declared type is variadic, not just when it fails the pointer-contract check — added `tests/fixtures.multi/unsafe_variadic` to lock in `pub unsafe extern "C" fn bump(...)`.
- **vfprintf/va_list plumbing**: `rust_type_with_aliases` gained `is_cir_va_list_type`/`function_type_contains_va_list` to recognize `__va_list_tag`/`__builtin_va_list` CIR record spellings (bare, behind a pointer, or as a 1-element array) and map them to `Type::VaList` instead of a generic record type.
- **Constant aggregates with function-pointer members**: `c_abi_function_targets` previously only found function-pointer targets reachable via `GetGlobal`; extended it to also scan `#cir.global_view<@...>` references inside constant-aggregate initializers (`parse_cir_global_views`), and taught constant-initializer lowering to wrap function-pointer fields in `Some(...)`.
- **`Void` → `VOID`**: renamed the `CLibType::Void` variant to `VOID` and moved per-type alignment onto a `CLibType::alignment()` method (was a hardcoded match on `MbState`/`Timespec`), part of prepping the type for the growing table of C-lib struct types chibicc pulls in.

Split the chibicc-compile epic into subtickets to track the remaining gaps.
