# Lower ordinary enum types in the slate frontend

_2026-09-30 20:57:20_

slate-p58o.3.20.

- A complete enum type (Type::Defined -> TypeDefinitionKind::Enum with an underlying type) lowers to that underlying integer type, in lower_type and in resolve_type, so storage_of, record layout checks and zero-init all see the integer.
- No Rust enum is emitted: a C enum object can hold any value of its underlying type, and an out-of-range discriminant would be UB in Rust. Enumerator references are already constants in the IR, and int_to_enum/enum_to_int lower as plain casts.
- Incomplete enums (no underlying type) stay unsupported.
- New fixture enum_typed_values.c: enum locals, params, returns, struct fields, globals and arrays; negative values; C23 fixed underlying type (: unsigned char); typedef'd anonymous enum; sizeof.
- Promoted: local_named_enum_declaration, enum_typed_values, 7 more local fixtures, 3 gcc-torture.
- 3.13 closed at user request (its fixtures already passed). 3.35's named fixtures also pass already; left open.
