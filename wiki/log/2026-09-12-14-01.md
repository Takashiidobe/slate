# Thread Loc-carrying errors through preprocessor

_2026-09-12 14:01:38_

Step 2 of epic slate-parser-11p. PPFailure is now {loc: Option<Loc>, kind: PPErrorKind} (src/pp/error.rs), a thiserror enum with one variant per diagnostic, replacing {line, message}. Preprocessor stores each file's source by FileId and renders to PPError once at parse_file/parse_str via render_error, so errors inside included headers render against the header's own source instead of being stringified into the includer (the 'DEBUG nested' eprintln is gone). Include resolution returns Option, and missing headers, include cycles and unreadable files are errors located at the #include directive instead of panics; an unreadable main file is an unlocated error (PPError.span is now Option<SourceSpan>). Unterminated conditionals point at the opening #if. parse_conditional folds excluded branches into an accumulator, removing two expects. Directive errors still span the whole physical line until the token-based directive tree lands. Kept: expect on builtin predefines (compiled-in constant, not user input). New error fixtures: missing-include.c, include-cycle.c (+ include-cycle.h); malformed-conditionals.c expectation now underlines the whole directive line.
