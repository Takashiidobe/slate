Outcome: complex arithmetic, vector compares and atomic RMW / compare-exchange no longer bind lowerer temps (`__t`) for literals, plain variables, or values read once; leftover `let __t` in slate fixture output went 1831 -> 1401.

Before (C `atomic_fetch_add(&a, 2)`):
    let __t1 = 2i32;
    let __t0 = AtomicI32::from_ptr(addr_of_mut!(a) as *mut i32).fetch_add(__t1, AcqRel);
    __t0
After:
    AtomicI32::from_ptr(addr_of_mut!(a) as *mut i32).fetch_add(2i32, AcqRel)

Before (C `5.0L + 6.0L * I`): five nested blocks of `let __tN = ...`. After:
    num_complex::Complex { re: L5 + L6 * __slate_f80_from_f32(0.0f32), im: L6 * __slate_f80_from_f32(1.0f32) }

Rules:
- complex.rs `bind`: returns the expression itself when `duplicable` (Var, literal, HexFloat, casts/fields/literal aggregates of those); flattens a nested block whose statements are all `__t` lets into the caller's list; binds each half of a `Complex { re, im }` literal separately. `part` folds `Complex { re, im }.re` to `re`. `parts_block` substitutes `__t` lets that are `pure` (duplicable, binary ops, `__slate_f80_*` shims) and read exactly once, and drops the block when no statements remain.
- vectors.rs compare: an operand that lowers to a plain Var calls `.to_array()` directly. The result let stays: its type annotation drives `from_array` inference.
- atomics.rs native RMW: the operand goes straight into the call when postfix (read once) or a literal; the old value goes straight into the result unless the combine is `Operand` (exchange returning the operand). C leaves the place and value of a compound assignment unsequenced, so evaluating the receiver first is allowed.
- atomics.rs compare-exchange: the result goes straight into the match / is_ok / unwrap_or_else. Expected and desired go straight into the call except in write-back form, where `*expected` must be read after desired is evaluated and expected is read twice (non-literal values stay bound).
- fetch_update path: postfix returns `to_c(previous)` without a let.

Measurement: a temporary `#[track_caller]` on `next_temp` encoded file and line into the temp index; leftover lets counted per call site over crates/slate/tests/fixtures/**. Not kept.

Fixture: 28 slate fixtures regenerated (x86_header_expanded_builtins, flag_complex_arithmetic_*, atomic_*, gnu_*atomic*, msvc/interlocked_volatile, float16_excess_precision, ...). slate profile (incl. gcc-torture, gcc.dg) and merge pass.

Limits: remaining temps are not read-once temps; follow-ups slate-8ge7.9.3 (aggregate builders, 332), .9.4 (complex constants, vector masks, ~313), .9.5 (asm scratch, 193), .9.6 (long tail triage).
