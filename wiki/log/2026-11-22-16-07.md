# slate-8ge7.24.19.1 string_views: strlen/strcmp/strspn on constant-string locals lift to &str/&CStr methods instead of folding; atoi helper moves to slate_support

_2026-11-22 16:07:57_

- bead: slate-8ge7.24.19.1
- kind: rewrite
- area: crates/slate-analysis/src/constant_strings.rs
- area: crates/slate/src/frontend/lowerer/string_views.rs
- area: crates/slate/vendor/slate-support

Outcome: constant-string locals are declared as `&str`/`&CStr` and libc string calls on them lift to Rust methods (`s.len()`, `a == b`, `starts_with`), replacing the slate-8ge7.24.12 constant folding; the atoi prelude and strspn/strcspn helpers now live in slate_support.

Before (slate-8ge7.24.12 folded results and lost the variable):

```rust
let alpha: *const i8 = c"alpha".as_ptr();
total += (0i32 == 0) as i32;
((7u64 as i32) > 4) as i32
(2u64 as i32) + (4u64 as i32)
```

After, same C (`strcmp(alpha, "alpha") == 0`, `strlen(s)`, `strspn(s, " ")`):

```rust
let alpha: &str = "alpha";
total += (alpha == "alpha") as i32;
(((s.len() as u64) as i32) > 4) as i32
((slate_support::__slate_strspn(s, " ") as u64) as i32)
```

Implementation:
- `constant_strings::ConstantString { bytes, readers, only_read_as_string }`. Readers come from an IR walk (`walk_function_body_with_macros`) over calls to `Known::string_arguments` functions outside macro expansions whose other string arguments also have views (literal, constant-string local, `c_string` param). Interior-NUL locals settle by fixpoint. An initializer with a macro wrap gets no fact, so kept macros (`TYPE_NAME!()`) stay.
- `frontend/lowerer/string_views.rs`: `string_local` picks `&str` (only read as a string, UTF-8, ato* content parses) or `&CStr` (a non-ato* reader, no interior NUL); a local with no lifted reader stays a raw pointer. `lower_string_call` replaces `fold_known_call`; `string_comparison` fuses `strcmp/strncmp(..) <op> 0` in `ValueKind::Compare` lowering.
- `&CStr` locals read outside a lifted call lower to `s.as_ptr()` (the `c_string` path); `c_string` params get the same peepholes (`word == c"if"`, `start.count_bytes()`).
- `slate_support/src/strings.rs` (core-only, ungated): `unsafe fn __slate_atoi/atol/atoll(*const c_char)` and `__slate_strspn/strcspn(impl AsRef<[u8]>, impl AsRef<[u8]>)`. `backend/engine/prelude.rs` no longer injects per-file helpers; `main.rs` vendors strings.rs.

Fixtures: libc_call_nested.c, libc_constant_string_escape.c regenerated as the record; 10 others regenerated for the support-crate atoi and `count_bytes()` forms.

Limits: unclean ato* literals (`"42abc"`) call the helper with `c"...".as_ptr()`; strings reaching a call through a copy into another local count as a pointer use; mem* on views and owned buffers are stages 2-4 of slate-8ge7.24.19.

See: slate-8ge7.24.19, slate-8ge7.24.12, slate-yar4.60 (slate_support std feature), wiki/concepts/slate-analysis.md#string-views-and-libc-calls.
