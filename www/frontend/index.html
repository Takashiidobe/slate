Slate: A C23 to Rust translator

GitHub - Documentation

Targets

C

Rust

Some translated programs need extra dependencies:

  • aligned: most generated programs use the vendored aligned crate.
  • bitfields: bitfield programs use the vendored bitfields crate.
  • bitint: extended-width integer programs use the vendored bitint crate.
  • complex: complex-number programs use the vendored num-complex crate.
  • long double, fenv, and complex long double: these use the generated C shims; complex long double needs both the shim and the complex crate.
