# Model bare weakref and weakref with alias per flavor

_2026-09-29 15:19:10_

slate-parser-cxg.50: bare weakref was an invalid attribute.

- AST: WeakRef(Option<String>); bare weakref parses to WeakRef(None).
- symbol_attributes: weakref plus alias("t") in one declaration becomes weakref="t" with no alias (defines nothing). weakref("t") beats alias("s") (clang; gcc uses s, documented).
- gcc split form (bare weakref on one redeclaration, alias on another, either order): Lowerer.bare_weakrefs records the entity; resolve_object_requests (weak_reference) moves the merged alias into weakref and clears the global's definition flag. A bare weakref with no target, or weakref on a function body / initialized object, is dropped, as gcc ignores it.
- Checker::weakref: clang rejects a bare weakref without an alias in the same declaration, and weakref on any definition; gcc rejects weakref with a target on an initialized object.

Fixtures: clang weakref_alias_attribute.c, gcc weakref_redeclarations.c, error clang weakref_target_required.c (4 configs), error gcc weakref_initialized_target.c; gcc-dg attr-weakref-1/3/4.c. All checked against clang and gcc output.
Docs: ir/declarations weakref rules, ast-grammar WeakRef(opt<string>).
