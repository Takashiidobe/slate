# Unprototyped functions: K&R identifier lists and call lowering

_2026-09-25 22:13:31_

slate-parser-dyd.44. K&R definitions are now ParameterList::IdentifierList in the AST with declared parameter types; parser-side promotion and ParameterDeclarationKind::declared_specifiers are gone (TypeSpecifier promotion missed typedefs like `typedef char C; f(a) C a;`).

Sema follows clang: a K&R declarator resolves to an unprototyped function type carrying the default-promoted params (clang's DeclRef type `int ()` with the definition's params). Each promoted parameter is an ABI slot of the promoted type, named like the source parameter; the body binds the name to a local of the declared type converted from the slot (clang's trunc/fptrunc prologue), so sizeof(a) and &a see char. gcc-torture 20020318-1.c now takes &c as ptr<i8>.

Calls to an unprototyped callee convert the first N args to known definition params (reason=arg) and default-promote the rest; count mismatch is accepted (clang warns, gcc silent). compatible_functions applies C11 6.7.6.3p15 to identifier-list types; the composite of two unprototyped types keeps known params.

New Warning::DeprecatedNonPrototype (clang flavor only) at clang's three sites: K&R definition, passing arguments to a callee with no prototype and no known params (callee named only for direct calls), and an empty-parens declaration followed by one with params. clang's unnamed too-few/too-many-arguments warning is not modeled.
