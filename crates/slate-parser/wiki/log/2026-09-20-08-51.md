# Type the generated Clang builtin registry

_2026-09-20 08:51:12_

Implemented slate-parser-dyd.1 by making the builtin registry typed instead
of stringly.

tools/generate_clang_builtins.py now parses each Builtins.td `Prototype`
spelling (a C-ish declarator grammar: qualifier suffixes, pointers,
references, `_Constant`, `_ExtVector<n, T>`, `...`) into a typed Rust
literal. It emits 368 deduplicated `static PROTOTYPE_nnnn: BuiltinPrototype`
values, plus `BuiltinAttribute` and `BuiltinLanguage` enum variants in place
of the old attribute/language strings. A prototype spelling the parser
cannot handle now fails generation rather than silently reaching sema. Two
builtins (pthread_create, umask) have no prototype in Builtins.td, so the
field is `Option<&'static BuiltinPrototype>`.

src/sema/builtins.rs holds the model (`BuiltinType` reusing sema's `IntRank`,
`FloatKind` and `Qualifiers`) and `TypeResolver::builtin_signature`, which
lowers a prototype to a `QualType` function type against the target.
Named types resolve to canonical target types, never to a TU typedef.
It declines for `CustomTypeChecking` builtins, for variadic prototypes with
no named parameters, and for leaves with no C type in our model (`FILE`,
`jmp_buf`, ObjC `id`, HLSL resources, C++ references, ext-vectors).

`Lowerer::function_like_builtin` dropped its hand-written record match
(Abort/MemCmp/MemCpy/MemMove/MemSet) and derives every non-overflow builtin
signature from the model. The three-way atomic/va/constant_p guard that was
duplicated in names.rs and expression.rs collapsed into
`expression::specially_lowered`.

Corpus IR sweep: 2195/2674 -> 2324/2674 accepted, 0 regressions. Remaining
builtin failures are all CustomTypeChecking (slate-parser-dyd.19).
Validated with cargo clippy, cargo fmt, cargo nextest run --release, and a
byte-identical regeneration of clang_builtins.rs.
