# Expression typer answers variably modified operands; typeof and __auto_type evaluate them for real

_2026-09-28 18:56:24_

slate-parser-cc94.4.5. Measured with a temporary SLATE_TYPER_LOG append at the three speculative callers: 33 unanswered typeof/sizeof operands before, 0 after.

Typer: TypeResolver::provisional_extents (set by the typer's type_name and statement-local declarator_type) makes derive give an unbound non-constant size Extent::Variable(None) instead of failing. typed() never memoizes a type with an unbound extent (CTypes::has_unbound_extent), so lowering's post-lowering cross-check re-types and sees the exact vla<T, %id>.

Lowering evaluates VM operands instead of speculating:
- sizeof: the next_id-moved test is replaced by has_effects(value) (effects.rs, the hoister's predicate; a Capture of a new extent counts). sizeof(m[i++]) on a VLA row now evaluates i++, as C and clang do.
- typeof(expr) of VM type: Lowerer::typeof_evaluations lowers it where extents are captured (capture_extents for declarations/parameters, once per declaration; type_name_extents for casts/compound literals/sizeof), kept as a synthetic temporary only when it has effects, so typeof(g) of a VM pointer inside g's initializer (gcc-dg vla-9) reads nothing. typeof(type-name) now captures its VLA bounds too (typeof(int[n++]) x).
- __auto_type/auto: reserve_extents allocates BindingIds for the initializer's non-constant sizes (VariableSizes visitor, skipping prototype parameters) before typing; extents() binds into the reserved id.

Bugs fixed: typeof(++i, (int (*)[i])a) q never incremented i and left q's extent binding dangling (reused by the next function); vla-16 f1's body was dropped; vla-16's compound literal object shared its id with its extent; the old __auto_type output was only right because the rolled-back speculative lowering happened to re-allocate the same ids. stdatomic-vm only renumbers.

Accepted: typeof of a VM expression at file scope is now vla<T, *> instead of rejected (permissive; clang and gcc reject).

Fixture: clang/linux/x86_64/variably_modified_operands.c (clang and gcc accept). Wiki: entity-model.md, ir-spec.md.
