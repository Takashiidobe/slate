# Add CompilerFlavor setting (slate-parser-25m.1)

_2026-09-13 14:08:34_

First step of the structured inline asm epic (slate-parser-25m).

- CompilerFlavor {Gcc, Clang, Msvc} in src/compiler_args.rs, default Clang (most fixtures are clang-oracle based). FromStr accepts gcc/clang/msvc.
- CompilerArgs.flavor parsed from --flavor=<name> or --flavor <name>. The flag exists only so the binary-driven fixture harness can select a flavor; inferring it from compile_commands.json is deferred.
- Parser::with_flavor / Parser::flavor; main.rs threads CompilerArgs.flavor through.
- Fixture header '// SLATE-FILECHECK-FLAVOR <name>' (absent = clang) is read by tests/filecheck.rs (normal, error, and clang-oracle paths) and tools/update_filecheck.py, which pass --flavor to the binary.
- New fixtures: compiler-flavor-unknown.c (error: unknown flavor, proves the header reaches the binary) and compiler-flavor-gcc.c.

Nothing consumes the flavor yet; asm gating (slate-parser-25m.5) is the first user.
Verification: clippy clean; cargo nextest r --release fails only the 2 pre-existing fixtures (20031031-2.c, 200031109-1.c).
