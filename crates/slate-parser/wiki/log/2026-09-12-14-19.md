# Accept #pragma, #line, #warning, #ident; implement #pragma once

_2026-09-12 14:19:05_

slate-parser-11p.7. DirectiveName gains Warning, Pragma, Line, LineMarker (a directive whose name token is an integer, i.e. GNU '# 7 "file" 1' linemarkers from preprocessed output) and Ident (#ident/#sccs). The walker accepts #line, linemarkers, #warning and #ident without effect: diagnostics use real source offsets and there is no warning channel yet; #line is not validated because its operands may be macro-expanded. #pragma once records the header's canonicalized path with the active Condition in Preprocessor.pragma_once; resolve_and_parse_include skips a header when a recorded condition equals the current active condition or is statically true (same visibility rule as macro lookup), so a header first included under A is still parsed when re-included under an unrelated B. Paths are canonicalized only for this key so include_next's parent-dir comparison is unaffected. All other pragmas are dropped. Verified with pp-pragma-line.c (+ pragma-once.h): one once_t typedef per section, versus two per section in a scratch control without the pragma. Follow-ups filed: push_macro/pop_macro (11p.10), C23 #elifdef/#elifndef (11p.11).
