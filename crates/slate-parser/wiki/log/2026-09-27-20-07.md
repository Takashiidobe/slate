# MSVC asm jumps across C labels

_2026-09-27 20:07:28_

MSVC name resolution now binds asm labels in the function label namespace and lets C goto target their position inside an asm block. Jumps from asm to C labels become asm-goto label operands. Clang flavor retains its separate asm label namespace and rejects both cross-boundary jumps. Added generated fixtures for both directions and refreshed affected MSVC asm expectations. MSVC accepted the source fixture; clang rejected both forms. Clippy, fmt, and all 4,346 release nextest tests passed.
