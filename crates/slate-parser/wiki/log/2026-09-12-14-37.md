# Support C23 #elifdef / #elifndef

_2026-09-12 14:37:36_

syntax.rs classifies elifdef/elifndef as DirectiveName::Elifdef/Elifndef.
They terminate a group like #elif (so nesting stays correct in dead groups)
and are rejected after #else; PPErrorKind::ElifAfterElse now carries the
directive spelling ('#elifdef after #else').

walk_conditional computes each branch's test first (Defined(X),
Not(Defined(X)), an evaluated #if/#elif expression, or none for #else) and
then folds it against the excluded prior conditions, so elifdef/elifndef
become And(Not(prior), Defined(X)) / And(Not(prior), Not(Defined(X))).
directive_spelling(name) supplies the directive name for diagnostics.

Fixtures: pp-elifdef.c (DEFAULT, FIRST, SECOND, THIRD; also a dead nested
#elifdef), elifdef-after-else.c. Results match clang -std=c23 -E.
