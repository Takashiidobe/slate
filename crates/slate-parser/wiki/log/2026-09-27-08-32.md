# Arm32 asm options fixture

_2026-09-27 08:32:12_

Follow-up to slate-parser-25m.16. Added sema/armv7-unknown-linux-gnueabihf/ir_asm_options.c
covering flags preserved without "cc", dropped with it, readonly memory input, basic asm.
Clang (armv7, thumbv7, thumbv6m) adds no implicit CC clobber. Gcc's thumb1_md_asm_adjust
clobbers CC on every Thumb-1 asm, but our Arm32 triples are armv7 (ARM or Thumb-2), so
that rule cannot apply. No ARM gcc cross compiler is installed to confirm gcc ARM mode.
