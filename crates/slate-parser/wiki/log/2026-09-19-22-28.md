# generated Clang builtin registry and IR lowering

_2026-09-19 22:28:45_

Implemented slate-parser-dyd.1. Added a generator that runs clang-tblgen --dump-json over Clang Builtins.td, expands template spellings and builtin-prefixed library aliases, and emits a checked-in Rust registry with prototypes, attributes, language/header metadata, and Clang record identity. Name resolution now leaves recognized implicit builtin callees outside the ordinary binding namespace while preserving source declarations as precedence. Function-like abort/memory builtins lower as builtin callees without fabricated declarations. Generic add/sub/mul overflow builtins lower to explicit overflow operations that store through the result place and return the overflow flag. Added generated FileCheck coverage and updated the IR spec and grammar. Representative GCC fixtures progress past builtin resolution to their existing later blockers. Validated with cargo clippy --allow-dirty --fix, cargo fmt, and cargo nextest run --release.
