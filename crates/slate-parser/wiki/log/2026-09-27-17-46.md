# Reachability roots emitted definitions from any file

_2026-09-27 17:46:38_

slate-parser-d2w. Include-only fixtures (sema/ir_control_compact.c, gcc tests like pr71626-2.c that #include another .c) lowered to a module with only target data: filter_translation_unit (src/reachability.rs) rooted only main-file and -include decls, so external definitions coming from an included file were pruned even though clang emits them.

Fix: defines_external_symbol adds roots from any file for what clang emits: non-static, non-inline function definitions; file-scope object declarations with no storage class (tentative definitions included, function declarators excluded); extern objects with an initializer. Static, inline, typedef, tag and plain extern declarations in headers stay pruned unless used.

Checked against clang -emit-llvm for ir_control_compact.c, include-cycle-guarded.c and the new tests/fixtures/reachable_from_include.c (+ .h), which pins both kept and pruned forms. Regenerated 13 fixtures (additions only). ir-spec.md Validation and declaration pruning now lists the current roots.

Gap left for slate-parser-3e4d: emitted inline definitions (C99 extern inline, gnu89 inline) from included files are still pruned.
