# Atomic builtins: sync, lock-free, float fetch, dynamic weak

_2026-09-19 14:18:17_

slate-parser-lh7.2.23, all five parts.

1. c_macro metadata: when an atomic builtin's identifier came from a macro, the innermost MacroOrigin link's name is recorded next to c_builtin (atomic_fetch_add_explicit, even through a user macro wrapping it). Kept c_builtin as-is instead of replacing it so neither name is lost.
2. __sync_*: fetch/op_and_fetch -> update seq_cst; bool/val_compare_and_swap -> compare_exchange with a new form field (write_back | success | old; the __sync forms take expected by value, no write-back). lock_test_and_set is acquire (gcc's documented contract; clang emits seq_cst), lock_release a release write of 0, synchronize a seq_cst fence, swap seq_cst. min/max force signed and umin/umax unsigned compares via reinterpret (verified: clang emits atomicrmw min on unsigned). Pointer operands offset in bytes (gcc lock addq $8; clang rejects int operands).
3. Lock-free queries follow clang's ExprConstant: power-of-two size <= TargetInfo::max_atomic_inline_bytes (new: 16 on AArch64 and x86-64+cx16, else 8) and size 1 / null ptr / pointee aligned >= size. Otherwise always_lock_free is false and the others call libatomic __atomic_is_lock_free, declared on first use. Every fold checked against clang 22.
4. Floating fetch add/sub use the ambient floating semantics. Floating min/max left unsupported (fmin is NaN-ignoring; compare+select is not): filed.
5. CompareExchange.weak is now Weakness { Strong, Weak, Dynamic(value) }, hoisted like MemoryOrder::Dynamic.

Printer: compare_exchange gains form=; existing fixtures regenerated. Noticed but untouched: c_builtin metadata prints twice on hoisted atomic temporaries (pre-existing).
