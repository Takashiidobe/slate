# Reachability follows function bodies

_2026-09-13 18:19:09_

filter_translation_unit (src/reachability.rs) now walks function bodies, parameters, initializers, enumerator values, array sizes, typeof expressions, and type names embedded in expressions (casts, sizeof, compound literals, va_arg, _Generic). Enumerator names map to their enum decl. Roots are still every decl in the main file.

Effect: header declarations used from user code (e.g. printf from libc-shim stdio.h, plus the types they use) now appear in the AST; unused header decls are still pruned.

New fixture tests/fixtures/reachable_from_body.c; existing fixtures regenerated (only additions of newly kept decls plus decl renumbering). Updated wiki/concepts/ast-enum-touchpoints.md: mark_stmt/mark_expr/mark_const_expr are new exhaustive match sites. Closes slate-parser-yp6.
