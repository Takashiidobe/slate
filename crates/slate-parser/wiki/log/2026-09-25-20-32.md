# Resolve __auto_type and C23 auto in sema through the typeof path

_2026-09-25 20:32:01_

slate-parser-dyd.38. Decisions from the user: reuse the typeof path; no IR mark
that a type was inferred; include clang's `auto *p` pattern form.

- AST: the stringly `TargetBuiltin("__auto_type")` became `TypeSpecifier::Inferred`.
  The parser now also recognizes `const __auto_type`, C23 `auto *p` /
  `auto (*fp)(...)`, and `static auto` (auto beside another storage class).
- `Lowerer::declaration`: `infer_type` checks the constraints, then types the
  initializer with `speculative_type` (the typeof machinery; one real lowering,
  so `index++` still runs once). It hands the base type to TypeResolver through a
  one-shot `inferred` slot that `base()` takes. Layout, entities, globals and
  initializer conversion are unchanged. The static-assert checker uses the same
  slot through `assertion_operand_type`.
- Deduction = lvalue conversion; per flavor, clang keeps `_Atomic`, gcc drops it.
  `pattern_base` unifies the declarator with the value type: pointer, function
  return, array element. `check_inferred` requires an exact match, except for
  added pointee qualifiers. Multiple declarators must agree once specifier
  qualifiers are removed.
- gcc: a single, plain-identifier declarator. The own-initializer check walks
  the initializer against the name bindings. A bit-field is Invalid, or
  Unsupported for gcc C23 auto, whose deduced `unsigned char:3` slate can't
  represent.

Correction: my first probe run silently didn't run the compilers (a fish loop), so
the atomic and bit-field claims I gave in the design discussion were wrong;
re-measured with bash. Writing the fixtures exposed slate-parser-97e (pointer
qualifier levels), fixed and committed separately first.

Every config was checked against clang 22 / gcc 16. Fixtures:
sema/c23_auto_inference.c (clang; 8 error configs) and
sema/gcc_auto_inference.c; the gnu_auto_type, statement_expr_auto_type,
c23_auto_nullptr_bool and c23_language repros now lower. Gap: nullptr is typed
`void *`, not nullptr_t (permissive; see ir-spec).
