# Give TypeResolver a scoped ordinary namespace

_2026-09-17 16:53:27_

The static-assertion pass used to model C scoping by cloning the whole
`TypeResolver` at every block, function, for-init and statement
expression, and by calling `hide_name`/`hide_tag` to punch shadowed names
out of the clone. That was a second scoping implementation living next to
`sema::names`, and it deep-cloned every type definition per scope.

`TypeResolver` now owns the scoping instead. The three string maps
(`aliases`, `constants`, `objects`) collapse into one ordinary-namespace
stack, `Vec<HashMap<String, Ordinary>>`, matching C's single namespace for
typedefs, enum constants and objects; `tag_names` becomes a stack too.
Lookups walk innermost-out, `declare` writes into the innermost frame, and
`push_scope`/`pop_scope` replace clone-and-restore. `Ordinary::Declared`
preserves the old hide-then-insert ordering: a name whose type fails to
resolve still shadows an outer binding.

Dropping `hide_tag` means `define_tag` reuses an entry only from the
innermost frame, so an inner `struct S { ... }` gets its own id while a
same-scope redefinition still completes the forward declaration.
`TypeResolver` no longer derives `Clone`; nothing clones it.

`static_assert_validation.c` gains tag and enum-constant scope-exit cases
plus a SHADOW_TAG error config where an inner tag shadows an outer one.
Closes slate-parser-ojy. The pass still runs twice per translation unit
(slate-parser-okr).
