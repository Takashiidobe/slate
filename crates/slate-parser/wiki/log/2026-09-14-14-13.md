# TypeSpecifier, TypeName and ParameterDeclaration replace CType

_2026-09-14 14:13:07_

Completes slate-parser-lh7.3.5 (step 2); also closes lh7.3.14 and ixa.11.

- CType is now TypeSpecifier with no Qualified/Pointer/Array/Function variants; derived types exist only in Declarator, qualifiers only in DeclarationSpecifiers and Pointer layers.
- TypeName {specifiers, declarator} replaces every ty: Box<CType> + declarator pair (casts, sizeof, _Alignof, offsetof, va_arg, compound literals, _Generic, __builtin_types_compatible_p), plus _Atomic(T), typeof(T) and aligned(T).
- Parameter {ty, declared_ty, declarator: Option} is ParameterDeclaration {specifiers, declarator, declared_specifiers, attributes}; an unnamed parameter uses Declarator::Abstract.
- DeclaratorParser owns parse_specifiers / parse_specifier_keywords / parse_type_name; decl.rs wraps them to map DeclaratorError into ParseError.
- apply_abstract_declarator is deleted (it mis-derived pointers over grouped declarators, lh7.3.14).
- K&R default argument promotion only applies to non-derived declarators; 'char *p' used to be promoted to int.
- signature_node_span no longer forgets a K&R identifier list when a later parameter declaration has parentheses ('float (*f)(void);').
- const_expr no longer folds sizeof(type-name); layout belongs in IR sema.
- filecheck declaration summaries spell types from specifiers + declarator.
- New fixtures: qualifier_single_encoding.c, knr_derived_parameters.c; all fixtures regenerated.
- wiki: ast-spec Migration rows for CType/TypeName removed; new rows for parameter provenance and TypeSpecifier variant naming. ast-enum-touchpoints lists TypeSpecifier touchpoints.
