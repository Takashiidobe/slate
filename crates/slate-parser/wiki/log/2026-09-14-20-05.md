# Lower numeric subtraction to IR

_2026-09-14 20:05:02_

sema::numeric now lowers same-concrete-type `-` like `+`: `BinaryOp::Sub` resolves to a new `ValueKind::Sub` printed as `sub<ty, ...>(l, r)`.

- Renamed `AddSemantics` to `ArithSema` since add and sub share the overflow/floating metadata; the IR printer shares one `format_arithmetic` helper.
- `ResolveError::Conversion` now carries the operator, and its message changed from "addition requires conversions..." to "arithmetic requires conversions...: l op r".
- Fixtures: sub cases added to sema/numeric_seed.c for i32/u32/i64/f16/f32/f64/f80/f128; a mixed-type `f32 - f64` error case added to sema/unsupported.c.
- wiki/concepts/ir-spec.md updated to describe subtraction.
