# Report #error/#warning per configuration from the driver

_2026-09-12 14:29:34_

The preprocessor no longer fails parsing on #error/#warning. Each directive is
recorded as a DirectiveDiagnostic { severity, condition, loc, error } on
Preprocessor, handed to Parser (directive_diagnostics / predefined_macros).

main builds an Env from the builtin predefines plus -D names, filters the
diagnostics by condition.eval(&env), dedupes by (file, offset), prints
warnings, and fails with a single report or DirectiveErrors for several.
sema::analyze now takes &Env instead of defines.

The Slate target defaults (**SLATE_ARCH_X86_64, **SLATE_KERNEL_LINUX,
**SLATE_LIBC_GLIBC, **SLATE_GLIBC_MINOR\_\_=43, ...) are seeded from
src/predefines/slate_target_defaults.h alongside the clang predefines, so
libc-shim's features.h target checks pass. This shifts user FileIds by one
in every fixture.

The filecheck harness passes configuration defines to error fixtures and
seeds its oracle Env with the predefines; update_filecheck.py mirrors this
and keeps warning lines. New fixtures: pp-directive-diagnostics.c,
pp-directive-forbid.c.
