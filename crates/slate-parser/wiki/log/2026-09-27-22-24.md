# GNU asm operands keep header names reachable

_2026-09-27 22:24:54_

Fixes slate-parser-hvnz, found while following up slate-parser-4opf.

Reachability treated GNU asm statements as leaves, so header globals,
typedefs and enumerators used only in an asm operand were pruned and
sema failed with 'unresolved ordinary name' or 'unresolved typedef
name'. clang accepts all of these. The new mark_gnu_asm in
src/reachability.rs walks the output and input operand expressions and
is used for both StmtKind::Asm and DeclKind::Asm. Clobbers and goto
labels name no C declarations. MS __asm was already marked.

Fixture: tests/fixtures/sema/asm_operand_header_names.c with header
tests/fixtures/asm_operand_header_names.h.

Filed slate-parser-xbm1: gcc 15+ accepts file-scope extended asm with
operands; slate-parser rejects it in the parser.
