# Drop the i386-unknown-linux-gnu target; i686 is the only 32-bit x86 Linux triple

_2026-09-28 13:04:36_

Rust has no i386-unknown-linux-gnu (its 32-bit x86 Linux triples are i586/i686), and nobody targets it, so it's gone from the target registry. The two triples shared one profile, and the fixture outputs differed only in the triple string.

- target_registry.rs: removed the spec. i386_linux_gnu(multiarch) became the I686_LINUX_GNU_PROFILE const. Predefine consts, names and slate_gnu_namespace_*.h files renamed i386 -> i686.
- The i686 profile's multiarch is now i386-linux-gnu (it was i686-linux-gnu). Debian/Ubuntu keep that directory name for i686, and clang --target=i686-unknown-linux-gnu --sysroot=X searches X/usr/include/i386-linux-gnu, never i686-linux-gnu. Only the removed triple had the right value.
- Fixtures: moved 5 i386-only clang fixtures to clang/linux/i686 (regenerated; only the triple changed). Deleted the i386 layout.c and the 3 target_registry.c copies, which duplicated the i686 ones.
- Wiki: fixture-layout example, ir-spec wording (i686, not i386).

i386 deliberately stays where it names the architecture, not a triple: the __i386__ / i386 predefines (gcc and clang emit them for i686), GCC's config/i386, Debian's multiarch dir, and llvm_lit_sweep's mapping of lit's i386 triples to i686.
