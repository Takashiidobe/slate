# pp: pull-based TokenSource and on-demand conditionals

_2026-09-30 08:12:12_

slate-parser-ryfo.2.

- Lexer::tokenize_lines replaces the with_newlines mode: newlines are no longer tokens, and each token carries at_line_start (true for the first token after a newline, comments included).
- syntax.rs: LogicalLine, logical_lines, merge_open_lines, GroupParser and the Item/Branch/IfSection tree are gone. TokenSource reads from the flagged stream. next_line returns a directive line (first non-comment token is #) or a text line. next_directive skips text, for skipped groups.
- mod.rs: walk_group and walk_conditional are replaced by process, which keeps a conditional stack and evaluates #if/#elif when the stream reaches them. It also has skip_group (directives only; tracks nesting, #else ordering and unterminated conditionals) and run_directive.
- The paren-depth line merge moves into TokenSource::next_line as a stopgap until ryfo.3 expands from the stream. Expansion itself is unchanged.

Deviations from the bead text:
- Includes still recurse per file instead of pushing a frame. An invocation cannot cross a file boundary, so nothing needs a shared stack yet.
- The pushback buffer arrives with ryfo.3, its first user.
- Structural errors (stray #endif, unterminated #if) now surface where the stream reaches them, so an earlier #if evaluation error takes precedence. Before, the whole file was grouped up front.

Validation:
- nextest --release: 7460 passed.
- tools/pp_diff.py --corpus: report byte-identical to the ryfo.1 baseline.
- sqlite3.c: pp output identical to the old binary, and parse --show-comments identical on sqlite3.c, deflate.c and cJSON.c.
- ir on sqlite3.c: 2.17s vs 2.30s.
- Conditional error cases (#else after #else inside a skipped group, #elif after #else, unterminated, stray #endif, a comment before #) match clang.
