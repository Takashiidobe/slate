# Capture implicit MS asm integer returns

_2026-09-27 19:46:45_

Implemented slate-parser-25m.6.5 for 32-bit x86 integer and pointer returns up to 8 bytes.
Every MS asm captures eax and, for wider results, edx into shared synthetic u32 locals.
Written return registers become early outputs and leave the clobber list; unwritten registers are late outputs.
Fallthrough::Return evaluates the captured value only when control reaches the function end.
Two-register results use unsigned widening, a 32-bit shift, and OR before return conversion.
Narrow integers truncate; bool keeps the low bit; enums and pointers preserve their return representation.
C99 main initializes its capture to zero; noreturn keeps ub fallthrough and naked functions add no captures.
Float, aggregate, wider integer, and x86_64 return capture remain excluded.
Updated the IR spec, printed grammar, and MS asm design notes.
Added generated fixtures for both flavors and x86_64 exclusion; regenerated affected MS asm fixtures.
Compared the fixture with clang 22.1.8 -target i686-pc-windows-msvc -fms-extensions -S -emit-llvm.
Int64ShllMod32, Int64ShraMod32, and Int64ShrlMod32 all match the EDX:EAX return of clang’s i64 =&A output.
Validation: cargo clippy --allow-dirty --fix; cargo fmt; cargo nextest run --release --no-fail-fast.
All 4343 tests passed.
