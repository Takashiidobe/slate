# Unify Expr and ConstExpr into one spanned Expr

_2026-09-13 20:11:25_

slate-parser-lh7.3.6, fixes lh7.1.16.

- ast::Expr is now Box<Span<ExprKind>>; ConstExpr, the Expr::Const wrapper,
  and the unused Expr variants (IntLit, Unary, Binary, SizeOf) are gone.
  Every expression node carries the span of its tokens.
- ExprKind follows ast-spec: Paren kept, Unary gains AddrOf/Deref/PreInc/PreDec,
  Postfix, Member { arrow }, Conditional { then_value: Option } replaces
  Ternary/Elvis, Comma { left, right }, SizeOfExpr, LabelAddress, VaArg { list }.
- Nested ({ }) is parsed: const_expr::Parser and DeclaratorParser carry
  statements: Option<&parser::Parser> and call parse_statement_expression_body.
  None for #if, attribute arguments and \_BitInt widths (error there).
- Removed the whole-statement and whole-initializer ({ }) special cases and the
  single-string-literal fast paths; the general expression parser covers them.
  The now-unused code: &str parameters on the declaration parsers went with them.
- sema: walk_const_expr/const_output_lvalue merged into walk_expr/output_lvalue;
  BodyNode::Tokens removed (labels inside ({ }) are real Labeled stmts now).
- reachability: mark_const_expr merged into mark_expr.
- #if evaluation unchanged: evaluate_with_defined parses to Expr and folds it.
- Still evaluated in the parser (lh7.3.8): enum values, array bounds that fold,
  designator indices. Type names are still CType + Declarator (lh7.3.5).
- Debug dumps do not print locations (Span Debug is transparent, as for all nodes).
- New fixture tests/fixtures/expressions.c; all fixtures regenerated, no
  diagnostic line changed. Wiki: touchpoints rewritten for ExprKind; spec
  migration row now tracks TypeName/AlignOfExpr.
