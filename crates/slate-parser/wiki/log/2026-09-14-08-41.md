# Coalesce CommentGroup into a single merged Comment

_2026-09-14 08:41:54_

CommentGroup previously held comments: Vec<Comment>, one entry per physical // or /\* \*/ comment (each with its own text, kind: Line|Block, loc). Changed to hold a single comment: Comment field instead.

New shape: CommentGroup { comment: Comment, provenance }, Comment { text: Vec<String>, loc: Loc }. loc spans from the start of the first comment in the group to the end of the last, covering any blank lines between them (comment_group() in src/parser/mod.rs now tracks min/max offsets instead of assuming monotonically increasing offsets — an earlier version that just subtracted offsets hit a subtract-with-overflow panic on gcc-torture fixtures where comment node expansions weren't strictly increasing). text keeps each original comment's raw text as a separate Vec entry rather than joining into one String with embedded \n, since a single joined String renders illegibly in FileCheck output (Debug escapes real newlines as literal \n). CommentKind (Line vs Block) was dropped since a merged block can mix styles and per-comment kind stopped being meaningful.

All fixtures regenerated via tools/update_filecheck.py --in-place; wiki/concepts/ast-spec.md's Comments section updated to match.
