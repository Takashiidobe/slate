# File root-cause epics for sema whack-a-mole

_2026-09-19 15:20:52_

Analysis of open tickets: most sema/lowering bugs trace to four structural gaps, not the AST shape.
1. No C type in sema: ir::Type is a layout type (char/schar -> i8, int/long collide on LLP64, qualifiers scattered); C type exists only as CTypeMetadata strings; type identity rules are approximated from layout (differ_only_in_sign, same_layout_ignoring_sign) and Lowerer::convert falls through to accept. Epic slate-parser-9ve.
2. No declared-entity record: alignment/atomic/const/tag identity implemented per declaration site, so each missing site becomes a ticket. Epic slate-parser-8lv (depends on 9ve).
3. IR nodes reuse AST NodeIds and metadata is keyed by NodeId, causing duplicate metadata. Epic slate-parser-xf9.
4. No shared exhaustive AST visitor; validate.rs checks skip contexts. Epic slate-parser-pin.
Final step, depends on all four: every fixture (incl. gcc-torture/gcc-dg, ~2660) renders AST + IR under FileCheck, plus a one-shot clang -fsyntax-only accept/reject diff over the corpus; gaps filed by root cause. Epic slate-parser-dyd.
Existing tickets linked as related to the epic that covers them.
