# Use Slate target sysroots for fixtures

_2026-09-24 17:27:32_

Fixture preprocessing and compiler invocation now use versioned compiler headers and the target-specific Slate sysroot instead of libc-shim and host Clang headers. Updated generated FileCheck output for the changed headers, made stdbit coverage conditional on sysroot availability, and lexed _FloatN typedef names as identifiers while gating _Float16 on language features. GCC signed aliases are accepted for glibc headers. Verified with clippy, fmt, Python syntax compilation, diff check, and release nextest.
