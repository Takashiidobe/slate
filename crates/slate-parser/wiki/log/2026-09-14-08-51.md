# Preserve comment groups inside enum bodies

_2026-09-14 08:51:35_

TagBody::Enum was Vec<Enumerator>, discarding all comments; enum-body comments were dropped at two different points depending on how the body was reached. In parser/decl.rs's multi-line tag-definition path, nodes_tokens() filters to PPNodeKind::Code nodes only, so standalone-comment PPNodes never reached the enumerator parser. In the same-line/inline (typeof-in-declarator) paths, comments survive as literal Token::Comment entries inside an already-flattened token stream and were explicitly filtered out (decl.rs's old parse_enumerators).

Added ast::EnumItem { Comment(CommentGroup) | Enumerator(Enumerator) } and SpannedEnumItem = Span<EnumItem>, matching the MemberItem/FieldItem pattern already used for struct/union bodies. TagBody::Enum now holds Vec<SpannedEnumItem>.

parser/decl.rs gained parse_enum_items(&[PPNode]), mirroring parse_field_items: walks nodes directly, turns runs of PPNodeKind::Comment into a CommentGroup via the existing comment_group() helper, and hands each run of Code nodes between comment groups to parse_enumerators (which now wraps each parsed Enumerator in EnumItem::Enumerator and returns Vec<SpannedEnumItem>, still filtering same-line Token::Comment tokens rather than grouping them — same level of support struct bodies have in their same-line path). The multi-line call site (parse_tag_definition) switched to parse_enum_items; the same-line call site keeps calling parse_enumerators directly on flattened body tokens.

declarator.rs::parse_enumerator_list (used for enum defined inline in a type-name, e.g. sizeof(enum{...}) or typeof) also updated to return Vec<SpannedEnumItem>, wrapping each Enumerator — that token stream never carries Token::Comment so no grouping logic was needed there.

reachability.rs's two TagBody::Enum matches updated: symbol collection now matches EnumItem::Enumerator specifically, and mark_type's enumerator-value walk filters through EnumItem::Enumerator before reading .value.

Regenerated all FileCheck fixtures (tools/update_filecheck.py --in-place, no args = full tests/fixtures tree, ~2400 files). Removed the now-resolved 'enum bodies drop comments' row from wiki/concepts/ast-spec.md's migration table.
