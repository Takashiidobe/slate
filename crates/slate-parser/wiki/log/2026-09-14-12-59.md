# Gate C23 auto inference and nullptr/true/false

_2026-09-14 12:59:38_

slate-parser-ixa.7: 'auto x = 1.0;' was parsed as TargetBuiltin("__auto_type")
with storage=Auto in every mode, conflating C23 type inference with the
pre-C23 storage-class keyword. nullptr/true/false were always plain
Identifiers, never literals.

- src/parser/decl.rs: parse_declaration_specifiers now only treats bare
  `auto <declarator>` as inference (TargetBuiltin("__auto_type"), storage
  cleared to None) when self.standard().is_c23_or_later(); pre-C23, `auto`
  stays a pure storage class and the type falls through to
  parse_base_type() as before (matching clang: a bare `auto z = 1.0;`
  under c17 is a parse error, since `z` gets consumed as a bogus type
  name). __auto_type (GNU) is untouched by standard mode.
- src/ast.rs: added ExprKind::BoolLiteral(bool) and ExprKind::NullPtrLiteral.
  const_expr::Parser::parse_primary produces them for the identifiers
  "true"/"false"/"nullptr" only when self.standard().is_c23_or_later()
  (added a standard() helper reading the threaded parser::Parser via
  `statements`, defaulting to LanguageStandard::default() when None).
- Touchpoint updates per wiki/concepts/ast-enum-touchpoints.md: evaluate_expr
  (BoolLiteral folds to 0/1; NullPtrLiteral is NotConstant), sema.rs's
  is_integer_constant_expression and walk_expr, reachability.rs's mark_expr.
- New fixture c23_auto_nullptr_bool.c (C17/C23 prefixes): C17 shows
  storage: Auto + explicit int type (via `#if __STDC_VERSION__ >= 202311L`
  branching to keep both prefixes parsing successfully) and nullptr/true/
  false as Identifier; C23 shows inferred TargetBuiltin with no storage
  and BoolLiteral/NullPtrLiteral.
- Regenerated 41 pre-existing fixtures that used nullptr/true/false
  (previously silently misrendered as bare identifiers); every diff was
  audited to be a clean Identifier -> BoolLiteral/NullPtrLiteral swap.
- cargo clippy --all-targets and cargo nextest run both clean; a
  whole-repo `update_filecheck.py` diff-only pass confirms nothing else
  needs regenerating.
