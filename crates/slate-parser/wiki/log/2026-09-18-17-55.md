# Lower string-literal array initializers

_2026-09-18 17:55:55_

Partial slate-parser-lh7.2.8. Lowerer::string_array_initializer (sema/expression.rs) handles 'T a[] = ".."' and 'T a[N] = ".."' at file and block scope: element must be an integer of the literal's width (any signedness for plain/u8, same signedness for u/U/L), length inferred when incomplete, units zero-padded or truncated to N, binding type completed. Emits ValueKind::CodeUnits on the declared array type; no new IR node. Incompatible element (int a[] = "ab") is Unsupported. Fixture sema/string_array_initializer.c. Braced/designated/compound-literal initializers still hit Unsupported("aggregate initializer").
