# Resolve malloc deallocators into function semantics

_2026-09-29 15:25:10_

slate-parser-cxg.51: malloc(f[, n]) was an invalid attribute.

- AST: Malloc { deallocator: Option<Expr>, argument: Option<Expr> }; the deallocator is an identifier Expr (resolved reference, per the name-argument rule), the index an expression.
- Names: Resolver::implicit_builtin (extracted from call handling) also binds a deallocator naming an undeclared builtin; visitor and reachability walk both expressions, so fclose from stdio.h survives pruning.
- IR: FunctionSemantics.deallocators: Vec<Deallocator { function: BindingId, argument: u32 }> (0-based), printed [deallocator=%f, argument=i], one per distinct pair across declarations, only when the function returns a pointer. An undeclared builtin gets its builtin_declaration.
- Rules (function::deallocator_argument, shared): non-function rejected (both); out-of-range index or non-pointer parameter rejected under clang, dropped under gcc. clang ignores the attribute but validates it; kept for Slate either way.
- Docs: attributes.md name-argument rule and malloc notes, ir/declarations function semantics, ir-grammar, ast-grammar, open-design.
