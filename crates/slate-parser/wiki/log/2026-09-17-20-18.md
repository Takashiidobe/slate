# Lower function decay and indirect calls

_2026-09-17 20:18:38_

slate-parser-kaw. sema/expression.rs read() rejected any Place whose type was Function ('function value or indirect call'), and Call lowering required the callee to be an Identifier bound directly to a function type, so calls through function pointers failed as 'non-function callee'.

ir::ValueKind gained FunctionDecay { place }, mirroring ArrayDecay: read() on a Function-typed place yields ptr<fn(..)>. ir::ValueKind::Call's `function: BindingId` became `callee: Callee`, where Callee is Direct(BindingId) or Indirect(Box<Value>). Keeping the direct form rather than routing everything through a callee value means zero churn in existing IR fixtures and preserves the spec's property that direct calls are explicit through binding IDs, which matters for emitting a Rust path call rather than a fn-pointer invocation.

Call lowering now goes through Lowerer::callee, which lowers the callee as an ordinary value, requires its type to be ptr<fn(..)>, and recovers Direct only when the value is a FunctionDecay of a Binding place. Everything else is Indirect, so struct fields, pointer tables, conditional callees, higher-order arguments, and call-returning-callee all work from one path.

read() also implements C's rule that *f on a function designator is that same designator: a Deref place of Function type unwraps to the pointer value it derefed. That makes (*fp)(x) lower identically to fp(x) and keeps (*f)(x) a direct call, so the IR has one spelling per call shape instead of an arbitrary chain of decay/deref wrappers.

Hoister::value lowers an indirect callee through self.value so side effects in the callee expression sequence correctly: ops[i++](i, i) hoists i++ and the callee reads the old value while the arguments read the new one. effects() treats FunctionDecay like ArrayDecay.

Unrelated observation while testing: an unprototyped indirect call int (*f)() needs -std=c17; under the default c23 it is a zero-parameter prototype and f(1,2) is correctly rejected.
