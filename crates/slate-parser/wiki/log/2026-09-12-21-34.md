# Preserve source context in parser diagnostics

_2026-09-12 21:34:48_

Statement and declaration diagnostics now use token expansion locations instead of reconstructed text when available. error_at_tokens skips synthetic or unreadable spans, walks backward to the nearest valid source token, clamps labels to source bounds, and uses a safe main-file fallback. split-5.c now identifies bits/x86_64/signal.h:66:25 instead of emitting a miette OutOfBounds label. Multi-declarator typedef support remains tracked as wf8.2.15.
