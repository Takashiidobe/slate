# MSVC asm design moved to wiki

_2026-09-27 18:31:59_

slate-parser-25m.6. Rewrote todo/msvc-asm-design.md as wiki/concepts/msvc-asm.md, dropping the typed
instruction IR and MASM PROC sketches already rejected by 25m.18.

Oracle findings (clang 22.1.8 i686-pc-windows-msvc, tools/cl.exe x86 /FAs):
- C names are memory operands (clang *m / =*m); arr[4] is a byte offset; s.b is a field offset;
  TYPE/LENGTH/SIZE fold from C types; MASM radix and C hex both accepted.
- Falling off the end after MS asm returns EAX / EDX:EAX; winnt.h Int64ShllMod32 relies on it.
- clang does not mark MS asm alignstack (the earlier 25m.6 comment was wrong); nostack=false
  still holds because blocks push/pop and clang clobbers ~{esp}.
- ; comments hide }; consecutive single-line __asm merge into one asm in clang.
- MSVC: __asm/_asm on x86 only (C4235 on x64). clang: __asm/_asm/asm { on every windows-msvc
  triple including x86_64. MSVC allows jumps between C and asm labels; clang rejects both.

Children 25m.6.1-.6 filed (parse, name resolution, lowering, effects table, implicit return,
C/asm label jumps). g097 now depends on 25m.6.5 instead of 25m.6.
