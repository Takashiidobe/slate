# Preprocessor oracle: slate-parser pp and tools/pp_diff.py

_2026-09-29 21:35:23_

slate-parser-ryfo.1. New `pp` command (Parser::preprocess_file + pp::write_preprocessed in src/pp/print.rs): one line per Code node, pragmas as #pragma, comments dropped, keywords printed with their source spelling, and a space inserted where adjacent tokens would relex as one (## results, _Pragma operands).

tools/pp_diff.py diffs it token by token against clang -E -P over ~/c-corpus compile_commands (--corpus), a compdb, or single files, and writes target/pp-diff.md. Clang runs with -nostdinc over slate's compiler headers and sysroot, and both sides get -std=gnu17 when the command has none. Pragmas clang consumes are skipped.

Baseline (same/diff/slate-error/clang-rejects): sqlite 102/0/0/0, chibicc, giflib, lz4, zlib 18, pcre2 33, utf8proc and yyjson all same. musl 1322/2, curl 250/4/105, libuv 5/239, lua 13/20, redis 136/80/0/81, mbedtls 169/37/0/161, libexpat 12/9, tinycc 6/6, cJSON 22/1, libyaml 19/3, quickjs 12/3, zstd 38/3.

First-difference clusters:
- 341: glibc signal.h __attribute_deprecated_msg__ with '(' on the next line (ryfo.3).
- 105: __has_declspec_attribute (dyd.67).
- ~40: __LINE__ in multi-line invocations; clang uses the ')' line (ryfo.6).
- 6: mbedtls, defined(__COUNTER__) false (ryfo.7).
- 1: redis, ', ##__VA_ARGS__' comma not elided when the variadic arg is omitted (ryfo.8).
- 4: tinycc ELFW / s1->s1-> and musl si_pid, lost paint (ryfo repros 4/5, cxg.7.2).

Also filed 6x05.6: slate defaults every flavor to gnu23, while clang 22 defaults to gnu17. It accounted for 94 sqlite diffs before -std was pinned.
