# Evaluate #ifdef/defined() from macro state; controlling macros; declared configuration names

_2026-09-12 15:06:07_

Resolves slate-parser-2u9 and replaces concretize_guard.

#ifdef/#ifndef/#elifdef/#elifndef and defined() in #if now use
defined_condition(name): the configurations where the translation unit's own
entries define the macro (macro_cases, latest wins), plus Defined(name) for the
never-touched remainder only when name is a declared configuration name. Any
other untouched name is undefined in #ifdef and defined() alike. #if splits
its cases on each defined operand before evaluating.

Configuration names are declared up front: Parser::with_configuration_names /
Preprocessor::set_configuration_names. main passes its -D names plus
-fslate-config=NAME (configurable without being defined). The filecheck
harness and update_filecheck.py pass the union of every SLATE-FILECHECK-DEFINES
line so one parse serves all configurations. Without this, every
defined(\_\_SLATE_LIBC_DARWIN)-style test in libc-shim became configurable:
add.c went from 0.04s to 19.6s and failed on a Darwin-only macro.

Include guards: syntax::controlling_macro detects clang's multiple-include
shape (only comments outside one #ifndef G / #if !defined(G) section whose body
opens with #define G). walk_guarded treats G as file state, never -D: the
first include walks the body under the active condition, a re-include is
skipped wherever G is already defined (wrapped in Not(file-defined G) when
that is partial). concretize_guard and replace_subterm are removed.

Fixture changes: predefined-type-macros.c (untouched GUARD_H is now
Constant(1)), pp-push-pop-macro.c (FRESH is undefined file state after the
pop, so its branch is gone). New: pp-ifdef-file-state.c, pp-controlling-macro.c
(+ controlling-macro.h, partially-guarded.h). All match clang -E.
