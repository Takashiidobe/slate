# Drop polyvariant preprocessing for a single-configuration pipeline

_2026-09-12 15:40:51_

Resolves slate-parser-crw.1 (epic slate-parser-crw).

The front end now works like a normal compiler for one configuration:
- Preprocessor::define_all turns -D NAME[=VALUE] into real #defines in a
  '<command line>' file after the target predefines.
- #if/#ifdef/#elif pick the first true branch (later #elif are not
  evaluated). defined() and #ifdef consult one HashMap<String, MacroEntry>.
- #undef removes. push/pop_macro is a plain per-name stack.
  #pragma once is a path set.

Removed:
- pp/condition.rs (satisfiability, intersect/difference)
- eval.rs and Env
- Condition/Conditional<T>
- every Decl/Stmt/FieldItem/Initializer ::Conditional variant
- the Concrete* duplicate AST
- PPNodeKind::Conditional
- controlling-macro guard detection
- declared configuration names and -fslate-config
- DirectiveDiagnostic condition/loc
- the typedef-per-branch parser fork
- the conditional-initializer special case

Unreachable marking moved from eval into the parser (function bodies).
The renderer prints one decl list, and sema analyzes the AST directly.

Top-level declarations that span lines without an open paren (e.g.
'int x =' / '11;') now join lines up to ';' or '{', which the old
conditional-initializer path used to cover.

All fixtures regenerated. Spot checks against clang -E match for:
initializers, pp-ifdef-file-state, pp-controlling-macro, pp-push-pop-macro,
pp-push-pop-conditional, conditionals.

AGENTS.md goal and wiki/concepts/ast-enum-touchpoints.md were updated.
README is left to slate-parser-xoe.
