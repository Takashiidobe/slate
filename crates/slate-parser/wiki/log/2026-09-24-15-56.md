# Select libc headers from target sysroot

_2026-09-24 15:56:46_

Removed the parse CLI's default libc-shim include path. System header lookup now adds existing include roots from ../slate-sysroots/sysroots/<target>, selecting MSVC CRT and SDK directories when --flavor=msvc and conventional usr/include roots for other flavors. Explicit -isystem paths remain first.
