# Split slate-parser-cxg.2 into per-cause beads

_2026-09-29 15:06:10_

slate-parser-cxg.2 grouped five unrelated attribute gaps. Split into:
- cxg.48 _Alignas/aligned operand naming an enumerator (ICE check runs before name resolution)
- cxg.49 ifunc lowered as a SymbolAttributes string (resolver implementation left to Slate)
- cxg.50 weakref: bare, weakref + alias, across redeclarations, on definitions; applies to functions and variables
- cxg.51 malloc(deallocator[, index]) resolved to a function reference and kept as an IR attribute
- cxg.52 always_inline/noinline conflict per flavor, dedupe the check

Decision: attribute name arguments are resolved references when possible (cleanup, malloc deallocator); strings only when they name assembler symbols (alias, weakref, ifunc).

pr87793.c and pr47276.c already pass; migrated to suites/gcc-dg.
