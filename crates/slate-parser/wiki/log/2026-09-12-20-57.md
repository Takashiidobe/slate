# Builtin date/time macros

_2026-09-12 20:57:52_

Implemented __DATE__ and __TIME__ expansion using a translation-start timestamp, local calendar formatting, and a Gregorian fallback. Added a stable FileCheck regression that verifies both macros expand to string literals during #if evaluation. Validation: cargo fmt; cargo clippy --allow-dirty --fix --all-targets -- -D warnings (pre-existing parser warning); cargo test --lib; cargo nextest (pre-existing fixture failures).
