# Apply pointers before array/function nodes in derive

_2026-09-18 18:09:02_

Fixed slate-parser-8e7. The parser nests base-type pointers inside the Array/Function declarator node (int *(*q)[4] is Array{Pointer{Grouped(Pointer{q})}}), so derive() wrapped the array first and the pointer last. TypeResolver now peels the pointer chain under an Array/Function node (apply_pointers), applies it to the element/return type, then wraps the array or function, then derives the grouped core. Also removes the separate grouped/non-grouped branches. Function pointers with pointer returns (int *(*f)(void), char *(*fp[2])(int)) used to fail with 'missing prototype'; they now resolve. Fixture sema/pointer_grouped_declarators.c.
