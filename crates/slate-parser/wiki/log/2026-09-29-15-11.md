# Resolve names in layout attribute operands

_2026-09-29 15:11:50_

slate-parser-cxg.48: _Alignas(E) with an enumerator failed 'layout attribute requires an integer constant expression'.

Causes and fixes:
- validate.rs::check_attributes checked aligned/vector_size/_Alignas operands syntactically before name resolution, rejecting every identifier (and offsetof, _Generic, __builtin_types_compatible_p). Removed; operands are folded where consumed.
- names.rs did not walk attributes on tags, field specifiers, or field declarators, so enumerators there had no reference. Now walked.
- names.rs never resolved _Alignas(type) operands (default visitor skips named types): _Alignas(T) with any typedef was 'internal error: unknown typedef'. New Resolver::attributes resolves them with the attribute's span.
- The checker swallowed requested_alignment / define_alias errors (.ok(), let _), so a non-constant operand on a global or typedef surfaced as an internal lowering error. Now reported as rejections.
