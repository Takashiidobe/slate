# IR design: flat IR, macro provenance, Rust-oriented casts

_2026-09-13 18:35:04_

Revised wiki/concepts/ir-design.md per user decisions: sema lowers AST directly to a flat CIR-shaped IR (no typed AST/side tables); Slate backwards compat not required. Macro constants keep both value and name via an OriginId -> Expansion side table (macro name, definition header, parent chain), enabling limits.h -> Rust consts. Clang CastKind rejected: conversions split into single-meaning ops (int_widen, int_truncate, int_reinterpret, float_widen/narrow, int_to_float exact, float_to_int out_of_range) with width-then-sign ordering; arithmetic carries overflow=Wraps|Undefined|Impossible. C reasons (promotion etc.) moved to optional origin reason. Found gap: Span lacks macro identity and ConstExpr nodes carry no spans. Open: structured region ops vs flat blocks, function type parameters, text format, range-fact scope.
