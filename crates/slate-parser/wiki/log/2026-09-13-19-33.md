# Group consecutive comments into CommentGroup

_2026-09-13 19:33:00_

Replaced per-comment Decl::Comment / Stmt::Comment / FieldItem::Comment nodes with Comment(CommentGroup { comments: Vec<Comment { text, kind: Line|Block, loc }>, provenance }).

- Parser::comment_group (src/parser/mod.rs) takes a run of comment PPNodes, skipping blank Code nodes between them, and stops at code or a comment from another file. The group span covers the run.
- Used at the three production sites: top-level decls, struct fields, statement lists.
- Added Span::map.
- New fixture tests/fixtures/comment_groups.c covers line+block runs across a blank line, in fields, and in bodies. The Write hook strips comments, so it was written via a shell heredoc.
- Regenerated every fixture that renders comments.
- ast-spec: groups never span files. The migration row now tracks enum-body comments (lh7.3.11, filed).
