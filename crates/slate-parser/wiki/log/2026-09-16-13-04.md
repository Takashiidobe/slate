# Target record and enum layout in IR

_2026-09-16 13:04:22_

Resolved AST tag definitions into IR records and enums for the x86_64 SysV target. Records now carry field offsets, size, alignment, bit positions, and occupied bit-field byte units, with packed, aligned, and \_Alignas requests applied during placement. Enums retain evaluated values, underlying types, and independent storage alignment. Added a generated FileCheck fixture and a clang record-layout comparator; 14 named layouts match clang-22. The type view and module dump both emit tag definitions.
