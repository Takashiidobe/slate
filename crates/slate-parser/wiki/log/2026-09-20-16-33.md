# Atomic aggregate ABI classification

_2026-09-20 16:33:27_

Threaded C atomic qualifiers into ABI classification so clang keeps atomic records and complex aggregates in memory while gcc uses the unqualified ABI. Added clang/GCC and AArch64/i386 IR filecheck fixtures covering parameters, results, calls, scalars, unions, and complex values. Verified with cargo clippy --allow-dirty --fix --release --all-targets -- -D warnings, cargo fmt, and cargo nextest run --release.
