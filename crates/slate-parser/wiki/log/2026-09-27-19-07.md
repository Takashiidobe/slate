# Lower MSVC __asm to InlineAsm

_2026-09-27 19:07:22_

slate-parser-25m.6.3.

- IR: AsmOperandKind::Memory { place, access: AsmAccess } for each C object
  the asm addresses, one operand per object. AsmPiece::Address { operand,
  displacement, base, index, size } marks each reference into it, and
  AsmPiece::LocalLabel(name) marks asm labels. Prints as mem<readwrite>,
  addr<dword>(%1 + 4), label(done). Operands without a constraint print
  none, and empty [options=] is omitted.
- sema/ms_asm.rs: builds InlineAsm (volatile, intel, memory Any, no
  nostack; options None in naked functions). Functions become Symbol
  operands, offset x becomes In(AddressOf x), register-only memory stays
  text with decimal numbers, and _emit becomes .byte. PTR size is explicit,
  or inferred from the innermost element type when there is no register
  operand (or for movzx/movsx, shifts/rotates, shld/shrd). That matches the
  dword/qword ptr clang inserts on the example file. The header template is
  the statement rebuilt from the AST.
- access is ReadWrite and clobbers are empty until 25m.6.4. The implicit
  EDX:EAX return is 25m.6.5 (winnt.h functions still fall through as
  ub_if_used).
- windows.h now lowers on i686 in both flavors.
- Fixtures: ms_asm_parse/names now check IR, plus new ms_asm_example.c
  (todo/msvc-asm-example.c) and ms_asm_winnt_pattern.c.
- Wiki: ir-spec.md, ir-grammar.md, msvc-asm.md.
