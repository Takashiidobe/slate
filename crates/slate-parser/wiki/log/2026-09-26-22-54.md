# Resolve asm constraint letters to operand classes

_2026-09-26 22:54:07_

ir::AsmConstraintLocation::Letters now carries classes: Vec<AsmOperandClass> beside the raw letters, resolved per target in sema/asm.rs.
AsmOperandClass = Register(AsmRegisterClass) | Explicit(AsmRegister) | Memory | Immediate | Unresolved(letters). Register classes use Rust names (reg, reg_abcd, xmm_reg, zmm_reg, kreg, x87_reg, mmx_reg, vreg, vreg_low16, sreg, dreg).
Checked against gcc/clang: q is reg_abcd on i386 but any reg on x86-64 (clang/gcc picked %sil); R is legacy-8 on x86-64 (picked %ebp), so unresolved there and reg on i386.
Multi-letter: x86 Y/W/j/B two chars, AArch64 U three, Arm U two. ?, !, *, ^, $ skipped; # ends the alternative. Space is not skipped (both compilers reject it).
x is xmm_reg regardless of width; ymm/zmm upgrade noted on slate-parser-25m.14.
Printer: operand lines gain a [..] list, one entry per alternative. 56 existing fixtures regenerated; the diff is only that column.
New fixtures: sema/ir_asm_classes.c plus i386, aarch64, armv7 gnueabihf variants.
