# C type layer: interner, renderer, layout (9ve.1)

_2026-09-19 16:13:46_

Added src/sema/ctype/ (CTypeKind, QualType, CTypes interner with canonical
forms stored at intern time, a TypePrinter-style renderer, and layout()).
TypeResolver::resolve/base/derive/define_alias/define_tag now build QualTypes;
ir::Type comes only from layout(). CTypeMetadata is rendered, not assembled:
the string-surgery helpers (strip_qualifiers, pointer_spelling,
top_pointer_star, skip_qualifier_words, qualifier_spelling, merge_qualifiers,
numeric_spelling, c_type, vector/tag_spelling, ResolvedType) are deleted.
field_c became record_fields: Vec<QualType>; enum_underlying records each
enum's underlying C type. __builtin_types_compatible_p compares canonical
unqualified C types (keeping _Atomic) plus enum/underlying compatibility.
type_of.rs reconstructs typeof operands over QualType (pointee, element,
function_parts, unqualified, lvalue_conversion); reverse_layout is a
temporary lossy ir->C map for untyped fallbacks until 9ve.2.

Reviewed fixture diffs (all deliberate):
- ir_atomic_stdatomic: function c_canon now shows desugared params
  int(enum memory_order, int *).
- ir_typeof_qualifiers: c_canon for test prints adjusted params
  int(int, const volatile int *, int (*)(int)).
- ir_implicit_calls_c23: C23 int empty() renders int(void).

Wiki: new concepts/c-type-layer.md; ir-spec metadata paragraph updated.
