# Keep enum fixed underlying type

_2026-09-14 14:30:54_

Fixes slate-parser-ixa.12.

- TagBody::Enum(Vec<SpannedEnumItem>) is now Enum { fixed_type: Option<TypeName>, enumerators }, matching ast-spec; fixed_type is hidden from Debug when None.
- Accepted in every -std: clang and gcc both accept 'enum E : T' before C23 and only error under -pedantic-errors (clang: -Wc23-extensions), so there is no standard gating.
- Top-level tag definitions parse the header between the name and '{' as a TypeName; anonymous 'enum : long {' no longer fails with 'expected tag name or {', and 'enum E : T' with '{' on the next line is recognized as a definition.
- DeclaratorParser::parse_enum_type keeps the parsed type instead of discarding it, and still backtracks so enum bit-fields ('enum small : 2;') parse as before.
- sema checks the fixed type for unknown typedef names; reachability marks it.
- Opaque 'enum E : int;' (no body) still drops the fixed type: TagSpecifier::Reference has nowhere to hold it (follow-up bead).
- New fixture enum_fixed_underlying_type.c; c23_language.c and gcc-dg/c23-tag-alias-3.c now show fixed_type; other enum fixtures only change shape.
