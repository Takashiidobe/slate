# Delete speculative lowering fallback

_2026-09-28 18:59:33_

slate-parser-cc94.4.3. Unevaluated operands are typed only by the expression typer now; nothing lowers an expression to learn its type and rolls it back.

- speculative_type -> Lowerer::operand_type, a plain TypeResolver::typed lookup; the old place-then-expr operand_type is gone.
- Lowerer::unevaluated (_Generic controlling expression) asks only the typer.
- unevaluated_type takes the typer's answer; a VLA-typed operand is lowered once (place when typed.lvalue, else expr) and kept when has_effects, with no rollback.
- Deleted Lowerer::discard_after and Entities::discard_after (next_id, globals, functions and builtin_declarations truncation).
- A typer Unimplemented is now a real error for sizeof/typeof/_Generic/__auto_type/classify operands.
- No fixture churn; gate 7275/7275.
- Wiki: entity-model.md, ir-spec.md and ast-enum-touchpoints.md no longer describe the fallback.
