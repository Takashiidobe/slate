# Lower braced initializers to ValueKind::Aggregate

_2026-09-18 18:06:04_

slate-parser-lh7.2.8, braced side. New sema/initializer.rs builds a tree of Builder/Entry per initializer list: positional cursor with C brace elision (shared Cursor, pending pre-evaluated value so nothing is lowered twice), designators (.f, [i], [a ... b], chained and through anonymous members, merged into one nested builder), union selected member, empty {} and {"str"} for char arrays. Output is ValueKind::Aggregate{members: sorted (AggregateTarget, Value), zero_fill}; effects.rs recurses members. Declared incomplete arrays take the inferred length. string_array_initializer moved into initializer.rs and now returns None for non-integer elements so char *names[] = {..} elides correctly. Also fixed a pre-existing TypeResolver bug: multi-dimensional arrays had reversed dimensions (char g[2][3] was array<array<i8,2>,3>) and pointer elements/grouped declarators were wrong; the Array arm now walks the whole suffix chain. Remaining gaps: compound literals, flexible-array members, elision after a designator, sizeof of brace-inferred arrays in static_assert (assertion.rs), and 'int *(*q)[4]' (outer pointer + grouped declarator, pre-existing). Fixtures: sema/braced_initializers.c, sema/multidimensional_array_declarators.c.
