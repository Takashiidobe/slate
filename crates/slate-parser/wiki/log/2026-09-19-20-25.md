# Entity table for ordinary identifiers

_2026-09-19 20:25:12_

Phase 1 of slate-parser-8lv. Pure refactor; regenerating all 2671 fixtures produced zero diff.

Three maps held an object's properties independently: TypeResolver.bindings
(type in scope), TypeResolver.declared (type merged across redeclarations,
added in 9ve.4) and Lowerer.object_requests (alignment and common). They are
now one table, src/sema/entity.rs, keyed by BindingId.

bindings and declared turned out to be one slot, not two. declare_global reads
bindings back as its 'declared' argument after array completion has already
overwritten it, so the declared map only ever received the value the entity
would hold anyway. The second slot existed because declare_global runs after
the declaration site has overwritten the first; since the write site and
declare_global sit in the same function on all three paths, the previous type
travels in a local instead.

merge_redeclaration therefore takes previous: Option<QualType> rather than
reading a map. That makes the ordering invariant found the hard way in 9ve.4 --
register above the 'already declared?' early return, or the first declaration
never registers -- structural rather than a rule to remember: there is no
registration step left to misplace.

Linkage, storage duration, definition state and symbol attributes stay on
ir::Global. Moving them here would copy rather than consolidate them until
ir::Global is derived from the entity, which is 8lv.5.
