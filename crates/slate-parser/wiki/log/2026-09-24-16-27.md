# Support Android Bionic and FreeBSD sysroots

_2026-09-24 16:27:32_

Added target information and Clang predefines profiles for aarch64/x86_64 Android and FreeBSD using the available sysroots. Added FileCheck fixtures for both architectures: Android includes Bionic sys/cdefs.h and verifies __BIONIC__ plus API level 21; FreeBSD includes sys/param.h and sys/capsicum.h and checks __FreeBSD_version and CAP_READ. Android fixtures add Clang's resource include directory because the NDK sysroots omit compiler-provided standard headers. cargo clippy, cargo fmt --check, and cargo nextest run --release pass.
