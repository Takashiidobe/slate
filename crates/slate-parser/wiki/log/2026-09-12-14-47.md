# Resolve conditional macro definitions and push/pop by reachability

_2026-09-12 14:47:58_

Use sites resolved a macro only from an entry whose condition equalled the
active one (or was always true), so '#define X 1 / #ifdef A #undef X
#define X 2 #endif / int a[X];' gave 1 under -DA (clang: 2). pop_macro also
required the push and pop conditions to be identical.

condition.rs gains is_satisfiable (truth table over Defined names, capped at
16), intersect/difference (collapse to one side when it lies within the other,
so case conditions stay minimal) and implies.

expand.rs macro_cases partitions the active condition by which recorded entry
is in effect (latest wins, remainder = never defined), cases in source order.
divergent_macro_conditions refines across every macro on the line using
definition_cases, which merges cases with identical definitions so a
re-recorded definition does not split lines; visible_entry returns the entry
when all cases agree. is_defined is true if any case defines the macro.

push_macro saves the macro's cases plus the condition it is on the stack
under. pop_macro walks pushes newest first: each push matches wherever it and
the unmatched part of the pop are jointly reachable, is consumed only there,
and its saved state is re-recorded under that joint condition (like an
#undef/#define at the pop). Pops with no reachable push are ignored.

Fixtures: pp-conditional-redefine.c (DEFAULT/A/B/AB), pp-push-pop-conditional.c
(push outside/pop in #ifdef A; push in #ifdef A/pop in #ifndef A; partial
pushes). All array sizes match clang -E.
