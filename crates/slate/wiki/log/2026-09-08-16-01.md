# classify object macro value strategies

_2026-09-08 16:01:45_

Added per-header classification for public object-like macros with usable compile-time type/value strategies. For every candidate, the configured oracle compiler builds a source containing typeof and equality assertions against its -dD replacement tokens; passing candidates are retained. The generated shim-only combined probe repeats those assertions without inspecting shim macro definitions, so it checks presence, type, and semantic value. glibc fcntl.h classifies 209 macro values and the resulting shim probe reports missing symbols such as AT_EXECVE_CHECK and FALLOC_FL_COLLAPSE_RANGE. Function-like and non-constant object macros remain explicitly outside this strategy.
