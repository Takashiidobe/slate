# Propagate global pointer mutability into escaping parameters

_2026-08-31 15:03:53_

Implemented slate-hos2.9. pointer_lattice.rs's classify pass treated
`global_ptr = param;` as a plain local alias rename (try_alias), so a
parameter only stored into a global (never dereferenced within the storing
function) kept unique/no-write facts and got lifted to `&T` even when the
global's own declared type is `*mut T`. Added collect_global_ptr_mutability()
(walks Item::Static for Type::Ptr{mutable}) threaded into ClassifyCtx; an
assignment into a known global pointer now marks the source binding ESCAPE
unconditionally and WRITE when the global is mutable, so resolved() correctly
falls into the escape-short-circuit RawMut row. tests/fixtures/
borrowck_hostile_aliasing.c (capture_global/global_alias_with_local) now
lowers/rewrites to *mut i32 end to end and compiles.

blocking a full rewrites-profile pass: alias_global, complex_record_fields,
goto_temp_cross_state (needs -O2 SLATE_CLANG_ARGS to regen correctly),

alternative alongside the existing `__retval = |let _v...` ones, since
