# cir.frem unreachable from C (slate-3i0x.15)

_2026-08-26 18:52:45_

cir.frem's only CIRGen producer is ScalarExprEmitter::emitRem's FP branch (CIRGenExprScalar.cpp:2096, builder.createFRem), reached when the '%' operator's operands are FP-or-vector-of-FP. But Sema rejects '%' on float operands in C entirely -- tried scalar double % double (constraint violation, as expected), and vector float '%' via both ext_vector_type and vector_size attributes (both rejected: 'invalid operands to binary expression'). __builtin_elementwise_fmod, which sounded like the obvious candidate, actually lowers to a *different* op, cir.fmod (already handled via lower_fmod), not cir.frem. No GNU or standard C construct reaches emitRem's FP path; it's likely only reachable from clang's other frontends (OpenCL C, CUDA) which Slate doesn't target. Todo fallback retained.
