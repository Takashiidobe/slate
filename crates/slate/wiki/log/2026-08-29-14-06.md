# Canonicalize cross-TU ABI-wrapper record names structurally

_2026-08-29 14:06:49_

slate-ft0v.1 (final child). XML_ExpatVersionInfo returns a by-value struct; Clang ABI-lowers it to a nameless coercion struct {u64,i32}. MLIR auto-aliases nameless structs as anon_struct/anon_struct1/... per-TU, numbered by appearance. misc_tests named the {u64,i32} wrapper anon_struct while xmlparse named it anon_struct1 (because {u64,u64} took anon_struct there). The by-name shared-type merge saw two names -> two nominal Rust types -> E0308 at the call site.

Fix: name nameless ABI-coercion structs structurally (anon*struct*<member sigs>, e.g. anon*struct_u64_i32) instead of by the per-TU MLIR alias key, so both TUs produce an identical name and the merge unifies them into one shared type. Added abi_coercion_canonical_name + canonical_alias_record_name (src/frontend/lowerer/types.rs); wired into the rust_type Named->Struct reference path, anon_local_records (definitions), and required_record_defs (cir_kinds). Widened is_abi_coercion_record_name to also match the new *<sig> suffix.

Fixture: tests/fixtures.multi/cross_tu_record_return (ver.c defines two by-value returns so the wrapper numbering diverges like libexpat; main.c calls one). Neutralized the now-stale anon_struct name assertions in 6 single-TU FileCheck fixtures by wildcarding the token (they only pin a generated name, irrelevant to codegen).

Result: libexpat generated crate 1 -> 0 errors; whole epic slate-ft0v now compiles. Translate ~5.8s (near 5.5s baseline). lowering 10 + rewrites 110 pass.
