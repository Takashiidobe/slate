# chibicc compiles end to end

_2026-08-09 00:00:00_

Got chibicc fully compiling through slate.

- **`e40291c1`**: `translate-project` grew `--target <triple>` (repeatable) instead of the old hardcoded x86_64/aarch64/riscv64 `target_variants()` list, driven through a new `cir::emit::target_config`/`target_cfg` that also emits `target_endian` alongside `target_arch`. Default behavior when no `--target` is passed reverted to compiling for the host toolchain only (previously it multiplied every project by all three baked-in targets, which was slow and not what most callers wanted).
- **`444358b2`**: added `--source-manifest <file>` to `translate-project --lib`, reading a newline-delimited file list (`collect_c_modules_from_manifest`) instead of always walking the whole project directory — lets a large multi-file project like chibicc be translated file-by-file while other files are still broken.
- **`fa104d2d`**: added `compile_commands.json` support so translate-project can pick up per-file include paths/defines instead of assuming a single flag set for the whole project.
- **`13351ce8`**: switched Clang-AST-JSON recursion in `c_ast.rs` onto `serde_stacker`, guarding against stack overflow when parsing deeply nested ASTs (chibicc's own parser produces deep expression trees); added `tests/fixtures/deep_ast.c` to lock it in.
- **`7f88f73e`**: taught `c_ast.rs`/`lower.rs` to recognize more Clang comment node shapes so translated doc comments survive more C source styles.
- **`94da5a10`**: fixed `codegen.rs` collapsing `use` imports and `mod` declarations onto adjacent lines instead of always separating them by a blank line.
- **`1f9b8de2`**: handled `stat` struct field access reached through macros (chibicc uses macro-wrapped `stat()` calls) — `c_ast.rs` and `lower.rs` both needed changes to keep the macro-expanded access resolvable back to the real struct fields.
- **`b2766b11`** / **`9efae4a9`** / **`93fc1959`**: three narrow C-semantics fixes hit by chibicc's own source: long double fields inside unions, decay of global (not just local) arrays to pointers, and anonymous enums nested in structs plus typedefs whose underlying type is "pointer to function returning T". Each landed with its own fixture (`tests/fixtures/long_double_union_representation.c`, `global_array_pointer_decay.c`, `anonymous_enum_record_field.c`, `function_typedef_pointer_return_struct.c`).

`translate-project` now defaults back to host-only toolchain, which also fixed accidental multi-target slowdown on every other multi-file test in the suite.
