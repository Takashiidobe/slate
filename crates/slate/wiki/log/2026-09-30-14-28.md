# chibicc lowering-barrier baseline

_2026-09-30 14:28:30_

slate-p58o.7.5. tools/corpus_barriers.py reads a compile_commands.json (default ~/c-corpus/chibicc), drops -c/-o/-g/-O/-M* (slate-parser rejects -g and -O), runs 'slate lowering-barriers' per TU in the entry's directory with the default clang flavor, and prints per-TU counts plus histograms of first barriers for defined functions, module-level barriers, declaration barriers, and TUs. Messages are normalized (global kind, type struct/enum/union via @typeN names, value/statement/place kind). Snapshot: wiki/concepts/chibicc-lowering-barriers.md (slate fd807d6ca008, slate-parser 9494cb503fdb with only tools/*.py dirty).

Report-mode changes in lowerer.rs: header declarations are reported separately from defined functions; @typeN in report messages gets '(struct Name)' appended; global barriers say extern / zero-initialized / initialized. Gotcha: Span<T> has its own id field, so definition.id on a Span<TypeDefinition> is the span id; use definition.value.id.

Baseline: all 9 TUs parse; 21/297 functions lower. Module: 49 zero-initialized, 31 initialized, 30 extern globals. Declarations: 75 type struct (FILE etc.).
