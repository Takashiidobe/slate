# Lower cir.vec.masked_load (slate-3i0x.12)

_2026-08-26 18:50:31_

cir.vec.masked_load is reachable from C via AVX-512VL's _mm_mask_loadu_epi32, gated with __attribute__((target("avx512f,avx512vl"))) on the probe function -- no global -march flag needed, matching the existing x86_simd_vector_intrinsics.c fixture convention. lower_vec_masked_load in intrinsics.rs materializes each lane as an if/else: mask lane (a bitint::BInt<1,*,*>) converted via bitint_to_int_expr and compared != 0 selects between an unsafe raw pointer read (addr cast to elem-ptr, .add(i), deref) and the pass_thru lane. Wired Op::VecMaskedLoad in dispatch.rs. Along the way found and fixed a real pre-existing bug (function_setup.rs): any function carrying both #[target_feature] and #[inline(always)] fails on current rustc (attrs can't combine); this already silently broke tests/fixtures/x86_simd_vector_intrinsics.c, which wasn't caught by the default lowering-profile filter since it lacks LOWERING-* FileCheck prefixes and only runs via explicit SLATE_DIFF_FIXTURE. Fix: skip inline(always) whenever target_feature_functions already has the function. Both the new vec_masked_load_ops.c fixture and the previously-broken x86_simd_vector_intrinsics.c now pass. Full lowering (10/10) and rewrites (118/118) profiles, fmt, clippy clean.
