# Create CIR op lowering sweep epic

_2026-08-26 16:31:31_

Created beads epic slate-3i0x with one child per C-relevant undispatched clang-ir-types operation. Each child requires a C fixture that proves the op reaches Slate before implementation. Reachable ops get typed lowering or an explicit semantic passthrough; ops that cannot be generated from C retain the todo fallback with the attempted configuration recorded. The cir.std.strlen child specifically requires exercising the CIR idiom recognizer. C++ exceptions, classes, constructors, destructors, and coroutines remain out of scope.
