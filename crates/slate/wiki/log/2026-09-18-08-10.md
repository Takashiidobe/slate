# Add libc feature rejection fixtures

_2026-09-18 08:10:00_

Added a compile-rejection fixture suite for hidden libc symbols and macros, with C89 strdup and strdupa examples across glibc and musl x86-64 shim configurations. The harness requires the expected diagnostic and exactly one compiler error, so unrelated failures cannot pass. Wired the suite into the libc nextest profile and documented how to add C89–C23 cases. The full libc profile passed (50/50), as did cargo fmt and cargo clippy.
