# \_Float16 support and FENV_ACCESS shim design

_2026-08-22 00:00:00_

Scoped \_Float16 to the only TS 18661-3 spelling Clang actually implements and mapped its lowering sites via the F128 template. Designed the FENV_ACCESS-constrained float op shim (C helper as compiler barrier, not soft-float) and confirmed via rustc probe that plain extern calls block LLVM reordering. See wiki/concepts/float16-and-fenv.md.
