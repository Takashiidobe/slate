# Add initial FreeBSD target and libc-shim profile

_2026-08-31 07:30:18_

Implemented slate-sfzn.10.2: FreeBSD kernel/libc selection in
src/frontend/toolchain.rs (Kernel::FreeBSD -> __SLATE_KERNEL_FREEBSD,
libc "freebsd" -> __SLATE_LIBC_FREEBSD, __SLATE_PLATFORM_FREEBSD,
target_os "freebsd", ELF fallback exclusion). Release baseline is a
separate input (SLATE_FREEBSD_RELEASE, default/only-supported "15.1",
diagnosed if anything else) since Rust's FreeBSD triples carry no release
info, mirroring the existing SLATE_ANDROID_API pattern. Clang target
becomes x86_64/aarch64-unknown-freebsd15.1, matching oracle.json, and
defines __SLATE_FREEBSD_VERSION__=1501000 (FreeBSD's own MMmmmXXX
__FreeBSD_version encoding).

libc-shim/bits/types.h and features.h gained a __SLATE_LIBC_FREEBSD
branch for fundamental types, sourced from the real 15.1-RELEASE sysroot
headers under target/freebsd-oracle/sysroots (not guessed). Notable
divergences from the generic LP64 branch: mode_t is uint16_t,
__blksize_t is int32_t even though off_t/blkcnt_t are 64-bit, wctrans_t
is a plain int not a pointer.

Added libc-shim/freebsd-basic-headers.txt (ISO C only, mirrors
macos-basic-headers.txt), a FreeBsd LibcVariant in
tests/support/libc_shim.rs, and a manifest-compile test in
tests/header_compilation.rs covering both x86_64 and aarch64 with
oracle-backed _Static_assert checks. Verified end-to-end via `slate
translate` on both FreeBSD targets and via rustup-installed
x86_64/aarch64-unknown-freebsd std. cargo fmt/clippy clean; libc and
lowering nextest profiles green (32/32).

Hit and fixed an unrelated missing #endif in bits/types.h from a
concurrent in-flight Darwin pthread-types refactor (broke compilation
for every libc variant, not just FreeBSD); self-resolved before a
targeted fix was needed. Documented the target-selection/release-baseline
contract in wiki/concepts/freebsd-libc-oracle.md.
