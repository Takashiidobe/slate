# Podman stdin forwarding fix

_2026-09-06 15:24:15_

Fixed slate-server's Podman job command by adding --interactive. Without it, Podman closed stdin before the container's translate-stdin wrapper read the request, so every API/demo request translated an empty C file and returned only the module scaffold. Verified live on g3 that the API response includes main's generated exit call; server tests and clippy pass.
