# Resolve asm-goto labels in statement expressions

_2026-08-30 16:23:23_

Slate now gets asm-goto label names and target source points directly from GCCAsmStmt through SlateMacroDump.so. This avoids parsing the macro invocation text, whose expansion range does not contain the asm body.

Nested asm-goto functions without cir.goto are flattened with --cir-flatten-cfg alone. Skipping --cir-goto-solver preserves cir.label operations so dispatch lowering can join each AST target point to the correct CIR state.

The differential fixture covers jump and fallthrough results from a macro-expanded statement expression. Repeated expansions with scoped duplicate labels still lose identity in CIR's goto solver; Slate now rejects that missing or ambiguous target instead of guessing and miscompiling.
