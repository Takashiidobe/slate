# Selective FileCheck generation from C regions

_2026-08-29 16:58:47_

tools/update_filecheck.py recognizes paired standalone @rewrite and @rewrite-not comments. It translates a temporary sibling C file where each pair becomes unique inline-assembly begin/end sentinels, then extracts only the enclosed generated Rust. @rewrite emits REWRITES-DAG lines from rewritten output. @rewrite-not compares the lowered and rewritten marker regions as multisets and emits REWRITES-NOT only for removed raw lines. Annotation mode omits full-output lowering blocks; unannotated fixtures retain the existing ordered full-output generator. Added filecheck_annotation_regions.c as an end-to-end positive/negative fixture and focused Python parser/extractor tests. Sentinels must stay reachable on the same structured path, so regions cannot end in return, break, continue, or goto. Validation: Python unittest, py_compile, idempotent regeneration, cargo fmt --check, cargo clippy --all-targets --all-features -- -D warnings, and the full release rewrites profile (110 passed).
