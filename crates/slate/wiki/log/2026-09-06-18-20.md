# Thread parsed Constraint enum through inline-asm lowering instead of raw strings

_2026-09-06 18:20:10_

Per review feedback: constraint strings from op.constraints were being
re-parsed (via ad hoc string checks and free functions taking &str) at
several separate points in intrinsics.rs::lower_extended_asm and
asm.rs::translate_asm_template. Parse once, thread the parsed value through.

- New pub(super) enum Constraint in asm.rs: Tied(usize) / FlagOutput(String) /
  Constant / Reg { kind: AsmRegConstraint, early_clobber: bool } / Unsupported.
  Constraint::parse(raw, is_output) is now the single parse site, called right
  where op.constraints.split(',') is collected. Methods: constant_only(),
  flag_condition(), reg_kind(), is_explicit_register(),
  has_out_of_band_placement(), wants_register_modifier(&[Constraint]).
- Renamed the old per-char classification enum Constraint -> ConstraintAtom
  (it's one letter of a constraint's alternative set, not a whole constraint).
- Deleted parse_output_reg_constraint, parse_input_reg_constraint,
  constraint_wants_register_modifier, constraint_is_explicit_register,
  constraint_is_constant_only's public surface -- folded into Constraint::parse
  and its methods.
- intrinsics.rs: dropped input_specs (Vec<Option<AsmRegConstraint>>) and
  flag_outputs (Vec<Option<&str>>) entirely -- both were caches working around
  the same string re-parsing; now every site reads straight from the one
  Vec<Constraint>. translate_asm_template's signature changed from
  constraints: &[&str] to &[Constraint].

Regression caught during the port: gnu_asm_flag_outputs. The old
constraint_is_explicit_register("={@cce}") accidentally returned true via its
naive starts_with('{') shortcut (true after stripping '=', regardless of what
followed), which coincidentally suppressed the "unreferenced operand" debug
comment for x86 flag-output slots in translate_asm_template's second pass.
Constraint::is_explicit_register() no longer has that accidental match, so
added Constraint::has_out_of_band_placement() (explicit register OR
flag-output) and used it for that skip condition specifically, rather than
folding flag-output into is_explicit_register's real meaning.

All 11 asm fixtures (9 pre-existing + gnu_asm_constant_letters +
gnu_asm_alternative_constraints) pass on both lowering and rewrites profiles.
cargo build/fmt/clippy clean.
