# Implement six clang-ir-types lowerings for slate-3i0x

_2026-08-26 18:28:19_

Lowered cir.clear_cache (slate-3i0x.1) to the existing clear_cache LLVM intrinsic call path. Lowered cir.clear_padding (slate-3i0x.2) to per-byte masked stores derived from the op's typed OffsetPair ranges, covering both tail struct padding and bitfield padding. Lowered cir.frexp (slate-3i0x.3) via an extern shim (frexp/frexpf selected by result type) writing the exponent through an out-pointer. Lowered cir.cosh/cir.sinh/cir.tanh (slate-3i0x.4/.5/.6) through the existing lower_unary_method scalar/vector dispatch, which already fans a vector operand out per-lane. Extended tests/fixtures/target_stack_builtin_ops.c with probes for each op, falling back to library calls when \_\_has_builtin is false. SLATE_DIFF_FIXTURE=target_stack_builtin_ops differential test passes; full lowering profile, fmt, and clippy are clean. Not yet committed; awaiting user code review.
