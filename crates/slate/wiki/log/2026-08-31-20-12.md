# peel-casts: collapse redundant adjacent casts

_2026-08-31 20:12:11_

## Adds
slate-dx0m.3: PeelCasts NodeRule (engine/rules/peel_casts.rs, priority 45).
Folds an adjacent Expr::Cast pair when the outer cast is a no-op reinterpret.

## v1 rules
- duplicate: (e as T) as T -> e as T. Always safe.
- pointer chain: (e as A) as B where A,B are thin raw Ptr AND innermost e
  provably yields a pointer/integer -> e as B.

Motivating: printf/puts args (b"...".as_ptr() as *mut i8) as *const i8
  -> b"...".as_ptr() as *const i8.

## Key correctness guard (found via differential)
The innermost-operand check is load-bearing, not conservatism. nonnull/pointer
idiomization turns some params into Rust references (&T). For those,
(arg as *const T) as *mut T is NOT peelable: &T as *mut T does not compile --
the *const bridge is required. So yields_ptr_or_int() excludes bare Var/Ref/
AddrOf; only Cast-to-ptr/int, .as_ptr()/.as_mut_ptr(), ArrayPtr, and int/null
literals qualify. Broke goto_temp_cross_state/pointer_return_alias/
returns_nonnull before the guard; all green after.

## Explicitly NOT peeled (unsafe)
float intermediates ((x as f32) as f64 rounds), integer narrowing-then-widening
((x as u8) as u32), saturating float->int, thin<->fat ptr. Verified preserved in
casts.c ((_v1 as f32) as f64 kept; ((4 as u8) as i32) as i32 -> (4 as u8) as i32
only drops the duplicate i32).
