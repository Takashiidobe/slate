# structure_goto stage 3: natural loops from the dispatch graph

_2026-09-03 21:50:52_

slate-04q.85.5. structure_goto::acyclic became structure_goto::reducible: same
dominator-tree emission, now handling back edges. Back edge = an edge whose
target dominates its source; a graph is taken only if deleting those leaves a
DAG, so irreducible functions still fall through to the dispatch loop.

A loop header is emitted as `loop { .. }`; a back edge becomes `continue`, an
exit becomes `break`, both unlabeled when the target is the innermost enclosing
loop, and the loop's label is dropped entirely when nothing references it.

Rust's `loop` re-iterates when control falls off the end; wasm's exits. Ramsey's
scheme relies on the wasm reading, so a loop's follow nodes cannot simply be its
merge children — they must be hoisted out of the loop. Each labeled node
therefore carries an owner: normally its immediate dominator, but for a node
that leaves a loop it is the header of the outermost loop it escapes, and those
are emitted after the `loop` rather than inside it. The innermost follow needs
no label of its own: breaking the loop already lands on it.

A secondary exit is inlined at its branch instead of hoisted when it has one
predecessor and diverges. Hoisting a non-diverging one would only push its
successor back out of the loop again.

**Bug the gcc-torture corpus caught, worth remembering.** `within` peeled its
join list with `split_last`, which made the *latest* join innermost and emitted
its code first — so a break from an earlier join's subtree to a later join
referenced a label that was neither in scope nor yet opened (E0426 in pr15296
and arith-rand). The list is sorted latest-first, so the outermost must be
peeled from the front: `split_first`. `wrap`/`wrap_labeled` build outward from
the core instead and are correct with `split_last`. Every fixture passed with
the broken order because none had two joins under one owner where the earlier
one's code could still reach the later.

goto_backward_loop is now a bare `loop` with a tail break and no labels;
goto_multi_exit_loop is one loop with two exits; new goto_nested_loops.c and
goto_sibling_loops.c cover the nested and sibling cases the pre-f5460307
version could not express, both emitting no labels at all.
