# structure_goto stage 2: acyclic dispatch loops collapse to if/else

_2026-09-03 21:32:30_

slate-04q.85.4. New rule `structure_goto::acyclic` (priority 2, runs after
`normalize`) deletes the dispatch loop outright when the normalized state graph
has no back edges.

Algorithm is Ramsey's dominator-tree structuring minus the loop cases. Each arm
parses into a prefix plus one of four terminators (diverge / jump / two-way
branch / switch), read off the last one or two statements before the
`continue '__dispatch`. Then: reverse postorder (bailing on any back edge),
Cooper-Harvey-Kennedy dominators, and a recursive emit where a successor with
one predecessor is inlined and a join node is wrapped in a labeled block at its
immediate dominator, reached by `break '__joinN_k`. Every node is emitted
exactly once — no tail duplication, which is what broke the pre-f5460307
version.

The one ordering subtlety: a node's join children are emitted innermost-first,
so the list must be sorted in **reverse** topological order (largest reverse-
postorder rank first). Sorted the other way, a join's code lands outside a
labeled block that a later branch still needs to break to.

Results — goto_forward, goto_if_scope, goto_nested_if, goto_switch_forward and
goto_return_value now emit no `__state`, no dispatch loop and no match on a
state index; goto_nested_if reads exactly like its C source. label_elide
strips every join label in those five, so no labeled block survives.
goto_into_later_switch_case (goto into a later case inside `for(;;)`) keeps two
real labeled blocks, which is the right answer for that shape. Params spill
back too: classify() went from a `let mut n` prologue to `fn classify(mut n: i32)`.

Bails, as intended, on anything cyclic (goto_backward_loop, goto_multi_exit_loop,
goto_irreducible) and on computed goto.

Divergence has to be proven, not assumed: an arm with no state write that does
not actually diverge would fall to the bottom of the loop and re-enter the same
state, so `diverges` checks for return / std::process::exit / std::process::abort
/ unreachable!() / panic!(), recursing through if, match and unsafe. Anything
else bails. Same for a `break`/`continue` that would bind to the dispatch loop.

rewrites profile: 92/92, including gcc-torture, chibicc and c-testsuite.
