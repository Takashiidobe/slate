# Remove duplicate project F80 extern producer

_2026-08-30 19:32:46_

Fixed slate-a28e.23. The --lib --compile-commands path emitted F80 runtime declarations twice when a module both used long-double operations and shared a record containing long double.

Lowerer::finish already emits the per-module declarations required by actual F80 operations. The project-level add_shared_long_double_externs helper was an obsolete bootstrap workaround and blindly appended the same 52 declarations whenever shared_long_double was true. Removed that helper and its three call sites rather than deduplicating generated Rust after the fact.

Extended the c23_strfrom library fixture with an ABI-reachable shared long-double record plus arithmetic, generated lowering and rewrite FileCheck regions, and moved its harness onto a generated compile_commands.json. The test reproduced 52 E0428 errors before the fix and now compiles and runs.

Verified targeted lowering FileCheck, full rewrites 90/90, cargo clippy, cargo fmt, and real just transpile-chibicc plus check-chibicc. tokenize.rs now has exactly one __slate_f80_add declaration.
