# Linux libc header-matrix handoff

_2026-09-09 08:18:25_

Created the Linux header-matrix handoff concept for slate-b66b.14.2. It defines the eight real glibc/musl oracle profiles, manifests, generated probe locations, visibility-first closure rule, and required focused/full libc verification. It also records the exact libc, architecture, and feature gates introduced by 1e1b6b68 so later header work does not leak glibc-only APIs or transitive headers into musl profiles. Claimed the next alphabetical headers: cpio.h, crypt.h, dirent.h, dlfcn.h, and elf.h.
