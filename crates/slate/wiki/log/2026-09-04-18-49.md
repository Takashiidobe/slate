# Bionic O_* flag ABI fix; lconv NDK cross-check

_2026-09-04 18:49:46_

slate-sfzn.7.4 (filesystem/dirent ABI): the aarch64/arm arch-specific
O_DIRECTORY/O_NOFOLLOW/O_DIRECT/O_LARGEFILE/O_TMPFILE values in
bits/aarch64/fcntl.h and bits/arm/fcntl.h were dead on arrival -- the
top-level libc-shim/include/fcntl.h unconditionally redefined the same
macro names with x86_64/generic values right after including bits/fcntl.h,
so every arch silently got the wrong flag bits. Confirmed against the NDK
r27d aarch64 oracle: O_DIRECTORY there is 040000, not 0200000 (arm/aarch64
kernel UAPI swaps the flag bit assignments relative to the generic
asm-generic/fcntl.h layout used by x86).

Fix: moved the generic fallback block into a new bits/generic/fcntl.h
(dispatched from bits/fcntl.h's `#else`, matching the existing
bits/stat.h convention), completed bits/aarch64/fcntl.h and
bits/arm/fcntl.h with the arch-invariant O_SEARCH/O_EXEC/O_TTY_INIT/
O_ACCMODE/O_RDONLY/O_WRONLY/O_RDWR macros so each arch file is
self-contained, and removed the clobbering block from the top-level
header entirely. Updated tests/fixtures/bionic/filesystem_layout.c's
O_DIRECTORY static_assert to branch on __SLATE_ARCH_X86_64 like the
existing struct-stat asserts in the same fixture.

slate-sfzn.7.3 (stdio/locale ABI): cross-checked struct lconv field-by-field
against the real NDK r27d sysroot locale.h -- order and types match the
shim's existing non-Darwin/FreeBSD branch exactly, no changes needed. This
closes the last open acceptance item noted in 7.3.

Verified: cargo nextest --release --profile libc (36/36) and both
--profile lowering/rewrites --test differential (all fixtures, including
Bionic aarch64/x86_64 NDK oracle cross-compiles) pass. fmt/clippy clean.
