# Improve libc matrix result reporting

_2026-09-07 20:48:39_

Changed tools/libc-abi-matrix.py to capture probe output and report explicit PASS/FAIL results. ABI mismatches now print each differing record under the failing libc/architecture label, toolchain failures are labeled separately, and a summary reports passed and failed counts. Validated with the musl x86_64 mismatch path and identical-oracle comparison.
