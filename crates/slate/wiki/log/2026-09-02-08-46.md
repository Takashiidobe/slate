# structure_dispatch: two-pass relooper engine, stack overflow + irreducible-var fixes

_2026-09-02 08:46:32_

Implemented src/backend/engine/rules/structure_dispatch.rs (slate-04q.85):
schedule() condenses cyclic SCCs into a reverse-postorder Vec<Unit>
(Node/Loop/Irreducible); render_units/wrap_all recursively renders and wraps
every non-first unit in a fresh Stmt::LabeledBlock, relying on Rust letting
break/continue target any enclosing label (not just the innermost, unlike
wasm). Unifies goto's __dispatch loop and switch's __switch_case loop under
one Cfg/Flow/Transfer/parse_flow front end.

Fixed today, continuing from prior session:
- schedule()'s recursive call for a natural loop's own body re-detected the
  identical SCC forever (a loop's members still mutually reach each other
  when the universe is restricted to just themselves) -> stack overflow on
  goto_backward_loop/goto_multi_exit_loop. Fixed by threading an
  exclude_into: Option<usize> through sccs_within/schedule so the header's
  back-edge is hidden from cycle re-detection at the recursive level.
- Irreducible-SCC dispatch var (__dispatchN_vM) was assigned via resolve()
  but never declared with `let` -> E0425. Added declare_irreducible_vars()
  emitting `let mut var: i32 = 0;` for every distinct irreducible var before
  rendering.
- Irreducible dispatch match had no wildcard arm -> E0004 non-exhaustive
  match (rustc can't know the var only ever holds SCC-member values). Added
  a trailing `_ => unreachable!()` arm.
- asm-goto (`asm!(... label { state = N; continue 'loop; })`) embeds a
  control transfer inside an expression operand that parse_flow can't see
  or retarget once the loop is restructured away. Added
  stmt_contains_asm_target() to detect this (recursing through
  Unsafe/Scope/If/Match/For/Loop) and bail parse_flow -> plan_goto returns
  None, leaving the original correct-but-unstructured dispatch loop in place.

All 4 previously-failing fixtures (goto_backward_loop, goto_multi_exit_loop,
goto_irreducible, asm_goto_statement_expr) now pass. Full --profile rewrites
suite: 92/92 passing, fmt+clippy clean.

Remaining for slate-04q.85: new fixtures for nested/sibling natural loops and
multiple independent irreducible islands (not covered by ported fixtures);
docs/src/goto.md still describes the deleted algorithm and needs updating to
match this implementation. Per explicit user direction, exact @rewrite
FileCheck shape assertions were deprioritized in favor of correctness --
REWRITES-DAG lines are currently no-ops anyway (see
project_rewrites_filecheck_disabled memory).
