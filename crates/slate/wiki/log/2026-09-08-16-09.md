# generate shim type surface assertions

_2026-09-08 16:09:31_

Generated shim-only structural probes from oracle typedef, record, and enum descriptors. The probe emits typedef compatibility assertions, named-record field typeof assertions for non-bitfield simple fields, and enum type/value assertions where the AST provides values. The manual glibc fcntl.h run now exposes missing off64_t, incomplete flock64/stat records, and f_owner_ex/open_how field type mismatches. Record size/alignment/offset and bitfield layout remain pending an oracle layout collector.
