# rewrite engine v2: slice 3 (EarlyInlineTemps ported)

_2026-08-27 20:50:44_

Ported EarlyInlineTemps into src/backend/engine/rules/inline_temps.rs,
priority 3 (matches passes.md's ordering, before zero_init=5,
singleton_scopes=10-12). Registered in engine/rules/mod.rs.

Ported from `git show 366d9f8b~1:src/backend/query/rules/inline_temps.rs`'s
early()/Phase::Early only (late() out of scope). Purity/effects re-derived
as a small self-contained Effects struct -- src/backend/facts/ isn't wired
into the module tree post-nuke (dead code on disk), matching zero_init.rs's
precedent of local pure helpers. Dropped the ReadOnlyCall whitelist (all
`Call`s -> unknown_call): a no-op-or-superset under early() since ReadOnly
producers never satisfy any early() branch anyway. Dropped
is_allowed_argument_use entirely (dead under `phase==Early` in old code).

Found and fixed two real bugs (latent in old `is_movable_pure_expr` too,
likely never exercised): NullPtr/None and unsuffixed I64/I128/U128/Float
codegen as bare literals relying on their enclosing `let _vN: T = ...` for
type inference; merging/chaining them can delete the only surviving type
annotation (E0283 on c23_nullptr, silent i32-overflow panic on gcc-torture
20001031-1.c). Fix: `expr_is_type_anchored` + `is_top_level_use` gate -- a
non-anchored initializer only inlines when the single use is the entire
top-level value, not nested under Cast/Binary. Updated 9
tests/fixtures.cfg/*.c DIRECTIVES-DAG checks to accept the now-correct
`__retval = N;` inlined shape.

Validation: rewrites 110/110 (unchanged from baseline), lowering 10/10,
fmt/clippy clean. libexpat (21 TUs), 3 runs averaged ~11.35s vs the ~10.52s
baseline -- delta ~0.83s, well under the old engine's isolated 4.6s cost.
