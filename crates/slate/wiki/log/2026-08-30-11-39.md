# add function-signature FileCheck markers to update_filecheck

_2026-08-30 11:39:41_

Added file-scope `@lowering-fn-begin`/`@rewrite-fn-begin` (+ `-fn-end`) markers so
a fixture can assert a whole function including its signature — the plain in-body
markers inject `__asm__` sentinels that only compile inside a body.

Mechanism: fn markers instrument as sentinel *marker functions* around the target
(`void __slate_filecheck_begin_N(void){}`); unused globals/structs get DCE'd and
can't serve, but functions survive and preserve source order. extract_generated_
regions grew a FN_MARKER_PATTERN branch that brackets everything between the
marker functions (skipping their bodies). Inserting marker functions shifts the
global `argN` param counter, so `arg[0-9]+` is now genericized to `{{arg[0-9]+}}`
globally in render_check_pattern.

Also fixed the global strip-ai-comments.py hook, whose annotation whitelist
didn't include the `-fn-` infix and was deleting the new markers.

Regenerated the whole fixture suite via the tool (skips handwritten blocks):
284 regenerated, 153 skipped, goto_temp_cross_state refreshed at -O2. lowering +
rewrites profiles fully green. New fixture: fn_signature_filecheck.c.
