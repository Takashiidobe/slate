# Model macOS pthread and synchronization ABI

_2026-08-31 07:34:07_

Added Darwin-specific pthread opaque storage with macOS 11 sizes, alignments, scalar identifiers, initializer signatures, cancellation constants, and POSIX declarations.
Added Darwin sched.h and semaphore.h surfaces without Linux-only timed semaphore, mutex, rwlock, barrier, spinlock, robust, or cond-clock APIs.
Darwin threads.h now reports the target's __STDC_NO_THREADS__ contract instead of exposing unsupported C11 thread symbols.
Added standalone header manifests, SDK layout/signature/symbol probes, and the pthread_sync aarch64-apple-darwin lowering/rewrite fixture.
Generated Rust retains Darwin _opaque_pthread records and does not import host libc pthread types.
Validated focused lowering/rewrites, the release libc profile, cargo fmt, and release clippy; the SDK oracle skipped explicitly because SLATE_MACOS_SDK is unset.
