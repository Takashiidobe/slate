# Document libc oracle setup and target matrix

_2026-09-08 13:26:23_

Closed slate-b66b.6 by extending wiki/concepts/cross-target-toolchains.md
rather than writing a new doc, since the musl bootstrap / glibc sysroot /
QEMU material already lived there from .1 and .3.

Added:
- Runtime differential matrix section documenting
  tests/libc_runtime_matrix_suite.rs and its env vars
  (SLATE_LIBC_RUNTIME_LIBC/ARCH/FIXTURE, SLATE_MUSL_RUST_CC), added in .5.
- "Standards baseline vs. glibc oracle vs. musl oracle" section explaining
  the three-way distinction the epic description calls for: libc-shim is
  the standards baseline Slate compiles against; the glibc/musl oracles
  exist only to check that baseline, never to replace each other or the
  shim in translated output.
- Cache locations section: target/libc-abi-probe/, target/libc-runtime-matrix/,
  target/test-cache/, and $SLATE_MUSL_SYSROOT_ROOT, with which are safe to
  delete individually vs. force a full rebuild.
- Documented previously-undocumented env vars: SLATE_MUSL_AARCH64_LINKER,
  SLATE_LIBC_QEMU_<ARCH>, and the musl-clang -l-marker linking gotcha
  (already fixed in code by .3/.5, now written down so it isn't
  re-discovered).

Also added the doc to wiki/index.md, which had never listed it.
