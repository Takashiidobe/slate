# fix update_filecheck.py fn-scope name scan on #if defined(...)

_2026-09-05 13:41:40_

Closes slate-0q4o. c_function_definition_name(lines) joined every C line
between @rewrite-fn-begin/@rewrite-fn-end (including any #if/#elif/#else
guarding the definition) before searching for the first identifier
followed by "(". When the marker directly wraps a conditional like:

  #if defined(_WIN64)
  int win64_code(void) { return 64; }
  #else
  ...

"defined(" matched before "win64_code(", so extract_generated_regions
raised "generated Rust has no definition of fn defined". Fix: filter out
lines starting with "#" before joining, mirroring the existing
strip_attribute_groups step for __attribute__/__declspec.

Regenerated the 7 affected tests/fixtures.cfg/*.c files (arch_targets,
arm_endian_targets, ndebug, os_targets, pointer_width_targets,
unix_target, win64_target); all now carry correct REWRITES-X86_64-GNU/
AARCH64-GNU blocks. arch_targets and arm_endian_targets picked up real
new aarch64-specific assertions (128, 200) that were never checked
before. Also discovered (not fixed): no Rust test currently FileChecks
these REWRITES/COMMON-REWRITES blocks in fixtures.cfg - only the
DIRECTIVES prefix is exercised (directive_translate.rs), and a separate
"compiles for current host" smoke test uses translate-directives, not
plain translate. Content was verified by hand against each fixture's C
source instead.
