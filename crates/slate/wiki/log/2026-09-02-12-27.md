# Switch fallthrough recovery via arm-path folding

_2026-09-02 12:27:17_

`structure_dispatch` now recovers a plain Rust `match` from the switch
trampoline (`'__switchN: loop` + `__switch_caseN` state variable). Goto
recovery is split into a separate stub rule, `structure_goto`, so the two
never share a code path.

Key observation: `lower_switch` can only emit one shape, and its fallthrough
edges are the path `0 -> 1 -> ... -> N-1`, always in tail position, never
conditional, never cyclic. So there is no CFG to construct. The rule verifies
that shape and bails otherwise; it does not analyze a general graph.

Per arm the rule records patterns (from inverting the value dispatch), the
stripped body, and a terminator (Exit / FallsThrough / Diverges). Then:

- empty fallthrough arms fold into the successor's or-pattern (recovers `3 | 4`);
- surviving chains are tail-duplicated, gated at 24 duplicated statements;
- the default arm moves last (constants are disjoint, so a value's arm index
  does not depend on arm order) while keeping its source-order fallthrough
  chain, which covers default-first and default-in-the-middle switches, and
  `case 2: default:` where the shared label folds into the wildcard;
- a non-tail `break '__switchN` keeps the label as a `LabeledBlock` wrapper
  instead of forcing the trampoline to survive.

Shared-tail emission (c2rust's `'s_34: { match ...; tail }`) is deliberately
not implemented; over the gate the trampoline is left alone.

Added `Pattern::Or`, re-added `arena::insert_stmts` / `arena::reify_bodies`.
Follow-ups: slate-kkl7 (parent), and the duplicated-`_vN` collision that blocks
`inline_temps` on copied arms.
