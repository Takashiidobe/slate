# g3 backend memory correction

_2026-09-06 15:16:02_

Reduced g3 translation-job memory and swap cgroup limits from 3 GiB to 2 GiB after observing only about 3.9 GiB available while other resident services run. The 16 KiB public input ceiling remains deliberately below the known large-CIR cliff, and 2 GiB preserves host headroom while retaining a hard kill boundary.
