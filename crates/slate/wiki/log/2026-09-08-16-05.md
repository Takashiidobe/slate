# collect oracle typedef record and enum surfaces

_2026-09-08 16:05:18_

Added an AST-derived type-surface collector for public-header verification. It records typedef underlying types, complete named struct/union definitions with field types and bitfield widths, and named enum enumerators with resolved constant values where Clang exposes them. The collector writes oracle-types.json alongside the function and macro artifacts. A glibc fcntl.h integration test validates mode_t, struct flock fields, and enum __pid_type; the generated manifest contains 128 typedefs, 9 records, and one enum. This intentionally establishes the structural oracle before adding shim-side typedef/layout/enum compile-time checks.
