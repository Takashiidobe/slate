# Move signal macros into architecture bits headers

_2026-09-08 22:50:08_

Replaced the x86_64 signal-number and alternate-stack enum constants with preprocessor macros in bits/x86_64/signal.h. Removed the unconditional signal macro block from signal.h. This keeps signal ABI definitions in the architecture-specific implementation header and preserves the glibc and musl x86_64 declaration matrices.
