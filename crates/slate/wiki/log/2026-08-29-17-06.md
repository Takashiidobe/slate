# Normalize unstable FileCheck identifiers

_2026-08-29 17:06:55_

Added a generated-pattern normalization layer to tools/update_filecheck.py. Extended filecheck_annotation_regions.c for selective temp and string coverage and added filecheck_pattern_normalization.c for full-output anon_struct and temp coverage. Per user direction, removed the Python unit-test file and validated through differential fixtures.
