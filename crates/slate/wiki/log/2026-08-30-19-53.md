# Complete Linux ioctl shim surface

_2026-08-30 19:53:16_

Audited sys/ioctl.h and related termios declarations against ~/glibc and ~/standalone_musl while fixing slate-a28e.25. The audit found that the generic ioctl header was empty, x86-64 exposed only encoding macros, and bits/types.h never fulfilled __NEED_struct_winsize. Added the complete generic Linux terminal and file ioctl request set shared by all supported architectures, retained the ARM FIOQSIZE fixup, modeled the four-ushort winsize ABI, imported tty defaults for glibc, and exposed musl-only tcgetwinsize/tcsetwinsize through termios.h. The glibc unsigned-long and musl int ioctl request parameter types remain distinct. Direct header probes pass for glibc and musl across x86, x86-64, ARM, AArch64, RISC-V 32, and RISC-V 64. libuv transpiles completely; QuickJS passes its ioctl failures and now reaches the CIR atomic increment bug tracked by slate-a28e.29. The libc profile passes 19/19, and fmt plus Clippy pass. No tests were added.
