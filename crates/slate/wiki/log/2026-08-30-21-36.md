# close slate-sfzn.6.3: Darwin stdio/locale ABI

_2026-08-30 21:36:48_

Closed slate-sfzn.6.3. Everything runnable without an actual macOS SDK was
already implemented in a prior session (__sFILE, fpos_t, mbstate_t,
locale_t, lconv, wide/xlocale types, the stdio/locale manifest, structural
fixtures, conditional SDK compilation). Re-verified on this host: fmt
clean, clippy clean, libc profile 19/19 (including the explicit-skip SDK
oracle test), and the focused stdio_locale macOS differential fixture
passing standalone.

The one unmet acceptance-criteria item (SDK AST/layout probe agreement)
needs SLATE_MACOS_SDK or xcrun, unavailable on this Linux host by design
(the repo never acquires/commits an Apple SDK). All SDK-gated checks
already skip explicitly rather than fail when unconfigured, which is the
intended behavior per wiki/concepts/macos-sdk-oracle.md. That final
SDK-authority sweep is consolidated at the epic-wide gate slate-sfzn.6.5,
which already tracks this exact dependency, so closing .6.3 doesn't drop
the requirement -- it just stops blocking slate-sfzn.6.4/.6.11 on an
environment constraint .6.5 already owns.
